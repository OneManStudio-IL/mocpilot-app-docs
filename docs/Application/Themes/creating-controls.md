# Create controls from a theme

Every control you add starts from a theme. You can configure it before adding it, and save the configured control as your own design.

## Configure before adding

1. Open **Add Controller** (**+** on the dashboard, **+ Controller** on a computer).
2. Select a control type and a look in the looks strip.
3. In **Configure**, use the **Style** and **Settings** tabs: size (the palette shows it as "W x H dots"), accent colour, icon, theme options, behaviour.
4. Tap **Add to dashboard**.

## Save a design

When you find a combination you like (say, a red Racing button with a horn icon), keep it:

1. Select a configured control of a theme you own.
2. Tap **Save design**.
3. The design appears under **My designs** → **Saved designs**. You can add it to the dashboard of any profile in one tap.

**Delete** removes a saved design.

## Copy controls on the dashboard

- **Duplicate** copies a control with all its properties.
- **Duplicate (Type Only)** adds the same control type with default properties.
- **Change theme** switches a control to another theme you own without losing its place or program connections.

## A good dashboard

- Put the driving controls under your thumbs: a joystick or pedals on one side, steering on the other.
- Use the **L** size for the controls you use most and **S** for the rare ones.
- Use one accent colour per function: green for driving, yellow for lights, red for stop.
- Lock the controls when the layout is ready (**Lock all**).
- Add a battery monitor so you know when to recharge.

:::info Your own graphics
You can't draw completely new controls or themes in the app. Themes are made by the MOCPilot team; if you have an idea for a theme, tell us through **Help → Ask a question**.
:::
