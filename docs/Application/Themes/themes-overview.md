# What is a theme

A **theme** is a visual style for dashboard controls. Themes share the same control types (joystick, sliders, buttons, switches, step switches, monitors) and they all work the same way; only the look is different.

You can mix themes on one dashboard: each control has its own theme.

<Screenshot name="palette-looks" alt="The Add Controller palette with a joystick selected and its look in every theme in the looks strip" width={900} />

## Available themes

**Basic** is free and built into the app. It has the Joystick, Directional Pad, Slider, Ver. slider, Button, Switch, Step switch, Ver. step switch and Monitor.

Every **paid theme** has all the Basic controls plus the **Rotary knob**, **Battery level**, **Speedometer** and **Tilt monitor**, each drawn in the theme's own style. The paid themes are:

Aura, Brick Builder, Buggy, Building machinery, Circuit Core, City Car, Classic, Classic 4x4, Concept, Deep Space, Formula, Heavy Haul, Heavy Truck, Hi-Fi Audio, Hi-Tech, Hologram, Long Haul, Miami, Neo Orbit, Off-Road Cab, Off-roader, Racing, Rally, Retro, Rock Crawler, Sedan, Sunset, Supercar, Tactical and Workhorse.

New themes are added from time to time; they appear in the palette automatically.

Every paid theme also comes with ready-made **dashboard backgrounds** in the same style. See [Dashboard Settings](/docs/Application/Dashboard/DashboardOverview#dashboard-settings).

**Special controls** are separate products: the steering wheel, pedals, gear shifter, handbrake, turn signals and train controller. Most of them have a look for every paid theme. See [Special controls](/docs/Application/Dashboard/SpecialControls).

All paid themes and special controls are included in [MocPilot Pro](/docs/Application/Account/Pro).

## Theme options

Some themes have their own options on the control's **Style** tab:

- Racing: **Colored carbon**, **Colored bezels**, **Show race lines**;
- Building machinery: **Indicator segments count**;
- Aura: **Display values**.

## Change the theme of a control

Long-press (or right-click) a control → **Change theme**, or use **Change theme** in its properties. You can switch to any theme you own that has the same control type. The position, size and program connections stay the same.
