# Glossary

**AI builder**: Describe your model in words, and the AI sets up the hubs, the dashboard and the program of the profile. Part of MocPilot Pro. See [AI builder](/docs/Application/Profiles/AiBuilder).

**Block**: In Logic Blocks, one piece of the program: an event, a command, a condition or a value. Blocks snap together into stacks. See [Introducing Logic Blocks](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing).

**Catalog**: The online **Profile Catalog** with official profiles for LEGO® sets and profiles shared by the community. You can publish your own profiles there too. See [Catalog and publishing](/docs/Application/Profiles/Catalog).

**Connection code**: A QR code and 6 digits that the remote shows to link a hub device. Valid for 5 minutes. See [Remote control](/docs/Application/Profiles/RemoteControl).

**Control (controller)**: An element on the dashboard: a joystick, slider, button, switch, step switch, monitor or special control. A control only passes its values to the program. See [Control types](/docs/Application/Dashboard/ControlTypes).

**Dashboard**: The screen you drive from: a grid with your controls. Each profile has its own dashboard. See [Dashboard](/docs/Application/Dashboard/DashboardOverview).

**Hub**: The Bluetooth brick in your model that motors, lights and sensors plug into. See [Hubs](/docs/Application/Hubs/HubsOverview) and [Supported devices](/docs/Introducing/SupportedDevices).

**Hub device**: In remote control, the phone, tablet or computer next to the model. Its MOCPilot app connects the hubs and runs the profile. See [Remote control](/docs/Application/Profiles/RemoteControl).

**Input**: In Quick Links, the start of a row: where the value comes from, such as a dashboard control, the gamepad, the vehicle or a hub sensor. See [Inputs](/docs/Application/Links/Inputs).

**Joint**: In Quick Links, the place where two blocks of a row meet. Its shape shows which blocks fit, and while the program runs it shows the live value. See [Quick Links](/docs/Application/Links/LinksIntroducing).

**List**: In Logic Blocks, a variable that holds several values in order. See [Lists](/docs/Application/BlockBuilder/Blocks/Lists).

**Logic Blocks**: The program editor where you build the program from blocks: events, loops, conditions, variables and sensors. See [Introducing Logic Blocks](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing).

**Look**: One of the visual styles of a special control, for example a racing steering wheel. The look changes only the picture, not the values. See [Special controls](/docs/Application/Dashboard/SpecialControls#looks).

**MocPilot Pro**: The subscription that includes all paid themes, special controls and hub slots, plus the AI builder and remote control. See [MocPilot Pro and purchases](/docs/Application/Account/Pro).

**My Block**: A block you make yourself from other blocks, to reuse it in the program. See [My Blocks](/docs/Application/BlockBuilder/Blocks/MyBlocks).

**Operation**: In Quick Links, what the hub should do with the value: Motor, Servo, Light, Run for degrees and so on. See [Operations](/docs/Application/Links/Operations).

**Output**: In Quick Links, the end of a row: a hub with the ports to use, or a direct output such as an Indicator or the Hub LED. See [Quick Links](/docs/Application/Links/LinksIntroducing).

**Port**: A socket on a hub for a motor, light or sensor, marked with a letter or a number. See [Hubs and ports](/docs/Application/Links/HubsAndPorts).

**Processing**: In Quick Links, optional blocks in the middle of a row that change the value on the way: Invert, Dead zone, Smooth and others. See [Processing](/docs/Application/Links/Processing).

**Profile**: Everything about one model: its hubs, its dashboard and its program. See [Profiles](/docs/Application/Profiles/ProfilesOverview).

**Quick Links**: The no-code program editor: each row connects an input to a hub, *input → processing → operation → output*. See [Quick Links](/docs/Application/Links/LinksIntroducing).

**Remote**: In remote control, the device you control the model from: the MOCPilot app on another device, or the web editor. See [Remote control](/docs/Application/Profiles/RemoteControl).

**Row**: One line of a Quick Links program that connects one input to one output. See [Quick Links](/docs/Application/Links/LinksIntroducing).

**Simulator**: Turns the pedals, the gear shifter and the handbrake into a vehicle that drives like a real car, with inertia, braking and gears. See [Simulator](/docs/Application/BlockBuilder/Blocks/Simulator).

**Slot**: A place for one hub in a profile. A profile has 5 slots: 2 free and 3 that you can unlock. See [Hub slots](/docs/Application/Hubs/HubsOverview#hub-slots).

**Special control**: A control that looks and works like the real thing: steering wheel, pedals, gearbox, handbrake, turn signals and train controller. Each is a separate purchase. See [Special controls](/docs/Application/Dashboard/SpecialControls).

**Stack**: In Logic Blocks, a group of connected blocks that runs as one script from top to bottom, usually starting with an event. See [Block stack](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing#block-stack).

**Theme**: The visual style of the dashboard controls. The Basic theme is free; other themes are paid. See [Themes](/docs/Application/Themes/ThemesOverview).

**Variable**: In Logic Blocks, a named place where the program keeps a value, such as a speed or a counter. See [Variables](/docs/Application/BlockBuilder/Blocks/Variables).

**Vehicle**: The car that the Simulator builds from the pedals, gear shifter and handbrake. In Logic Blocks you create it in the Simulator category; in Quick Links it's the Vehicle input. See [Vehicles](/docs/Application/BlockBuilder/Blocks/Simulator#vehicles).

**Web editor**: MOCPilot in the browser on mocpilot.com, for editing profiles without installing the app. See [Web editor](/docs/Introducing/WebEditor).
