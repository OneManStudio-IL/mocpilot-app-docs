# MocPilot Pro 与购买 {#mocpilot-pro-and-purchases}

MOCPilot 可以免费使用：两种编辑器、所有集线器、基础主题以及每个配置文件 2 个集线器槽位。**MocPilot Pro** 会解锁其余所有内容，你也可以单独购买各个项目。

## 免费内容 {#whats-free}

- 逻辑积木和快速连接，以及所有受支持的集线器、电机和传感器；
- **基础**主题及其所有控件；
- 每个配置文件 2 个集线器槽位；
- 同步、目录、发布和网页编辑器。

## MocPilot Pro {#mocpilot-pro}

“MOCPilot 全部内容，适用于你的所有设备”：

- **全部免费**：无需单独购买任何东西。包含所有付费项目：主题、特殊控件和扩展，以及所有集线器槽位；
- **AI 助手**：描述你的模型，它就会在应用和网页编辑器中设置好集线器、仪表板和程序（参见 [AI 构建器](/docs/Application/Profiles/AiBuilder)）；
- **远程控制**：在另一台手机、平板或电脑上运行配置文件，并用你的设备或网页编辑器控制它（参见[远程控制](/docs/Application/Profiles/RemoteControl)）；
- **持续更新**：新的 Pro 功能一经发布即可使用。

### 方案 {#plans}

| 方案 | 价格 |
|---|---|
| 按月 | 每月 $4.99 |
| 按年（“最划算”） | 每年 $41.99 |

价格可能因国家/地区和应用商店而异。新订阅用户可享受 **7 天免费试用**。

MocPilot Pro 与你的 MOCPilot 账户关联，因此可在你的所有设备上使用；订阅前需要登录。无法在浏览器中订阅：请在 iPhone、iPad、Mac、Android 或 Windows 上的应用中订阅，Pro 在网页编辑器中同样有效。

打开 Pro 页面的方法：**账户 → 购买 → MocPilot Pro**，或平板侧边栏中的 **MocPilot Pro** 卡片。

### 管理或取消 {#manage-or-cancel}

Pro 页面上的**管理订阅**会打开你订阅时使用的应用商店（App Store、Google Play 或 Microsoft Store）。如果你是在其他平台上订阅的，请在那里管理订阅。除非你在当前周期结束前至少 24 小时取消，否则订阅会自动续订。

该页面会显示订阅状态：有效及续订日期、有效至某日期且已关闭自动续订、免费试用的结束时间，或需要在应用商店中解决的付款问题。

没有网络时，Pro 仍可继续使用一段时间；之后应用会显示“MocPilot Pro 需要联网验证”，直到重新联网。

## 购买 {#purchases}

单独购买的项目永久归你所有，即使没有 Pro 也是如此：

| 项目 | 你将获得 |
|---|---|
| 一个付费主题 | 该主题的所有控件 |
| 一个特殊控件：方向盘、踏板、变速箱、手刹、转向灯、列车控制器 | 该控件的所有样式 |
| 额外的集线器槽位（最多 3 个） | 每个配置文件中多一个集线器槽位 |

主题和控件可在仪表板的**添加控制器**面板中购买（[方法](/docs/Application/Themes/GettingThemes)），集线器槽位可在我的集线器中通过**解锁槽位**购买。

## 恢复购买 {#restore-purchases}

在新设备上或重新安装应用后，请使用同一账户登录，打开**账户 → 购买**并轻点**恢复**。Pro 页面上也有**恢复购买**。

在 Windows 上，你还可以在访客模式下、不使用 MOCPilot 账户恢复 Microsoft Store 购买项目；参见[恢复 Microsoft Store 购买项目](/docs/Application/Account/UserAccount#restore-microsoft-store-purchases)。

你可能会看到以下消息：

- **订阅已关联到其他账户**：此应用商店账户已为另一个 MOCPilot 账户开通了 MocPilot Pro。请使用那个账户登录。
- **没有可恢复的购买**：未找到此应用商店账户的有效订阅。
- **即将完成**：购买已完成，但无法连接服务器。应用联网后，Pro 会立即激活。
