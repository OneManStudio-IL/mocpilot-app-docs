# 设备间同步 {#sync-between-devices}

登录后，MOCPilot 会让你的配置文件和设置在每台设备上保持一致：手机、平板、电脑以及[网页编辑器](/docs/Introducing/WebEditor)。无需手动开启：只要使用账户，同步就始终开启。

## 工作原理 {#how-it-works}

- 更改会先保存在设备上，联网时再上传（“正在同步个人资料…”）。
- 其他设备联网时会下载新版本。
- 购买项目不会作为文件同步；它们属于你的账户，在你登录的任何地方都可使用。
- 在网站上添加的配置文件（目录中的**添加到我的账户**）或在网页编辑器中编辑的配置文件，都会通过同步到达。
- 在访客模式下不会同步任何内容：配置文件只保存在这台设备上。

## 冲突 {#conflicts}

如果同一个配置文件在两台设备同步之前都被修改过，则以你账户中的版本为准，这台设备上的版本会另存为副本（在名称后添加“(copy)”）。MOCPilot 会通过**个人资料同步**消息告诉你。如果你在这里修改过的配置文件在另一台设备上被删除了，也会这样处理。

如果你打开一个正在另一台设备上编辑的配置文件，可以选择**仅查看**（更改不会保存）或**接管编辑**。

## 离线使用 {#working-offline}

集线器、你的配置文件和已下载的主题都可以在没有网络时使用。

- 如果 MOCPilot 启动时无法连接服务器，会显示**无互联网连接**，以及**离线工作**和**重试**。
- 离线期间，顶部会显示**离线**标签。需要服务器的功能（目录和发布、AI 构建器、远程控制、通知、购买、客服消息）会提示你需要网络连接。
- 离线时所做的更改会在恢复连接后上传。应用重新连上服务器时，会显示**连接已恢复**以及**联网**。

## 退出登录 {#signing-out}

退出登录会从这台设备上移除你的配置文件和设置；它们仍保存在你的账户中，重新登录后就会回来。如果还有更改尚未上传，MOCPilot 会先提醒你并列出相关配置文件：请连接网络等待同步完成，或选择**仍然退出**（应用的 Backup 文件夹中会保留一份副本）。

## 提示 {#tips}

- 把配置文件发布到目录之前，请确保它已同步：目录会从你的账户中获取它。
- 要把配置文件转移到没有账户的设备上，请通过 `.dat` 文件使用**分享**和**导入配置文件…**。参见[管理配置文件](/docs/Application/Profiles/ManageProfiles)。
