# 账户 {#account}

MOCPilot 账户能让你的配置文件、设置和购买项目安全无虞，并在你的所有设备上可用。

## 为什么需要账户 {#why-have-an-account}

- 配置文件和设置会保存在服务器上，并在你的设备之间同步。
- 更换或丢失设备后，你可以找回所有内容。
- 购买项目和 MocPilot Pro 可在你的所有设备和网页编辑器中使用。
- 你可以把配置文件发布到目录，并接收通知。

## 登录 {#sign-in}

在登录界面输入你的**邮箱或登录名**和**密码**，或者使用**使用 Google 登录** / **通过 Apple 登录**。

<Screenshot name="sign-in" alt="MOCPilot 登录界面" width={900} />

**使用二维码登录**：用手机扫描二维码，并通过面容 ID 或指纹确认，即可在这台设备上登录。这需要手机上有通行密钥：只需在 mocpilot.com 的**账户 → 设置 → 通行密钥**中添加一次即可。

## 创建账户 {#create-an-account}

轻点**创建账户**：输入两次邮箱、一个用户名和密码（输入两次），并确认你的地区。也可以使用**使用 Google 注册** / **通过 Apple 注册**。通过激活邮件确认你的邮箱；账户验证之前，部分功能将保持禁用（如果没收到邮件，请轻点**重新发送激活邮件**）。

## 忘记密码 {#forgot-your-password}

轻点“忘记密码？”旁边的**重置**，输入你的邮箱，然后输入邮件中的验证码以设置新密码。

## 访客模式 {#guest-mode}

在登录界面选择**无需账户继续**，会打开一个简短的页面，列出账户能为你带来的好处。在那里再次轻点**无需账户继续**，即可立即开始使用应用。所有内容都只保存在这台设备上，删除应用或丢失设备后就会丢失。

你可以稍后再登录：在手机上，轻点**设置**顶部的**创建账户或登录**；在平板或电脑上，打开**账户**（访客模式下显示**登录**），它会显示同样的页面，其中有**创建账户**和**已经有账户了吗？**。

### 恢复 Microsoft Store 购买项目 {#restore-microsoft-store-purchases}

在 Windows 上，访客页面还有**恢复 Microsoft Store 购买项目**。Microsoft Store 购买项目属于你在 Windows 中使用的 Microsoft 账户，因此无需 MOCPilot 账户即可找回：点击该按钮（应用需要联网），应用会检查 Microsoft Store（**正在检查 Microsoft Store...**），并在这台电脑上解锁该 Microsoft 账户购买过的内容，包括 MocPilot Pro 订阅。

<Screenshot name="guest-mode-windows" alt="Windows 上带有“恢复 Microsoft Store 购买项目”的访客页面" width={900} />

## 地区 {#region}

如果你的账户是在 MOCPilot 要求填写地区之前创建的，应用会在每台设备上询问一次，时间是登录后几秒钟：**设置您的地区**。地区可以帮助应用提供合适的应用商店和价格。轻点**选择**可在**账户详情**中选择你的国家/地区，轻点**以后再说**则跳过。你可以随时在**账户详情**中更改地区。

## 账户页面 {#account-page}

手机：**设置 → 账户**。平板：侧边栏底部的你的账户。电脑：顶部栏中的**账户**按钮。

- **账户详情**：登录名、邮箱、地区和账户 ID（轻点某一项即可复制）。
- **购买**：参见 [MocPilot Pro 与购买](/docs/Application/Account/Pro#purchases)。
- **更改密码**。
- **登出**：参见[退出登录](/docs/Application/Account/Sync#signing-out)。
- **删除账户**。

## 删除账户 {#delete-your-account}

**删除账户**会永久删除你的账户数据：个人信息、偏好设置、历史记录以及保存在服务器上的配置文件。你还将无法再访问与该账户关联的任何已购买或已订阅的内容。此操作无法撤销。

输入你的当前密码，然后通过**滑动以删除账户**（触摸屏）或**删除账户**（电脑）进行确认。

有效的订阅由应用商店管理：请先在那里取消订阅，再删除账户。

## 通知 {#notifications}

**通知**（电脑上为铃铛图标；手机和平板上为**通知**标签页）会显示你所发布配置文件的审核结果、客服对你的请求的回复以及 MOCPilot 团队的新闻。你可以把它们标记为已读、选中并删除。通知需要账户。
