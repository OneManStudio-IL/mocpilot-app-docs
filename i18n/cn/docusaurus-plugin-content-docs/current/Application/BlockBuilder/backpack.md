# 背包 {#backpack}

**背包**用来存放积木程序的片段，以便在其他配置文件中重复使用：一段转向程序、一段灯光秀，或者一个你写过一次、想在所有地方使用的“我的模块”。在一个配置文件中把一组积木保存到背包，然后就可以把它插入到任何其他配置文件中，无论是在这台设备上，还是在你已登录的任何设备上。

背包是[逻辑积木](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing)编辑器的一部分。快速连接配置文件没有背包。

## 背包里存放什么 {#what-the-backpack-keeps}

背包中的每一项都是你所保存积木的**副本**：

- **积木堆**：你选中的积木，连同连接在它下方和嵌套在它内部的所有积木，与**复制**所复制的内容相同。
- **我的模块**：如果你保存的是某个[我的模块](/docs/Application/BlockBuilder/Blocks/MyBlocks)的 `定义 …` 积木，背包会保存完整的定义。这类项会标有**我的积木**。

每一项还会记住这些积木用到的“我的模块”（包括通过其他“我的模块”间接用到的），以及它们引用的变量、列表、消息、车辆和声音的名称，这样插入到别处后积木仍能正常工作。

插入的积木会成为配置文件程序中普通的一部分。配置文件中的任何内容都不依赖背包：删除或重命名某一项，不会改变你已插入它的程序。背包中的项无法直接编辑。要修改某一项，请先插入它，在程序中编辑积木，然后把它们作为新的一项再次保存到背包。

## 把积木保存到背包 {#save-blocks}

1. 在程序中右键点击一个积木（电脑），或长按它（手机、平板）。
2. 选择**添加到背包**。
3. 在**积木名称**中输入名称，然后轻点**保存**。

该积木以及连接在它上面的所有积木都会放进背包。要保存“我的模块”的定义，请打开它的 `定义 …` 积木的菜单。

## 打开背包 {#open}

- **电脑和网页编辑器**：编辑器顶栏中的**背包**按钮、菜单中的**视图 → 背包**，或 **Ctrl+Shift+B**（Mac 上为 **⌘⇧B**）。如果窗口较窄，该按钮位于**更多**菜单中。背包会以面板形式在编辑器右侧打开；如果[监视器](/docs/Application/BlockBuilder/Editor#monitor)也已打开，背包会显示在它旁边。
- **手机和平板**：编辑器顶栏中的**更多 → 背包**。背包会以面板形式覆盖在编辑器上方打开。

背包打开时，该按钮会高亮显示。再按一次即可关闭背包。

每一项都会显示它的图片、名称以及其中的积木数量（**积木: N**）。面板底部的提示会告诉你背包保存在哪里（见[下文](#where-it-is-kept)）。

## 把积木插入程序 {#insert}

- **轻点某一项**：它的积木会出现在程序的可见区域中。
- **把某一项拖到程序上**：积木会落在你松手的位置。请横向朝程序方向拖动；上下拖动会滚动列表。
- **项菜单（⋯）**：**插入**、**重命名…**或**删除**。

在手机和平板上，插入后背包会自动关闭，以便你看到这些积木。一次**撤销**即可移除插入的全部内容。

### 插入时会发生什么 {#what-happens}

- **我的模块**：如果配置文件中已有内容相同的“我的模块”，会直接复用它，因此再次插入相同的积木不会产生它的副本。如果配置文件中另一个不同的“我的模块”在内部使用了相同的名称，插入的模块会获得自己的一份。插入一个配置文件中已有的“我的模块”项不会有任何效果，并会显示**已存在**：请在**我的模块**中找到该积木。
- **变量、列表、消息和车辆**：如果配置文件中已有同名的项，积木会使用它；否则会新建一个。变量的值和列表的内容不会被复制。如果该名称已被其他东西占用，你会看到类似这样的提示：*无法创建变量“speed”: 名称已被使用*。
- **声音**：你自己的声音是配置文件中的文件，不会保存在背包中。如果配置文件中没有该名称的声音，你会看到*此配置中没有声音“…”: 请在积木中选择声音*。内置声音在任何地方都能使用。
- **集线器和仪表板积木**：用于本配置文件中没有的集线器、仪表板控件或游戏手柄的积木无法插入。在做出任何更改之前，应用会显示**部分积木无法插入**，列出这些积木以及将被略过的数量，并询问是否插入其余积木。如果想保留它们，请先添加相应的集线器或仪表板控件。如果所有积木都不适用于该配置文件，则不会插入任何内容。

## 重命名和删除 {#rename-delete}

打开项菜单（⋯）：

- **重命名…**：更改该项的名称。
- **删除**：确认后将其移除（**从背包中删除?**）。已插入它的程序会保留这些积木。

背包从不自动移除任何项：请自行删除不再需要的内容。

## 背包保存在哪里 {#where-it-is-kept}

- **未登录（访客）**：仅保存在这台设备上。面板会显示*保存在此设备上。登录后即可在所有设备上使用背包。*
- **已登录**：同时保存在你的账户中，因此你在所有设备上（包括[网页编辑器](/docs/Introducing/WebEditor)）都拥有同一个背包。面板会显示*保存在你的账户中:所有设备上都是同一个背包。*在一台设备上所做的更改会出现在其他设备上。
- **首次登录**：你在这台设备上以访客身份保存的项会转移到你的账户中。

离线时也可以使用背包。更改会保存在设备上，并在网络恢复后发送到你的账户（在此期间面板会显示**正在同步…**）。仍在从你的账户下载的项暂时无法插入：应用会提示**尚未就绪**，请稍后再试。

## 限制 {#limits}

| | 限制 |
|---|---|
| 背包中的项数 | 200 |
| 单项大小 | 约 512 KB（非常大的程序片段可能放不下：请保存较小的部分） |
| 项名称 | 最多 100 个字符 |

如果你账户中的背包已满，或某一项对它来说太大，该项将只保存在这台设备上，应用会提示你。由较新版本应用保存的项，只有在你更新应用后才能插入。

## 故障排除 {#troubleshooting}

| 提示 | 怎么办 |
|---|---|
| **背包已满(200 项)。请删除不需要的内容。** | 删除不再使用的项。 |
| **积木太多,无法放入背包。请保存较小的部分。** | 保存较小的积木堆，或把程序拆分成多个项。 |
| **部分积木无法插入** | 配置文件缺少这些积木所需的集线器、仪表板控件或游戏手柄。添加后再次插入，或只插入其余积木。 |
| **已存在** | 该“我的模块”已在此配置文件中：请在**我的模块**中查找。 |
| **尚未就绪** | 该项仍在从你的账户下载。请稍等片刻后再试。 |
| **这些积木由较新版本的应用保存。请更新应用后再使用。** | 在这台设备上更新 MOCPilot。 |
