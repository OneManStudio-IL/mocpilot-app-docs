# 在编辑器中工作 {#working-in-the-editor}

<Screenshot name="blocks-editor" alt="逻辑积木编辑器" width={900} />

## 积木面板和程序区 {#palette-and-program-area}

- 通过**视图 → 积木面板**（⌘P / Ctrl+P）显示或隐藏积木面板。
- 选择一个类别，把积木拖到程序区，放在另一个积木下方即可连接上去。预览会显示它将吸附的位置。
- 拖动顶部积木即可移动整个积木堆；从中间拖动某个积木，会把它连同下面的所有积木一起拿走。
- 要删除积木，把它们拖回积木面板即可。
- 变量、列表、消息和“我的模块”可以通过各自类别中的按钮创建（**创建变量**、**创建列表**、**添加消息**、**创建一个块**），也可以通过**编辑 → 新建变量… / 新建列表… / 新建消息… / 新建积木…**创建。声音和车辆也有各自的按钮：[声音](/docs/Application/BlockBuilder/Blocks/Sounds)中的**添加声音**和[模拟器](/docs/Application/BlockBuilder/Blocks/Simulator)中的**创建车辆**。

## 缩放和滚动 {#zoom-and-scroll}

- 双指捏合（在触摸屏上），或使用**视图 → 放大 / 缩小 / 实际大小**（⌘+ / ⌘− / ⌘0）。
- 拖动空白处即可移动画面。
- 空白处的上下文菜单包含 **Zoom +**、**缩小**、**重置缩放**和**删除 N 个块**。

## 积木菜单 {#block-menu}

长按（在触摸屏上）或右键点击积木：

- **编辑**：修改它的数值；
- **复制**；
- **删除块** / **删除 N 个块**；
- **关于该模块**：在本文档中打开该积木的说明；
- **将块导出为 SVG** / **将所有块导出为 SVG**：保存一张图片，用于教程或论坛帖子。

<Screenshot name="blocks-block-menu" alt="逻辑积木中某个积木的上下文菜单" width={900} />

与仪表板控件关联的积木，只有在解除与该控件的关联后才能删除。

## 撤销和重做 {#undo-and-redo}

使用**编辑 → 撤销 / 重做**（⌘Z / ⇧⌘Z、Ctrl+Z / Ctrl+Shift+Z）或浮动按钮。

- 一次拖动算一步；快速连续修改同一个数值会合并为一步。
- 即使程序正在运行，也可以撤销。
- 创建或删除变量、列表、消息或“我的模块”也算一步；撤销这类操作会停止正在运行的程序。
- 变量和列表中存储的值不会被撤销。
- 仪表板有自己独立的撤销历史。

## 监视器 {#monitor}

**监视器**（⇧⌘M / Ctrl+Shift+M）在程序运行时显示变量和列表的当前值。在电脑上，你可以在单独的窗口中打开它。查找错误时它非常有用。

<Screenshot name="blocks-monitor" alt="程序运行时显示变量和列表的监视器" width={900} />

## 编辑器设置 {#editor-settings}

- **点击积木启动**：点击某个积木即可运行它，方便单独测试；如果程序已停止，也会同时启动程序。
- **在中间打开程序**：打开配置文件时，程序以 100% 显示在画布中央（如果程序更大，则从左上角开始显示），无论你编辑时停留在哪里。此设置适用于此设备上的所有配置文件。
- **程序停止时停止集线器端口**：按下**停止**时，停止所有电机并关闭所有灯光。除非电机需要保持状态，否则请保持开启。
- **选择积木级别**：初学者、进阶或大师。

<Screenshot name="blocks-editor-settings" alt="逻辑积木中的编辑器设置面板" width={900} />

## 积木级别 {#block-levels}

| 级别 | 显示内容 |
|---|---|
| **初学者** | 最简单的积木；积木面板简洁，适合孩子和入门 |
| **进阶** | 常用的逻辑和设备积木 |
| **大师** | 全部积木 |

级别保存在配置文件中。降低级别后，程序中已有的积木仍然可以正常工作。

## AI 构建器 {#ai-builder}

使用 [MocPilot Pro](/docs/Application/Account/Pro) 时，**AI 构建器**（闪光图标按钮，⇧⌘I / Ctrl+Shift+I）可以根据你输入或说出的描述来设置集线器、仪表板和程序，然后按照你的要求修改配置文件。它适用于逻辑积木和快速连接配置文件。请参阅 [AI 构建器](/docs/Application/Profiles/AiBuilder)。

### 如何获得好的结果 {#ai-builder-tips}

说出集线器的名称，说明每个端口上连接了什么、它应该做什么，以及你想如何控制它。请参阅[写出好的请求](/docs/Application/Profiles/AiBuilder#ai-builder-tips)。

## 桌面菜单 {#desktop-menus}

| 菜单 | 菜单项 |
|---|---|
| 文件 | 关闭配置文件（⌘W） |
| 编辑 | 撤销、重做、新建变量…、新建列表…、新建消息…、新建积木… |
| 视图 | 积木面板、放大、缩小、实际大小 |
| 程序 | 运行（⌘R）、停止（⌘.） |
