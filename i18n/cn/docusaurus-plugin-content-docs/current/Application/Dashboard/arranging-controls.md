# 添加和排列控件 {#add-and-arrange-controls}

## 添加控件 {#add-a-control}

1. 在仪表板上轻点 **+**（**添加控制器**）；在电脑上，点击顶栏右侧的 **+ 控制器**。在电脑上，面板会在独立窗口中打开，其顶栏中间显示**添加控制器**。
2. 在列表中选择一种控件类型。类型分为以下几组：**操纵杆**、**滑块**、**按钮和开关**、**监视器**，然后是包含[特殊控件](/docs/Application/Dashboard/SpecialControls)的**车辆与特殊**，以及包含你所保存设计的**我的设计**。要快速找到某个控件，请在**搜索控件**中输入名称。
3. 外观条会显示所选类型在每个[主题](/docs/Application/Themes/ThemesOverview)中的样子（对于特殊控件，则显示它的所有外观）。轻点某个外观即可在大预览图中查看；你还可以直接在预览中试用。
4. 在**配置**中设置控件：**样式**和**设置**标签页以及大小。
5. 轻点**添加到仪表板**（在电脑上，是面板顶栏右侧的橙色按钮）。在电脑上，你可以连续添加多个控件。

<Screenshot name="controller-palette" alt="添加控制器面板" width={900} />

控件会放到第一个空闲区域，并带有**新**标记。如果没有空间，MOCPilot 会提示你：请腾出一些空间，或选择更小的尺寸。

对于你未拥有的主题中的控件，会显示**购买**和 **MocPilot Pro 全拥有**，而不是**添加到仪表板**。参见[获取、购买和更新主题](/docs/Application/Themes/GettingThemes)。

## 移动 {#move}

在编辑模式下，按住并拖动控件。松开后，它会吸附到最近的网格单元。如果它会与其他控件重叠，就会弹回原位。

## 大小 {#sizes}

每个控件都有三种大小：**S**、**M** 和 **L**。可在控件属性中的**大小**里更改。以网格单元表示的大小（宽 × 高）：

| 控件 | S | M | L |
|---|---|---|---|
| 操纵杆、方向键 | 7×7 | 10×10 | 13×13 |
| 滑块 | 10×3 | 14×4 | 18×5 |
| 垂直滑块 | 3×10 | 4×14 | 5×18 |
| 旋钮 | 6×6 | 8×8 | 10×10 |
| 按钮、开关 | 3×3 | 4×4 | 5×5 |
| 步进开关 | 8×3 | 12×4 | 16×5 |
| 垂直步进开关 | 3×8 | 4×12 | 5×16 |
| 监视器 | 4×2 | 6×2 | 8×3 |
| 电池电量、速度计 | 6×6 | 8×8 | 10×10 |
| 倾斜监视器 | 8×4 | 12×6 | 16×8 |
| 方向盘 | 8×8 | 12×12 | 16×16 |
| 踏板 | 11×8 | 16×12 | 21×16 |
| 手动变速箱、自动变速箱 | 8×8 | 10×10 | 12×12 |
| 手刹 | 4×7 | 6×10 | 8×13 |
| 转向灯 | 8×5 | 10×6 | 14×8 |
| 列车控制器 | 6×8 | 8×10 | 10×13 |

整个区域为 40 × 20 个单元。如果放不下更大的尺寸，请先移动相邻的控件。

## 选择和编辑 {#select-and-edit}

轻点（单击）控件即可选中它并打开它的**属性**。参见[控件属性](/docs/Application/Dashboard/ControlProperties)。

## 上下文菜单 {#context-menu}

长按（触摸屏）或右键单击（电脑）控件：

- **锁定** / **解锁**
- **属性**
- **更改主题**：把控件切换到你已拥有、且有相同控件类型的另一个主题
- **复制**：一份属性相同的副本
- **仅复制类型**：一个使用默认属性的同类型新控件
- **删除**

长按或右键单击区域中的空白处：

- **锁定所有** / **解锁所有**
- **删除 N 个控制器**：删除所有未锁定的控件

在电脑上，当属性面板打开时：**Esc** 关闭面板，**Delete** / **Backspace** 删除控件，**⌘D / Ctrl+D** 复制控件。

## 锁定控件 {#lock-controls}

**锁定**的控件无法移动或删除，这样在驾驶或编辑时就不会不小心把它碰乱。它会显示一个锁形图标。可以通过控件菜单或其设置中的**锁定控制器**锁定单个控件，也可以用**锁定所有**锁定全部控件。

## 控件名称 {#control-names}

每个控件都有一个简短的名称，在编辑模式下显示在其边框上，例如 **JOY1**、**SLDR2** 或 **BTN1**。程序通过这些名称引用控件：在快速连接中，输入积木上显示 *JOY1*；在逻辑积木中，你在积木的菜单里选择 *JOY1*。

## 删除 {#delete}

使用菜单中的**删除**或属性中的垃圾桶按钮。已锁定的控件无法删除。程序正在使用的控件无法删除，需先移除相关的行或积木。
