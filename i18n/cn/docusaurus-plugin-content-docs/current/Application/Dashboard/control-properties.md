# 控件属性 {#control-properties}

在编辑模式下，轻点（单击）控件即可打开它的属性。

- **手机和平板**：仪表板上方的一个面板；轻点面板外部即可关闭。
- **电脑**：一个侧边面板；面板打开时，你仍可以继续操作仪表板。

<Screenshot name="controller-properties" alt="控件属性面板，带有样式和设置标签页" width={900} />

标题栏显示控件的名称（例如 **JOY1**）、垃圾桶按钮、复制菜单和**确定**。

## 样式标签页 {#style-tab}

- **大小**：S、M 或 L。参见[大小](/docs/Application/Dashboard/ArrangingControls#sizes)。
- **重点颜色**：控件的主色。
- **图标**：控件上的图案（按钮、开关、监视器），可从 260 多个图标中选择。
- **外观**：[特殊控件](/docs/Application/Dashboard/SpecialControls)的外观，例如方向盘的样式。
- 主题选项，因主题而异：例如赛车主题中的**彩色碳**、**彩色边框**和**显示赛车线**，建筑机械主题中的**指示器段数**，光环主题中的**显示值**。
- **更改主题**：把控件切换到你已拥有、且有相同控件类型的另一个主题。

## 设置标签页 {#settings-tab}

通用设置：

- **锁定控制器**：锁定的控件无法移动或删除。
- **交互性**：非交互式控件不会响应按压。

各类型的设置：

| 控件 | 设置 |
|---|---|
| 操纵杆 | **轴类型**：两个方向 (X, Y)、仅水平 (X)、仅垂直 (Y) |
| 滑块、垂直滑块 | **归零**、**负值**、**步长** |
| 旋钮 | **定位档数（0 = 平滑）**（0–24）、**中心为零（-100..100）** |
| 步进开关、垂直步进开关 | **步骤计数**（1–100）、**负值**、**启用重置** |
| 监视器 | **文本布局**、**文本溢出**、**最大行数**、**滚动方向**、**滚动速度**、**显示滚动条**、**交互式滚动**、**文本对齐**、**文本缩放** |
| 倾斜监视器 | **反转俯仰**、**反转滚动** |
| 方向盘 | **方向盘角度**（20–120°）、**声音效果** |
| 踏板 | **声音效果** |
| 手动变速箱 | **挡位数**（2–6） |
| 自动变速箱 | **挡位数**（2–8） |
| 转向灯 | **转向灯输出闪烁**；样式标签页中的**图标：左**、**图标：灯**、**图标：右** |

数值设置都有一个**重置**按钮，可恢复默认值。

## 通过程序更改属性 {#change-properties-from-the-program}

在逻辑积木中，积木可以在程序运行时更改控件：设置它的颜色、开启或关闭交互性、在监视器上显示数值。参见[屏幕控制器积木](/docs/Application/BlockBuilder/Blocks/DashboardControllers)。
