# 控件类型 {#control-types}

每个[主题](/docs/Application/Themes/ThemesOverview)都会以自己的风格绘制同一套控件类型。免费的**基础**主题包含其中九种；每个付费主题还会额外提供**旋钮**和三种图形监视器。方向盘、踏板、换挡杆以及其他[特殊控件](/docs/Application/Dashboard/SpecialControls)是单独的产品。

| 控件 | 仪表板上的名称 | 传给程序的内容 | 适用范围 |
|---|---|---|---|
| 操纵杆 | JOY | X 轴和 Y 轴 | 所有主题 |
| 方向键 | DPAD | 上 / 下 / 左 / 右按钮 | 所有主题 |
| 滑块 | SLDR | 一个数值 | 所有主题 |
| 垂直滑块 | VSLDR | 一个数值 | 所有主题 |
| 旋钮 | DIAL | 一个数值 | 付费主题 |
| 按钮 | BTN | 按下 / 松开 | 所有主题 |
| 开关 | SWCH | 开 / 关 | 所有主题 |
| 步进开关 | STPR | 步数 | 所有主题 |
| 垂直步进开关 | VSTPR | 步数 | 所有主题 |
| 监视器 | MNTR | 显示文本或数值 | 所有主题 |
| 电池电量 | MNTBT | 显示电量 | 付费主题 |
| 速度计 | MNTSP | 显示速度 | 付费主题 |
| 倾斜监视器 | MNTLT | 显示俯仰和横滚 | 付费主题 |
| 方向盘、踏板、变速箱、手刹、转向灯、列车控制器 | STWHEEL、PDLS、GEAR、GEARA、HBRK、STALK、TRTHR | 参见[特殊控件](/docs/Application/Dashboard/SpecialControls) | 特殊产品 |

仪表板上的名称后面会加上编号：第一个操纵杆是 **JOY1**，第二个是 **JOY2**。

## 操纵杆 {#joystick}

一根会自动回中的摇杆。它提供 **X**（左/右）和 **Y**（上/下）两个数值；中心为零。

- **轴类型**：**两个方向 (X, Y)**、**仅水平 (X)** 或**仅垂直 (Y)**。如果只用于驱动或只用于转向，单轴操纵杆更好用。
- 典型用法：Y 轴用于驱动，X 轴用于转向；或者坦克的每条履带各用一个操纵杆。

## 方向键 {#directional-pad}

四个按钮：上、下、左、右。每个按钮只有按下或松开两种状态。在快速连接中，方向键的一个轴会输出 −1、0 或 +1（**上 / 下**或**左 / 右**），非常适合起重机吊钩这类逐步移动的动作。

## 滑块和垂直滑块 {#slider-and-ver-slider}

沿水平或垂直轨道移动的滑柄。

- **归零**：松手后滑柄会弹回（像油门一样），而不是停在你放开的位置（像火车的速度设定那样）。
- **负值**：零点位于中间，因此滑块会输出负值和正值（倒退和前进）。
- **步长**：滑块按步长移动。

## 旋钮 {#rotary-knob}

一个圆形旋钮，类似音量旋钮，位于每个付费主题的**滑块**分组中。用一根手指绕着中心转动它：它每个方向大约可转 135°，并停在你放开的位置。

- **定位档数（0 = 平滑）**（0–24）：设置档位后，旋钮会从一个档位咔哒跳到下一个档位。
- **中心为零（-100..100）**：旋钮输出 −100 到 100，零点在中间，而不是 0 到 100。
- 积木：*当旋钮 … 被转动 / 按下 / 松开 / 转到最小值 / 转到最大值*、*旋钮值 …*、*旋钮 … 是否被按下 / 处于最小值 / 处于最大值？* 参见[屏幕控制器](/docs/Application/BlockBuilder/Blocks/DashboardControllers#rotary-knob-blocks)。
- 在快速连接中，旋钮的作用与[滑块](/docs/Application/Links/Blocks/InputBlocks#controller-knob)相同。

基础主题没有旋钮。由于每个付费主题都有旋钮，**更改主题**可以把旋钮切换为另一个主题的外观。

## 按钮 {#button}

按住时为按下状态，松开时为松开状态。可用于喇叭或短暂的动作，也可以在快速连接中配合**切换**积木来开关某个部件。

## 开关 {#switch}

保持开或关的状态：轻点即可切换。可用于车灯、模式或绞盘锁止。

## 步进开关和垂直步进开关 {#step-switch-and-ver-step-switch}

一个 **−** / **+** 控件，用于计数步数，例如挡位或火车的速度档。

- **步骤计数**：1 到 100（默认 10）。
- **负值**：允许低于零的步数（倒车档）。
- **启用重置**：轻点数值即可将其归零。

## 监视器 {#monitor}

显示来自程序的文本或数字：速度、电量、模式名称、传感器数值。

- **文本布局**（单行或多行）、**文本溢出**（裁剪、换行、跑马灯、滚动）、**最大行数**、滚动选项、**文本对齐**和**文本缩放**。

## 电池电量、速度计、倾斜监视器 {#battery-level-speedometer-tilt-monitor}

付费主题中的图形指示器。它们的数值由程序设置：集线器的电量、电机的速度、集线器的倾斜。**倾斜监视器**有**反转俯仰**和**反转滚动**选项。参见[指示器和监视器](/docs/Application/Dashboard/Indicators)。

## 特殊控件 {#special-controls}

方向盘、踏板、手动或自动变速箱、手刹、转向灯拨杆和列车控制器。每种都是单独的产品，并提供多种外观。参见[特殊控件](/docs/Application/Dashboard/SpecialControls)。

## 交互性 {#interactivity}

每个可交互的控件都有**交互性**选项（默认开启）。非交互式控件不会响应触摸。程序可以开启或关闭交互性，例如在启动检查完成之前锁住油门。
