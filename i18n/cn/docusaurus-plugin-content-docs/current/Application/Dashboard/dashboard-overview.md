# 仪表板编辑器 {#dashboard-editor}

**仪表板**是你用来驾驶模型的界面：操纵杆、滑块、按钮、监视器及其他控件。每个配置文件都有一个仪表板。

用编辑器顶栏中的**仪表板**按钮打开它（电脑上为 ⌘2 / Ctrl+2）。在屏幕较窄的手机上，它位于**更多**中。

- **手机和平板**：仪表板在编辑器上方全屏打开。
- **电脑**：仪表板在独立的**仪表板**窗口中打开，你可以把它放在程序旁边。
- **网页编辑器**：一个可以拖动并调整大小的浮动面板。

<Screenshot name="dashboard-edit" alt="编辑模式下带点阵网格的仪表板" width={900} />

## 区域和网格 {#the-field-and-the-grid}

- 区域始终为 **2:1** 的比例并适应屏幕，因此仪表板在手机、平板和电脑上看起来都一样。
- 在编辑模式下，会显示 40 × 20 个单元的**点阵网格**。控件会吸附到网格上。
- 控件不能重叠。如果某个控件放不下，它会回到原来的位置。

## 顶栏 {#toolbar}

**手机和平板**

| 按钮 | 作用 |
|---|---|
| ← | 返回程序编辑器 |
| 撤销 / 重做 | 撤销和重做仪表板上的更改 |
| **选择** | 选择多个控件，一起锁定、解锁、删除或编辑它们；轻点**完成**结束 |
| ⚙（仪表板设置） | 背景和网格选项（见下文） |
| **+**（添加控制器，带橙色圆环） | 打开控制器面板；参见[添加和排列控件](/docs/Application/Dashboard/ArrangingControls) |
| ▶ / ■ | **运行** / **停止**：启动和停止程序 |

程序运行时，编辑按钮会隐藏。

**电脑和网页编辑器**

顶栏与编辑器的顶栏相似：

- **左侧**：**主页**（关闭配置文件）、**文件**、**编辑**和**视图**菜单，然后是**撤销**和**重做**。
- **中间**：配置文件名称和**积木**（快速连接配置文件中为**连接**，⌘1 / Ctrl+1），用于返回程序。仪表板本身在这里没有按钮：你当前就在这个页面上。
- **右侧**：**选择**、**仪表板设置**（⚙）和橙色的 **+ 控制器**按钮（添加控制器）。在窄窗口中，配置文件名称和**积木**按钮会隐藏，**+ 控制器**只保留 **+**。

在电脑上，仪表板的顶栏中没有**运行**：请在编辑器中运行和停止程序（⌘R / Ctrl+R，⌘. / Ctrl+.）。程序运行时，**选择**、**仪表板设置**和 **+ 控制器**不可用。

菜单：**文件**（关闭配置文件、在单独窗口中打开）、**编辑**（撤销、重做）和**视图**（积木 ⌘1、仪表板 ⌘2）。在单独的仪表板窗口中，顶栏显示窗口标题而不是**主页**，**文件**中有**关闭窗口**，并且没有**视图**菜单和**积木**按钮。

## 撤销和重做 {#undo-and-redo}

仪表板有自己的历史记录，与程序分开。你可以撤销每一次移动、调整大小、属性更改、添加和删除。

## 仪表板设置 {#dashboard-settings}

**背景图像**：轻点**更改**并选择：

- **选择预设**：主题自带的现成背景。图库会显示此仪表板上控件所属主题的背景。预设背景总会填满区域周围的屏幕，因此下面的选项对它不起作用。
- **上传自己的**：设备上的任意图片。它会保存在配置文件中。

**移除**会清除背景。

<Screenshot name="dashboard-backgrounds" alt="仪表板设置，显示预设背景图库" width={900} />

对于你自己的图片，还可以设置：

- **图像填充模式**：拉伸、保持纵横比适应、保持纵横比裁剪、平铺、垂直平铺、水平平铺或填充。
- **图像父级**：**工作区**（仅区域）或**整个屏幕**。
- **图像不透明度**、**启用图像模糊**和**模糊值**：让背景更柔和，使控件更醒目。

**隐藏点阵**：在配置文件运行时隐藏网格点。在编辑模式下，点阵仍然可见，方便你对齐控件。

## 控件和程序 {#controls-and-the-program}

控件提供数值；程序决定这些数值的用途。程序正在使用的控件无法删除，需等程序不再使用它。在快速连接中，请移除使用它的行；在逻辑积木中，请移除它的积木。
