# 指示器和监视器 {#indicators-and-monitors}

监视器会在你驾驶时在仪表板上显示信息：电池电量、速度、倾斜、与障碍物的距离、当前挡位或模式。

| 监视器 | 显示内容 | 主题 |
|---|---|---|
| **监视器** | 文本或数字 | 所有主题 |
| **电池电量** | 电量表 | 付费主题 |
| **速度计** | 速度表 | 付费主题 |
| **倾斜监视器** | 模型的俯仰和横滚 | 付费主题 |

监视器只用于显示信息，不能用来驾驶。显示什么由程序决定。

## 在快速连接中 {#in-quick-links}

使用**指示器**输出。这一行以指示器结尾，而不是集线器：

- *集线器*（电池）→ *指示器*（电池电量）：在电量表上显示集线器电量。
- *集线器*（电机速度，端口 A）→ *指示器*（速度计）。
- *集线器*（倾斜俯仰）→ *指示器*（倾斜监视器，Tilt X），再用第二行把倾斜横滚 → Tilt Y。
- *集线器*（电池电压）→ *指示器*（监视器）：显示带单位的数值，例如“7.85 V”。

指示器会按原样显示数值，因此这一行没有操作。参见[指示器](/docs/Application/Links/Blocks/OutputBlocks#dash-indicator)。

## 在逻辑积木中 {#in-logic-blocks}

使用屏幕控制器积木：

- 用*在 … 监视器上显示 …* 控制监视器；
- 用*将 … 监视器设为 …* 控制电池电量和速度计；
- 用*将 … 俯仰 / 横滚监视器设为 …* 控制倾斜监视器。

你可以显示任何能计算出来的内容：传感器数值、变量、像“2 挡”这样的文本。参见[屏幕控制器](/docs/Application/BlockBuilder/Blocks/DashboardControllers#monitor-blocks)。

## 提示 {#tips}

- 把电量监视器放在角落里，免得被手指挡住。
- 对于较长的消息，请使用多行监视器，并把溢出方式设为**跑马灯**或**滚动**。
- 程序可以更改大多数控件的颜色，例如在电量低时把按钮变成红色。
