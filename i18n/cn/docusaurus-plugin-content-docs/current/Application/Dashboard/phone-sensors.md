# 手机传感器 {#phone-sensors}

你的手机或平板配有运动传感器。MOCPilot 可以把它们用作输入：倾斜手机来转向，摇晃手机来触发某个动作，或在仪表板上显示手机的电量。

手机传感器可在**逻辑积木**中使用（**传感器**类别）。快速连接使用仪表板控件、游戏手柄和集线器传感器作为输入。

## 传感器积木 {#sensor-blocks}

| 积木 | 提供 |
|---|---|
| `设备倾斜`（俯仰、横滚） | 设备的倾斜角度，单位为度 |
| `设备加速度`（x、y、z） | 设备的加速度，单位为 m/s² |
| `设备加速度计`（x、y、z） | 加速度计原始数值，单位为 m/s² |
| `设备 % 电池` | 设备的电池电量 |

详情：[传感器](/docs/Application/BlockBuilder/Blocks/Sensors)。

## 示例：倾斜手机来转向 {#example-steer-by-tilting-the-phone}

```text
当程序启动时
永远重复
    转到位置  (集线器 1，端口 B)  ←  设备倾斜 (横滚) × 2
```

转向请使用带绝对位置的电机（角度电机）。

像握方向盘一样横向握住手机。用*介于*或*最小/最大*运算符限制数值，以免转向撞到限位。

## 提示 {#tips}

- 锁定设备的屏幕旋转，否则倾斜时系统可能会旋转屏幕。
- 电脑没有运动传感器；在电脑上这些积木的输出为零。
- 要在仪表板上显示倾斜，请把角度发送到**倾斜监视器**（付费主题）。参见[指示器和监视器](/docs/Application/Dashboard/Indicators)。
- 集线器也有自己的倾斜传感器：请参见集线器传感器积木以及快速连接中的**集线器**输入。
