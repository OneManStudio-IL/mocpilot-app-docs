# 特殊控件 {#special-controls}

特殊控件的外观和操作都像真实部件：方向盘、踏板、换挡杆、手刹、转向灯拨杆、分动箱和机车控制器。每种都是单独的产品：你可以只购买需要的，也可以通过 [MocPilot Pro](/docs/Application/Account/Pro) 获得全部。

<Screenshot name="special-controls-dashboard" alt="带有方向盘、踏板、换挡杆、手刹、转向灯和列车控制器的仪表板" width={900} />

| 控件 | 产品 | 仪表板上的名称 | 传给程序的内容 |
|---|---|---|---|
| [方向盘](#steering-wheel) | 方向盘 | STWHEEL | 转向角度、喇叭 |
| [踏板](#pedals) | 踏板 | PDLS | 油门和刹车 |
| [手动变速箱](#gear-shifter) | 换挡杆 | GEAR | 挡位：R、N、1…6 |
| [自动变速箱](#gear-shifter) | 换挡杆 | GEARA | 选挡器：P、R、N、D |
| [手刹](#handbrake) | 手刹 | HBRK | 力度、是否拉起 |
| [转向灯](#turn-signals) | 转向灯 | STALK | 左转向灯、右转向灯、灯光 |
| [分动箱](#transfer-case) | 分动箱 | XFER | 驱动模式：2H、4H、N、4L；差速锁 |
| [列车控制器](#train-controller) | 列车控制器 | TRTHR | 功率档位、方向、牵引力 |

**旋钮**不是单独的产品：每个付费主题都自带旋钮。参见[控件类型](/docs/Application/Dashboard/ControlTypes#rotary-knob)。

## 添加特殊控件 {#add-a-special-control}

1. 打开仪表板，轻点 **+**（**添加控制器**；在电脑上为 **+ 控制器**）。
2. 在控件类型列表中，滚动到**车辆与特殊**并选择一个控件。
3. 外观条会显示它的所有外观。选择一个，然后在**配置**中设置控件。
4. 轻点**添加到仪表板**。对于尚未拥有的控件，请轻点**购买**或 **MocPilot Pro 全拥有**。

<Screenshot name="special-control-looks" alt="添加控制器面板，已选中方向盘，外观条中显示它的各种外观" width={900} />

## 外观 {#looks}

每种特殊控件都有多种**外观**。其中大多数与某个付费主题相对应（赛车、光环、经典、全息等），因此方向盘、换挡杆和手刹可以与仪表板的其他部分风格一致。你可以随时更改外观：选中控件，在**样式**标签页的**外观**中选择另一种。外观只改变图案：数值、积木和程序都保持不变。

有些外观在选择时还会把重点颜色设为与之相配的颜色。

## 所有特殊控件的通用设置 {#settings-of-all-special-controls}

- **外观**（样式标签页）：见上文。
- **重点颜色**（样式标签页）：换挡杆、手刹、转向灯、分动箱和列车控制器。
- **锁定控制器**和**交互性**（设置标签页），与所有控件相同。参见[控件属性](/docs/Application/Dashboard/ControlProperties)。

## 方向盘 {#steering-wheel}

把手指放在方向盘上，绕着中心转动它。松手后，它会自动回中。按下方向盘中央即可鸣笛：这不会转动方向盘。

**设置**

- **方向盘角度**（20–120°，默认 60°）：转到底需要转动方向盘的角度。它不会改变程序得到的数值。
- **声音效果**：喇叭声以及程序通过方向盘播放的声音。需要打开应用声音。

**数值**：转向角度，从 −100（向左打满）经 0 到 100（向右打满）；按住喇叭时为 100，否则为 0。

**外观**：越野车、重型卡车、超级跑车、复古木质、赛车方向盘、拉力麂皮、越野实用、概念光效、重型卡车（Big rig）、家用轿车、城市小车、沙滩车、经典四驱、建筑机械、高保真音频、光环、积木、电路核心、深空、重型牵引、新轨道、越野驾驶室、赛车、攀岩车、战术、经典、日落、迈阿密、高科技、全息。

供程序使用的**声音**：轿车喇叭、卡车喇叭、跑车喇叭。

**快速连接**：[方向盘](/docs/Application/Links/Blocks/InputBlocks#controller-wheel)输入，通道为**转向角度**和**喇叭**。

## 踏板 {#pedals}

刹车踏板在左边，油门踏板在右边。用手指按压踏板：手指在踏板上的位置越高，踩得越深。靠近底部时为轻踩；靠近顶部时为踩到底。松手后踏板会弹回。你可以同时按压两个踏板。

**设置**：**声音效果**：允许程序播放踏板声音。需要打开应用声音。

**数值**：油门和刹车，各为 0 到 100。

**外观**：越野车、重型卡车、超级跑车、复古镀铬、碳纤维红、赛车打孔、越野防滑、概念光效、重型卡车（Big rig）、家用轿车、城市小车、沙滩车、经典四驱、建筑机械、高保真音频、光环、积木、电路核心、深空、重型牵引、新轨道、越野驾驶室、赛车、攀岩车、战术、经典、日落、迈阿密、高科技、全息。

供程序使用的**声音**：轿车刹车、跑车刹车、卡车气刹、倒车提示音。

**快速连接**：[踏板](/docs/Application/Links/Blocks/InputBlocks#controller-pedals)输入，通道为**油门踏板**和**刹车踏板**。

:::tip 光有踏板还不能变成一辆车
踏板只提供每个踏板被踩下的程度。如果某一行把油门直接送到电机，电机就会完全按照踏板踩下的程度运转。要让模型逐渐加速、滑行、刹车和倒车，请使用[车辆模拟器](#vehicle-simulator)。
:::

## 换挡杆 {#gear-shifter}

**换挡杆**产品包含两个控件：**手动变速箱**和**自动变速箱**。

### 手动变速箱 {#manual-gearbox}

一个带倒挡和最多六个前进挡的 H 形挡位槽。沿中间一行拖动挡把，再向上或向下拨入某个挡位。松手后，挡把会卡入最近的挡位或回到空挡。

- **挡位数**（2–6，默认 6，设置标签页）：挡位槽会随之变化。倒挡始终在最左列，空挡在中间。
- **数值**：−1 = 倒挡（R），0 = 空挡（N），1…6 = 前进挡。

### 自动变速箱 {#automatic-gearbox}

一个有四个位置的选挡器：**P**（驻车）、**R**（倒挡）、**N**（空挡）和 **D**（前进挡）。操作方式取决于外观：

| 选挡器 | 使用方法 | 外观 |
|---|---|---|
| 拨杆 | 沿着槽滑动手柄；它会停在最近的位置 | 高科技 |
| 旋钮 | 用手指转动旋钮；它会咔哒卡入 P、R、N 或 D | 经典、深空、战术、建筑机械、高保真音频、光环、电路核心、攀岩车、越野驾驶室、新轨道、越野车、越野工作车、概念车、轿车、城市小车、经典四驱 |
| 按钮 | 轻点 P、R、N 或 D | 赛车、重型牵引、积木、重型卡车、复古、拉力赛、超级跑车、方程式、长途卡车、沙滩车、日落、迈阿密、全息 |

- **挡位数**（2–8，默认 6，设置标签页）：[车辆模拟器](#vehicle-simulator)在 D 挡时换挡经过的挡位数。模拟器选择挡位后，选挡器会显示该挡位，例如 **D3**。
- **数值**：−2 = P，−1 = R，0 = N，1 = D。三种选挡器输出的数值相同，因此程序适用于任何外观。

两种变速箱的外观相同：经典、赛车、深空、战术、重型牵引、建筑机械、高保真音频、光环、电路核心、攀岩车、越野驾驶室、积木、新轨道、重型卡车、复古、拉力赛、越野车、超级跑车、方程式、越野工作车、概念车、长途卡车、轿车、城市小车、沙滩车、日落、经典四驱、迈阿密、高科技、全息。

**快速连接**：[换挡杆](/docs/Application/Links/Blocks/InputBlocks#controller-gear)输入，通道为**挡位**（手动：相对于挡位数的挡位，倒挡为负；自动：方向）和**方向（R − / 前进 +）**：倒挡为 −1，空挡和驻车为 0，任意前进挡为 +1。

## 手刹 {#handbrake}

一根手刹拉杆。握住拉杆的手柄并向下拉。制动力取决于拉动的幅度。松手后拉杆会弹回。

要**拉紧锁定**，请把拉杆拉到底，然后沿拉杆向其根部滑动手指：手柄会向下滑动，拉杆保持锁定。要**松开**已锁定的拉杆，请轻点控件或把拉杆拖回。

**数值**：0 到 100 的力度，以及拉杆是否已锁定。

**外观**：经典、拉力赛、重型卡车、复古、深空、战术、光环、重型牵引、建筑机械、高保真音频、新轨道、越野驾驶室、赛车、积木、电路核心、攀岩车、越野车、超级跑车、方程式、越野工作车、概念车、长途卡车、轿车、城市小车、沙滩车、日落、经典四驱、迈阿密、高科技、全息。

**快速连接**：[手刹](/docs/Application/Links/Blocks/InputBlocks#controller-handbrake)输入，通道为**手刹已拉起**（开/关，类似开关）和**手刹力度**。

## 转向灯 {#turn-signals}

一个带灯光开关的转向灯拨杆。

- 把拨杆**向上**拨为左转向灯，**向下**拨为右转向灯。它会停在你放开的位置；把它拨回中间即可关闭转向灯。
- **轻点**拨杆或大灯按钮即可开关灯光。这不会移动拨杆。

**设置**

- **图标：左**、**图标：灯**、**图标：右**（样式标签页）：指示灯的图标。
- **转向灯输出闪烁**（设置标签页，默认开启）：转向灯输出会与拨杆上的指示灯一起闪烁，因此接在这些输出上的灯会自动闪烁。关闭后，转向灯开启期间输出会保持常亮。积木始终获取的是常亮状态。

**数值**：左转向灯、右转向灯和灯光，各为开或关。

**外观**：经典、赛车、深空、战术、重型牵引、建筑机械、高保真音频、光环、电路核心、攀岩车、越野驾驶室、积木、新轨道、重型卡车、复古、拉力赛、越野车、超级跑车、方程式、越野工作车、概念车、长途卡车、轿车、城市小车、沙滩车、日落、经典四驱、迈阿密、高科技、全息。

**快速连接**：[转向灯](/docs/Application/Links/Blocks/InputBlocks#controller-turnsignals)输入，通道为**转向灯（左 − / 右 +）**（同一端口上两盏极性相反的灯）、**左转向灯**、**右转向灯**和**灯光**。

## 分动箱 {#transfer-case}

越野车的分动箱决定发动机驱动哪些车轮。这个控件有一个四个位置的选择器，以及差速锁开关：

| 位置 | 含义 |
|---|---|
| **2H** | 两轮驱动：只驱动后轮，适合普通道路 |
| **4H** | 四轮驱动：驱动所有车轮，适合泥地、沙地和雪地 |
| **N** | 空挡：发动机与车轮断开 |
| **4L** | 带**低速挡**的四轮驱动：速度慢、力量大，适合陡坡和攀岩 |

**差速锁**让同一车桥上的车轮（**前**、**后**）或前后两根车桥（**中央**）一起转动，这样失去抓地力的车轮就不会只是空转。

<Screenshot name="transfer-case-dashboard" alt="仪表板上的分动箱控件：选择器、差速锁开关和显示屏" width={700} />

### 使用方法 {#transfer-case-use}

- **选择器**：位置从上到下依次为 2H、4H、N、4L。根据外观不同，它是一个**滑块**（槽中带棱纹的滑钮：沿槽滑动；松手后会吸附到最近的位置）或一个**旋钮**（转动它，会在各位置咔嗒定位）。槽是直的，因此和真实的拨杆式分动箱一样，从 4H 到 4L 必须经过 N。
- **差速锁**：一排开关，分别对应前、中央和后差速锁：根据外观不同，是带指示灯的拨动开关，或是圆环以重点颜色亮起的自锁按钮。轻点开关接合差速锁，再点一次即可松开。
- **显示屏**：选择器旁的 2H、4H、N、4L 标签保持不变；显示屏用重点颜色显示所选位置和已接合的差速锁（**F**、**C**、**R**）。

### 设置 {#transfer-case-settings}

在**设置**标签页中：

- **空挡位置 (N)**（默认开启）：关闭后，选择器只有 2H、4H 和 4L。
- **前差速锁**（开）、**中央差速锁**（关）、**后差速锁**（开）：控件显示哪些差速锁开关。少于三个时，它们会移到这一排的中间。
- **前、中差速锁仅在四驱时可用**（开）：和真实汽车一样，前差速锁和中央差速锁只在 4H 和 4L 下有效。在 2H 下轻点它们会被拒绝（开关闪红色），换入 2H 时它们会松开。N 会保持它们原来的状态。后差速锁在任何位置都可用。

### 数值 {#transfer-case-values}

- **位置**：0 = 2H，1 = 4H，2 = N，3 = 4L。
- **四轮驱动**：在 4H 和 4L 下为开。**低速挡**：在 4L 下为开。
- 每个差速锁：开或关。

**外观**：每个主题都有一个以其命名的外观：经典、经典四驱、越野车，以及每个付费主题各一个。有些外观是滑块，有些是旋钮。**全息**把整个控件画成重点颜色的单色轮廓。

**快速连接**：[分动箱](/docs/Application/Links/Blocks/InputBlocks#controller-transfercase)输入，通道为**四轮驱动**、**低速挡**、**前差速锁**、**中央差速锁**和**后差速锁**（各为开/关，类似开关）。[车辆](/docs/Application/Links/Blocks/InputBlocks#src-vehicle)输入通过其**分动箱**设置获取整个分动箱。

## 列车控制器 {#train-controller}

一个带调速手柄和换向手柄的机车主控制器。

- **调速手柄**：向上或向下拖动手柄。它有 8 个功率档位（0–8），并停在你放开的档位上。
- **换向手柄**：把它的旋钮向上拖为**向前**，向下拖为**倒车**；中间为**空挡**。旋钮会在各位置之间跳动，从不停在中间。与真实驾驶室一样，只有调速手柄处于 0 时它才能移动。

**数值**：功率档位（0–8）、换向手柄（1 = 向前，0 = 空挡，−1 = 倒车）以及**牵引力**：档位 ÷ 8 × 100，并带上方向的正负号，范围为 −100 到 100。牵引力可以直接驱动火车电机。

**外观**：原版、建筑机械、高保真音频、光环、积木、沙滩车、电路核心、城市小车、经典、概念车、深空、越野车、重型牵引、经典四驱、重型卡车、迈阿密、新轨道、超级跑车、越野工作车、越野驾驶室、赛车、拉力赛、攀岩车、轿车、日落、战术、长途卡车、复古、方程式、高科技、全息。

**快速连接**：[滑块](/docs/Application/Links/Blocks/InputBlocks#controller-train)输入；它提供牵引力。

## 积木 {#blocks}

每种特殊控件都会在逻辑积木的**屏幕控制器**类别中添加自己的积木：

| 控件 | 事件 | 数值 |
|---|---|---|
| 方向盘 | *当方向盘 … 被转动 / 按下 / 松开* | *方向盘 …*、*方向盘 … 是否被按下 / 松开？* |
| 踏板 | *当踏板 … 任意 / 刹车 / 油门被移动 / 按下 / 松开* | *踏板 … 油门 / 刹车*、*踏板 … 是否被按下 / 松开？* |
| 变速箱 | *当变速箱 … 换挡 / 升挡 / 降挡 / 换入空挡 / 倒挡 / 驻车挡* | *挡位 …*、*变速箱 … 是否处于空挡 / 倒挡 / 前进挡 / 驻车挡？*、*… 的挡位数* |
| 手刹 | *当手刹 … 被拉动 / 锁定 / 解锁 / 松开* | *手刹力度 …*、*手刹 … 是否已锁定 / 已解锁 / 被拉动？* |
| 转向灯 | *当转向灯 … 左转向灯 / 右转向灯 / 灯光打开 / 关闭* | *转向灯 … 左转向灯 / 右转向灯 / 灯光已打开？* |
| 分动箱 | *当分动箱 … 2H / 4H / N / 4L / 四轮驱动 / 低速挡 / 前差速锁 / 中央差速锁 / 后差速锁接合 / 断开* | *分动箱 … [同上] 已接合？*、*分动箱挡位 …* |
| 列车控制器 | *当列车控制器 … 档位改变 / 档位提高 / 档位降低、回到零位、换向手柄移动、手柄松开* | *列车控制器 … 牵引力 / 档位 / 换向手柄*、*列车控制器 … 是否向前 / 倒车 / 空挡 / 在零位？* |

方向盘和踏板还有*… 的声音 …* 积木：它会从它们的声音中选择一个，供**声音**积木使用。详情：[屏幕控制器](/docs/Application/BlockBuilder/Blocks/DashboardControllers)。

## 车辆模拟器 {#vehicle-simulator}

特殊控件只提供原始输入。**车辆模拟器**会把踏板、换挡杆和手刹变成一个像汽车一样行驶的模型：它会带着惯性加速、滑行、刹车、倒车，在 D 挡自动换挡，并能用手刹停住。

- **快速连接**：使用[车辆](/docs/Application/Links/Blocks/InputBlocks#src-vehicle)输入。从仪表板中选择**踏板**、**换挡杆**、**手刹**和**分动箱**，再选择**车辆类型**（轿车、越野车、跑车、卡车）和**输出**：**速度**、**发动机转速（rpm）**、**制动中**或**拉着手刹**。
- **逻辑积木**：当仪表板上有踏板、换挡杆或手刹时，会出现**模拟器**类别。在其中创建一辆车（**创建车辆**），并把*驾驶*积木放在某个事件下面。把数值插入它的插槽：*油门*、*刹车*、*挡位*、*共*（挡位数；*… 的挡位数*积木正好适用）、*手刹*、*锁定*和*分动箱*（*分动箱挡位 …*积木正好适用；如果模型没有分动箱，就留空）。其他模拟器积木可以设置车辆类型、发动机惯性和倒车速度，读取速度、发动机转速和挡位，并在车辆起步、停车、刹车或换挡时做出响应。

模拟器的行驶方式：

- **油门**让模型带着惯性加速；松开后模型会滑行。**刹车**让它减速。
- **没有变速箱时**，在模型停下后继续踩住刹车，模型就会倒车。
- **手动变速箱**：R 倒车，N 不行驶。还可以让每个挡位限制最高速度。
- **自动变速箱**：R 倒车，N 不行驶，P 像锁定的手刹一样让模型停住。在 D 挡时，模拟器会自动升降挡，并在选挡器上显示挡位。
- **手刹**：它的力度会叠加到制动力上；锁定的手刹可以让模型停住。
- **分动箱**：2H 和 4H 的行驶方式与没有分动箱时相同。**N** 不行驶：模型会滑行，刹车只会让它减速而不会倒车。**4L** 把前进和倒车的速度都限制在 40 %，发动机转速相应升高；如果换入 4L 时模型速度更快，它会减速到限制速度。差速锁不会改变模拟器的行驶方式：它们只是控件的输出。
- **车辆类型**：卡车更重（惯性更大）并有气刹；跑车反应更快，倒车也更快。

程序使用模拟器积木时，仪表板上最后一组踏板、换挡杆或手刹无法删除。
