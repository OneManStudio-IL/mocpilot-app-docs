# 输入积木 {#input-blocks}

每一行都从一个输入开始。积木面板的**输入**标签页显示你的配置文件当前可以使用的积木：每个仪表板控件对应一个积木（有多个通道的控件每个通道各对应一个），以及**车辆**积木、**游戏手柄**积木和每个集线器对应的一个**集线器**积木。使用方法请参阅[输入](/docs/Application/Links/Inputs)。

每个输入沿行发送以下两种信号之一：

- **数值**：−1 到 1 之间的数字（没有负方向的控件为 0…1）；
- **开/关**：1 或 0。

处理积木和操作只接受它们能处理的信号；请参阅[处理积木](/docs/Application/Links/Blocks/ProcessingBlocks)。

## 控制器 {#src-controller}

仪表板上的控件，按名称显示（**JOY1**、**SLDR1**、**BTN2**…）。

- **控制器**：下面列出的任意仪表板控件。监视器是输出，不是输入。
- **通道**：对于有多个通道的控件，表示控件提供什么。积木面板中每个通道各对应一个积木。

方向盘、踏板、换挡杆、手刹、转向灯和列车控制器在[特殊控件](/docs/Application/Dashboard/SpecialControls)中有介绍。

如果控件从仪表板上删除，这一行会提示“选择一个仪表板控制器”。如果它的通道已不存在，会提示“选择…提供的内容”（操纵杆则提示“…不沿此轴移动”）。

### 操纵杆 {#controller-joystick}

- **通道**：**X 轴**或 **Y 轴**。设为**仅水平（X）**或**仅垂直（Y）**的操纵杆只提供对应的轴。
- 输出：数值 −1…1，居中时为 0。

### 滑块、垂直滑块 {#controller-slider}

- 无通道。
- 输出：数值 0…1；开启**负值**时为 −1…1。

### 列车控制器 {#controller-train}

列车控制器（特殊控件）在快速连接中相当于滑块。

- 无通道。
- 输出：数值 −1…1：手柄位置占全部档位的比例，换向手柄处于倒车位置时为负，空挡时为 0。

### 旋钮 {#controller-knob}

付费主题中的旋钮在快速连接中相当于滑块。

- 无通道。
- 输出：数值 0…1；如果旋钮的零点在中间，则为 −1…1。

### 方向盘 {#controller-wheel}

- **通道**：**转向角度**（默认）或**喇叭**。
- 转向角度输出：数值 −1…1，直行时为 0。
- 喇叭输出：按住喇叭区域时为 1，否则为 0。

### 踏板 {#controller-pedals}

- **通道**：**油门踏板**（默认）或**刹车踏板**。
- 输出：数值 0…1，表示踏板踩下的程度。
- 踏板提供的是原始踏板位置。如果想让汽车自行加速、减速和倒车，请使用[车辆](#src-vehicle)输入。

### 换挡杆 {#controller-gear}

手动和自动换挡杆（特殊控件）。

- **通道**：**挡位**（默认）或**方向（R − / 前进 +）**。
- 挡位，手动变速箱：当前挡位除以前进挡数量：最高挡为 1，空挡为 0，倒挡为负。有 4 个挡位时，2 挡为 0.5。
- 挡位，自动变速箱：与方向相同。
- 方向输出：R 挡为 −1，N 挡（以及 P 挡）为 0，任何前进挡或 D 挡为 +1。

### 手刹 {#controller-handbrake}

- **通道**：**手刹已拉起**（默认）或**手刹力度**。
- 手刹已拉起输出：开/关，手柄锁定时为开。
- 手刹力度输出：数值 0…1，表示手柄拉起的程度。

### 转向灯 {#controller-turnsignals}

转向灯拨杆（特殊控件）。

- **通道**：**转向灯（左 − / 右 +）**（默认）、**左转向灯**、**右转向灯**或**灯光**。
- 转向灯输出：数值 −1（左）、0（关）或 +1（右）。
- 左转向灯和右转向灯输出：对应转向灯开启时为 1（如果控件开启了闪烁，则随灯一起闪烁），否则为 0。
- 灯光输出：灯开启时为 1，否则为 0。

### 方向键 {#controller-dpad}

- **通道**：**上 / 下**或**左 / 右**。
- 输出：数值 +1（上或右）、−1（下或左）或 0。

### 按钮 {#controller-button}

- 无通道。
- 输出：开/关，按住时为开。

### 开关 {#controller-switch}

- 无通道。
- 输出：开/关。

### 步进开关 {#controller-stepper}

- 无通道。
- 输出：数值：当前挡位除以**挡位数**，因此最后一挡为 1（最后一个负挡为 −1）。

## 车辆 {#src-vehicle}

由仪表板的踏板、换挡杆和手刹驾驶的模拟汽车：它会像真实车辆一样加速、刹车、滑行和倒车，这一行得到的是它的速度或发动机转速。当仪表板上有踏板、换挡杆或手刹时，积木面板会显示车辆积木，每种输出对应一个积木，并且已经关联到每类控件中的第一个。

- **踏板**：驾驶车辆的仪表板踏板（必填）。
- **换挡杆**：**无**或仪表板上的某个换挡杆。没有换挡杆时，在静止状态下踩住刹车踏板会让车辆倒车。
- **手刹**：**无**或仪表板上的某个手刹。
- **车辆类型**：**轿车**（默认）、**越野车**、**跑车**或**卡车**。各类型的惯性和倒车速度不同；卡车还有气刹。
- **输出**：
  - **速度**（默认）：数值 −1…1，倒车时为负；
  - **发动机转速（rpm）**：数值 0…1；
  - **制动中**：开/关，车辆刹车时为开；
  - **拉着手刹**：开/关。

问题提示：“选择车辆的踏板”“…不在仪表板上”。

## 游戏手柄 {#src-gamepad}

连接到你设备上的游戏控制器。只有开启了**启用游戏手柄块**（顶栏中的**游戏手柄**页面）时，积木面板中才会有这个积木；否则这一行会提示“请在‘游戏手柄’页面（顶栏）中启用游戏手柄积木”。

- **输入**（默认**左摇杆 Y**）。标签跟随**游戏手柄按钮布局**（Xbox / PlayStation）：
  - **左摇杆 Y**、**左摇杆 X**、**右摇杆 Y**、**右摇杆 X**：数值 −1…1；
  - **RT** / **R2**、**LT** / **L2**（扳机）：数值；
  - **A**、**B**、**X**、**Y** / **叉**、**圆圈**、**方块**、**三角**：开/关；
  - **LB** / **L1**、**RB** / **R1**（肩键）：开/关；
  - **上**、**下**、**左**、**右**（方向键）：开/关。

## 集线器 {#src-hub}

集线器自身的按钮或传感器：位于集线器上或其某个端口上。配置文件中的每个集线器各有一个集线器输入，但 Mould King 集线器除外，因为它们只接收命令。

- **集线器**：配置文件中的某个集线器。
- **按钮或传感器**：只列出该集线器能够报告的内容（见下表）。
- **端口**：用于端口上的传感器（电机数值、端口传感器）。
- **集线器方向**：用于可以更改方向的集线器上的倾斜和加速度：**保持**（默认）或集线器在模型中的安装方式。

传感器数值沿行传递时会除以其满量程，并限制在 −1…1 之间：电量为 50 % 的电池输出 0.5。紧跟在传感器后面的文本**监视器**会显示带单位的真实数值。

| 按钮或传感器 | 信号 | 单位，满量程 | 集线器 |
|---|---|---|---|
| **按钮 1、2…** | 开/关 | | 带按钮的集线器；LEGO® Powered Up 遥控器的按钮 |
| **电池** | 数值 | %，100 | 能报告电量的集线器 |
| **电池电压** | 数值 | V，12 | 能报告电压的集线器 |
| **输出电压** | 数值 | V，12 | BuWizz 2.0 |
| **温度** | 数值 | °C，100 | 能报告温度的集线器 |
| **倾斜俯仰** | 数值 | °，90 | 带倾斜传感器的集线器 |
| **倾斜滚转** | 数值 | °，180 | 带倾斜传感器的集线器 |
| **倾斜偏航** | 数值 | °，180 | 带偏航轴的集线器 |
| **加速度 X / Y / Z** | 数值 | m/s²，19.6 | 带加速度计的集线器 |
| **电机速度** | 数值 | %，100 | 端口；所有带端口的集线器 |
| **电机角度** | 数值 | °，360（相对） | 端口；带编码器的电机；不支持 SBrick、BuWizz 2.0、WeDo 2.0 |
| **电机位置** | 数值 | °，180（绝对） | 端口；角度电机 |
| **电机功率** | 数值 | %，100 | 端口；Robot Inventor |
| **电机电流** | 数值 | A，3 | 端口；BuWizz 2.0、BuWizz 3.0 Pro |
| **距离传感器** | 数值 | 250 | 端口；不支持 SBrick 或 BuWizz |
| **颜色传感器** | 数值 | 颜色编号，10 | 端口；不支持 SBrick、BuWizz 或 WeDo 2.0 |
| **反射光**、**环境光** | 数值 | %，100 | 端口；不支持 SBrick、BuWizz 或 WeDo 2.0 |
| **倾斜传感器俯仰 / 滚转** | 数值 | °，45 | 端口；WeDo 2.0 / BOOST 倾斜传感器；不支持 SBrick 或 BuWizz |
| **功率模式** | 数值 | 1–4，4 | BuWizz 2.0 |
| **已连接** | 开/关 | | 所有集线器 |

集线器连接后，MOCPilot 还会检查端口上的设备：“端口 A：没有电机”“端口 A：电机没有编码器”“端口 A：没有距离传感器”等。
