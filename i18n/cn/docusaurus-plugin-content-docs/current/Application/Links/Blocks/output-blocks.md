# 操作与输出积木 {#operation-and-output-blocks}

积木面板的**输出**标签页包含操作和输出。使用方法请参阅[操作与输出](/docs/Application/Links/Operations)。

- **操作**说明做什么。它后面必须跟一个[集线器](#hub-out)输出，说明在哪里。
- **直接输出**（[指示器](#dash-indicator)、[集线器 LED](#hub-led)、[LED 点阵](#hub-matrix)、[校准舵机](#cmd-calibrate)）可以单独结束一行；这一行不能有操作。

**电机**、**舵机**、**定时电机**和**灯光**始终在积木面板中。其他操作只在配置文件中的某个集线器支持时才会出现。

下文中的“开”指开/关信号处于开启状态，或数值不小于 0.5（正负均可）。

## 端口操作 {#operations-for-ports}

### 电机 {#op-motor}

按输入的数值驱动电机：推得越多转得越快；为 0 时停止。

- 接收：数值或开/关（开 = 全速）。
- **停止时**：**集线器默认**（默认）、**惯性滑行**、**刹车**或**保持位置**。
- **集线器加速**：**集线器默认**（默认）、**快**、**均衡**、**平滑**、**慢**或**很慢**：集线器自身的加减速曲线。如需自定义加减速，请使用[平滑](/docs/Application/Links/Blocks/ProcessingBlocks#mod-smooth)。
- **卡死检测**：**集线器默认**（默认）、**开**或**关**。
- 集线器：任何带端口的集线器。**停止时**和**集线器加速**需要支持位置控制的集线器（不支持 SBrick、BuWizz 2.0、WeDo 2.0 或 Mould King）；**卡死检测**需要 Robot Inventor。在 Technic Move Hub 上，电机在**汽车配置文件**模式下用于驱动汽车，在**端口**模式下驱动电机 `A`–`C`（[Technic Move Hub](/docs/Application/Links/HubsAndPorts#technic-move-hub)）。

### 舵机 {#op-servo}

用带编码器的电机转向：输入 −1…1 会让电机转到 *中心 + 数值 × 角度*，为 0 时回到中心。

- 接收：数值或开/关。
- **校准**：**手动**（默认）或**自动**。
- **角度**：±30°、±45°、±60°、±90°、±120°、±180°、±1 圈、±2 圈、±3 圈或 ±5 圈（默认 ±90°）。仅限手动。
- **中心**：−20°、−10°、−5°、0°、+5°、+10° 或 +20°（默认 0°）。仅限手动。
- **转动速度**：25、50、75 或 100 %（默认 100 %）。
- 手动：零点是电机通电时所在的位置，或者你用**设为零点**设定的位置（可以先用 **◀ 5°** / **5° ▶** 微调）。
- 自动：每次启动时，电机会转到两端限位；中间位置成为零点，行程成为角度。**立即校准**会马上执行校准。转向机构必须有限位。
- 集线器和端口：支持位置控制的集线器（不支持 SBrick、BuWizz 2.0、WeDo 2.0 或 Mould King）上带编码器的电机。在**汽车配置文件**模式下的 Technic Move Hub 上，舵机转动集线器的转向齿条，由集线器自行校准；在**端口**模式下，请在端口 `C` 上使用**自动**校准。

### 定时电机 {#op-timed}

每当输入变为开时，电机运转设定的时间。速度和方向取决于当时的输入数值。

- 接收：数值或开/关。
- **时间**：0.5、1、2、3、5 或 10 秒（默认 1 秒）。
- 集线器：任何带端口的集线器；在**汽车配置文件**模式下的 Technic Move Hub 上用于驱动汽车。

### 按角度运行 {#op-degrees}

每当输入变为开时，电机转动设定的角度。输入为负时朝另一方向转动。

- 接收：数值或开/关。
- **角度**：45°、90°、180°、1 圈、2 圈、3 圈、5 圈或 10 圈（默认 1 圈）。
- **速度**：25、50、75 或 100 %（默认 50 %）。
- 集线器和端口：支持位置控制的集线器上带编码器的电机。

### 转到位置 {#op-goto}

输入变为开时，电机转到一个绝对位置；变为关时，转到另一个位置。电机走最短路径。

- 接收：数值或开/关。
- **开时位置**：0°、45°、90°、135°、180°、225°、270° 或 315°（默认 90°）。
- **关时位置**：**保持不动**或上述位置之一（默认 0°）。
- **速度**：25、50、75 或 100 %（默认 50 %）。
- 集线器和端口：支持位置控制的集线器上的角度电机（绝对位置）。

### 灯光 {#op-light}

驱动端口上的 LEGO® 灯。

- 接收：数值或开/关。接收数值时，亮度随数值变化（−1 和 1 都是最大亮度）。
- **亮度**：25、50、75 或 100 %（默认 100 %）。
- **闪烁：开时**：**不闪烁**（默认）、0.25、0.5、1 或 2 秒：每次闪烁时灯亮的时长。
- **闪烁：关时**：**与开时相同**（默认）、0.25、0.5、1 或 2 秒：灯灭的时长。
- 集线器：除 WeDo 2.0 外任何带端口的集线器。在 Technic Move Hub 上，灯光在**汽车配置文件**模式下用于开关汽车的灯，在**端口**模式下逐个控制灯 `1`–`6`。

### 端口颜色 {#op-portcolor}

设置 BuWizz 3.0 Pro 端口 LED 的颜色。

- 接收：数值或开/关。
- **颜色**：**从列表**（默认）或 **RGB**。
- **开时颜色**（默认红色）和**关时颜色**（默认关）：关、粉色、紫色、蓝色、浅蓝色、浅绿色、绿色、黄色、橙色、红色、白色。
- **红色**、**绿色**、**蓝色**（RGB）：0、32、64、128、192 或 255（默认 255, 0, 0）。
- 集线器和端口：BuWizz 3.0 Pro，端口 1–4。程序停止时 LED 熄灭。

### 传感器灯光 {#op-sensorlights}

输入为开时，点亮 Technic 距离传感器“眼睛”周围的四段灯。

- 接收：数值或开/关。
- **灯**：**全部**（默认）、**上**、**下**、**左**、**右**或**对角**。
- **亮度**：25、50、75 或 100 %（默认 100 %）。
- 集线器和端口：Robot Inventor、SPIKE Prime 和 Technic Hub，接距离传感器的一个端口。程序停止时灯熄灭。

### 颜色传感器灯 {#op-colorlights}

输入为开时，点亮 Technic 颜色传感器（SPIKE 颜色传感器）镜头周围的三盏灯。

- 接收：数值或开/关。
- **灯**：**全部**（默认）、1、2、3、1 + 2、2 + 3 或 1 + 3。
- **亮度**：25、50、75 或 100 %（默认 100 %）。
- 集线器和端口：Technic Hub，接颜色传感器的端口。
- 灯亮着时，传感器不进行任何测量。输入变为关或程序停止时，灯熄灭，传感器重新开始测量颜色。如果某一行读取的颜色传感器所在的端口被另一行点亮，就会显示问题（“第 2 行点亮了端口 A 上的颜色传感器：点亮的传感器不进行任何测量”）。

## 整个集线器的操作 {#operations-for-the-whole-hub}

这些操作后面的集线器积木不需要端口。

### 刹车 {#op-brake}

输入为开时让汽车刹车。

- 接收：数值或开/关。无设置项。
- 集线器：Technic Move。

### Boost {#op-boost}

输入为开时把集线器切换到 Boost 功率模式，变为关时恢复正常。

- 接收：数值或开/关。无设置项。
- 集线器：Technic Move。

### 动力脉冲 {#op-pulse}

每当输入变为开时发送一次动力脉冲：电机以最大功率运转约两秒。

- 接收：数值或开/关。无设置项。
- 集线器：使用 **Batmobile™ Tumbler** 配置的 Technic Move；请参阅 [Technic Move Hub 配置](/docs/Application/Hubs/TechnicMoveHubConfigurations)。

### 功率模式 {#op-powermode}

输入变为开时设置 BuWizz 2.0 的功率模式；如果你选择了关时模式，输入变为关时也会设置。

- 接收：数值或开/关。
- **开时模式**：**慢**、**正常**（默认）、**快**或 **Ludicrous**。
- **关时模式**：**保持**（默认）或上述模式之一。
- 集线器：BuWizz 2.0。

### 通道 {#op-channel}

输入变为开时切换 Mould King 集线器的控制通道；如果你选择了关时通道，输入变为关时也会切换。

- 接收：数值或开/关。
- **开时通道**：**A**（默认）、**B** 或 **C**。
- **关时通道**：**保持**（默认）、**A**、**B** 或 **C**。
- 集线器：Mould King 4.0 和 6.0。

## 输出 {#outputs}

### 集线器 {#hub-out}

操作在哪里执行：一个集线器及其端口。配置文件中的每个集线器各对应一个集线器积木。

- **集线器**：配置文件中的某个集线器。
- **端口**：该集线器的一个或多个端口（大多数集线器和 SBrick 为 A–D，Robot Inventor 和 Mould King 6.0 为 A–F，BuWizz 2.0 为 1–4，BuWizz 3.0 Pro 为 1–4 加上 A 和 B）。一个端口只能属于一行。
- 接收：一个操作。**汽车配置文件**模式下的 Technic Move Hub 和整个集线器的操作不需要端口。在**端口**模式下，Technic Move Hub 有端口 A–C，**灯光**还有灯 1–6。
- 更多内容：[集线器积木与端口](/docs/Application/Links/HubsAndPorts)。

### 指示器 {#dash-indicator}

在仪表板监视器上按原样显示数值。

- 接收：数值或开/关，前面不能有操作。
- **仪表板指示器**：仪表板上的**文本监视器**（监视器）、**数值监视器**（电池电量、速度表）或**倾斜监视器**。
- **轴**：**倾斜 X** 或**倾斜 Y**，仅用于倾斜监视器（每个轴一行）。
- 紧跟在集线器传感器后面的文本监视器会显示带单位的真实数值。

### 集线器 LED {#hub-led}

集线器的彩色状态灯：输入为开时显示一种颜色，为关时显示另一种颜色。

- 接收：数值或开/关，前面不能有操作。
- **集线器**：带彩色 LED 的集线器。
- **颜色**：**从列表**（默认）或 **RGB**。
- **开时颜色**（默认红色）和**关时颜色**（默认关）：关、粉色、紫色、蓝色、浅蓝色、浅绿色、绿色、黄色、橙色、红色、白色。
- **红色**、**绿色**、**蓝色**（RGB）：0、32、64、128、192 或 255（默认 255, 0, 0）。
- 集线器：LEGO® 集线器（Technic、Technic Move、City、BOOST、WeDo 2.0、Robot Inventor、Powered Up 遥控器）；不支持 BuWizz、SBrick 或 Mould King。

### LED 点阵 {#hub-matrix}

集线器的灯光点阵。

- 接收：数值或开/关，前面不能有操作。
- **集线器**：带 LED 点阵的集线器。
- **显示**：**条形图**（默认；随数值从下往上逐行点亮）、**数字**（数值从 −100 到 100）或**开时图像**。
- **图片**：**爱心**（默认）、**笑脸**、**难过**、**对勾**、**叉**、**向上箭头**、**向下箭头**、**向左箭头**、**向右箭头**或**全亮**。
- **方向**：**保持**（默认）、**正放**、**倒置**、**左**或**右**。
- 集线器：Robot Inventor。程序停止时点阵清空。

### 校准舵机 {#cmd-calibrate}

每当输入变为开时，程序中所有处于**自动**模式的[舵机](#op-servo)都会重新校准。

- 接收：数值或开/关，前面不能有操作。无设置项。
- 程序中必须有一个处于自动模式且已就绪的舵机行，否则这一行会提示“此程序中没有处于‘自动’校准模式的舵机”。
