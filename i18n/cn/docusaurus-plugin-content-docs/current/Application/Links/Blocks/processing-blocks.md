# 处理积木 {#processing-blocks}

处理积木位于输入和操作（或指示器）之间，在途中改变信号。一行中可以有任意数量的处理积木，顺序不限。无法接收传入信号的积木不会吸附上去；如果文件中出现这种情况，会提示“‘…’不适用于此控制器”。使用方法请参阅[处理](/docs/Application/Links/Processing)。

## 反转 {#mod-invert}

反转信号。

- 无设置项。
- 接收：数值或开/关。输出：同类信号。
- 数值：改变正负号（0.7 变为 −0.7）。开/关：开变为关，关变为开。

## 限制 {#mod-limit}

按比例缩小数值，使推到底时也不超过最大值。

- **最大值**：20、30、40、50、60、70、80 或 90 %（默认 50 %）。
- 接收：数值或开/关。输出：数值（经过限制的按钮输出 0 或最大值）。

## 死区 {#mod-deadzone}

把零点附近的微小数值当作零；其余部分会重新拉伸到完整范围，因此推到底时仍然输出 1。

- **区域**：5、10、15、20 或 30 %（默认 10 %）。
- 接收：数值。输出：数值。

## 阈值 {#mod-threshold}

把数值转换为开/关。

- **开启条件：数值**：**高于**（默认）或**低于**。
- **阈值（占满量程）**：−50、−20、0、5、10、20、30、50、70 或 90 %（默认 20 %）。
- 接收：数值。输出：开/关。
- 少量回差（满量程的 2 %）可防止数值在阈值附近徘徊时输出来回跳变。

## 平滑 {#mod-smooth}

逐渐趋近传入的数值，而不是突然跳变。

- **加速（到全速）**：**即时**、0.25、0.5、1、2 或 3 秒（默认 0.5 秒）：从 0 到满值（离开零点方向）所需的时间。
- **减速（到停止）**：选项相同（默认 0.5 秒）：从满值回到 0 所需的时间。
- 接收：数值或开/关。输出：数值（经过平滑的按钮会逐渐升高和降低）。

## 切换 {#mod-toggle}

把按钮变成开关：每按一次，输出就在开和关之间切换一次。输出初始为关。

- 无设置项。
- 接收：开/关。输出：开/关。
