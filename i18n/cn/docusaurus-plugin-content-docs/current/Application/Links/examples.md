# 示例 {#examples}

现成的方案。请先把控件放到仪表板上，并在“我的集线器”中添加集线器，然后再搭建各行。

## 舵机转向的汽车 {#car-with-servo-steering}

仪表板：左侧放 **JOY1**（仅垂直），右侧放 **JOY2**（仅水平），再加上 **BTN1** 和一个**电池电量**监视器。

| # | 输入 | 处理 | 操作 | 输出 |
|---|---|---|---|---|
| 1 | JOY1，Y 轴 | 死区 10 %，平滑 0.5 秒 | 电机 | Technic Hub，端口 A + B |
| 2 | JOY2，X 轴 | | 舵机（自动，±90°） | Technic Hub，端口 D |
| 3 | BTN1 | 切换 | 灯光 | Technic Hub，端口 C |
| 4 | 集线器：电池 | | | 指示器：电池电量 |

如果某个驱动电机转反了，就把第 1 行拆成两行，并在其中一行加上**反转**。

## 带方向盘、踏板和变速箱的汽车 {#car-with-a-wheel-pedals-and-a-gearbox}

仪表板：**方向盘**、**踏板**、**换挡杆**、**手刹**和**转向灯**。[车辆](/docs/Application/Links/Blocks/InputBlocks#src-vehicle)输入会把踏板、变速箱和手刹转换成像真车一样逐渐提升和衰减的速度。

| # | 输入 | 处理 | 操作 | 输出 |
|---|---|---|---|---|
| 1 | 车辆：速度 | | 电机 | Technic Hub，端口 A + B |
| 2 | 方向盘：转向角度 | | 舵机（自动） | Technic Hub，端口 D |
| 3 | 车辆：制动中 | | 灯光 | Technic Hub，端口 C（刹车灯） |
| 4 | 转向灯：左转向灯 | | 灯光 | City Hub，端口 A |
| 5 | 转向灯：右转向灯 | | 灯光 | City Hub，端口 B |

## 坦克（两条履带） {#tank-two-tracks}

仪表板：两个垂直滑块 **VSLDR1** 和 **VSLDR2**，开启**自动回零**和**负值**。

| # | 输入 | 处理 | 操作 | 输出 |
|---|---|---|---|---|
| 1 | VSLDR1 | 平滑 0.25 秒 | 电机 | 集线器，端口 A |
| 2 | VSLDR2 | 反转，平滑 0.25 秒 | 电机 | 集线器，端口 B |

如果使用游戏手柄，第 1 行用左摇杆 Y，第 2 行用右摇杆 Y。

## 起重机 {#crane}

仪表板：**DPAD1**、**SLDR1**、**SWCH1**。

| # | 输入 | 处理 | 操作 | 输出 |
|---|---|---|---|---|
| 1 | DPAD1，左 / 右 | 限制 50 % | 电机 | 集线器，端口 A（回转） |
| 2 | DPAD1，上 / 下 | | 电机 | 集线器，端口 B（吊钩绞盘） |
| 3 | SLDR1 | 死区 10 % | 电机 | 集线器，端口 C（吊臂） |
| 4 | SWCH1 | | 灯光（闪烁 0.5 秒） | 集线器，端口 D（警示灯） |

## 火车 {#train}

仪表板：一个开启了**负值**（前进和倒退的速度挡位）的**步进开关** **STPR1**，以及控制灯光的 **BTN1**。

| # | 输入 | 处理 | 操作 | 输出 |
|---|---|---|---|---|
| 1 | STPR1 | 平滑 2 秒 | 电机 | City Hub，端口 A |
| 2 | BTN1 | 切换 | 灯光 | City Hub，端口 B |
| 3 | 集线器：电池 | | | 指示器：监视器 |

平滑积木能让火车像真车一样平稳起步和停车。如果仪表板上有**列车控制器**，就在第 1 行用它代替 STPR1：它提供手柄位置，倒车时为负值。

## Technic Move 汽车 {#technic-move-car}

| # | 输入 | 处理 | 操作 | 输出 |
|---|---|---|---|---|
| 1 | 车辆：速度 | | 电机 | Technic Move（驱动） |
| 2 | 方向盘：转向角度 | | 舵机 | Technic Move（转向） |
| 3 | BTN1 | 切换 | 灯光 | Technic Move（灯光） |
| 4 | BTN2 | | Boost | Technic Move |

如果仪表板上没有换挡杆，在静止时踩住刹车踏板，汽车就会倒车。
