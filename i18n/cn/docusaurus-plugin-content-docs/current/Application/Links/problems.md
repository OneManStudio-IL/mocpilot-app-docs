# 运行与排查问题 {#running-and-fixing-problems}

## 一切准备就绪了吗？ {#is-everything-ready}

编辑器顶栏中的**问题**按钮会显示：

- **绿色对勾**：“所有行均已就绪”；
- **红色“!”**：“问题：N”。

点按它即可打开问题面板（在手机上是侧边面板，在平板电脑或电脑上是菜单）。面板会列出“第 N 行 — 原因”；点按某一项即可跳转到该行。导致问题的积木带有**红框**。一切正常时，面板会显示“所有已开启的行都可以运行。”

<Screenshot name="links-problems" alt="问题面板，其中有一行尚未就绪" width={900} />

有问题的行不会运行；其他行照常运行。

## 常见提示信息 {#common-messages}

| 提示信息 | 怎么做 |
|---|---|
| 将一个输入和一个输出（集线器或仪表板指示器）拖到该行 | 该行为空 |
| 在行首添加一个输入 | 先拖入控件、车辆、游戏手柄或集线器输入 |
| 添加一个输出：集线器或仪表板指示器 | 用一个输出结束这一行 |
| 在集线器前添加一个操作：电机、舵机、灯光 | 集线器输出前面需要一个操作 |
| 请在集线器上至少选择一个端口 | 在集线器积木上点按一个端口选项 |
| 选择一个仪表板控制器 | 点按输入积木并选择一个控件 |
| …不沿此轴移动 | 该操纵杆只有一个轴：选择另一个轴或更改操纵杆 |
| 选择…提供的内容 | 该控件已不再有这个通道：请选择一个 |
| 选择车辆的踏板 | 车辆输入需要仪表板上有踏板 |
| …不在仪表板上 | 为车辆选择的换挡杆或手刹已被删除 |
| “…”不适用于此控制器 | 此处理积木与信号不匹配 |
| 端口 A：此设备不能用作舵机（需要带编码器的电机） | 使用带编码器的电机或换用其他操作 |
| 端口 A 连接的是传感器，不是电机 | 检查端口上插的是什么 |
| 端口 A 也在第 2 行中使用 | 每个端口只能属于一行 |
| 请在“游戏手柄”页面（顶栏）中启用游戏手柄积木 | 打开**游戏手柄**并开启**启用游戏手柄块** |
| 指示器按原样显示数值：请移除操作 | 指示器行不需要操作 |
| 校准不需要操作：请将其移除 | 校准舵机行不需要操作 |
| 选择带彩色 LED 的集线器（LEGO 集线器） | 集线器 LED 仅适用于 LEGO® 集线器 |
| 端口颜色仅适用于 BuWizz 3 | 端口颜色需要 BuWizz 3.0 Pro |
| 此程序中没有处于“自动”校准模式的舵机 | 校准舵机需要一个处于自动模式的舵机 |
| 此积木需要更新版本的应用 | 该配置文件是在更新的版本中制作的：请更新 MOCPilot |
| 该行已关闭 | 在行菜单中开启它 |

## 实时数值 {#live-values}

程序运行时，积木之间的每个接口都会显示流经它的数值。移动一个控件，沿着这一行跟踪数值：

- 输入处没有任何变化：控件或游戏手柄没有发送任何数据；检查通道或轴；
- 数值在变化但电机不动：检查集线器的连接圆点和端口；
- 经过**限制**或**死区**后数值很小：调整它们的设置。

## 模型不动 {#the-model-does-not-move}

1. 集线器连接了吗？检查**我的集线器**以及集线器积木上的连接圆点。
2. 选对端口了吗？电机插的位置和你想的一样吗？
3. 这一行开启了吗？有没有红框？
4. 程序在运行吗（**运行**）？
5. 电池有电吗？添加一行 *电池 → 指示器*，随时关注电量。

更多内容请参阅[故障排除](/docs/Help/Troubleshooting)。
