# AI 构建器 {#ai-builder}

用你自己的话描述模型，无论是打字还是说话，**AI 构建器**都会为你设置好配置文件：集线器和端口、仪表板控件以及程序。它在两种编辑器中都能使用：在[逻辑积木](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing)配置文件中搭建积木，在[快速连接](/docs/Application/Links/LinksIntroducing)配置文件中搭建行。之后，你可以继续与它对话来修改配置文件，也可以自己动手编辑。

AI 构建器属于 [MocPilot Pro](/docs/Application/Account/Pro)，可在应用和[网页编辑器](/docs/Introducing/WebEditor)中使用。它需要网络连接。

## 打开 AI 构建器 {#open-the-ai-builder}

1. 打开一个配置文件进行编辑。
2. 在电脑上，按下顶栏右侧的 **AI 构建器**按钮（闪光图标），或按 ⇧⌘I / Ctrl+Shift+I；在窄窗口中，它位于**更多**（⋯）中。在手机或平板上，轻点**更多** → **AI 构建器**。
3. 在 **AI 应该构建或修改什么？**中输入你的请求，然后按**发送**（或按 Enter；Shift+Enter 换行）。

没有 MocPilot Pro 时，该按钮会介绍 AI 构建器的功能，并显示**获取 MocPilot Pro** 和**以后再说**。

面板的打开位置：

- **手机**：在编辑器上方打开一个全屏页面。
- **平板**：一张浮动卡片；拖动它的标题栏可将其移到左侧或右侧。
- **电脑**：右侧的一张卡片。在应用中（浏览器中不支持），可以按下标题栏中的**在单独窗口中打开**，并把窗口放在编辑器旁边。

AI 工作时，面板会显示它正在做什么（**正在思考您的模型…**、**正在检查配置文件…**等）。完成后，更改会立即出现在编辑器中，并附有一段简短的更改摘要。面板为空时，会推荐几个示例请求：轻点其中一个即可填入文本框，然后可以直接发送，也可以先修改。

每个配置文件的对话都会保留，因此你可以关闭面板，稍后再回来继续。

## 写出好的请求 {#ai-builder-tips}

:::tip 说明你用的是哪个集线器、每个端口接了什么，以及它应该做什么
像“一辆带灯的车”这样一句话的请求是不够的：AI 只能猜测集线器、端口以及每个电机的用途，结果很可能需要修改。请写明：

- **集线器**：Technic Hub、City Hub、BOOST Move Hub、Robot Inventor、Technic Move Hub、BuWizz、SBrick……
- **每个端口接了什么**：驱动电机、转向电机（舵机）、灯、传感器。
- **各自应该做什么**：驱动、带校准的转向、开关、限速。
- **你想如何控制它**：操纵杆、滑块、按钮、游戏手柄。
:::

就像向朋友解释一样来描述。你可以用自己的语言书写。

如果结果仍不理想，请告诉 AI 要改什么，而不必从头开始。

## 示例请求 {#example-requests}

**一辆车**：“一辆使用 Technic Hub 的车：驱动电机接在端口 A，转向电机接在端口 C 并用作舵机，车灯接在端口 D。左边是转向操纵杆，右边是油门，再加一个开关车灯的按钮。”

**一台起重机**：“一台使用 Technic Hub 的起重机：旋转电机接在端口 A，吊臂电机接在端口 B，吊钩绞盘接在端口 C。用一个滑块控制旋转，用上/下按钮控制吊臂，用一个操纵杆控制吊钩，吊臂速度限制在 50%。”

**一列火车**：“一列使用 City Hub 的 City 火车：火车电机接在端口 A，车灯接在端口 B。用一个步进开关控制速度，加一个速度计和一个车灯按钮。”

## 修改现有配置文件 {#change-an-existing-profile}

在已有的配置文件（即使是你手动搭建的）中打开 AI 构建器，说出要修改的内容。AI 能看到当前的集线器、仪表板和程序，并对它们进行编辑：

- “让转向慢一点。”
- “添加一个停止按钮。”
- “把控件复制到我的游戏手柄上。”
- “把吊臂速度限制在 50%。”

你也可以询问有关配置文件的问题，例如“车灯接在哪个端口？”。AI 会在面板中回答，并保持配置文件不变。

## 你的配置文件会发生什么 {#what-happens-to-your-profile}

- AI 会直接修改当前打开的配置文件：集线器、仪表板和程序会同时更新。如果程序正在运行，它会停止。
- AI 会遵循配置文件的程序类型：在逻辑积木配置文件中编写积木，在快速连接配置文件中编写行。它绝不会把一种类型转换为另一种。如果某个请求需要快速连接的行无法实现的功能，AI 会告诉你需要使用逻辑积木配置文件。
- AI 不需要修改的部分会保持原样。
- **撤销上一次 AI 更改**（面板标题栏中的撤销按钮）会把配置文件恢复到上一次 AI 更改之前的状态。再按一次可以继续往前撤销，最多 10 次更改。打开其他配置文件时，撤销记录会被清除。
- 你随时都可以继续自己编辑配置文件。

## 语音输入 {#voice-input}

按下**口述**（麦克风按钮）并说出你的请求；文字会出现在输入框中，你可以在发送前进行修改。再次按下该按钮即可停止。如果有多种语言可用，麦克风旁边的小语言按钮可以切换口述语言；应用会记住你的选择。

| 平台 | 方法 |
|---|---|
| iPhone、iPad、Mac | **口述**；首次使用时，允许访问麦克风和语音识别 |
| Android | **口述**；首次使用时，允许访问麦克风 |
| Windows | 按 **Win+H**，使用 Windows 语音输入进行口述（麦克风按钮会提醒你） |
| 网页编辑器 | 在 Chrome、Edge 和 Safari 中使用**口述**；允许该网站访问麦克风。Firefox 不支持口述 |

语音输入消息：

| 消息 | 处理方法 |
|---|---|
| **请在系统设置中允许 MOCPilot 访问麦克风** | 在系统设置中为 MOCPilot 打开麦克风访问权限 |
| **请在系统设置中允许 MOCPilot 使用语音识别** | 在 Apple 设备上，在系统设置中为 MOCPilot 打开语音识别 |
| **请在浏览器中允许此网站访问麦克风** | 在浏览器的网站设置中允许使用麦克风 |
| **未听到任何声音** | 按下**口述**并重新说一遍 |
| **语音输入需要网络连接** | 连接网络，或手动输入请求 |
| **此语言目前不支持语音识别** | 切换口述语言或手动输入请求 |
| **未找到麦克风** / **此设备不支持语音输入** | 手动输入请求 |

## 限额 {#limits}

- 每天约 30 次请求，另有每月限额。面板标题栏会显示你的使用量：**今日 5/30 · 本月 12%**。
- 免费试用期间，AI 请求次数有限；订阅开始后即可继续使用。
- 一次只能处理一个请求：请等收到回答后再发送下一个。
- AI 构建器只用于构建和编辑配置文件，不回答其他话题的问题。

## 错误消息 {#error-messages}

| 消息 | 处理方法 |
|---|---|
| **AI 构建器不可用** / **无法访问 AI 服务。请检查网络连接后重试。** | 检查网络连接，然后重新打开面板 |
| **无法连接 AI 服务。请检查网络连接后重试。** | 检查网络连接，然后重新发送请求 |
| **与 AI 服务的连接已断开…** | 恢复联网后，回答会出现在面板中；也可以重新发送请求 |
| **AI 未及时响应。请重新发送请求。** / **请求已丢失，请重新发送** | 重新发送请求 |
| **AI 无法为此请求生成可用的配置。请换一种说法试试。** | 换一种说法：写明集线器、端口以及各自的用途 |
| **配置太大，无法一次生成。请每次少提一些要求。** | 把请求拆分成更小的步骤 |
| **AI 拒绝了此请求。** | 换一种说法，使请求与配置文件相关 |
| **您已达到今日 AI 请求上限。请明天再试。** | 等到明天，或自己编辑配置文件 |
| **您已达到本月的 AI 上限。** | 限额会在下个月重置 |
| **你已用完免费试用中的所有 AI 请求。订阅开始后即可继续使用。** | 等待订阅开始 |
| **AI 构建器只用于构建和编辑配置文件。其他话题的请求过多：请一小时后再试。** | 等待一小时，并只询问与配置文件相关的问题 |
| **当前 AI 请求过多。请一分钟后再试。** | 一分钟后重试 |
| **上一个请求仍在处理中。** | 等待回答 |
| **AI 服务暂时不可用。请稍后再试。** / **您已拥有 MocPilot Pro。AI 构建器目前不可用，请稍后再试。** | 稍后重试 |
| **该回复属于另一个配置文件** | AI 工作时你打开了另一个配置文件，因此更改未被应用。请重新打开第一个配置文件并再次发送请求 |
| **请先打开一个配置文件进行编辑** | 在编辑器中打开配置文件，然后发送请求 |
| **无法在编辑器中更新配置文件** / **无法撤销此更改** | 重试；如果问题反复出现，请关闭并重新打开配置文件 |
