# 目录与发布 {#catalog-and-publishing}

**配置文件目录**是一个现成配置文件库：既有 MOCPilot 团队为 LEGO® 套装制作的官方配置文件，也有其他玩家分享的社区配置文件。它与 [mocpilot.com](https://mocpilot.com) 上的目录是同一个。

## 打开目录 {#open-the-catalog}

- 手机：在**我的配置文件**页面选择 **+** → **在线搜索**。
- 平板：侧边栏中的**配置文件目录**，或**新建配置文件**菜单中的**在线搜索**。
- 电脑：**文件 → 在线搜索**。

目录需要网络连接。如果你的设备无法在应用内显示目录，请轻点**在浏览器中打开**。

你可以按名称、描述、标签、作者和套装编号搜索目录。卡片上会显示配置文件的下载次数。

<Screenshot name="profile-catalog" alt="包含官方和社区配置文件的配置文件目录" width={900} />

## 安装配置文件 {#install-a-profile}

在目录中打开一个配置文件并添加它。它的副本会出现在你的配置文件列表中。

- 只要你不修改它，配置文件就会完全按照发布时的样子运行，包括你未拥有的付费主题。
- 作者发布新版本后，卡片上会显示**有可用更新**。轻点**更新**即可安装；在你更新之前，不会有任何变化。
- 首次修改该配置文件时，MOCPilot 会提醒你：修改之后，它将不再接收目录更新，你未拥有的产品会被替换为 基础主题或被锁定。参见[管理配置文件](/docs/Application/Profiles/ManageProfiles#paid-themes-in-shared-profiles)。

在网站上，你也可以在任意目录配置文件上按下**添加到我的账户**；它随后会通过[同步](/docs/Application/Account/Sync)出现在应用中。

## 发布你的配置文件 {#publish-your-profile}

与所有人分享你的模型：

1. 确保你已登录，并且配置文件已同步：目录会从你的账户中复制它，并把你显示为作者。
2. 打开**编辑配置文件**，轻点**发送到目录**。
3. 检查各项要求，填写表单，然后按下**提交审核**。

<Screenshot name="publish-profile" alt="“发布到目录”页面，列出了尚未满足的要求" width={900} />

### 要求 {#requirements}

提交审核之前，配置文件需要具备：

- 至少 3 个字符的名称，且不能是“New profile”或“Untitled”之类的默认名称；
- 一张图片；
- 至少 20 个字符的描述；
- 至少一个集线器；
- 用于控制的方式：仪表板控制器或游戏手柄；
- 至少包含一个积木或一行的程序；
- 至少一个标签。

发布页面会列出所有缺少的项目。

### 表单 {#the-form}

- **名称**和**描述**：模型能做什么以及如何控制它。
- **标签**。
- **可见性**：**公开**（显示在目录中）或**仅限链接**。
- **集线器**：从配置文件中获取。
- 可能会要求填写其他字段，例如套装编号。
- **新增内容**：用于新版本。

### 审核 {#review}

审核员会检查每一份提交。结果会显示在**通知**中：

- “您的配置文件‘…’已通过审核”：它现在已出现在网站和应用的目录中。
- “您的配置文件‘…’未通过审核”：审核员的备注会说明需要修改的地方。修改后再次提交即可。

发布页面会显示状态：等待审核、已发布、已发布且新版本正在等待审核、已拒绝或已隐藏。

你每月最多可以提交 5 个配置文件或新版本；页面会显示剩余次数。

### 新版本和取消发布 {#new-versions-and-unpublishing}

再次发布同一个配置文件会把一个**新版本**提交审核。已安装它的用户会看到**有可用更新**。你也可以隐藏已发布的配置文件。
