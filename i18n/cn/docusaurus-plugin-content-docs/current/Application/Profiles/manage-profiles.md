# 管理配置文件 {#manage-profiles}

## 编辑配置文件详情 {#edit-profile-details}

在配置文件上轻点**编辑**（手机、平板）或点击**编辑…**（电脑）。在**编辑配置文件**中，你可以更改：

- **图片**和**名称**；
- **描述**（配置文件的用途、适用的模型、驾驶方法）；
- **积木级别**（逻辑积木）；
- **标签**；
- **收藏**（手机、平板）：收藏的配置文件会移到列表顶部。在电脑上，**收藏**位于配置文件页面的底部栏中。

<Screenshot name="edit-profile" alt="“编辑配置文件”窗口，包含图片、名称、描述和标签" width={900} />

你也可以在这里删除配置文件；登录后，还可以把它发送到目录。

程序类型无法更改。要把模型迁移到另一种编辑器，请新建一个配置文件。

## 分享（导出）配置文件 {#share-export-a-profile}

**分享…**会把配置文件打包成一个 `.dat` 文件（名称类似 `Technic Buggy_<id>.dat`），并打开系统的分享面板。你可以通过消息或电子邮件发送它，也可以把它保存到文件中。

该文件包含集线器、仪表板和程序，但不包含购买项目：接收者编辑配置文件时，其未拥有的主题和特殊控件会被替换或锁定（参见[下文](#paid-themes-in-shared-profiles)）。

## 导入配置文件 {#import-a-profile}

1. 在**我的配置文件**中选择**导入配置文件…**（手机：**+** → **导入配置文件…**；平板：**新建配置文件**菜单；电脑：**文件 → 导入配置文件…**，⌘O / Ctrl+O）。
2. 选择一个 `.dat` 文件。

如果你已经有这个配置文件：

- 版本不同：选择**替换**、**另存为副本**（在名称后添加“(copy)”）或**取消**；
- 文件完全相同：不会再次加载。

不是配置文件的文件会被拒绝。

:::tip 复制配置文件
没有单独的“复制”命令。要获得副本，请把配置文件分享为文件，然后用**另存为副本**导入。
:::

## 删除配置文件 {#delete-a-profile}

打开**编辑配置文件**：

- 手机和平板：**滑动以删除个人资料**；
- 电脑：**删除配置文件**，然后确认。配置文件卡片的菜单中也有**删除配置文件**。

配置文件会从这台设备和你的账户中删除，因此也会从你的其他设备上消失。此操作无法撤销；如果之后可能还需要它，请先把它分享为文件。

## 来自目录的配置文件 {#profiles-from-the-catalog}

从[配置文件目录](/docs/Application/Profiles/Catalog)安装的配置文件是你自己的副本：

- 只要你不修改它，它就会完全按照发布时的样子运行；作者发布新版本时，**更新**会安装新版本（**编辑配置文件**中的**从目录更新**作用相同）；
- 首次修改时会显示警告：修改之后，配置文件将不再接收目录更新。

## 共享配置文件中的付费主题 {#paid-themes-in-shared-profiles}

配置文件可以使用付费[主题](/docs/Application/Themes/ThemesOverview)和特殊控件（方向盘、踏板、变速箱等）。当你编辑一个使用了你未拥有的产品的配置文件时：

- 你未拥有的主题中的控件会切换为免费的 **基础**主题；
- 没有免费替代品的特殊控件会被锁定，直到你购买为止；
- 你已拥有的产品保持不变。

未经修改的目录配置文件会带着它的所有产品运行，即使其中有你未拥有的产品。

## 同步 {#sync}

登录后，每次更改都会上传，并出现在你的其他设备上。参见[设备间同步](/docs/Application/Account/Sync)。

如果你打开一个正在另一台设备上编辑的配置文件，MOCPilot 会请你选择：**仅查看**（更改不会保存）或**接管编辑**。
