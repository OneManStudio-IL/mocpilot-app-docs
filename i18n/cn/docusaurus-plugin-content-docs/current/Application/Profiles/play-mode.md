# 驾驶模型（运行） {#driving-a-model-run}

配置文件有两种模式：

- **编辑**：修改集线器、仪表板和程序。
- **运行**：程序运行，用仪表板控件驾驶模型。

## 启动和停止 {#start-and-stop}

按下编辑器顶栏最右端的**运行**（▶）；在手机或平板上，仪表板上也有这个按钮。在电脑上，**运行**是编辑器中的橙色按钮（也可以用**程序 → 运行**，⌘R / Ctrl+R）。按下**停止**（■）即可回到编辑状态（⌘. / Ctrl+.）。

<Screenshot name="dashboard-run" alt="程序运行时的仪表板" width={900} />

程序运行时：

- 仪表板的网格点会隐藏，它的编辑按钮也会隐藏（在电脑上则变为不可用）；
- 控件响应触摸和游戏手柄操作；
- 监视器和指示器显示实时数值；
- 在快速连接中，编辑器会在每一行的积木之间显示实时数值，此时无法编辑各行；
- 在逻辑积木中，程序仍可编辑，因此你可以实时进行微调。

## 在手机或平板上 {#on-a-phone-or-tablet}

打开配置文件时，手机会切换为横屏全屏，让仪表板占满整个屏幕。在设置中打开**保持屏幕常亮**，这样驾驶时屏幕就不会变暗。参见[设置](/docs/Application/Account/Settings)。

## 按下运行之前 {#before-you-press-run}

- 打开集线器电源，并在**我的集线器**中确认它们已连接（**我的集线器**按钮上的数字显示已连接的数量，在电脑上该按钮为**集线器**）。
- 在快速连接中，查看**问题**按钮：红色“!”表示有些行无法运行。参见[运行与修复问题](/docs/Application/Links/Problems)。
- 第一次尝试时，请把模型放在支架上，或让它远离桌子边缘。

## 程序停止时 {#when-the-program-stops}

- **快速连接**会停止各行用到的所有电机，并重置输出（清除 LED 矩阵，关闭端口颜色和传感器灯）。
- **逻辑积木**会在编辑器设置中开启了**程序停止时停止集线器端口**时停止集线器端口。
- 如果程序运行时某个集线器断开连接，它的电机会停止。在快速连接中，可以用“已连接”集线器输入在仪表板上显示这一状态。
- 使用远程控制时，如果遥控器与集线器设备之间的连接中断约 4 秒，集线器设备会停止配置文件和所有电机。

## 用另一台设备驾驶 {#drive-from-another-device}

有了 [MocPilot Pro](/docs/Application/Account/Pro)，你可以在一台设备（集线器设备，负责连接集线器）上运行配置文件，并用另一台设备或网页编辑器来控制它。参见[远程控制](/docs/Application/Profiles/RemoteControl)。
