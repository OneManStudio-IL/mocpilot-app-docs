# 配置文件 {#profiles}

**配置文件**包含 MOCPilot 所知道的关于一个模型的一切：它的集线器、仪表板和程序。每个模型保留一个配置文件。

<Screenshot name="profiles-desktop" alt="“我的配置文件”列表" width={900} />

## 配置文件从哪里来 {#where-profiles-come-from}

- **你自己的配置文件**，用**新建配置文件**创建。参见[创建配置文件](/docs/Application/Profiles/CreateProfile)。
- **来自目录的配置文件**：MOCPilot 团队为 LEGO® 套装制作的官方配置文件，以及其他玩家的社区配置文件。安装后，列表中会添加一份你自己的副本。参见[目录与发布](/docs/Application/Profiles/Catalog)。
- **导入的配置文件**：别人分享给你的 `.dat` 文件。参见[管理配置文件](/docs/Application/Profiles/ManageProfiles#import-a-profile)。

它们都在同一个列表中。

## 配置文件列表 {#the-profile-list}

该页面名为**我的配置文件**。

- **搜索**可按名称、标签、作者、集线器、套装编号或年份查找配置文件。
- **排序和筛选**可按**最新套装**、**最旧套装**、**名称 (A–Z)**、**名称 (Z–A)**、**作者 (A–Z)**、**作者 (Z–A)** 或**使用的集线器**排序。**仅我的配置文件**会隐藏从目录安装的配置文件。
- **按标签筛选**（平板和电脑）只显示带有所选标签的配置文件。
- **收藏**的配置文件始终排在最前面。

卡片会显示配置文件的图片和名称，如果已知，还会显示套装编号、发布年份和零件数量。**有可用更新**表示你可以安装目录配置文件的新版本。

## 配置文件操作 {#profile-actions}

| 操作 | 手机 | 平板 | 电脑 |
|---|---|---|---|
| 打开（启动） | 卡片上的**启动** | 连按两下卡片，或选中后轻点**启动** | 双击卡片，或选择**启动** |
| 编辑名称、图片、标签、描述 | 卡片上的**编辑** | **编辑** | **编辑…** |
| 添加到收藏 | 在**编辑配置文件**中 | **添加到收藏** | **添加到收藏** |
| 以文件形式分享 | 卡片上的**分享** | **分享** | **分享…** |
| 从目录更新 | **更新** | **更新** | **更新** |
| 发送到目录 | 在**编辑配置文件**中 | 在**编辑配置文件**中 | 在**编辑配置文件**中 |
| 删除 | **编辑配置文件**中的**滑动以删除个人资料** | 同上，或卡片菜单中的**删除配置文件** | **编辑配置文件**或卡片菜单中的**删除配置文件** |

## 两种程序 {#two-kinds-of-programs}

每个配置文件使用两种程序编辑器之一，在创建时选择：

- **快速连接**：把控件连接到电机和灯光的行，无需代码。参见[快速连接](/docs/Application/Links/LinksIntroducing)。
- **逻辑积木**：包含事件、循环、条件和变量的积木程序。参见[逻辑积木](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing)。

:::info
用较新版本的 MOCPilot 制作的配置文件，可能无法在旧版本中打开（“配置文件不兼容”）。请在该设备上更新应用。
:::
