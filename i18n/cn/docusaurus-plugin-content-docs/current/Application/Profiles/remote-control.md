# 远程控制 {#remote-control}

借助远程控制，你可以驾驶连接在另一台设备上的模型。一台设备留在模型旁边，通过蓝牙与集线器通信；你手持另一台设备，使用它的仪表板。由于浏览器无法连接集线器，在[网页编辑器](/docs/Introducing/WebEditor)中驾驶模型也是通过这种方式。

## 两台设备 {#the-two-devices}

- **集线器设备**是模型旁边的手机、平板或电脑。其上的 MOCPilot 应用负责连接集线器并运行配置文件。它不需要账户。
- **遥控器**是你用来控制的设备：另一台设备上的 MOCPilot 应用，或 [mocpilot.com](https://mocpilot.com) 上的网页编辑器。配置文件在遥控器上打开，并由遥控器发送到集线器设备。

## 你需要准备 {#what-you-need}

- **遥控器**上登录的账户需要开通 [MocPilot Pro](/docs/Application/Account/Pro)。集线器设备不需要账户，也不需要 Pro。
- 集线器设备上安装了 MOCPilot 应用。
- 两台设备都已联网。

## 连接集线器设备 {#connect-a-hub-device}

1. 在遥控器上打开配置文件，按下配置文件顶栏中**运行**旁边的**远程控制**（遥控器图标：一座带信号弧线的房子）。在网页编辑器中，在打开的面板中按下**显示代码**。

   遥控器会显示一个**连接代码**：一个二维码和 6 位数字。
2. 在集线器设备上打开 MOCPilot，在**我的配置文件**页面轻点**连接遥控器**。在 Mac 上，也可以选择**文件 → 连接遥控器…**。
3. 输入代码：
   - **在手机或平板上**，把相机对准二维码，或轻点**输入代码**并输入 6 位数字；
   - **在电脑上**，输入 6 位数字并按下**连接**。
4. 两台设备随即连接。遥控器会把配置文件发送到集线器设备并在那里启动它，集线器设备则显示全屏的**远程控制**页面。

<Screenshot name="remote-control-code" alt="已打开的配置文件中的远程控制面板，显示二维码和 6 位代码" width={900} />

关于连接代码：

- 它只能使用一次，有效期为 5 分钟。只要遥控器一直显示它，过期后就会自动换成新代码。
- 请在 MOCPilot 应用中扫描，不要用手机的相机应用扫描。
- 如果在集线器设备连接之前关闭了遥控器上的面板，就不会建立任何连接；请再次按下**远程控制**获取新代码。

<Screenshot name="remote-connect-code-entry" alt="电脑上的“连接遥控器”窗口，带有输入 6 位数字的输入框" width={900} />

## 设备连接后 {#when-the-devices-are-connected}

**在遥控器上：**

- **远程控制**按钮变为绿色（在手机或平板上为绿色圆环），其面板会显示集线器设备的名称和**断开连接**按钮。
- **我的集线器**显示集线器设备的集线器。像平常一样在这里连接集线器：由集线器设备进行搜索，因此在提示时请按下集线器上的按钮。
- 仪表板用于控制模型。

**在集线器设备上**，全屏的**远程控制**页面会显示：

- 状态，例如**正在运行“我的车”**；
- **已连接集线器：N**，搜索时还会显示**正在查找集线器：请按下集线器上的按钮。**；
- 一条提醒：**请保持此应用打开。这是集线器设备：它连接集线器并运行配置文件，遥控器只负责控制。**；
- 一个**停止**按钮。

连接期间，集线器设备的屏幕会保持常亮。配置文件不会保存在集线器设备上，也不会出现在它的配置文件列表中。

<Screenshot name="remote-hub-device" alt="集线器设备上的全屏远程控制页面，显示连接状态、已连接集线器数量和停止按钮" width={900} />

## 运行和停止 {#run-and-stop}

- 在遥控器上按下**停止**，即可停止集线器设备上的配置文件。集线器设备总会停止所有电机，即使配置文件中关闭了**程序停止时停止集线器端口**。
- 在遥控器上按下**运行**，即可在集线器设备上再次启动它。
- 在网页编辑器中，对于在同一个浏览器标签页中打开的每个配置文件，集线器设备都保持配对：**运行**会在集线器设备上启动配置文件。未配对集线器设备时，**运行**会在浏览器中运行配置文件，不连接集线器。

## 如果连接中断 {#if-the-connection-drops}

:::caution 安全
如果集线器设备 4 秒内没有收到遥控器的任何消息，它会停止配置文件和所有电机。
:::

随后：

- 集线器设备会显示**与遥控器的连接已断开。配置文件已停止。正在等待遥控器…**并等待；
- 遥控器上的应用会显示**连接已断开。正在重试…**，以及**重试**和**断开连接**；
- 网页编辑器会显示**集线器设备已断开连接**：“*设备* 停止响应。其上的配置文件已停止，电机已关闭。”它会持续尝试重新连接；你也可以按下**重新连接**、**在浏览器中运行**或**停止**。

设备重新连接后，请在遥控器上检查状态，如果配置文件没有在运行，请按下**运行**。

## 断开连接 {#disconnect}

- **在遥控器上**：按下**远程控制**，然后选择**断开连接**。
- **在集线器设备上**：在**远程控制**页面按下**停止**。

无论哪种方式，配置文件和电机都会停止，集线器设备会关闭配置文件。

## 故障排除 {#troubleshooting}

| 消息 | 位置 | 处理方法 |
|---|---|---|
| **远程控制是 MocPilot Pro 的一部分** | 遥控器 | 为遥控器的账户订阅 [MocPilot Pro](/docs/Application/Account/Pro)。无法在浏览器中订阅：请在应用中订阅，Pro 在网页编辑器中同样有效 |
| **无法连接到服务器** | 任一设备 | 检查网络连接，然后重试 |
| **无法从服务器获取代码** | 遥控器 | 按下**显示代码**重试 |
| **代码错误或已过期。请核对遥控器上显示的 6 位数字。** | 集线器设备 | 输入遥控器当前显示的 6 位数字 |
| **代码已过期。请在遥控器上显示新代码并重新扫描。** | 集线器设备 | 在遥控器上按下**远程控制**，然后扫描新代码 |
| **这不是 MOCPilot 代码。请扫描遥控器显示的代码。** | 集线器设备 | 扫描遥控器**远程控制**面板中的二维码 |
| **错误代码过多。请几分钟后重试。** | 集线器设备 | 等待几分钟，然后输入当前代码 |
| **请在系统设置中允许 MOCPilot 使用相机以扫描代码。** | 集线器设备 | 在系统设置中允许访问相机，或轻点**输入代码**并输入 6 位数字 |
| **遥控器没有响应。请检查其上是否已打开配置文件，以及是否在线。** | 集线器设备 | 在遥控器上保持配置文件打开，并检查它的网络连接 |
| **此版本的应用无法连接到遥控器** | 任一设备 | 更新 MOCPilot |
| **此浏览器无法建立直接连接（WebRTC）** | 网页编辑器 | 换用其他浏览器，例如 Chrome、Edge 或 Safari |
| **配置文件过大** / **配置文件未完整接收** | 任一设备 | 检查网络连接，然后再次按下**运行** |
| **另一台设备无法保存配置文件** / **另一台设备无法打开配置文件** | 遥控器 | 再次按下**运行**；如果问题反复出现，请断开并重新连接集线器设备 |
| **与*设备*的连接已断开** / **与遥控器的连接已断开。正在等待…** | 任一设备 | 参见[如果连接中断](#if-the-connection-drops) |
