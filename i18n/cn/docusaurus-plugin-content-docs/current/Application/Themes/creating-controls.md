# 用主题创建控件 {#create-controls-from-a-theme}

你添加的每个控件都基于某个主题。你可以在添加之前对它进行配置，并把配置好的控件保存为你自己的设计。

## 添加前先配置 {#configure-before-adding}

1. 打开**添加控制器**（仪表板上的 **+**）。
2. 选择一种控件类型，并在外观条中选择一种外观。
3. 在**配置**中，使用**样式**和**设置**标签页：大小（面板中显示为“宽 x 高 点”）、重点颜色、图标、主题选项、行为。
4. 轻点**添加到仪表板**。

## 保存设计 {#save-a-design}

当你找到满意的组合时（比如一个带喇叭图标的红色赛车风格按钮），就把它保存下来：

1. 选择一个属于你已拥有主题的、已配置好的控件。
2. 轻点**保存设计**。
3. 该设计会出现在**我的设计** → **已保存的设计**中。轻点一下即可把它添加到任意配置文件的仪表板上。

**删除**会移除已保存的设计。

## 在仪表板上复制控件 {#copy-controls-on-the-dashboard}

- **复制**会复制控件及其所有属性。
- **仅复制类型**会添加一个使用默认属性的同类型控件。
- **更改主题**会把控件切换到你已拥有的另一个主题，而不会改变它的位置或与程序的连接。

## 好用的仪表板 {#a-good-dashboard}

- 把驾驶控件放在拇指下方：一侧放操纵杆或踏板，另一侧放转向控件。
- 最常用的控件使用 **L** 尺寸，不常用的使用 **S** 尺寸。
- 每种功能使用一种重点颜色：绿色表示驾驶，黄色表示灯光，红色表示停止。
- 布局完成后锁定控件（**锁定所有**）。
- 添加一个电量监视器，这样你就知道何时该充电了。
