# 获取、购买和更新主题 {#get-buy-and-update-themes}

没有单独的商店页面：你可以直接在使用主题的地方，也就是仪表板的**添加控制器**面板中浏览和购买主题。

## 试用主题 {#try-a-theme}

1. 打开仪表板，轻点 **+**（**添加控制器**；在电脑上为 **+ 控制器**）。
2. 选择一种控件类型，例如操纵杆。外观条会显示它在每个主题中的样子；特殊控件位于**车辆与特殊**中。
3. 轻点某个外观即可在大预览图中查看并试用。在**配置**中，可以试试不同的颜色、尺寸和选项。

在 mocpilot.com 上的[网页编辑器演示](/docs/Introducing/WebEditor)中，你甚至可以把付费控件放到仪表板上进行试用。

## 购买 {#buy}

对于你未拥有的主题，面板会显示：

- **购买 &lt;价格&gt;**：一次性购买此主题（或此特殊控件），永久归你所有；
- **MocPilot Pro 全拥有**：通过订阅获得所有主题和特殊控件。参见 [MocPilot Pro](/docs/Application/Account/Pro)。

购买通过 App Store、Google Play 或 Microsoft Store 完成，并归属于你的 MOCPilot 账户，因此你需要登录。购买项目可在你的所有设备和网页编辑器中使用。

## 安装和更新 {#install-and-update}

主题无需手动安装。登录后，MOCPilot 会下载你拥有的主题并保持更新。免费的基础主题内置于应用中。

如果缺少某个主题：

- 检查网络连接，并确认你登录的是正确的账户；
- 前往**账户 → 购买**，轻点**恢复**（恢复购买）；
- 重新启动应用。

## 包含你未拥有主题的配置文件 {#profiles-with-themes-you-dont-own}

- 从[目录](/docs/Application/Profiles/Catalog)安装的配置文件，只要你不修改，就会带着它的所有主题运行。
- 当你编辑包含未拥有主题的配置文件时，这些控件会切换为基础主题，特殊控件（方向盘、踏板等）则会保持锁定，直到你购买为止。

## 其他商店 {#alternative-stores}

在**账户 → 购买 → 购买设置**中，你可以为付款页面开启**使用其他商店**和**在系统浏览器中打开**。它们适用于常规应用商店不可用的地区。
