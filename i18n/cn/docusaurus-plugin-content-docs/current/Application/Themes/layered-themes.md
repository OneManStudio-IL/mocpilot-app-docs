# 分层主题 {#layered-themes}

付费主题和[特殊控件](/docs/Application/Dashboard/SpecialControls)采用**分层**格式。分层控件由多个叠放的图层绘制而成，而不是一张图片：

- **图像**图层：主体、边框、玻璃和阴影，均已预先处理好效果；
- **形状和弧线**：随数值变化的圆环、刻度和进度弧；
- **文本和图标**：标签、数字以及你选择的图标；
- **监视器文本**：监视器显示的文本。

应用会实时组合这些图层：滑块的滑柄在轨道上移动，速度计的指针转动，弧线逐渐填满，重点颜色为相应的图层着色。

## 这能带来什么 {#what-this-gives-you}

- **任何尺寸都清晰**：S、M、L 以及任意屏幕像素密度。
- **你的颜色**：重点颜色和主题选项可以改变外观，无需新的图形。
- **流畅又轻量**：每个控件只用几张图像，因此即使在较旧的手机上，仪表板也能保持流畅。
- **行为一致**：任何主题的操纵杆都与基础主题的操纵杆表现完全相同，因此你无需改动程序即可更换主题。

## 版本和兼容性 {#versions-and-compatibility}

主题会不定期在服务器上更新：新增控件、修复问题、改进图形。应用会下载它能显示的最新版本。旧版应用会继续获取为其制作的版本，因此主题永远不会在更新后失效。要获得最新外观，请保持 MOCPilot 为最新版本。
