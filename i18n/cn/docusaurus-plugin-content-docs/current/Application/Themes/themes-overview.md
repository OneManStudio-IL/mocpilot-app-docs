# 什么是主题 {#what-is-a-theme}

**主题**是仪表板控件的视觉风格。各主题共享相同的控件类型（操纵杆、滑块、按钮、开关、步进开关、监视器），工作方式也完全相同；只有外观不同。

你可以在同一个仪表板上混用多个主题：每个控件都有自己的主题。

## 可用的主题 {#available-themes}

**基础**主题免费，并内置于应用中。它包含操纵杆、方向键、滑块、垂直滑块、按钮、开关、步进开关、垂直步进开关和监视器。

每个**付费主题**都包含基础主题的所有控件，另外还有**旋钮**、**电池电量**、**速度计**和**倾斜监视器**，并且全部以该主题自己的风格绘制。付费主题包括：

光环、积木、沙滩车、建筑机械、电路核心、城市小车、经典、经典四驱、概念车、深空、方程式、重型牵引、重型卡车、高保真音频、高科技、全息、长途卡车、迈阿密、新轨道、越野驾驶室、越野车、赛车、拉力赛、复古、攀岩车、轿车、日落、超级跑车、战术和越野工作车。

新主题会不定期推出；它们会自动出现在面板中。

每个付费主题还附带同样风格的现成**仪表板背景**。参见[仪表板设置](/docs/Application/Dashboard/DashboardOverview#dashboard-settings)。

**特殊控件**是单独的产品：方向盘、踏板、换挡杆、手刹、转向灯和列车控制器。它们大多为每个付费主题都提供了相应的外观。参见[特殊控件](/docs/Application/Dashboard/SpecialControls)。

所有付费主题和特殊控件都包含在 [MocPilot Pro](/docs/Application/Account/Pro) 中。

## 主题选项 {#theme-options}

有些主题在控件的**样式**标签页中有自己的选项：

- 赛车：**彩色碳**、**彩色边框**、**显示赛车线**；
- 建筑机械：**指示器段数**；
- 光环：**显示值**。

## 更改控件的主题 {#change-the-theme-of-a-control}

长按（或右键单击）控件 → **更改主题**，或者使用其属性中的**更改主题**。你可以切换到任何你已拥有、且有相同控件类型的主题。位置、大小以及与程序的连接都保持不变。
