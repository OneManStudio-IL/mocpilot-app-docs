# 用快速连接制作你的第一辆遥控车 {#your-first-rc-car-with-quick-links}

在本教程中，你将在[快速连接](/docs/Application/Links/LinksIntroducing)中制作一辆完整的遥控车：一个操纵杆负责驾驶和转向，一个按钮负责开关车灯。整个过程大约 15 分钟，而且不需要编写任何代码。

**你需要准备**

- 一个 LEGO® Technic™ 集线器（88012）；
- 一个接在**端口 A** 上的驱动电机；
- 一个接在**端口 B** 上、带位置传感器（编码器）的转向电机，例如 Technic L 或 XL 电机，或任意 Technic 角度电机。转向机构必须有限位：车轮向左和向右只能转到一定角度；
- 接在**端口 C** 上的 LEGO® 灯（可选）；
- 安装了 MOCPilot 并带有蓝牙的手机、平板或电脑。

:::note City 集线器
City 集线器（88009）只有两个端口。把驱动电机接在 **A** 上、转向电机接在 **B** 上，并跳过车灯，或者为车灯再添加一个集线器。其余步骤完全相同。
:::

**最终效果**：一个包含三行的配置文件：

| # | 输入 | 处理 | 操作 | 输出 |
|---|---|---|---|---|
| 1 | JOY1，Y 轴 | 平滑 | 电机 | Technic Hub，端口 A |
| 2 | JOY1，X 轴 | | 舵机（自动） | Technic Hub，端口 B |
| 3 | BTN1 | 切换 | 灯光 | Technic Hub，端口 C |

## 1. 创建配置文件 {#create-the-profile}

1. 前往**我的配置文件**并新建一个配置文件：在手机上轻点 **+** → **新建配置文件**；在平板上轻点页眉中的**新建配置文件**；在电脑上选择**文件 → 新建配置文件**。
2. 选择**快速连接**磁贴。
3. 输入**名称**，例如“我的第一辆车”。图片和标签暂时可以不填。
4. 轻点**创建**。配置文件会在快速连接编辑器中打开，其中有一个空行。

程序类型之后无法更改。更多内容请参见[创建配置文件](/docs/Application/Profiles/CreateProfile)。

## 2. 添加并连接集线器 {#add-the-hub}

1. 在编辑器中轻点**我的集线器**（在电脑上为顶栏中的**集线器**）。
2. 在空闲槽位中轻点**添加新集线器**，在列表中选择 Technic Hub，然后轻点**添加**。
3. 打开集线器电源并按下它的按钮。MOCPilot 会找到并连接它；集线器会一直保留在该槽位中。
4. 如果出现**需要更新固件**对话框，请轻点**更新**，并让集线器保持开机、放在附近，直到更新完成。参见[固件更新](/docs/Application/Hubs/FirmwareUpdating)。

提示：打开已连接的集线器即可查看它的[集线器监视器](/docs/Application/Hubs/ConnectingHubs#hub-monitor)。它会显示每个端口上接了什么设备，方便你在搭建各行之前先检查电机。

更多内容请参见[添加并连接集线器](/docs/Application/Hubs/ConnectingHubs)。

## 3. 在仪表板上放置控件 {#dashboard}

1. 打开**仪表板**，轻点 **+**（**添加控制器**；在电脑上为 **+ 控制器**）。
2. 在**操纵杆**分组中选择**操纵杆**，然后轻点**添加到仪表板**。它的名称是 **JOY1**。**轴类型**保持为**两个方向 (X, Y)**：上下用于驾驶，左右用于转向。
3. 再次轻点 **+**。在**按钮和开关**中选择**按钮**，然后轻点**添加到仪表板**。它的名称是 **BTN1**。
4. 把操纵杆拖到左侧、按钮拖到右侧，也就是拇指所在的位置。轻点控件可以更改它的大小（**S**、**M** 或 **L**）或外观。

<Screenshot name="tutorial-car-dashboard" alt="仪表板：左侧是 JOY1 操纵杆，右侧是 BTN1 按钮" width={900} />

更喜欢用两个拇指分别驾驶和转向？那就改为添加两个操纵杆：**JOY1** 设为**仅垂直 (Y)**，**JOY2** 设为**仅水平 (X)**，并在转向行中使用 JOY2。

更多内容请参见[添加和排列控件](/docs/Application/Dashboard/ArrangingControls)和[控件类型](/docs/Application/Dashboard/ControlTypes)。

### 可选：方向盘和踏板 {#wheel-and-pedals}

如果你拥有**方向盘**和**踏板**[特殊控件](/docs/Application/Dashboard/SpecialControls)，可以用它们代替操纵杆。在第 4 步中，第 1 行使用[车辆](/docs/Application/Links/Blocks/InputBlocks#src-vehicle)输入，并把**输出**设为**速度**（它会像真车一样加速和减速，因此不需要平滑）；第 2 行使用**方向盘**输入，并选择**转向角度**通道。

## 4. 搭建各行 {#rows}

回到程序。底部的面板有三个标签页：**输入**、**处理**和**输出**。每一行从左到右运行：输入 → 处理 → 操作 → 集线器。编辑器的使用方法请参见[快速连接简介](/docs/Application/Links/LinksIntroducing)。

### 第 1 行：驱动 {#row-drive}

1. 在**输入**中，把通道为 **Y 轴**的 **JOY1** 拖到空行（“新行：输入”）。下方会出现一个新的空行。
2. 在**处理**中，把**平滑**拖到输入之后。默认的**加速（到全速）**和**减速（到停止）**均为 0.5 秒，是个不错的起点。
3. 在**输出**中，把**电机**拖到平滑之后。
4. 把 **Technic Hub** 输出拖到电机之后，然后轻点 **A** 端口标签。

### 第 2 行：转向 {#row-steering}

1. 把通道为 **X 轴**的 **JOY1** 拖到下一个空行。
2. 从**输出**中拖入**舵机**。
3. 轻点舵机积木，把**校准**设为**自动**。
4. 把 **Technic Hub** 输出拖到舵机之后，然后轻点 **B**。

在**自动**模式下，每次程序启动时，转向电机都会转到两端的限位；中间位置成为中心，行程成为转向角度。想立即试一试，可以在集线器已连接时，在舵机设置中轻点**立即校准**。如果校准失败，请检查集线器、电机，以及转向机构是否确实有限位。

<Screenshot name="links-servo-settings" alt="舵机积木的设置" width={900} />

没有限位？请使用**手动**：用手把车轮摆正，轻点**设为零点**，然后选择**角度**。参见[舵机](/docs/Application/Links/Blocks/OutputBlocks#op-servo)。

### 第 3 行：车灯 {#row-lights}

1. 把 **BTN1** 拖到下一个空行。
2. 从**处理**中拖入**切换**。它会把按钮变成开关：按一次打开，再按一次关闭。
3. 从**输出**中拖入**灯光**。
4. 把 **Technic Hub** 输出拖到灯光之后，然后轻点 **C**。

<Screenshot name="tutorial-car-links-rows" alt="小车完成后的三行：驱动、转向和车灯" width={900} />

三行全部就绪后，顶栏中的**问题**按钮（紧挨在**运行**之前）会显示绿色对勾。红色“!”表示还剩几个问题；轻点它，再轻点某个问题，即可跳转到对应的行。参见[运行与修复问题](/docs/Application/Links/Problems)。

## 5. 运行和测试 {#run}

1. 把车放在支架上，或用手拿着，让车轮离开桌面。
2. 按下**运行**。转向电机会进行校准：先转向两侧，再回到中间。
3. 上下推动操纵杆：车会前进和后退，起步和停车都很平稳。左右移动操纵杆：车轮随之转向。
4. 按下 **BTN1**：车灯打开。再按一次：车灯关闭。
5. 按下**停止**即可回到编辑状态。

程序运行时，积木之间的每个连接点都会显示经过它的数值，你可以跟踪信号从操纵杆一路传到集线器。

<Screenshot name="links-live-values" alt="正在运行的快速连接程序，连接点上显示实时数值" width={900} />

更多内容请参见[驾驶模型（运行）](/docs/Application/Profiles/PlayMode)。

## 6. 微调 {#tune}

请先按下**停止**：程序运行时无法编辑各行。

- **向上推时车却在后退？**在第 1 行中添加**反转**。如果车轮转向方向反了，在第 2 行中也可以这样做。
- **松开操纵杆后电机仍在嗡嗡响或缓慢移动？**在第 1 行的平滑之前添加**死区**。默认的**区域**为 10%，是个不错的起点。
- **太快了？**在第 1 行中添加**限制**，例如把**最大值**设为 50%。
- **反应太迟钝？**轻点平滑并选择更短的时间，或选择**即时**。

驱动行比较合适的顺序是*死区 → 限制 → 平滑*。所有设置请参见[处理积木](/docs/Application/Links/Blocks/ProcessingBlocks)。

## 7. 可选：使用游戏手柄驾驶 {#gamepad}

1. 在系统的蓝牙设置中，把 Xbox 或 PlayStation 风格的游戏手柄与设备配对。
2. 在编辑器中打开**游戏手柄**，并开启**启用游戏手柄块**。
3. 在每一行中，把仪表板输入拖回面板将其移除，再把**游戏手柄**输入拖到它的位置。设置它的**输入**：第 1 行为**左摇杆 Y**，第 2 行为**右摇杆 X**，第 3 行为 **A**（PlayStation 上为**叉**）。

每个端口只能属于一行，因此一行要么用仪表板驱动端口，要么用游戏手柄驱动端口。更多内容请参见[游戏手柄](/docs/Application/Dashboard/Gamepad)。

## 如果有部件不动 {#if-something-does-not-move}

1. 集线器连接了吗？检查**我的集线器**以及集线器积木上的连接指示点。
2. 电机是否插在各行中所选的端口上？
3. **问题**按钮是否显示绿色对勾？每一行是否都已开启？
4. 程序是否正在运行？
5. 运行程序并观察实时数值：如果输入处的数值有变化而电机不转，请检查集线器和端口。

如果出现“端口 B：此设备不能用作舵机（需要带编码器的电机）”之类的消息，说明该端口上的电机没有编码器。更多消息及解决方法请参见[运行与修复问题](/docs/Application/Links/Problems)和[故障排除](/docs/Help/Troubleshooting)。

## 8. 保存和分享 {#save-and-share}

没有保存按钮：配置文件会自动保留你的更改。登录后，它还会[同步](/docs/Application/Account/Sync)到你的其他设备。

- **以文件形式分享**：在**我的配置文件**中，轻点配置文件卡片上的**分享**（电脑上为**分享…**）。你会得到一个 `.dat` 文件，可以发送给朋友。参见[管理配置文件](/docs/Application/Profiles/ManageProfiles)。
- **发布到目录**：打开**编辑配置文件**，轻点**发送到目录**。请先添加图片、描述和标签。参见[目录与发布](/docs/Application/Profiles/Catalog)。
