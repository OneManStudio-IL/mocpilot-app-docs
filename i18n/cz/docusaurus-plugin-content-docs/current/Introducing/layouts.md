# Telefon, tablet a počítač {#phone-tablet-and-desktop}

MOCPilot má tři rozložení a aplikace jedno z nich vybere automaticky:

- **Telefon**: telefony iPhone a Android.
- **Tablet**: tablety iPad a Android (od 7 palců).
- **Počítač**: počítače Mac a Windows. [Webový editor](/docs/Introducing/WebEditor) v prohlížeči používá také editor pro počítač.

Profily, editory i panel jsou všude stejné; liší se jen navigace.

## Telefon {#phone}

<Screenshot name="profiles-phone" alt="Stránka Moje profily na telefonu se spodní lištou" width={360} />

- **Spodní lišta** obsahuje **Profily**, **Nastavení** a **Nápověda** a po přihlášení také **Oznámení**.
- **Účet** najdete nahoře v **Nastavení**.
- V záhlaví **Moje profily** je **Řazení a filtr**, **Připojit dálkový ovladač** (ikona dálkového ovladače), **+** (Nový profil, Importovat profil…, Hledat online) a pole hledání.
- Hlavní obrazovky jsou na výšku. Když otevřete profil, aplikace se přepne **na šířku a na celou obrazovku**, aby editor a panel měly celou plochu. Po zavření profilu se vrátí zobrazení na výšku.
- V editoru dávají kulatá tlačítka podél horního okraje rychlý přístup k těmto funkcím: Domů, Zpět, Znovu, AI tvůrce, Nastavení editoru, Problémy (Rychlá propojení), Herní ovladač, Moje huby, Dálkové ovládání, Panel, Monitor (Logické bloky) a Spustit / Zastavit.

<Screenshot name="editor-phone" alt="Editor profilu na telefonu s kulatými tlačítky podél horního okraje" width={900} />

## Tablet {#tablet}

<Screenshot name="profiles-tablet" alt="Stránka Moje profily na tabletu s bočním panelem" width={900} />

- **Boční panel** vlevo obsahuje **Profily**, **Katalog profilů**, **Oznámení**, **Nastavení** a **Nápověda**. Pod nimi je karta **MocPilot Pro** a váš účet (v režimu hosta **Přihlásit se**). Boční panel můžete sbalit na ikony.
- V záhlaví **Moje profily** je **Nový profil** (jeho nabídka obsahuje také Importovat profil…, Připojit dálkový ovladač a Hledat online), **Řazení a filtr**, **Filtrovat podle hashtagů**, **Připojit dálkový ovladač** a pole hledání.
- Klepnutím na kartu profilu ji vyberete: lišta dole zobrazí **Sdílet**, **Upravit**, **Přidat do oblíbených** a **Spustit**. Dvojitým klepnutím profil spustíte. Dlouhým stisknutím karty otevřete její nabídku, která obsahuje také **Smazat profil**.
- Na širokých obrazovkách se Nastavení a Nápověda otevírají vedle seznamu.
- Profil se otevře na šířku a editor má stejná kulatá tlačítka jako na telefonu.

## Počítač (Mac a Windows) {#desktop-mac-and-windows}

<Screenshot name="profiles-desktop" alt="Moje profily na počítači" width={900} />

- Vpravo na horní liště: **Účet** (v režimu hosta **Přihlásit se**), **Oznámení** (když jste přihlášeni), **Připojit dálkový ovladač** (ikona dálkového ovladače) a **Nastavení** (ozubené kolo).
- Nastavení, Nápověda, Účet, Nový profil, Upravit profil, Katalog profilů a další stránky se otevírají jako **okna** nad seznamem profilů.
- Kliknutím na kartu profilu uvidíte, co s ním můžete dělat (**Sdílet…**, **Upravit…**, **Přidat do oblíbených**, **Spustit**); dvojklikem ho spustíte. Kliknutím pravým tlačítkem na kartu otevřete její nabídku, která obsahuje také **Smazat profil**.
- V editoru se **Panel** otevírá ve **vlastním okně**, takže program a panel vidíte vedle sebe.

### Nabídky {#menus}

Ve Windows jsou nabídky vlevo na horní liště aplikace. Na Macu jsou v systémovém řádku nabídek nahoře na obrazovce.

| Nabídka | Windows | Mac |
|---|---|---|
| **MOCPilot** (nabídka aplikace) | — | O aplikaci MOCPilot, Nastavení…, Ukončit |
| **Soubor** | Nový profil, Importovat profil…, Hledat online, Ukončit | Nový profil, Importovat profil…, Hledat online, Připojit dálkový ovladač… |
| **Zobrazení** | Celá obrazovka | Celá obrazovka / Ukončit celou obrazovku |
| **Okno** | Minimalizovat, Maximalizovat / Obnovit | Minimalizovat |
| **Nápověda** | Nápověda MOCPilot, Položit otázku, Nahlásit chybu, O aplikaci MOCPilot | Nápověda MOCPilot, Položit otázku, Nahlásit chybu |

Když je otevřený profil, má editor vlastní nabídky **Soubor**, **Upravit**, **Zobrazení** a **Program** (viz [Nabídky na počítači](/docs/Application/BlockBuilder/Editor#desktop-menus)) a okno Panelu má nabídky **Soubor**, **Upravit** a **Zobrazení** (viz [Panel](/docs/Application/Dashboard/DashboardOverview)).

### Klávesové zkratky {#keyboard-shortcuts}

Na Macu dělá ⌘ (Command) totéž co Ctrl ve Windows; ⇧ je Shift, ⌃ je Control.

**Všude**

| Akce | Windows | Mac |
|---|---|---|
| Nastavení | Ctrl+2 | ⌘, |
| Zapnout / vypnout celou obrazovku | F11 nebo Alt+Enter | ⌃⌘F |
| Minimalizovat okno | — | ⌘M |
| Ukončit | Alt+F4 | ⌘Q |

**Moje profily** (žádný profil není otevřený)

| Akce | Windows | Mac |
|---|---|---|
| Nový profil | Ctrl+N | ⌘N |
| Importovat profil | Ctrl+O | ⌘O |
| Hledat profily | Ctrl+F | — |
| Profily / Nastavení / Nápověda / Účet | Ctrl+1 / Ctrl+2 / Ctrl+3 / Ctrl+4 | — |

**Editor profilu**

| Akce | Windows | Mac |
|---|---|---|
| Zavřít profil | Ctrl+W | ⌘W |
| Spustit / Zastavit | Ctrl+R / Ctrl+. | ⌘R / ⌘. |
| Zpět / Znovu | Ctrl+Z / Ctrl+Shift+Z nebo Ctrl+Y | ⌘Z / ⇧⌘Z |
| Zobrazit panel | Ctrl+2 | ⌘2 |
| Moje huby | Ctrl+Shift+H | ⇧⌘H |
| AI tvůrce | Ctrl+Shift+I | ⇧⌘I |
| Zobrazit / skrýt paletu bloků (Logické bloky) | Ctrl+P | ⌘P |
| Hledat v paletě bloků (Logické bloky) | Ctrl+F | ⌘F |
| Monitor (Logické bloky) | Ctrl+Shift+M | ⇧⌘M |
| Přiblížit / oddálit / skutečná velikost (Logické bloky) | Ctrl++ / Ctrl+− / Ctrl+0 | ⌘+ / ⌘− / ⌘0 |

**Panel**

| Akce | Windows | Mac |
|---|---|---|
| Zpět / Znovu | Ctrl+Z / Ctrl+Shift+Z nebo Ctrl+Y | ⌘Z / ⇧⌘Z |
| Zpět k programu (když je panel v hlavním okně) | Ctrl+1 | ⌘1 |
| Zavřít okno Panelu | — | ⌘W |
| Ukončit režim **Vybrat** nebo zavřít panel vlastností | Esc | Esc |
| Smazat ovládací prvek (s otevřeným panelem vlastností) | Delete nebo Backspace | Delete nebo Backspace |
| Duplikovat ovládací prvek (s otevřeným panelem vlastností) | Ctrl+D | ⌘D |

Na tabletu s klávesnicí zobrazí nebo skryje boční panel zkratka Ctrl+B (⌘B na iPadu).

## Editor profilu ve všech rozloženích {#the-profile-editor-on-every-layout}

Editor nemá karty. Celou obrazovku vyplňuje **program** (řádky Rychlých propojení nebo Logické bloky) a vše ostatní otevírají tlačítka:

| Tlačítko | Otevře |
|---|---|
| **Moje huby** | [sloty pro huby](/docs/Application/Hubs/ConnectingHubs) v profilu |
| **Panel** | [panel](/docs/Application/Dashboard/DashboardOverview) |
| **Herní ovladač** | [nastavení herního ovladače](/docs/Application/Dashboard/Gamepad) |
| **Monitor** | hodnoty proměnných a seznamů (jen Logické bloky) |
| **Nastavení editoru** | [možnosti editoru](/docs/Application/BlockBuilder/Editor#editor-settings) |
| **AI tvůrce** | [AI tvůrce](/docs/Application/Profiles/AiBuilder) (MocPilot Pro) |
| **Problémy** | řádky, které nelze spustit (jen Rychlá propojení) |
| **Dálkové ovládání** | spuštění profilu na jiném zařízení a jeho ovládání odsud (MocPilot Pro); viz [Dálkové ovládání](/docs/Application/Profiles/RemoteControl) |
| **Spustit / Zastavit** | spouští a zastavuje program |
