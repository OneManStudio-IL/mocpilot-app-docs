# Einstellungen {#settings}

So öffnen Sie die Einstellungen:

- **Smartphone**: **Einstellungen** in der unteren Leiste.
- **Tablet**: **Einstellungen** in der Seitenleiste.
- **Computer**: die Zahnrad-Schaltfläche in der oberen Leiste. Auf dem Mac können Sie auch **MOCPilot → Einstellungen…** (⌘,) wählen; unter Windows drücken Sie Strg+2. Die Einstellungen öffnen sich in einem eigenen Fenster.

## Konto {#account}

Auf einem Smartphone zeigen die Einstellungen oben Ihr Konto an, im Gastmodus **Konto erstellen oder anmelden**. Auf einem Tablet befindet sich das Konto unten in der Seitenleiste, auf einem Computer ist es die Schaltfläche **Konto** in der oberen Leiste. Siehe [Konto](/docs/Application/Account/UserAccount).

## Einstellungen {#settings}

| Einstellung | Funktion |
|---|---|
| **Ton** | Töne der App und der Steuerelemente (zum Beispiel Effekte von Lenkrad und Pedalen) |
| **Vibration** | eine kurze Vibration, wenn Sie Steuerelemente berühren; nur auf Smartphones, die vibrieren können |
| **Bildschirm eingeschaltet lassen** | verhindert, dass sich der Bildschirm ausschaltet, solange ein Profil geöffnet ist; schalten Sie es zum Fahren ein. Auf iPhone, iPad, Android und Windows (nicht auf dem Mac) |
| **Sprache** | die Sprache der App; siehe [Sprache](#language) unten |
| **Dunkelmodus** | dunkles oder helles Erscheinungsbild. Beim ersten Start entspricht es dem Erscheinungsbild Ihres Geräts |

Die Fernsteuerung befindet sich nicht in den Einstellungen: Damit ein anderes Gerät dieses Gerät steuern kann, verwenden Sie **Fernbedienung verbinden** auf der Seite **Meine Profile**. Siehe [Fernsteuerung](/docs/Application/Profiles/RemoteControl).

## Sprache {#language}

Beim ersten Start verwendet MOCPilot die Sprache Ihres Geräts, sofern die App sie anbietet, andernfalls Englisch. So ändern Sie sie:

- **Smartphone und Tablet**: Tippen Sie auf **Sprache** und dann auf eine Sprache. Die App wechselt sofort. Die Liste zeigt die Sprache, die Sie bereits verwenden, nicht an.
- **Computer**: Klicken Sie auf **Sprache**, klicken Sie auf eine Sprache (sie erhält ein ✓; bei der aktuell verwendeten steht **Aktuell**) und klicken Sie dann auf **Übernehmen** oder drücken Sie die Eingabetaste. **Abbrechen** oder Esc behält die aktuelle Sprache bei.

## Barrierefreiheit {#accessibility}

Die Schaltflächen der App haben Namen, die Screenreader (VoiceOver auf Apple-Geräten, TalkBack unter Android) vorlesen. Das gilt auch für Schaltflächen, die nur ein Symbol zeigen, etwa **Zurück**, **Schließen**, **Einstellungen** oder **Rückgängig**.

## Info {#about}

Auf einem Smartphone oder Tablet öffnet **Version** unten in den Einstellungen **Über MOCPilot** mit Datenschutzerklärung, Nutzungsbedingungen und Versionshinweisen / Neuigkeiten. Auf einem Computer verwenden Sie **Hilfe → Über MOCPilot** in der oberen Leiste (auf dem Mac **MOCPilot → Über MOCPilot**).

## Profileinstellungen {#profile-settings}

Einstellungen, die zu einem einzelnen Profil gehören, finden Sie im Editor:

- **Editor-Einstellungen**: Blockstufe, Block per Klick starten, Hub-Ports beim Programmstopp stoppen; siehe [Arbeiten im Editor](/docs/Application/BlockBuilder/Editor#editor-settings);
- **Dashboard-Einstellungen**: Hintergrund und Raster; siehe [Dashboard](/docs/Application/Dashboard/DashboardOverview#dashboard-settings);
- **Gamepad**: siehe [Gamepad](/docs/Application/Dashboard/Gamepad).

Wenn Sie angemeldet sind, sind die App-Einstellungen auf all Ihren Geräten gleich. Siehe [Synchronisierung zwischen Geräten](/docs/Application/Account/Sync).
