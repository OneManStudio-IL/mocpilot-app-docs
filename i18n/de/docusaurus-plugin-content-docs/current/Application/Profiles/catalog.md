# Katalog und Veröffentlichen {#catalog-and-publishing}

Der **Profilkatalog** ist eine Bibliothek fertiger Profile: offizielle Profile für LEGO®-Sets vom MOCPilot-Team und Profile aus der Community, die andere Baumeister teilen. Es ist derselbe Katalog wie auf [mocpilot.com](https://mocpilot.com).

## Katalog öffnen {#open-the-catalog}

- Smartphone: **+** → **Online suchen** auf der Seite **Meine Profile**.
- Tablet: **Profilkatalog** in der Seitenleiste oder **Online suchen** im Menü **Neues Profil**.
- Computer: **Datei → Online suchen**.

Der Katalog benötigt eine Internetverbindung. Kann er auf Ihrem Gerät nicht in der App angezeigt werden, tippen Sie auf **Im Browser öffnen**.

Sie können den Katalog nach Name, Beschreibung, Hashtags, Autor und Setnummer durchsuchen. Die Karten zeigen, wie oft ein Profil heruntergeladen wurde.

## Ein Profil installieren {#install-a-profile}

Öffnen Sie ein Profil im Katalog und fügen Sie es hinzu. Eine Kopie erscheint in Ihrer Profilliste.

- Solange Sie es nicht ändern, läuft das Profil genau so wie veröffentlicht, einschließlich kostenpflichtiger Themes, die Sie nicht besitzen.
- Veröffentlicht der Autor eine neue Version, zeigt die Karte **Update verfügbar**. Tippen Sie auf **Aktualisieren**, um sie zu installieren; bis dahin ändert sich nichts.
- Wenn Sie das Profil zum ersten Mal ändern, warnt MOCPilot Sie: Nach der Änderung erhält es keine Katalog-Updates mehr, und Produkte, die Sie nicht besitzen, werden durch das Theme „Grundlegend“ ersetzt oder gesperrt. Siehe [Profile verwalten](/docs/Application/Profiles/ManageProfiles#paid-themes-in-shared-profiles).

Auf der Website können Sie bei jedem Katalogprofil auch **Zu meinem Konto hinzufügen** drücken; es gelangt dann über die [Synchronisierung](/docs/Application/Account/Sync) in die App.

## Ihr Profil veröffentlichen {#publish-your-profile}

Teilen Sie Ihr Modell mit allen:

1. Stellen Sie sicher, dass Sie angemeldet sind und das Profil synchronisiert ist: Der Katalog kopiert es aus Ihrem Konto und zeigt Sie als Autor an.
2. Öffnen Sie **Profil bearbeiten** und tippen Sie auf **An den Katalog senden**.
3. Prüfen Sie die Anforderungen, füllen Sie das Formular aus und drücken Sie **Zur Prüfung senden**.

<Screenshot name="publish-profile" alt="Seite „Im Katalog veröffentlichen“ mit der Liste der fehlenden Anforderungen" width={900} />

### Anforderungen {#requirements}

Bevor Sie es zur Prüfung senden, benötigt das Profil:

- einen Namen mit mindestens 3 Zeichen, keinen Standardnamen wie „Neues Profil“ oder „Unbenannt“;
- ein Bild;
- eine Beschreibung mit mindestens 20 Zeichen;
- mindestens einen Hub;
- etwas, womit es gesteuert wird: einen Dashboard-Controller oder das Gamepad;
- ein Programm mit mindestens einem Block oder einer Zeile;
- mindestens einen Hashtag.

Die Veröffentlichungsseite listet alles auf, was noch fehlt.

### Das Formular {#the-form}

- **Name** und **Beschreibung**: was das Modell tut und wie es gesteuert wird.
- **Hashtags**.
- **Sichtbarkeit**: **Öffentlich** (im Katalog angezeigt) oder **Nur per Link**.
- **Hubs**: werden aus dem Profil übernommen.
- Zusätzliche Felder, etwa die Setnummer, können abgefragt werden.
- **Neuigkeiten**: für eine neue Version.

### Prüfung {#review}

Ein Moderator prüft jede Einreichung. Das Ergebnis erhalten Sie unter **Benachrichtigungen**:

- „Dein Profil „…“ hat die Prüfung bestanden“: Es ist jetzt im Katalog auf der Website und in der App.
- „Dein Profil „…“ hat die Prüfung nicht bestanden“: Die Notiz des Moderators sagt, was zu korrigieren ist. Korrigieren Sie es und senden Sie es erneut.

Die Veröffentlichungsseite zeigt den Status: wartet auf Prüfung, veröffentlicht, veröffentlicht mit einer neuen Version, die auf Prüfung wartet, abgelehnt oder ausgeblendet.

Sie können bis zu 5 Profile oder neue Versionen pro Monat senden; die Seite zeigt, wie viele Ihnen noch bleiben.

### Neue Versionen und Zurückziehen {#new-versions-and-unpublishing}

Wenn Sie dasselbe Profil erneut veröffentlichen, wird eine **neue Version** zur Prüfung gesendet. Wer es installiert hat, sieht **Update verfügbar**. Sie können ein veröffentlichtes Profil auch ausblenden.
