# Steuerelemente aus einem Theme erstellen {#create-controls-from-a-theme}

Jedes Steuerelement, das Sie hinzufügen, basiert auf einem Theme. Sie können es vor dem Hinzufügen konfigurieren und das konfigurierte Steuerelement als eigenes Design speichern.

## Vor dem Hinzufügen konfigurieren {#configure-before-adding}

1. Öffnen Sie **Controller hinzufügen** (**+** auf dem Dashboard, **+ Controller** auf einem Computer).
2. Wählen Sie einen Steuerelementtyp und im Streifen eine Variante.
3. Verwenden Sie unter **Konfigurieren** die Tabs **Stil** und **Einstellungen**: Größe (die Palette zeigt sie als „B x H Punkte“), Akzentfarbe, Symbol, Theme-Optionen, Verhalten.
4. Tippen Sie auf **Zum Dashboard hinzufügen**.

## Ein Design speichern {#save-a-design}

Wenn Sie eine Kombination gefunden haben, die Ihnen gefällt (etwa eine rote Taste im Theme „Rennen“ mit Hupensymbol), behalten Sie sie:

1. Wählen Sie ein konfiguriertes Steuerelement aus einem Theme, das Sie besitzen.
2. Tippen Sie auf **Design speichern**.
3. Das Design erscheint unter **Meine Designs** → **Gespeicherte Designs**. Sie können es mit einem Tipp zum Dashboard jedes Profils hinzufügen.

**Löschen** entfernt ein gespeichertes Design.

## Steuerelemente auf dem Dashboard kopieren {#copy-controls-on-the-dashboard}

- **Duplizieren** kopiert ein Steuerelement mit all seinen Eigenschaften.
- **Duplizieren (nur Typ)** fügt denselben Steuerelementtyp mit Standardeigenschaften hinzu.
- **Theme ändern** stellt ein Steuerelement auf ein anderes Theme um, das Sie besitzen, ohne dass es seinen Platz oder seine Verbindungen zum Programm verliert.

## Ein gutes Dashboard {#a-good-dashboard}

- Legen Sie die Fahrsteuerung unter Ihre Daumen: einen Joystick oder Pedale auf eine Seite, die Lenkung auf die andere.
- Verwenden Sie die Größe **L** für die meistgenutzten Steuerelemente und **S** für die seltenen.
- Verwenden Sie eine Akzentfarbe pro Funktion: Grün zum Fahren, Gelb für Licht, Rot für Stopp.
- Sperren Sie die Steuerelemente, wenn das Layout fertig ist (**Alles sperren**).
- Fügen Sie einen Akkumonitor hinzu, damit Sie wissen, wann Sie aufladen müssen.

:::info Eigene Grafiken
Völlig neue Steuerelemente oder Themes können Sie in der App nicht zeichnen. Themes werden vom MOCPilot-Team erstellt; wenn Sie eine Idee für ein Theme haben, teilen Sie sie uns über **Hilfe → Eine Frage stellen** mit.
:::
