# Themes erhalten, kaufen und aktualisieren {#get-buy-and-update-themes}

Einen eigenen Store-Bildschirm gibt es nicht: Sie stöbern und kaufen Themes genau dort, wo Sie sie verwenden, in der Palette **Controller hinzufügen** des Dashboards.

## Ein Theme ausprobieren {#try-a-theme}

1. Öffnen Sie das Dashboard und tippen Sie auf **+** (**Controller hinzufügen**; auf einem Computer **+ Controller**).
2. Wählen Sie einen Steuerelementtyp, zum Beispiel einen Joystick. Der Streifen mit den Varianten zeigt ihn in jedem Theme; die Spezial-Steuerelemente finden Sie unter **Fahrzeug & Spezial**.
3. Tippen Sie auf eine Variante, um sie in der großen Vorschau zu sehen und auszuprobieren. Probieren Sie unter **Konfigurieren** Farben, Größen und Optionen aus.

In der [Demo des Web-Editors](/docs/Introducing/WebEditor) auf mocpilot.com können Sie sogar kostenpflichtige Steuerelemente auf dem Dashboard platzieren und ausprobieren.

## Kaufen {#buy}

Für ein Theme, das Sie nicht besitzen, zeigt die Palette:

- **Kaufen &lt;Preis&gt;**: Kaufen Sie dieses Theme (oder dieses Spezial-Steuerelement) einmal, und es gehört Ihnen für immer;
- **Alles mit MocPilot Pro**: Erhalten Sie jedes Theme und jedes Spezial-Steuerelement mit dem Abo. Siehe [MocPilot Pro](/docs/Application/Account/Pro).

Käufe laufen über den App Store, Google Play oder den Microsoft Store und gehören zu Ihrem MOCPilot-Konto, daher müssen Sie angemeldet sein. Sie funktionieren auf all Ihren Geräten und im Web-Editor.

## Installieren und aktualisieren {#install-and-update}

Themes installieren Sie nicht von Hand. Wenn Sie angemeldet sind, lädt MOCPilot die Themes herunter, die Sie besitzen, und hält sie aktuell. Das kostenlose Theme „Grundlegend“ ist in die App integriert.

Wenn ein Theme fehlt:

- prüfen Sie die Internetverbindung und stellen Sie sicher, dass Sie mit dem richtigen Konto angemeldet sind;
- gehen Sie zu **Konto → Käufe** und tippen Sie auf **Wiederherstellen** (Käufe wiederherstellen);
- starten Sie die App neu.

## Profile mit Themes, die Sie nicht besitzen {#profiles-with-themes-you-dont-own}

- Ein aus dem [Katalog](/docs/Application/Profiles/Catalog) installiertes Profil läuft mit all seinen Themes, solange Sie es nicht ändern.
- Wenn Sie ein Profil mit Themes bearbeiten, die Sie nicht besitzen, wechseln diese Steuerelemente zum Theme „Grundlegend“, und Spezial-Steuerelemente (Lenkrad, Pedale und die anderen) bleiben gesperrt, bis Sie sie kaufen.

## Alternative Stores {#alternative-stores}

Unter **Konto → Käufe → Kaufeinstellungen** können Sie **Alternativen Store verwenden** und **Im Systembrowser öffnen** für die Zahlungsseite einschalten. Diese Optionen sind für Regionen gedacht, in denen die üblichen Stores nicht verfügbar sind.
