# Mehrschichtige Themes {#layered-themes}

Die kostenpflichtigen Themes und die [Spezial-Steuerelemente](/docs/Application/Dashboard/SpecialControls) verwenden das **mehrschichtige** Format. Ein mehrschichtiges Steuerelement wird aus mehreren übereinanderliegenden Ebenen gezeichnet statt aus einem einzigen Bild:

- **Bild**-Ebenen: Gehäuse, Rahmen, Glas und Schatten, mit ihren Effekten vorbereitet;
- **Formen und Bögen**: Ringe, Skalen und Fortschrittsbögen, die sich mit dem Wert bewegen;
- **Text und Symbole**: Beschriftungen, Zahlen und das Symbol, das Sie wählen;
- **Monitortext**: der Text, den ein Monitor anzeigt.

Die App setzt die Ebenen live zusammen: Der Griff eines Schiebereglers bewegt sich über seine Bahn, die Nadel eines Geschwindigkeitsmessers dreht sich, ein Bogen füllt sich, die Akzentfarbe tönt die passenden Ebenen ein.

## Was Ihnen das bringt {#what-this-gives-you}

- **Scharf in jeder Größe**: S, M und L und bei jeder Bildschirmauflösung.
- **Ihre Farben**: Akzentfarbe und Theme-Optionen ändern das Aussehen ohne neue Grafiken.
- **Flüssig und leicht**: wenige Bilder pro Steuerelement, sodass Dashboards auch auf älteren Smartphones schnell bleiben.
- **Gleiches Verhalten**: Ein Joystick jedes Themes verhält sich genau wie ein Joystick aus „Grundlegend“, sodass Sie Themes wechseln können, ohne das Programm anzufassen.

## Versionen und Kompatibilität {#versions-and-compatibility}

Themes werden von Zeit zu Zeit auf dem Server aktualisiert: neue Steuerelemente, Korrekturen, bessere Grafiken. Die App lädt die neueste Version herunter, die sie anzeigen kann. Eine ältere App erhält weiterhin die für sie erstellte Version, sodass ein Theme nach einem Update nie kaputtgeht. Um das neueste Aussehen zu erhalten, halten Sie MOCPilot aktuell.
