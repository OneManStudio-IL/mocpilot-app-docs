# Smartphone, Tablet und Desktop {#phone-tablet-and-desktop}

MOCPilot hat drei Layouts, und die App wählt automatisch eines davon:

- **Smartphone**: iPhone und Android-Smartphones.
- **Tablet**: iPad und Android-Tablets (ab 7 Zoll).
- **Desktop**: Mac- und Windows-Computer. Auch der [Web-Editor](/docs/Introducing/WebEditor) im Browser verwendet den Desktop-Editor.

Profile, Editoren und das Dashboard sind überall gleich; nur die Navigation unterscheidet sich.

## Smartphone {#phone}

<Screenshot name="profiles-phone" alt="Seite „Meine Profile“ auf einem Smartphone mit der unteren Leiste" width={360} />

- Die **untere Leiste** enthält **Profile**, **Einstellungen** und **Hilfe**, dazu **Benachrichtigungen**, wenn Sie angemeldet sind.
- **Konto** befindet sich oben in den **Einstellungen**.
- Im Kopfbereich von **Meine Profile** finden Sie **Sortieren und filtern**, **Fernbedienung verbinden** (das Fernbedienungssymbol), **+** (Neues Profil, Profil importieren…, Online suchen) und das Suchfeld.
- Die Hauptbildschirme werden im Hochformat angezeigt. Wenn Sie ein Profil öffnen, wechselt die App ins **Querformat mit Vollbild**, sodass Editor und Dashboard den ganzen Bildschirm nutzen. Nach dem Schließen des Profils kehrt das Hochformat zurück.
- Im Editor bieten runde Schaltflächen am oberen Rand schnellen Zugriff auf Startseite, Rückgängig, Wiederholen, KI-Builder, Editor-Einstellungen, Probleme (Schnellverknüpfungen), Gamepad, Meine Hubs, Fernsteuerung, Dashboard, Monitor (Logikblöcke) und Start / Stopp.

<Screenshot name="editor-phone" alt="Profileditor auf einem Smartphone mit den runden Schaltflächen am oberen Rand" width={900} />

## Tablet {#tablet}

<Screenshot name="profiles-tablet" alt="Seite „Meine Profile“ auf einem Tablet mit der Seitenleiste" width={900} />

- Die **Seitenleiste** links enthält **Profile**, **Profilkatalog**, **Benachrichtigungen**, **Einstellungen** und **Hilfe**. Darunter befinden sich die Karte **MocPilot Pro** und Ihr Konto (**Anmelden** im Gastmodus). Sie können die Seitenleiste auf Symbole reduzieren.
- Im Kopfbereich von **Meine Profile** finden Sie **Neues Profil** (dessen Menü auch Profil importieren…, Fernbedienung verbinden und Online suchen enthält), **Sortieren und filtern**, **Nach Hashtags filtern**, **Fernbedienung verbinden** und das Suchfeld.
- Tippen Sie auf eine Profilkarte, um sie auszuwählen: Die Leiste unten zeigt **Teilen**, **Bearbeiten**, **Zu Favoriten hinzufügen** und **Starten**. Mit einem Doppeltipp auf eine Karte starten Sie das Profil. Halten Sie eine Karte gedrückt, um ihr Menü zu öffnen, das auch **Profil löschen** enthält.
- Auf breiten Bildschirmen öffnen sich Einstellungen und Hilfe neben der Liste.
- Ein Profil öffnet sich im Querformat, und der Editor hat dieselben runden Schaltflächen wie auf dem Smartphone.

## Desktop (Mac und Windows) {#desktop-mac-and-windows}

<Screenshot name="profiles-desktop" alt="„Meine Profile“ auf einem Computer" width={900} />

- Rechts in der oberen Leiste: **Konto** (**Anmelden** im Gastmodus), **Benachrichtigungen** (wenn Sie angemeldet sind), **Fernbedienung verbinden** (das Fernbedienungssymbol) und **Einstellungen** (das Zahnrad).
- Einstellungen, Hilfe, Konto, Neues Profil, Profil bearbeiten, der Profilkatalog und andere Seiten öffnen sich als **Fenster** über der Profilliste.
- Klicken Sie auf eine Profilkarte, um zu sehen, was Sie damit tun können (**Teilen…**, **Bearbeiten…**, **Zu Favoriten hinzufügen**, **Starten**); ein Doppelklick startet das Profil. Klicken Sie mit der rechten Maustaste auf eine Karte, um ihr Menü zu öffnen, das auch **Profil löschen** enthält.
- Im Editor öffnet sich das **Dashboard** in einem **eigenen Fenster**, sodass Sie Programm und Dashboard nebeneinander sehen.

### Menüs {#menus}

Unter Windows befinden sich die Menüs links in der oberen Leiste der App. Auf dem Mac sind sie in der Menüleiste des Systems am oberen Bildschirmrand.

| Menü | Windows | Mac |
|---|---|---|
| **MOCPilot** (App-Menü) | — | Über MOCPilot, Einstellungen…, Beenden |
| **Datei** | Neues Profil, Profil importieren…, Online suchen, Beenden | Neues Profil, Profil importieren…, Online suchen, Fernbedienung verbinden… |
| **Ansicht** | Vollbild | Vollbild ein/aus |
| **Fenster** | Minimieren, Maximieren / Wiederherstellen | Minimieren |
| **Hilfe** | MOCPilot-Hilfe, Eine Frage stellen, Einen Fehler melden, Über MOCPilot | MOCPilot-Hilfe, Eine Frage stellen, Einen Fehler melden |

Wenn ein Profil geöffnet ist, hat der Editor eigene Menüs **Datei**, **Bearbeiten**, **Ansicht** und **Programm** (siehe [Desktop-Menüs](/docs/Application/BlockBuilder/Editor#desktop-menus)), und das Dashboard-Fenster hat **Datei**, **Bearbeiten** und **Ansicht** (siehe [Dashboard](/docs/Application/Dashboard/DashboardOverview)).

### Tastenkürzel {#keyboard-shortcuts}

Auf dem Mac übernimmt ⌘ (Befehlstaste) die Rolle von Strg unter Windows; ⇧ ist die Umschalttaste, ⌃ die Control-Taste.

**Überall**

| Aktion | Windows | Mac |
|---|---|---|
| Einstellungen | Strg+2 | ⌘, |
| Vollbild ein / aus | F11 oder Alt+Eingabe | ⌃⌘F |
| Fenster minimieren | — | ⌘M |
| Beenden | Alt+F4 | ⌘Q |

**Meine Profile** (kein Profil geöffnet)

| Aktion | Windows | Mac |
|---|---|---|
| Neues Profil | Strg+N | ⌘N |
| Profil importieren | Strg+O | ⌘O |
| Profile durchsuchen | Strg+F | — |
| Profile / Einstellungen / Hilfe / Konto | Strg+1 / Strg+2 / Strg+3 / Strg+4 | — |

**Profileditor**

| Aktion | Windows | Mac |
|---|---|---|
| Profil schließen | Strg+W | ⌘W |
| Start / Stopp | Strg+R / Strg+. | ⌘R / ⌘. |
| Rückgängig / Wiederholen | Strg+Z / Strg+Umschalt+Z oder Strg+Y | ⌘Z / ⇧⌘Z |
| Dashboard anzeigen | Strg+2 | ⌘2 |
| Meine Hubs | Strg+Umschalt+H | ⇧⌘H |
| KI-Builder | Strg+Umschalt+I | ⇧⌘I |
| Blockpalette ein- / ausblenden (Logikblöcke) | Strg+P | ⌘P |
| Blockpalette durchsuchen (Logikblöcke) | Strg+F | ⌘F |
| Monitor (Logikblöcke) | Strg+Umschalt+M | ⇧⌘M |
| Vergrößern / Verkleinern / Originalgröße (Logikblöcke) | Strg++ / Strg+− / Strg+0 | ⌘+ / ⌘− / ⌘0 |

**Dashboard**

| Aktion | Windows | Mac |
|---|---|---|
| Rückgängig / Wiederholen | Strg+Z / Strg+Umschalt+Z oder Strg+Y | ⌘Z / ⇧⌘Z |
| Zurück zum Programm (wenn das Dashboard im Hauptfenster ist) | Strg+1 | ⌘1 |
| Dashboard-Fenster schließen | — | ⌘W |
| Modus **Auswählen** verlassen oder Eigenschaftenbereich schließen | Esc | Esc |
| Steuerelement löschen (Eigenschaftenbereich geöffnet) | Entf oder Rücktaste | Entf oder Rücktaste |
| Steuerelement duplizieren (Eigenschaftenbereich geöffnet) | Strg+D | ⌘D |

Auf einem Tablet mit Tastatur blendet Strg+B (⌘B auf dem iPad) die Seitenleiste ein oder aus.

## Der Profileditor in allen Layouts {#the-profile-editor-on-every-layout}

Der Editor hat keine Tabs. Das **Programm** (Zeilen der Schnellverknüpfungen oder Logikblöcke) füllt den Bildschirm, und Schaltflächen öffnen alles andere:

| Schaltfläche | Öffnet |
|---|---|
| **Meine Hubs** | die [Hub-Slots](/docs/Application/Hubs/ConnectingHubs) des Profils |
| **Dashboard** | das [Dashboard](/docs/Application/Dashboard/DashboardOverview) |
| **Gamepad** | die [Gamepad-Einstellungen](/docs/Application/Dashboard/Gamepad) |
| **Monitor** | Werte von Variablen und Listen (nur Logikblöcke) |
| **Editor-Einstellungen** | die [Editor-Optionen](/docs/Application/BlockBuilder/Editor#editor-settings) |
| **KI-Builder** | den [KI-Builder](/docs/Application/Profiles/AiBuilder) (MocPilot Pro) |
| **Probleme** | Zeilen, die nicht ausgeführt werden können (nur Schnellverknüpfungen) |
| **Fernsteuerung** | das Profil auf einem anderen Gerät ausführen und von hier aus steuern (MocPilot Pro); siehe [Fernsteuerung](/docs/Application/Profiles/RemoteControl) |
| **Start / Stopp** | startet und stoppt das Programm |
