# Crear controles a partir de un tema {#create-controls-from-a-theme}

Cada control que añades parte de un tema. Puedes configurarlo antes de añadirlo y guardar el control configurado como diseño propio.

## Configurar antes de añadir {#configure-before-adding}

1. Abre **Añadir controlador** (**+** en el panel).
2. Selecciona un tipo de control y una apariencia en la tira de apariencias.
3. En **Configurar**, usa las pestañas **Estilo** y **Configuración**: tamaño (la paleta lo muestra como «An x Al puntos»), color de acento, icono, opciones del tema y comportamiento.
4. Toca **Añadir al panel**.

## Guardar un diseño {#save-a-design}

Cuando encuentres una combinación que te guste (por ejemplo, un botón rojo de Carreras con icono de claxon), consérvala:

1. Selecciona un control configurado de un tema que tengas.
2. Toca **Guardar diseño**.
3. El diseño aparece en **Mis diseños** → **Diseños guardados**. Puedes añadirlo al panel de cualquier perfil con un toque.

**Eliminar** borra un diseño guardado.

## Copiar controles en el panel {#copy-controls-on-the-dashboard}

- **Duplicar** copia un control con todas sus propiedades.
- **Duplicar (Solo tipo)** añade el mismo tipo de control con las propiedades predeterminadas.
- **Cambiar tema** pasa un control a otro tema que tengas sin perder su posición ni sus conexiones con el programa.

## Un buen panel {#a-good-dashboard}

- Pon los controles de conducción bajo los pulgares: un joystick o los pedales a un lado y la dirección al otro.
- Usa el tamaño **L** para los controles que más usas y **S** para los que usas poco.
- Usa un color de acento por función: verde para conducir, amarillo para las luces, rojo para detener.
- Bloquea los controles cuando la distribución esté lista (**Bloquear todo**).
- Añade un monitor de batería para saber cuándo recargar.

:::info Tus propios gráficos
En la app no se pueden dibujar controles ni temas completamente nuevos. Los temas los crea el equipo de MOCPilot; si tienes una idea para un tema, cuéntanosla en **Ayuda → Hacer una pregunta**.
:::
