# MocPilot Pro et achats {#mocpilot-pro-and-purchases}

MOCPilot est gratuit : les deux éditeurs, tous les hubs, le thème De base et 2 emplacements de hub par profil. **MocPilot Pro** débloque tout le reste ; vous pouvez aussi acheter des éléments à l'unité.

## Ce qui est gratuit {#whats-free}

- Blocs logiques et Liens rapides, ainsi que tous les hubs, moteurs et capteurs compatibles ;
- le thème **De base** avec toutes ses commandes ;
- 2 emplacements de hub par profil ;
- la synchronisation, le catalogue, la publication et l'éditeur web.

## MocPilot Pro {#mocpilot-pro}

« Tout MOCPilot, sur tous vos appareils » :

- **Tout est inclus** : rien à acheter séparément. Tous les éléments payants sont compris : thèmes, commandes spéciales et extensions, y compris tous les emplacements de hub ;
- **Assistant IA** : décrivez votre modèle et il configure les hubs, le tableau de bord et le programme, dans l'application comme dans l'éditeur web (voir [Assistant IA](/docs/Application/Profiles/AiBuilder)) ;
- **Contrôle à distance** : lancez un profil sur un autre téléphone, une tablette ou un ordinateur et pilotez-le depuis votre appareil ou depuis l'éditeur web (voir [Contrôle à distance](/docs/Application/Profiles/RemoteControl)) ;
- **Toujours plus** : les nouvelles fonctions Pro sont ajoutées dès leur sortie.

### Formules {#plans}

| Formule | Prix |
|---|---|
| Mensuel | 4,99 $ par mois |
| Annuel (« Meilleur prix ») | 41,99 $ par an |

Les prix peuvent varier selon le pays et le store. Les nouveaux abonnés bénéficient d'un **essai gratuit de 7 jours**.

MocPilot Pro est lié à votre compte MOCPilot : il fonctionne donc sur tous vos appareils ; vous devez être connecté pour vous abonner. Vous ne pouvez pas vous abonner dans le navigateur : abonnez-vous dans l'application sur iPhone, iPad, Mac, Android ou Windows, et Pro fonctionnera aussi dans l'éditeur web.

Pour ouvrir la page Pro : **Compte → Achats → MocPilot Pro**, ou la carte **MocPilot Pro** dans la barre latérale sur tablette.

### Gérer ou résilier {#manage-or-cancel}

**Gérer l'abonnement** sur la page Pro ouvre le store où vous vous êtes abonné (App Store, Google Play ou Microsoft Store). Si vous vous êtes abonné sur une autre plateforme, gérez l'abonnement depuis celle-ci. Il se renouvelle automatiquement, sauf si vous le résiliez au moins 24 heures avant la fin de la période en cours.

La page indique l'état de l'abonnement : actif et date de renouvellement, actif jusqu'à une date avec le renouvellement automatique désactivé, date de fin de l'essai gratuit, ou problème de paiement à régler dans le store.

Sans Internet, Pro continue de fonctionner un certain temps ; ensuite, l'application affiche « MocPilot Pro doit être vérifié en ligne » jusqu'au retour de la connexion.

## Achats {#purchases}

Les éléments achetés à l'unité vous appartiennent pour toujours, même sans Pro :

| Élément | Ce que vous obtenez |
|---|---|
| Un thème payant | toutes les commandes de ce thème |
| Une commande spéciale : volant, pédales, boîte de vitesses, frein à main, clignotants, manipulateur de train | cette commande dans tous ses styles |
| Emplacement de hub supplémentaire (jusqu'à 3) | un emplacement de hub de plus dans chaque profil |

Achetez les thèmes et les commandes dans la palette **Ajouter un contrôleur** du tableau de bord ([comment faire](/docs/Application/Themes/GettingThemes)), et les emplacements de hub avec **Déverrouiller l'emplacement** dans Mes hubs.

## Restaurer les achats {#restore-purchases}

Sur un nouvel appareil ou après avoir réinstallé l'application, connectez-vous avec le même compte, ouvrez **Compte → Achats** et touchez **Restaurer**. La page Pro propose aussi **Restaurer les achats**.

Sous Windows, vous pouvez aussi restaurer les achats Microsoft Store sans compte MOCPilot, en mode invité ; voir [Restaurer les achats Microsoft Store](/docs/Application/Account/UserAccount#restore-microsoft-store-purchases).

Messages que vous pouvez rencontrer :

- **Abonnement lié à un autre compte** : ce compte de store dispose déjà de MocPilot Pro pour un autre compte MOCPilot. Connectez-vous avec ce compte.
- **Rien à restaurer** : aucun abonnement actif n'a été trouvé pour ce compte de store.
- **Presque terminé** : l'achat a abouti, mais le serveur n'a pas pu être joint. Pro sera activé dès que l'application sera en ligne.
