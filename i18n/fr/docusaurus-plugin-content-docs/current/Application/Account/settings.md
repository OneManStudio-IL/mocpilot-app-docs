# Paramètres {#settings}

Pour ouvrir les Paramètres :

- **Téléphone** : **Paramètres** dans la barre du bas.
- **Tablette** : **Paramètres** dans la barre latérale.
- **Ordinateur** : le bouton en forme de roue dentée dans la barre supérieure. Sur Mac, vous pouvez aussi choisir **MOCPilot → Paramètres…** (⌘,) ; sous Windows, appuyez sur Ctrl+2. Les Paramètres s'ouvrent dans leur propre fenêtre.

## Compte {#account}

Sur un téléphone, le haut des Paramètres affiche votre compte, ou **Créer un compte ou se connecter** en mode invité. Sur une tablette, le compte se trouve en bas de la barre latérale, et sur un ordinateur, c'est le bouton **Compte** de la barre supérieure. Voir [Compte](/docs/Application/Account/UserAccount).

## Paramètres {#settings}

| Paramètre | Ce qu'il fait |
|---|---|
| **Son** | sons de l'application et des commandes (par exemple, les effets du volant et des pédales) |
| **Vibration** | une courte vibration quand vous touchez les commandes ; uniquement sur les téléphones capables de vibrer |
| **Garder l'écran allumé** | empêche l'écran de s'éteindre tant qu'un profil est ouvert ; activez-le pour piloter. Sur iPhone, iPad, Android et Windows (pas sur Mac) |
| **Langue** | la langue de l'application ; voir [Langue](#language) ci-dessous |
| **Mode sombre** | apparence sombre ou claire. Au premier lancement, elle suit l'apparence de votre appareil |

Le contrôle à distance ne se trouve pas dans les Paramètres : pour qu'un autre appareil puisse piloter celui-ci, utilisez **Connecter une télécommande** sur la page **Mes profils**. Voir [Contrôle à distance](/docs/Application/Profiles/RemoteControl).

## Langue {#language}

Au premier lancement, MOCPilot utilise la langue de votre appareil si l'application la propose, et l'anglais sinon. Pour la changer :

- **Téléphone et tablette** : touchez **Langue**, puis une langue. L'application change de langue immédiatement. La liste n'affiche pas la langue que vous utilisez déjà.
- **Ordinateur** : cliquez sur **Langue**, cliquez sur une langue (elle reçoit une coche ✓ ; celle utilisée actuellement porte la mention **Actuelle**), puis cliquez sur **Appliquer** ou appuyez sur Entrée. **Annuler** ou Échap conserve la langue actuelle.

## Accessibilité {#accessibility}

Les boutons de l'application ont des noms que les lecteurs d'écran (VoiceOver sur les appareils Apple, TalkBack sur Android) lisent à voix haute. Cela inclut les boutons qui n'affichent qu'une icône, comme **Retour**, **Fermer**, **Paramètres** ou **Annuler**.

## À propos {#about}

Sur un téléphone ou une tablette, **Version** en bas des Paramètres ouvre **À propos de MOCPilot**, avec la Politique de confidentialité, les Conditions et les Notes de version / Actualités. Sur un ordinateur, utilisez **Aide → À propos de MOCPilot** dans la barre supérieure (sur Mac, **MOCPilot → À propos de MOCPilot**).

## Paramètres du profil {#profile-settings}

Les réglages propres à un profil se trouvent dans l'éditeur :

- **Paramètres de l'éditeur** : niveau des blocs, lancer un bloc au clic, arrêter les ports du hub quand le programme s'arrête ; voir [Travailler dans l'éditeur](/docs/Application/BlockBuilder/Editor#editor-settings) ;
- **Paramètres du tableau de bord** : arrière-plan et grille ; voir [Tableau de bord](/docs/Application/Dashboard/DashboardOverview#dashboard-settings) ;
- **Manette de jeu** : voir [Manette de jeu](/docs/Application/Dashboard/Gamepad).

Lorsque vous êtes connecté, les paramètres de l'application sont les mêmes sur tous vos appareils. Voir [Synchronisation entre appareils](/docs/Application/Account/Sync).
