# Compte {#account}

Un compte MOCPilot protège vos profils, vos paramètres et vos achats, et les rend disponibles sur tous vos appareils.

## Pourquoi créer un compte {#why-have-an-account}

- Les profils et les paramètres sont enregistrés sur le serveur et synchronisés entre vos appareils.
- Vous pouvez tout récupérer si vous remplacez ou perdez un appareil.
- Les achats et MocPilot Pro fonctionnent sur tous vos appareils et dans l'éditeur web.
- Vous pouvez publier des profils dans le catalogue et recevoir des notifications.

## Se connecter {#sign-in}

Sur l'écran de connexion, saisissez votre **Email ou identifiant** et votre **Mot de passe**, ou utilisez **Se connecter avec Google** / **Se connecter avec Apple**.

<Screenshot name="sign-in" alt="L'écran de connexion de MOCPilot" width={900} />

**Se connecter avec un code QR** vous connecte sur cet appareil en scannant le code avec votre téléphone et en confirmant avec Face ID ou votre empreinte. Il faut pour cela une clé d'accès sur le téléphone : ajoutez-la une fois sur mocpilot.com dans **Compte → Paramètres → Clés d'accès**.

## Créer un compte {#create-an-account}

Touchez **Créer un compte** : saisissez deux fois votre adresse e-mail, un nom d'utilisateur et un mot de passe (deux fois), puis confirmez votre région. Vous pouvez aussi utiliser **S'inscrire avec Google** / **S'inscrire avec Apple**. Confirmez votre adresse e-mail grâce à l'e-mail d'activation ; certaines fonctions restent désactivées tant que le compte n'est pas vérifié (touchez **Renvoyer le mail d'activation** s'il n'est pas arrivé).

## Mot de passe oublié {#forgot-your-password}

Touchez **Réinitialiser** à côté de « Mot de passe oublié ? », saisissez votre adresse e-mail et tapez le code reçu par e-mail pour définir un nouveau mot de passe.

## Mode invité {#guest-mode}

**Continuer sans compte** sur l'écran de connexion ouvre un court écran qui liste ce qu'un compte vous apporte. Touchez de nouveau **Continuer sans compte** pour commencer à utiliser l'application tout de suite. Tout reste alors uniquement sur cet appareil et sera perdu si vous supprimez l'application ou perdez l'appareil.

Vous pourrez vous connecter plus tard : sur un téléphone, touchez **Créer un compte ou se connecter** en haut des **Paramètres** ; sur une tablette ou un ordinateur, ouvrez **Compte** (**Se connecter** en mode invité), qui affiche le même écran avec **Créer un compte** et **Vous avez déjà un compte ?**.

### Restaurer les achats Microsoft Store {#restore-microsoft-store-purchases}

Sous Windows, l'écran invité propose aussi **Restaurer les achats Microsoft Store**. Les achats Microsoft Store appartiennent au compte Microsoft que vous utilisez dans Windows : vous n'avez donc pas besoin d'un compte MOCPilot pour les récupérer. Cliquez sur le bouton (l'application a besoin d'Internet) : l'application interroge le Microsoft Store (**Vérification du Microsoft Store...**) et débloque sur ce PC ce que ce compte Microsoft a acheté, y compris un abonnement MocPilot Pro.

## Région {#region}

Si votre compte a été créé avant que MOCPilot ne demande la région, l'application vous la demande une fois sur chaque appareil, quelques secondes après la connexion : **Indiquez votre région**. La région permet à l'application de proposer le bon store et les bons prix. Touchez **Choisir** pour sélectionner votre pays dans **Détails du compte**, ou **Pas maintenant** pour passer. Vous pouvez changer de région à tout moment dans **Détails du compte**.

## Page du compte {#account-page}

Téléphone : **Paramètres → Compte**. Tablette : votre compte en bas de la barre latérale. Ordinateur : le bouton **Compte** de la barre supérieure.

- **Détails du compte** : identifiant, e-mail, région et ID du compte (touchez un élément pour le copier).
- **Achats** : voir [MocPilot Pro et achats](/docs/Application/Account/Pro#purchases).
- **Changer le mot de passe**.
- **Se déconnecter** : voir [Se déconnecter](/docs/Application/Account/Sync#signing-out).
- **Supprimer le compte**.

## Supprimer votre compte {#delete-your-account}

**Supprimer le compte** efface définitivement les données de votre compte : informations personnelles, préférences, historique et profils stockés sur le serveur. Vous perdez aussi l'accès à tout contenu acheté ou obtenu par abonnement lié au compte. Cette action est irréversible.

Saisissez votre mot de passe actuel et confirmez avec **Glissez pour supprimer le compte** (écrans tactiles) ou **Supprimer le compte** (ordinateur).

Un abonnement actif est géré par le store : résiliez-le depuis celui-ci avant de supprimer le compte.

## Notifications {#notifications}

**Notifications** (la cloche sur un ordinateur ; l'onglet **Notifications** sur un téléphone et une tablette) affiche les résultats de vérification des profils que vous publiez, les réponses à vos demandes d'assistance et les actualités de l'équipe MOCPilot. Vous pouvez les marquer comme lues, les sélectionner et les supprimer. Les notifications nécessitent un compte.
