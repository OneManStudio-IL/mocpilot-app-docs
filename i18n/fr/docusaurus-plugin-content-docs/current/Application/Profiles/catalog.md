# Catalogue et publication {#catalog-and-publishing}

Le **Catalogue de profils** est une bibliothèque de profils prêts à l'emploi : des profils officiels pour les sets LEGO® créés par l'équipe MOCPilot, et des profils de la communauté partagés par d'autres constructeurs. C'est le même catalogue que sur [mocpilot.com](https://mocpilot.com).

## Ouvrir le catalogue {#open-the-catalog}

- Téléphone : **+** → **Rechercher en ligne** sur la page **Mes profils**.
- Tablette : **Catalogue de profils** dans la barre latérale, ou **Rechercher en ligne** dans le menu **Nouveau profil**.
- Ordinateur : **Fichier → Rechercher en ligne**.

Le catalogue nécessite une connexion Internet. S'il ne peut pas s'afficher dans l'application sur votre appareil, touchez **Ouvrir dans le navigateur**.

Vous pouvez rechercher dans le catalogue par nom, description, hashtags, auteur et numéro de set. Les cartes indiquent combien de fois un profil a été téléchargé.

## Installer un profil {#install-a-profile}

Ouvrez un profil dans le catalogue et ajoutez-le. Une copie apparaît dans votre liste de profils.

- Tant que vous ne le modifiez pas, le profil fonctionne exactement comme il a été publié, y compris avec des thèmes payants que vous ne possédez pas.
- Quand l'auteur publie une nouvelle version, la carte affiche **Mise à jour disponible**. Touchez **Mettre à jour** pour l'installer ; rien ne change tant que vous ne le faites pas.
- La première fois que vous modifiez le profil, MOCPilot vous prévient : après la modification, il ne reçoit plus les mises à jour du catalogue, et les produits que vous ne possédez pas sont remplacés par le thème De base ou verrouillés. Voir [Gérer les profils](/docs/Application/Profiles/ManageProfiles#paid-themes-in-shared-profiles).

Sur le site web, vous pouvez aussi appuyer sur **Ajouter à mon compte** sur n'importe quel profil du catalogue ; il arrive ensuite dans l'application grâce à la [synchronisation](/docs/Application/Account/Sync).

## Publier votre profil {#publish-your-profile}

Partagez votre modèle avec tout le monde :

1. Vérifiez que vous êtes connecté et que le profil est synchronisé : le catalogue le copie depuis votre compte et vous affiche comme auteur.
2. Ouvrez **Modifier le profil** et touchez **Envoyer au catalogue**.
3. Vérifiez les conditions requises, remplissez le formulaire et appuyez sur **Envoyer pour vérification**.

<Screenshot name="publish-profile" alt="Page Publier dans le catalogue avec la liste des conditions manquantes" width={900} />

### Conditions requises {#requirements}

Avant d'être envoyé pour vérification, le profil doit avoir :

- un nom d'au moins 3 caractères, autre qu'un nom par défaut comme « Nouveau profil » ou « Sans titre » ;
- une image ;
- une description d'au moins 20 caractères ;
- au moins un hub ;
- un moyen de le piloter : un contrôleur du tableau de bord ou la manette de jeu ;
- un programme avec au moins un bloc ou une ligne ;
- au moins un hashtag.

La page de publication liste tout ce qui manque.

### Le formulaire {#the-form}

- **Nom** et **Description** : ce que fait le modèle et comment le piloter.
- **Hashtags**.
- **Visibilité** : **Public** (affiché dans le catalogue) ou **Par lien uniquement**.
- **Hubs** : repris du profil.
- Des champs supplémentaires, comme le numéro de set, peuvent être demandés.
- **Nouveautés** : pour une nouvelle version.

### Vérification {#review}

Un modérateur vérifie chaque envoi. Le résultat arrive dans **Notifications** :

- « Votre profil … a été approuvé » : il figure désormais dans le catalogue, sur le site web et dans l'application.
- « Votre profil … n'a pas été approuvé » : la note du modérateur indique ce qu'il faut corriger. Corrigez-le et envoyez-le de nouveau.

La page de publication affiche le statut : en attente de vérification, publié, publié avec une nouvelle version en attente de vérification, refusé ou masqué.

Vous pouvez envoyer jusqu'à 5 profils ou nouvelles versions par mois ; la page indique combien il vous en reste.

### Nouvelles versions et retrait de la publication {#new-versions-and-unpublishing}

Publier à nouveau le même profil envoie une **nouvelle version** pour vérification. Les personnes qui l'ont installé voient **Mise à jour disponible**. Vous pouvez aussi masquer un profil publié.
