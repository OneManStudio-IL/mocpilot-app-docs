# Créer des commandes à partir d'un thème {#create-controls-from-a-theme}

Chaque commande que vous ajoutez part d'un thème. Vous pouvez la configurer avant de l'ajouter, puis enregistrer la commande configurée comme votre propre design.

## Configurer avant d'ajouter {#configure-before-adding}

1. Ouvrez **Ajouter un contrôleur** (**+** sur le tableau de bord, **+ Contrôleur** sur un ordinateur).
2. Sélectionnez un type de commande et une apparence dans le bandeau des apparences.
3. Dans **Configurer**, utilisez les onglets **Style** et **Paramètres** : taille (la palette l'indique sous la forme « L x H points »), couleur d'accent, icône, options du thème, comportement.
4. Touchez **Ajouter au tableau de bord**.

## Enregistrer un design {#save-a-design}

Quand vous trouvez une combinaison qui vous plaît (par exemple un bouton Course rouge avec une icône de klaxon), conservez-la :

1. Sélectionnez une commande configurée d'un thème que vous possédez.
2. Touchez **Enregistrer le design**.
3. Le design apparaît dans **Mes designs** → **Designs enregistrés**. Vous pouvez l'ajouter d'un seul geste au tableau de bord de n'importe quel profil.

**Supprimer** efface un design enregistré.

## Copier des commandes sur le tableau de bord {#copy-controls-on-the-dashboard}

- **Dupliquer** copie une commande avec toutes ses propriétés.
- **Dupliquer (Type uniquement)** ajoute le même type de commande avec les propriétés par défaut.
- **Changer de thème** fait passer une commande à un autre thème que vous possédez, sans perdre sa position ni ses liens avec le programme.

## Un bon tableau de bord {#a-good-dashboard}

- Placez les commandes de conduite sous vos pouces : un joystick ou des pédales d'un côté, la direction de l'autre.
- Utilisez la taille **L** pour les commandes que vous utilisez le plus et **S** pour les plus rares.
- Utilisez une couleur d'accent par fonction : vert pour la conduite, jaune pour les lumières, rouge pour l'arrêt.
- Verrouillez les commandes quand la disposition est prête (**Verrouiller tout**).
- Ajoutez un moniteur de batterie pour savoir quand recharger.

:::info Vos propres graphismes
Vous ne pouvez pas dessiner de commandes ou de thèmes entièrement nouveaux dans l'application. Les thèmes sont créés par l'équipe MOCPilot ; si vous avez une idée de thème, faites-nous-en part via **Aide → Poser une question**.
:::
