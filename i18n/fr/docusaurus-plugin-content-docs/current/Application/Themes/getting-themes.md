# Obtenir, acheter et mettre à jour des thèmes {#get-buy-and-update-themes}

Il n'y a pas d'écran de boutique à part : vous parcourez et achetez les thèmes là où vous les utilisez, dans la palette **Ajouter un contrôleur** du tableau de bord.

## Essayer un thème {#try-a-theme}

1. Ouvrez le tableau de bord et touchez **+** (**Ajouter un contrôleur** ; sur un ordinateur, **+ Contrôleur**).
2. Sélectionnez un type de commande, par exemple un joystick. Le bandeau des apparences le montre dans chaque thème ; les commandes spéciales se trouvent dans **Véhicule et spéciaux**.
3. Touchez une apparence pour la voir dans le grand aperçu et l'essayer. Dans **Configurer**, essayez les couleurs, les tailles et les options.

Dans la [démo de l'éditeur web](/docs/Introducing/WebEditor) sur mocpilot.com, vous pouvez même placer des commandes payantes sur le tableau de bord et les essayer.

## Acheter {#buy}

Pour un thème que vous ne possédez pas, la palette affiche :

- **Acheter &lt;prix&gt;** : achetez ce thème (ou cette commande spéciale) une fois, et il vous appartient pour toujours ;
- **Tout avec MocPilot Pro** : obtenez tous les thèmes et toutes les commandes spéciales avec l'abonnement. Voir [MocPilot Pro](/docs/Application/Account/Pro).

Les achats passent par l'App Store, Google Play ou le Microsoft Store et appartiennent à votre compte MOCPilot : vous devez donc être connecté. Ils fonctionnent sur tous vos appareils et dans l'éditeur web.

## Installer et mettre à jour {#install-and-update}

Vous n'installez pas les thèmes à la main. Lorsque vous êtes connecté, MOCPilot télécharge les thèmes que vous possédez et les tient à jour. Le thème gratuit De base est intégré à l'application.

Si un thème manque :

- vérifiez la connexion Internet et assurez-vous d'être connecté au bon compte ;
- allez dans **Compte → Achats** et touchez **Restaurer** (Restaurer les achats) ;
- redémarrez l'application.

## Profils avec des thèmes que vous ne possédez pas {#profiles-with-themes-you-dont-own}

- Un profil installé depuis le [catalogue](/docs/Application/Profiles/Catalog) fonctionne avec tous ses thèmes tant que vous ne le modifiez pas.
- Lorsque vous modifiez un profil comportant des thèmes que vous ne possédez pas, ces commandes passent au thème De base, et les commandes spéciales (volant, pédales et autres) restent verrouillées jusqu'à ce que vous les achetiez.

## Boutiques alternatives {#alternative-stores}

Dans **Compte → Achats → Paramètres d'achats**, vous pouvez activer **Utiliser une boutique alternative** et **Ouvrir dans le navigateur du système** pour la page de paiement. Ces options sont destinées aux régions où les boutiques habituelles ne sont pas disponibles.
