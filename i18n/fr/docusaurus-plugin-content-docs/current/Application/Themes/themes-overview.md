# Qu'est-ce qu'un thème {#what-is-a-theme}

Un **thème** est un style visuel pour les commandes du tableau de bord. Les thèmes partagent les mêmes types de commandes (joystick, curseurs, boutons, interrupteurs, interrupteurs à pas, moniteurs) et fonctionnent tous de la même façon ; seule l'apparence change.

Vous pouvez mélanger les thèmes sur un même tableau de bord : chaque commande a son propre thème.

## Thèmes disponibles {#available-themes}

**De base** est gratuit et intégré à l'application. Il comprend la Manette (joystick), la Croix directionnelle, le Curseur, le Curseur ver., le Bouton, l'Interrupteur, l'Interrupteur à pas, l'Interrupteur à pas ver. et le Moniteur.

Chaque **thème payant** comprend toutes les commandes De base, ainsi que le **Bouton rotatif**, le **Niveau de la batterie**, la **Vitesse** et le **Moniteur inclinable**, chacun dessiné dans le style du thème. Les thèmes payants sont :

Aura, Briques, Buggy, Machines de construction, Cœur de circuit, Citadine, Classique, 4x4 classique, Concept, Espace lointain, Formule, Convoi lourd, Camion lourd, Audio Hi-Fi, High-tech, Hologramme, Long-courrier, Miami, Néo Orbite, Cabine tout-terrain, Tout-terrain, Course, Rallye, Rétro, Rock Crawler, Berline, Coucher de soleil, Supercar, Tactique et Bête de somme.

De nouveaux thèmes sont ajoutés de temps en temps ; ils apparaissent automatiquement dans la palette.

Chaque thème payant est aussi fourni avec des **arrière-plans de tableau de bord** prêts à l'emploi, dans le même style. Voir [Paramètres du tableau de bord](/docs/Application/Dashboard/DashboardOverview#dashboard-settings).

Les **commandes spéciales** sont des produits à part : le volant, les pédales, le levier de vitesses, le frein à main, les clignotants et le manipulateur de train. La plupart ont une apparence pour chaque thème payant. Voir [Commandes spéciales](/docs/Application/Dashboard/SpecialControls).

Tous les thèmes payants et toutes les commandes spéciales sont inclus dans [MocPilot Pro](/docs/Application/Account/Pro).

## Options des thèmes {#theme-options}

Certains thèmes ont leurs propres options dans l'onglet **Style** de la commande :

- Course : **Carbone coloré**, **Bordures colorées**, **Afficher les lignes de course** ;
- Machines de construction : **Nombre de segments de l'indicateur** ;
- Aura : **Afficher les valeurs**.

## Changer le thème d'une commande {#change-the-theme-of-a-control}

Appui long (ou clic droit) sur une commande → **Changer de thème**, ou utilisez **Changer de thème** dans ses propriétés. Vous pouvez passer à n'importe quel thème que vous possédez et qui propose le même type de commande. La position, la taille et les liens avec le programme restent les mêmes.
