# MocPilot Pro と購入 {#mocpilot-pro-and-purchases}

MOCPilot は無料で使えます。両方のエディター、すべてのハブ、基本テーマ、プロフィールあたり 2 つのハブスロットが無料です。**MocPilot Pro** ではそれ以外のすべてが使えるようになります。個別のアイテムを購入することもできます。

## 無料で使えるもの {#whats-free}

- ロジックブロックとクイックリンク、対応するすべてのハブ、モーター、センサー
- **基本** テーマとそのすべてのコントロール
- プロフィールあたり 2 つのハブスロット
- 同期、カタログ、公開、Web エディター

## MocPilot Pro {#mocpilot-pro}

「MOCPilot のすべてを、すべてのデバイスで」：

- **すべて無料**：個別に購入するものはありません。テーマ、特殊コントロール、拡張機能（すべてのハブスロットを含む）など、有料アイテムがすべて含まれます。
- **AI アシスタント**：モデルを説明すると、アプリと Web エディターでハブ、ダッシュボード、プログラムを設定してくれます（[AI ビルダー](/docs/Application/Profiles/AiBuilder)を参照）。
- **リモートコントロール**：別のスマートフォン、タブレット、パソコンでプロフィールを実行し、自分のデバイスや Web エディターから操作します（[リモートコントロール](/docs/Application/Profiles/RemoteControl)を参照）。
- **今後も追加**：新しい Pro の機能は、リリースされ次第追加されます。

### プラン {#plans}

| プラン | 価格 |
|---|---|
| 月間 | 月額 $4.99 |
| 年間（「お得」） | 年額 $41.99 |

価格は国やストアによって異なる場合があります。新規登録の方は **7 日間の無料トライアル** を利用できます。

MocPilot Pro は MOCPilot アカウントに紐づくので、すべてのデバイスで使えます。登録するにはサインインしている必要があります。ブラウザーでは登録できません。iPhone、iPad、Mac、Android、Windows のアプリで登録すれば、Web エディターでも Pro が使えます。

Pro のページを開くには：**アカウント → 購入 → MocPilot Pro**、またはタブレットのサイドバーの **MocPilot Pro** カード。

### 管理と解約 {#manage-or-cancel}

Pro のページの **サブスクリプションを管理** を押すと、登録したストア（App Store、Google Play、Microsoft Store）が開きます。別のプラットフォームで登録した場合は、そちらでサブスクリプションを管理してください。現在の期間が終了する少なくとも 24 時間前までに解約しない限り、サブスクリプションは自動的に更新されます。

ページにはサブスクリプションの状態が表示されます：有効で次回の更新日、自動更新オフで有効期限、無料トライアルの終了日、またはストアで解決が必要な支払いの問題。

インターネットに接続していなくても、Pro はしばらく使い続けられます。その後は、オンラインに戻るまで「MocPilot Pro はオンラインでの確認が必要です」と表示されます。

## 購入 {#purchases}

個別に購入したアイテムは、Pro がなくてもずっと使えます。

| アイテム | 得られるもの |
|---|---|
| 有料テーマ | そのテーマのすべてのコントロール |
| 特殊コントロール：ハンドル、ペダル、変速機、サイドブレーキ、ウインカー、マスコン | そのコントロールのすべてのスタイル |
| 追加のハブスロット（最大 3 つ） | すべてのプロフィールでハブスロットが 1 つ増える |

テーマとコントロールはダッシュボードの **コントローラーを追加** パレットで（[方法](/docs/Application/Themes/GettingThemes)）、ハブスロットはマイハブの **スロットを解除** で購入します。

## 購入を復元する {#restore-purchases}

新しいデバイスやアプリの再インストール後は、同じアカウントでサインインし、**アカウント → 購入** を開いて **復元する** をタップします。Pro のページにも **購入を復元** があります。

Windows では、ゲストモードで MOCPilot アカウントなしに Microsoft Store の購入を復元することもできます。[Microsoft Store の購入を復元](/docs/Application/Account/UserAccount#restore-microsoft-store-purchases)を参照してください。

表示される可能性のあるメッセージ：

- **サブスクリプションは別のアカウントに紐づいています**：このストアアカウントには、別の MOCPilot アカウント用の MocPilot Pro がすでにあります。そのアカウントでサインインしてください。
- **復元するものはありません**：このストアアカウントで有効なサブスクリプションが見つかりませんでした。
- **あと少しです**：購入は完了しましたが、サーバーに接続できませんでした。アプリがオンラインになるとすぐに Pro が有効になります。
