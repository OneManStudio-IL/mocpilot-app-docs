# 設定 {#settings}

設定を開くには：

- **スマートフォン**：下部バーの **設定**。
- **タブレット**：サイドバーの **設定**。
- **パソコン**：上部バーの歯車ボタン。Mac では **MOCPilot → 設定…**（⌘,）、Windows では Ctrl+2 でも開けます。設定は専用のウインドウで開きます。

## アカウント {#account}

スマートフォンでは、設定のいちばん上にアカウント（ゲストモードでは **アカウントを作成またはサインイン**）が表示されます。タブレットではサイドバーの下部、パソコンでは上部バーの **アカウント** ボタンです。[アカウント](/docs/Application/Account/UserAccount)を参照してください。

## 設定項目 {#settings-1}

| 設定 | 内容 |
|---|---|
| **音** | アプリとコントロールの音（たとえばハンドルやペダルの効果音） |
| **振動** | コントロールに触れたときの短い振動。振動に対応したスマートフォンのみ |
| **画面を常にオンにする** | プロフィールを開いている間、画面が消えないようにします。操作するときはオンにしましょう。iPhone、iPad、Android、Windows で利用できます（Mac は不可） |
| **言語** | アプリの言語。下記の[言語](#language)を参照 |
| **ダークモード** | ダークまたはライトの外観。初回起動時はデバイスの外観に合わせます |

リモートコントロールは設定にはありません。別のデバイスからこのデバイスを操作するには、**私のプロフィール** ページの **リモコンを接続** を使います。[リモートコントロール](/docs/Application/Profiles/RemoteControl)を参照してください。

## 言語 {#language}

初回起動時、MOCPilot はアプリが対応していればデバイスの言語を使い、対応していなければ英語を使います。変更するには：

- **スマートフォンとタブレット**：**言語** をタップし、言語をタップします。アプリはすぐに切り替わります。現在使っている言語はリストに表示されません。
- **パソコン**：**言語** をクリックし、言語をクリックします（✓ が付きます。使用中の言語には **現在** と表示されます）。続いて **適用** をクリックするか Enter を押します。**キャンセル** または Esc で現在の言語のままになります。

アプリは 19 の言語に対応しています。選択画面には、それぞれの言語自身での名前で表示されます。

## アクセシビリティ {#accessibility}

アプリのボタンには、スクリーンリーダー（Apple デバイスの VoiceOver、Android の TalkBack）が読み上げる名前が付いています。**戻る**、**閉じる**、**設定**、**元に戻す** など、アイコンだけのボタンも含まれます。

## バージョン情報 {#about}

スマートフォンやタブレットでは、設定の下部にある **バージョン** から **MOCPilot について** が開き、プライバシーポリシー、利用規約、リリースノート / ニュースを確認できます。パソコンでは、上部バーの **ヘルプ → MOCPilot について**（Mac では **MOCPilot → MOCPilot について**）を使います。

## プロフィールの設定 {#profile-settings}

1 つのプロフィールに属する設定はエディターにあります。

- **エディター設定**：ブロックレベル、クリックでブロックを実行、プログラム停止時にハブのポートを停止。[エディターでの作業](/docs/Application/BlockBuilder/Editor#editor-settings)を参照してください。
- **ダッシュボード設定**：背景とグリッド。[ダッシュボード](/docs/Application/Dashboard/DashboardOverview#dashboard-settings)を参照してください。
- **ゲームパッド**：[ゲームパッド](/docs/Application/Dashboard/Gamepad)を参照してください。

サインインしていれば、アプリの設定はすべてのデバイスで同じになります。[デバイス間の同期](/docs/Application/Account/Sync)を参照してください。
