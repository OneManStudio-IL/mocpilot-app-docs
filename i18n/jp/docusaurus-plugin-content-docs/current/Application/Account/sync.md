# デバイス間の同期 {#sync-between-devices}

サインインしていれば、MOCPilot はプロフィールと設定をすべてのデバイス（スマートフォン、タブレット、パソコン、[Web エディター](/docs/Introducing/WebEditor)）で同じ状態に保ちます。オンにする操作は必要ありません。アカウントでは同期が常にオンです。

## しくみ {#how-it-works}

- 変更はまずデバイスに保存され、オンラインのときにアップロードされます（「プロフィールを同期中…」）。
- ほかのデバイスは、オンラインのときに新しいバージョンをダウンロードします。
- 購入品はファイルとして同期されるのではなく、アカウントに紐づいていて、サインインしたどこでも使えます。
- Web サイトで追加したプロフィール（カタログの **Add to my account**）や、Web エディターで編集したプロフィールは、同期によって届きます。
- ゲストモードでは何も同期されず、プロフィールはこのデバイスにだけ残ります。

## 競合 {#conflicts}

同期される前に同じプロフィールが 2 台のデバイスで変更された場合は、アカウントのバージョンが優先され、このデバイスのバージョンはコピーとして保存されます（名前に「(copy)」が付きます）。MOCPilot は **プロフィールの同期** メッセージでそのことを知らせます。ここで変更したプロフィールが別のデバイスで削除されていた場合も同じです。

別のデバイスで編集中のプロフィールを開くと、**閲覧のみ**（変更は保存されません）か **編集を引き継ぐ** を選べます。

## オフラインでの作業 {#working-offline}

ハブ、プロフィール、ダウンロード済みのテーマはインターネットなしで使えます。

- 起動時に MOCPilot がサーバーに接続できない場合は、**インターネットに接続されていません** と表示され、**オフラインで作業** と **再試行** が表示されます。
- オフラインの間は、上部に **オフライン** のラベルが表示されます。サーバーが必要な機能（カタログと公開、AI ビルダー、リモートコントロール、通知、購入、サポートへのメッセージ）では、インターネット接続が必要であることが表示されます。
- オフラインで行った変更は、接続が戻るとアップロードされます。アプリが再びサーバーに接続できるようになると、**接続が回復しました** と表示され、**オンラインにする** が表示されます。

## サインアウト {#signing-out}

サインアウトすると、このデバイスからプロフィールと設定が削除されます。それらはアカウントに残っていて、再びサインインすると戻ってきます。まだアップロードされていない変更がある場合は、MOCPilot が先に警告し、該当するプロフィールを一覧表示します。インターネットに接続して同期が終わるのを待つか、**サインアウトする** を選びます（コピーはアプリの Backup フォルダーに保存されます）。

## ヒント {#tips}

- プロフィールをカタログに公開する前に、同期されていることを確認しましょう。カタログはアカウントからプロフィールを取得します。
- アカウントのないデバイスにプロフィールを移すには、`.dat` ファイルで **共有** と **プロフィールをインポート…** を使います。[プロフィールの管理](/docs/Application/Profiles/ManageProfiles)を参照してください。
