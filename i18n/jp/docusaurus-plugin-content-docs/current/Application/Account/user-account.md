# アカウント {#account}

MOCPilot アカウントがあれば、プロフィール、設定、購入品が安全に保管され、すべてのデバイスで使えます。

## アカウントを持つ理由 {#why-have-an-account}

- プロフィールと設定がサーバーに保存され、デバイス間で同期されます。
- デバイスを買い替えたり紛失したりしても、すべてを取り戻せます。
- 購入品と MocPilot Pro が、すべてのデバイスと Web エディターで使えます。
- プロフィールをカタログに公開したり、通知を受け取ったりできます。

## サインイン {#sign-in}

サインイン画面で **メールまたはログイン名** と **パスワード** を入力するか、**Google でログイン** / **Sign In with Apple ID**（Apple ID でサインイン）を使います。

<Screenshot name="sign-in" alt="MOCPilot のサインイン画面" width={900} />

**QRコードでサインイン** では、スマートフォンでコードをスキャンし、Face ID または指紋で確認して、このデバイスでサインインします。スマートフォンにパスキーが必要です。mocpilot.com の **アカウント → 設定 → パスキー** で一度追加してください。

## アカウントを作成する {#create-an-account}

**アカウントを作成** をタップします。メールアドレスを 2 回、ユーザー名、パスワード（2 回）を入力し、地域を確認します。または **Continue with Google** / **Continue with Apple ID**（Google / Apple ID で続行）を使います。アクティベーションメールでメールアドレスを確認してください。アカウントが確認されるまで、一部の機能は使えません（メールが届かない場合は **アクティベーションメールを再送信** をタップします）。

## パスワードを忘れた場合 {#forgot-your-password}

「パスワードをお忘れですか？」の横の **リセット** をタップし、メールアドレスを入力して、メールに届いたコードを入力すると、新しいパスワードを設定できます。

## ゲストモード {#guest-mode}

サインイン画面の **アカウントなしで続行** を押すと、アカウントで得られることを一覧にした短い画面が開きます。そこでもう一度 **アカウントなしで続行** をタップすると、すぐにアプリを使い始められます。すべてのデータはこのデバイスだけに保存され、アプリを削除したりデバイスを紛失したりすると失われます。

後からサインインすることもできます。スマートフォンでは **設定** のいちばん上の **アカウントを作成またはサインイン** をタップします。タブレットやパソコンでは **アカウント**（ゲストモードでは **サインイン**）を開くと、**アカウントを作成** と **すでにアカウントをお持ちですか?** がある同じ画面が表示されます。

### Microsoft Store の購入を復元 {#restore-microsoft-store-purchases}

Windows では、ゲスト画面に **Microsoft Store の購入を復元** もあります。Microsoft Store の購入品は Windows で使っている Microsoft アカウントに紐づいているので、取り戻すのに MOCPilot アカウントは不要です。ボタンをクリックすると（インターネット接続が必要です）、アプリが Microsoft Store を確認し（**Microsoft Store を確認しています...**）、その Microsoft アカウントで購入したもの（MocPilot Pro のサブスクリプションを含む）をこの PC で使えるようにします。

<Screenshot name="guest-mode-windows" alt="「Microsoft Store の購入を復元」がある Windows のゲスト画面" width={900} />

## 地域 {#region}

MOCPilot が地域を尋ねるようになる前にアカウントを作成した場合、各デバイスでサインインの数秒後に一度だけ **地域を設定してください** と表示されます。地域は、アプリが適切なストアと価格を提示するのに役立ちます。**選択** をタップして **アカウントの詳細** で国を選ぶか、**今はしない** でスキップします。地域はいつでも **アカウントの詳細** で変更できます。

## アカウントページ {#account-page}

スマートフォン：**設定 → アカウント**。タブレット：サイドバー下部のアカウント。パソコン：上部バーの **アカウント** ボタン。

- **アカウントの詳細**：ログイン名、メールアドレス、地域、アカウント ID（項目をタップするとコピーできます）。
- **購入**：[MocPilot Pro と購入](/docs/Application/Account/Pro#purchases)を参照してください。
- **パスワードを変更する**。
- **サインアウト**：[サインアウト](/docs/Application/Account/Sync#signing-out)を参照してください。
- **アカウントを削除する**。

## アカウントを削除する {#delete-your-account}

**アカウントを削除する** は、アカウントのデータを完全に削除します。個人情報、設定、履歴、サーバーに保存されたプロフィールです。アカウントに紐づく購入済みやサブスクリプションのコンテンツも使えなくなります。元に戻すことはできません。

現在のパスワードを入力し、**アカウントを削除するにはスライドしてください**（タッチスクリーン）または **アカウントを削除する**（パソコン）で確定します。

有効なサブスクリプションはストアで管理されています。アカウントを削除する前に、ストアで解約してください。

## 通知 {#notifications}

**通知**（パソコンではベルのアイコン、スマートフォンとタブレットでは **通知** タブ）には、公開したプロフィールの審査結果、サポートへの問い合わせへの返信、MOCPilot チームからのお知らせが表示されます。既読にしたり、選択して削除したりできます。通知にはアカウントが必要です。
