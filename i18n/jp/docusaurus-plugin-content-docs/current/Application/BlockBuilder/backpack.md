# バックパック {#backpack}

**バックパック**は、ブロックプログラムの一部をほかのプロフィールで再利用するためにしまっておく場所です。ステアリングの処理、ライトショー、一度作ってどこでも使いたい私のブロックなどを入れておけます。あるプロフィールでブロックのスタックをバックパックに保存すれば、この端末でも、サインインしているほかの端末でも、別のプロフィールに挿入できます。

バックパックは[ロジックブロック](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing)エディターの機能です。クイックリンクのプロフィールにはありません。

## バックパックに保存されるもの {#what-the-backpack-keeps}

バックパックの各アイテムは、保存したブロックの**コピー**です。

- **スタック**：選んだブロックと、その下や内側につながっているすべてのブロック。**複製**でコピーされる範囲と同じです。
- **私のブロック**：[私のブロック](/docs/Application/BlockBuilder/Blocks/MyBlocks)の `定義する …` ブロックを保存すると、定義全体が保存されます。このようなアイテムには**マイブロック**の印が付きます。

アイテムには、ブロックが使っている私のブロック（ほかの私のブロックを経由して使っているものも含む）と、ブロックが参照している変数、リスト、メッセージ、車両、サウンドの名前も記録されます。そのため、別の場所に挿入してもブロックが動作します。

挿入したブロックは、プロフィールのプログラムの普通の一部になります。プロフィールはバックパックに依存しないので、アイテムを削除したり名前を変更したりしても、挿入先のプログラムは変わりません。バックパックの中でアイテムを編集することはできません。変更したい場合は、アイテムを挿入してプログラム内でブロックを編集し、新しいアイテムとしてもう一度バックパックに保存します。

## ブロックをバックパックに保存する {#save-blocks}

1. プログラム内のブロックを右クリック（パソコン）または長押し（スマートフォン、タブレット）します。
2. **バックパックに追加** を選びます。
3. **ブロックの名前** に名前を入力し、**保存** をタップします。

そのブロックと、つながっているすべてのブロックがバックパックに入ります。私のブロックの定義を保存するには、その `定義する …` ブロックでメニューを開きます。

## バックパックを開く {#open}

- **パソコンと Web エディター**：エディターの上部バーにある **バックパック** ボタン、メニューの **表示 → バックパック**、または **Ctrl+Shift+B**（Mac では **⌘⇧B**）。ウインドウの幅が狭いときは、ボタンは **その他** メニューにあります。バックパックはエディターの右側にパネルとして開きます。[モニター](/docs/Application/BlockBuilder/Editor#monitor)も開いている場合は、その隣に表示されます。
- **スマートフォンとタブレット**：エディターの上部バーで **その他 → バックパック**。バックパックはエディターの上にパネルとして開きます。

バックパックが開いている間は、ボタンが強調表示されます。もう一度押すとバックパックが閉じます。

各アイテムには、画像、名前、含まれるブロックの数（**ブロック: N**）が表示されます。パネル下部の注記には、バックパックの保存場所が表示されます（[下記](#where-it-is-kept)を参照）。

## プログラムにブロックを挿入する {#insert}

- **アイテムをタップ**：プログラムの表示されている部分にブロックが追加されます。
- **アイテムをプログラムにドラッグ**：ドロップした位置にブロックが置かれます。プログラムの方向へ横にドラッグしてください。上下にドラッグするとリストがスクロールします。
- **アイテムのメニュー（⋯）**：**挿入**、**名前を変更…**、**削除**。

スマートフォンとタブレットでは、挿入後にバックパックが閉じ、ブロックが見えるようになります。**元に戻す** を 1 回押すと、挿入したものがすべて取り消されます。

### 挿入するとどうなるか {#what-happens}

- **私のブロック**：内容が同じ私のブロックがプロフィールにすでにあれば、それが再利用されます。そのため、同じブロックを何度挿入しても私のブロックのコピーは増えません。プロフィール内の別の私のブロックが同じ名前を使っている場合は、挿入したものが独自の私のブロックになります。プロフィールにすでにある私のブロックのアイテムを挿入しても何も起こらず、**すでにあります** と表示されます。そのブロックは **私のブロック** で探してください。
- **変数、リスト、メッセージ、車両**：プロフィールに同じ名前のものがあればブロックはそれを使い、なければ新しく作成されます。変数の値やリストの中身はコピーされません。その名前がほかのものに使われている場合は、*変数「speed」を作成できませんでした: 名前が使われています* のようなメッセージが表示されます。
- **サウンド**：自分で追加したサウンドはプロフィールのファイルなので、バックパックには保存されません。プロフィールにその名前のサウンドがない場合は、*サウンド「…」はこのプロファイルにありません: ブロックでサウンドを選んでください* と表示されます。内蔵サウンドはどこでも使えます。
- **ハブとダッシュボードのブロック**：このプロフィールにないハブ、ダッシュボードのコントロール、ゲームパッド用のブロックは挿入できません。何かが変更される前に、アプリは **挿入できないブロックがあります** と表示し、該当するブロックの一覧と除外される数を示して、残りのブロックを挿入するかどうかを確認します。それらのブロックも残したい場合は、先にハブやダッシュボードのコントロールを追加してください。どのブロックもプロフィールに合わない場合は、何も挿入されません。

## 名前の変更と削除 {#rename-delete}

アイテムのメニュー（⋯）を開きます。

- **名前を変更…**：アイテムの名前を変更します。
- **削除**：確認（**バックパックから削除しますか?**）のあとで削除します。挿入先のプログラムのブロックはそのまま残ります。

バックパックがアイテムを自動的に削除することはありません。不要になったものは自分で削除してください。

## バックパックの保存場所 {#where-it-is-kept}

- **アカウントなし（ゲスト）**：この端末にのみ保存されます。パネルには *このデバイスに保存されています。ログインすると、すべてのデバイスでバックパックを使えます。* と表示されます。
- **サインイン中**：アカウントにも保存されるので、[Web エディター](/docs/Introducing/WebEditor)を含むすべての端末で同じバックパックを使えます。パネルには *アカウントに保存: すべてのデバイスで同じバックパックを使えます。* と表示されます。ある端末での変更は、ほかの端末にも反映されます。
- **初めてサインインしたとき**：この端末でゲストとして保存したアイテムがアカウントに移されます。

バックパックはオフラインでも使えます。変更は端末に保存され、接続が戻るとアカウントに送られます（その間、パネルには **同期中…** と表示されます）。アカウントからまだダウンロード中のアイテムは挿入できません。アプリに **まだ準備ができていません** と表示されたら、少し待ってからもう一度お試しください。

## 制限 {#limits}

| | 制限 |
|---|---|
| バックパックのアイテム数 | 200 |
| 1 アイテムのサイズ | 約 512 KB（プログラムのとても大きな部分は収まらないことがあります。小さな部分を保存してください） |
| アイテム名 | 100 文字まで |

アカウントのバックパックがいっぱいの場合や、アイテムが大きすぎる場合は、そのアイテムはこの端末にのみ保存され、アプリがそのことを知らせます。新しいバージョンのアプリで保存されたアイテムは、アプリを更新しないと挿入できません。

## トラブルシューティング {#troubleshooting}

| メッセージ | 対処法 |
|---|---|
| **バックパックがいっぱいです(200 個)。不要なものを削除してください。** | 使わなくなったアイテムを削除します。 |
| **バックパックに入れるにはブロックが多すぎます。もっと小さな部分を保存してください。** | 小さなスタックを保存するか、プログラムを複数のアイテムに分けます。 |
| **挿入できないブロックがあります** | ブロックに必要なハブ、ダッシュボードのコントロール、ゲームパッドがプロフィールにありません。追加してからもう一度挿入するか、ほかのブロックだけを挿入します。 |
| **すでにあります** | その私のブロックはすでにこのプロフィールにあります。**私のブロック** で探してください。 |
| **まだ準備ができていません** | アイテムはまだアカウントからダウンロード中です。少し待ってからもう一度お試しください。 |
| **これらのブロックは新しいバージョンのアプリで保存されました。使うにはアプリを更新してください。** | この端末の MOCPilot を更新します。 |
