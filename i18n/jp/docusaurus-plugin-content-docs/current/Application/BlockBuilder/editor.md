# エディターでの作業 {#working-in-the-editor}

<Screenshot name="blocks-editor" alt="ロジックブロックのエディター" width={900} />

## 上部バー {#top-bar}

- **コンピューターと Web エディター**：左側に**ホーム**とメニュー、その隣に**元に戻す**と**やり直す**があります。中央には、プロフィール名と**ダッシュボード**、**ハブ**、**ゲームパッド**があります。右側には、**AI ビルダー**、[**バックパック**](/docs/Application/BlockBuilder/Backpack)、**モニター**、**その他**（⋯）、**リモートコントロール**、オレンジ色の**実行**ボタンがあります。ウインドウの幅が狭いと、収まらないボタンは**その他**に移ります。**その他**には常に**エディター設定…**があります。
- **スマートフォンとタブレット**：左側に**ホーム**、右側に**元に戻す**、**やり直す**、**ダッシュボード**、**マイハブ**、**リモートコントロール**、**その他**、**実行 / 停止**があります。**その他**には、**AI ビルダー**、**バックパック**、**モニター**、**ゲームパッド**、**エディター設定**があります。

狭いウインドウでバーがどのように折りたたまれるかは、[スマートフォン、タブレット、デスクトップ](/docs/Introducing/Layouts#editor-top-bar)を参照してください。

## パレットとプログラムエリア {#palette-and-program-area}

- パレットの表示・非表示は**表示 → ブロックパレット**（⌘P / Ctrl+P）で切り替えます。
- カテゴリーを選び、ブロックをプログラムエリアにドラッグして、別のブロックの下にドロップするとつながります。どこにはまるかはプレビューで確認できます。
- スタック全体を動かすには、一番上のブロックをドラッグします。途中のブロックをドラッグすると、そのブロックと下にあるすべてのブロックが一緒に動きます。
- ブロックを削除するには、パレットにドラッグして戻します。
- 変数、リスト、メッセージ、私のブロックは、各カテゴリーのボタン（**変数を作成**、**リストを作成**、**メッセージを追加**、**ブロックを作成**）か、**編集 → 新しい変数… / 新しいリスト… / 新しいメッセージ… / 新しいブロック…** で作成します。サウンドと車両にも専用のボタンがあります。[サウンド](/docs/Application/BlockBuilder/Blocks/Sounds)の**サウンドを追加**と、[シミュレーター](/docs/Application/BlockBuilder/Blocks/Simulator)の**車両を作成**です。

## ズームとスクロール {#zoom-and-scroll}

- ピンチ操作（タッチスクリーンの場合）か、**表示 → ズームイン / ズームアウト / 実際のサイズ**（⌘+ / ⌘− / ⌘0）を使います。
- 何もない場所をドラッグすると、表示位置を移動できます。
- 何もない場所のコンテキストメニューには、**ズームイン**、**ズームアウト**、**ズームをリセット**、**N ブロックを削除**があります。

## ブロックメニュー {#block-menu}

ブロックを長押し（タッチスクリーンの場合）または右クリックします。

- **編集**：値を変更します。
- **複製**
- **ブロックを削除** / **N ブロックを削除**
- **バックパックに追加**：ブロックと、つながっているすべてのブロックを[バックパック](/docs/Application/BlockBuilder/Backpack)に保存します。
- **ブロックについて**：このドキュメントでブロックの説明を開きます。
- **ブロックを SVG としてエクスポート** / **すべてのブロックを SVG としてエクスポート**：チュートリアルやフォーラムの投稿用に画像を保存します。

<Screenshot name="blocks-block-menu" alt="ロジックブロックのブロックのコンテキストメニュー" width={900} />

ダッシュボードのコントロールに関連付けられたブロックは、そのコントロールから解放してからでないと削除できません。

## 元に戻す・やり直す {#undo-and-redo}

**編集 → 元に戻す / やり直す**（⌘Z / ⇧⌘Z、Ctrl+Z / Ctrl+Shift+Z）か、上部バーの**元に戻す**と**やり直す**のボタン（コンピューターではメニューの隣）を使います。

- 1 回のドラッグが 1 ステップです。同じ値を続けて素早く編集した場合は 1 ステップにまとめられます。
- プログラムの実行中でも元に戻せます。
- 変数、リスト、メッセージ、私のブロックの作成や削除も 1 ステップです。これを元に戻すと、実行中のプログラムは停止します。
- 変数やリストに保存された値は元に戻りません。
- ダッシュボードには別の元に戻す履歴があります。

## モニター {#monitor}

**モニター**（⇧⌘M / Ctrl+Shift+M、**表示 → モニター**）は、プログラムの実行中に変数とリストの現在の値を表示します。ボタンは、コンピューターでは上部バーに、スマートフォンやタブレットでは**その他**にあります。コンピューターでは別ウィンドウで開けます。バグを探すときにとても役立ちます。

## バックパック {#backpack}

**バックパック**（⇧⌘B / Ctrl+Shift+B、**表示 → バックパック**）には、どのプロフィールでも再利用できるブロックのスタックを保存しておけます。ブロックのメニューで**バックパックに追加**を選び、アイテムをタップまたはドラッグすると、どのプログラムにも挿入できます。ボタンは上部バーの**モニター**の隣、または**その他**にあります。[バックパック](/docs/Application/BlockBuilder/Backpack)を参照してください。

<Screenshot name="blocks-monitor" alt="プログラム実行中に変数とリストを表示しているモニター" width={900} />

## エディター設定 {#editor-settings}

上部バーの**その他 → エディター設定**から開きます（コンピューターでは**プログラム → エディター設定…**からも開けます）。

- **クリックでブロックを起動**：ブロックをクリックすると、そのブロックだけを実行してテストできます。プログラムが停止している場合は、プログラムも開始されます。
- **プログラムを中央で開く**：プロフィールを開いたとき、編集時にどこにあったかに関係なく、プログラムを 100% でキャンバスの中央に表示します（大きい場合は左上から表示します）。この端末のすべてのプロフィールに適用されます。
- **プログラム停止時にハブのポートを停止**：**停止**を押すと、すべてのモーターを止め、すべてのライトを消します。モーターの状態を保つ必要がなければ、オンのままにしておきましょう。
- **ブロックレベルを選択**：初心者、上級者、達人。

<Screenshot name="blocks-editor-settings" alt="ロジックブロックのエディター設定パネル" width={900} />

## ブロックレベル {#block-levels}

| レベル | 表示されるブロック |
|---|---|
| **初心者** | 最もシンプルなブロック。子どもや初めての方向けのすっきりしたパレット |
| **上級者** | 一般的なロジックとデバイスのブロック |
| **達人** | すべてのブロック |

レベルはプロフィールに保存されます。レベルを下げても、プログラムにすでにあるブロックはそのまま動作します。

## AI ビルダー {#ai-builder}

[MocPilot Pro](/docs/Application/Account/Pro) では、**AI ビルダー**（上部バーのキラキラのボタン、スマートフォンやタブレットでは**その他 → AI ビルダー**、⇧⌘I / Ctrl+Shift+I）が、入力または音声で伝えた説明からハブ、ダッシュボード、プログラムを設定し、その後もリクエストに応じてプロフィールを変更します。ロジックブロックとクイックリンクのプロフィールで使えます。[AI ビルダー](/docs/Application/Profiles/AiBuilder)を参照してください。

### よい結果を得るには {#ai-builder-tips}

ハブの名前、各ポートに何が接続されていて何をさせたいか、どのように操作したいかを伝えてください。[よいリクエストの書き方](/docs/Application/Profiles/AiBuilder#ai-builder-tips)を参照してください。

## デスクトップのメニュー {#desktop-menus}

| メニュー | 項目 |
|---|---|
| ファイル | プロフィールを閉じる（⌘W） |
| 編集 | 元に戻す、やり直す、新しい変数…、新しいリスト…、新しいメッセージ…、新しいブロック… |
| 表示 | ブロックパレット（⌘P）、[バックパック](/docs/Application/BlockBuilder/Backpack)（⇧⌘B）、モニター（⇧⌘M）、ズームイン、ズームアウト、実際のサイズ |
| プログラム | 実行（⌘R）、停止（⌘.）、エディター設定… |

Windows では、⌘ の代わりに Ctrl、⇧ の代わりに Shift を使います。
