# 例 {#examples}

最初の一歩に使える短いプログラムです。ブロック名は[ブロックリファレンス](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing#block-reference)に従います。かっこ内の値は、ハブ、ポート、またはスロットに入れた値ブロックです。字下げした行は C ブロックの中に入ります。

## ジョイスティックで走る {#drive-with-a-joystick}

ダッシュボード：ジョイスティック **JOY1**。駆動モーターはポート A。

```text
プログラムが開始されたとき
いつも繰り返す
    モーターを起動（設定値） (ジョイスティック JOY1 Y軸) 速度 %  (ハブ 1、ポート A)
```

## サーボでステアリングする {#steer-with-a-servo}

ステアリングモーター（アンギュラーモーター）はポート B。現在の位置を中心に設定し、ジョイスティックに追従させます。`× 0.9` でジョイスティックの −100…100 を −90…90 度に変換します。

```text
プログラムが開始されたとき
相対位置を設定 0  (ハブ 1、ポート B)
いつも繰り返す
    相対位置へ移動 (ジョイスティック JOY1 X軸 × 0.9) で 100 速度 %  (ハブ 1、ポート B)
```

エンドストップ付きのステアリングラックは、先にキャリブレーションします（[モーター](/docs/Application/BlockBuilder/Blocks/Motors#block_hubs_all_motors_port_calibrate_steering_rack)を参照）。`中心値` と `範囲` は変数です。キャリブレーション後、ラックは中央に止まりますが、そこでの相対位置は 0 ではなく中心値なので、ステアリングの前に 0 に設定します。

```text
プログラムが開始されたとき
ラックをキャリブレーション (中心値) 中心 (範囲) 度  (ハブ 1、ポート B)
相対位置を設定 0  (ハブ 1、ポート B)
いつも繰り返す
    相対位置へ移動 ((範囲 × ジョイスティック JOY1 X軸) ÷ 100) で 100 速度 %  (ハブ 1、ポート B)
```

## スイッチでライトを点ける {#lights-on-a-switch}

```text
スイッチの場合 SWCH1 切り替えられた 有効
    でオンにする 100 明るさ %  (ハブ 1、ポート C)
スイッチの場合 SWCH1 切り替えられた オフ
    オフにする  (ハブ 1、ポート C)
```

## クラクションボタン {#horn-button}

```text
ボタンを押したとき BTN1 が 押された
    サウンド 乗用車のクラクション 終わるまで再生
```

## バッテリー警告 {#battery-warning}

モニター **MNTR1**。バッテリーが少なくなるとボタンが赤くなります。

```text
プログラムが開始されたとき
いつも繰り返す
    表示 (ハブ 1 % バッテリー) 上 MNTR1 モニター
    もし (ハブ 1 % バッテリー) < 20 その後
        設定する BTN1 色に設定 赤
    待つ 5 秒
```

## 障害物の手前で止まる {#stop-before-an-obstacle}

Technic 距離センサーはポート D、駆動モーターはポート A。

```text
プログラムが開始されたとき
いつも繰り返す
    もし (距離 cm  (ハブ 1、ポート D)) < 10 その後
        モーターを停止  (ハブ 1、ポート A)
        LEDの色を設定 赤  (ハブ 1)
    他の
        モーターを起動（設定値） (スライダー SLDR1) 速度 %  (ハブ 1、ポート A)
        LEDの色を設定 緑  (ハブ 1)
```

## ステップスイッチで速度を制限する {#speed-limit-on-a-stepper}

4 段のステップスイッチ **STPR1** で最高速度を制限します。

```text
プログラムが開始されたとき
いつも繰り返す
    設定する (速度制限) へ (ステップスイッチ STPR1 × 25)
    モーターを起動（設定値） (ジョイスティック JOY1 Y軸 × 速度制限 / 100) 速度 %  (ハブ 1、ポート A)
```

`速度制限` は変数です（**変数 → 変数を作成**）。

## 起動時のチェック {#startup-check}

両方のハブが接続されるまでスロットルをロックします。

```text
プログラムが開始されたとき
設定する JOY1 インタラクティビティ 無効化
まで待つ (ハブ 1 接続済み) かつ (ハブ 2 接続済み)
表示 "準備完了" 上 MNTR1 モニター
設定する JOY1 インタラクティビティ 有効化
```

## ゲームパッド {#gamepad}

[ゲームパッドのページ](/docs/Application/Dashboard/Gamepad)で**ゲームパッドの値の範囲**を −100…100 に設定し、**ゲームパッドブロックを有効にする**をオンにします。

```text
プログラムが開始されたとき
いつも繰り返す
    モーターを起動（設定値） (スティック 左 Y軸) 速度 %  (ハブ 1、ポート A)
    相対位置へ移動 (スティック 右 X軸 × 0.9) で 100 速度 %  (ハブ 1、ポート B)
```
