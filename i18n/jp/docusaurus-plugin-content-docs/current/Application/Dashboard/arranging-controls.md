# コントロールの追加と配置 {#add-and-arrange-controls}

## コントロールを追加する {#add-a-control}

1. ダッシュボードで **+**（**コントローラーを追加**）をタップします。パソコンでは、上部バーの右側にある **+ コントローラー** をクリックします。パソコンでは、パレットが専用のウインドウで開き、その上部バーの中央に **コントローラーを追加** と表示されます。
2. リストからコントロールの種類を選びます。種類はグループに分かれています：**ジョイスティック**、**スライダー**、**ボタンとスイッチ**、**モニター**、続いて[特殊コントロール](/docs/Application/Dashboard/SpecialControls)の **車両・特殊**、保存したデザインの **マイデザイン**。コントロールをすばやく見つけるには、**コントロールを検索** に入力します。
3. 外観の一覧には、選んだ種類がすべての[テーマ](/docs/Application/Themes/ThemesOverview)で表示されます（特殊コントロールの場合は、そのすべての外観）。外観をタップすると大きなプレビューで表示され、その場で試すこともできます。
4. **設定** でコントロールを設定します：**スタイル** と **設定** のタブ、そしてサイズ。
5. **ダッシュボードに追加** をタップします（パソコンでは、パレットの上部バーの右側にあるオレンジ色のボタン）。パソコンでは、続けて複数のコントロールを追加できます。

<Screenshot name="controller-palette" alt="「コントローラーを追加」パレット" width={900} />

コントロールは最初の空きエリアに配置され、**新しい** バッジが付きます。スペースがない場合は MOCPilot がそのことを知らせるので、スペースを空けるか小さいサイズを選んでください。

お持ちでないテーマのコントロールには、**ダッシュボードに追加** の代わりに **購入** と **MocPilot Pro ですべて** が表示されます。[テーマの入手、購入、アップデート](/docs/Application/Themes/GettingThemes)を参照してください。

## 移動する {#move}

編集モードで、コントロールを押したままドラッグします。離すと、最も近いグリッドのマスに吸着します。ほかのコントロールと重なる場合は、元の位置に戻ります。

## サイズ {#sizes}

どのコントロールにも **S**、**M**、**L** の 3 つのサイズがあります。コントロールのプロパティの **サイズ** で変更します。グリッドのマス単位のサイズ（幅 × 高さ）：

| コントロール | S | M | L |
|---|---|---|---|
| ジョイスティック、方向パッド | 7×7 | 10×10 | 13×13 |
| スライダー | 10×3 | 14×4 | 18×5 |
| 縦型スライダー | 3×10 | 4×14 | 5×18 |
| ロータリーノブ | 6×6 | 8×8 | 10×10 |
| ボタン、スイッチ | 3×3 | 4×4 | 5×5 |
| ステップスイッチ | 8×3 | 12×4 | 16×5 |
| 縦型ステップスイッチ | 3×8 | 4×12 | 5×16 |
| モニター | 4×2 | 6×2 | 8×3 |
| バッテリーレベル、スピードメーター | 6×6 | 8×8 | 10×10 |
| 傾きモニター | 8×4 | 12×6 | 16×8 |
| ハンドル | 8×8 | 12×12 | 16×16 |
| ペダル | 11×8 | 16×12 | 21×16 |
| マニュアル変速機、オートマチック変速機 | 8×8 | 10×10 | 12×12 |
| サイドブレーキ | 4×7 | 6×10 | 8×13 |
| ウインカー | 8×5 | 10×6 | 14×8 |
| マスコン | 6×8 | 8×10 | 10×13 |

フィールド全体は 40 × 20 マスです。大きいサイズが収まらない場合は、先に隣のコントロールを移動してください。

## 選択と編集 {#select-and-edit}

コントロールをタップ（クリック）すると選択され、その **プロパティ** が開きます。[コントロールのプロパティ](/docs/Application/Dashboard/ControlProperties)を参照してください。

## コンテキストメニュー {#context-menu}

コントロールを長押し（タッチスクリーン）または右クリック（パソコン）します。

- **ロック** / **ロック解除**
- **プロパティ**
- **テーマを変更**：お持ちのテーマのうち、同じ種類のコントロールがある別のテーマに切り替えます
- **複製**：同じプロパティのコピーを作ります
- **複製（種類のみ）**：同じ種類の新しいコントロールを初期設定のプロパティで作ります
- **削除**

フィールドの空いている部分を長押しまたは右クリックします。

- **すべてをロック** / **すべてをアンロック**
- **N 個のコントローラーを削除**：ロックされていないすべてのコントロールを削除します

パソコンでは、プロパティパネルが開いているとき：**Esc** で閉じる、**Delete** / **Backspace** でコントロールを削除、**⌘D / Ctrl+D** で複製します。

## コントロールをロックする {#lock-controls}

**ロックされた** コントロールは移動も削除もできないので、操作中や編集中にうっかり位置がずれることがありません。ロックのアイコンが表示されます。1 つのコントロールをロックするにはメニューか設定の **コントローラーをロックする** を使い、すべてをロックするには **すべてをロック** を使います。

## コントロールの名前 {#control-names}

各コントロールには短い名前があり、編集モードでは枠に表示されます。たとえば **JOY1**、**SLDR2**、**BTN1** などです。プログラムはこの名前でコントロールを参照します。クイックリンクでは入力ブロックに *JOY1* と表示され、ロジックブロックではブロックのメニューで *JOY1* を選びます。

## 削除する {#delete}

メニューの **削除** か、プロパティのゴミ箱ボタンを使います。ロックされたコントロールは削除できません。プログラムで使われているコントロールは、その行やブロックを取り除くまで削除できません。
