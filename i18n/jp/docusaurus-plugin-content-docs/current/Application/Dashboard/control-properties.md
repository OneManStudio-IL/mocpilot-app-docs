# コントロールのプロパティ {#control-properties}

編集モードでコントロールをタップ（クリック）すると、プロパティが開きます。

- **スマートフォンとタブレット**：ダッシュボードの上にパネルとして開きます。パネルの外をタップすると閉じます。
- **パソコン**：サイドパネルとして開きます。開いたままダッシュボードで作業を続けられます。

<Screenshot name="controller-properties" alt="スタイルと設定のタブがあるコントロールのプロパティパネル" width={900} />

ヘッダーには、コントロールの名前（たとえば **JOY1**）、ゴミ箱ボタン、複製メニュー、**OK** が表示されます。

## スタイルタブ {#style-tab}

- **サイズ**：S、M、L。[サイズ](/docs/Application/Dashboard/ArrangingControls#sizes)を参照してください。
- **アクセントカラー**：コントロールのメインの色。
- **アイコン**：コントロール（ボタン、スイッチ、モニター）に表示する画像。260 種類以上のアイコンから選べます。
- **外観**：[特殊コントロール](/docs/Application/Dashboard/SpecialControls)の外観。たとえばハンドルのスタイルなど。
- テーマ固有のオプション：たとえば、レーシングの **カラー炭素**、**カラフルなベゼル**、**レースラインを表示**、建設機械の **インジケーターのセグメント数**、オーラの **値を表示** など。
- **テーマを変更**：お持ちのテーマのうち、同じ種類のコントロールがある別のテーマに切り替えます。

## 設定タブ {#settings-tab}

共通の設定：

- **コントローラーをロックする**：ロックされたコントロールは移動も削除もできません。
- **インタラクティビティ**：インタラクティブでないコントロールは、押しても反応しません。

種類ごとの設定：

| コントロール | 設定 |
|---|---|
| ジョイスティック | **軸の種類**：両方の軸 (X, Y)、水平のみ (X)、垂直のみ (Y) |
| スライダー、縦型スライダー | **ゼロに戻す**、**負の値**、**ステップ値** |
| ロータリーノブ | **クリック段数（0 = なめらか）**（0～24）、**中央ゼロ（-100..100）** |
| ステップスイッチ、縦型ステップスイッチ | **ステップ数**（1～100）、**負の値**、**リセットを有効にする** |
| モニター | **テキストレイアウト**、**テキストのはみ出し**、**最大行数**、**スクロール方向**、**スクロール速度**、**スクロールバーを表示**、**インタラクティブスクロール**、**テキスト配置**、**テキスト倍率** |
| 傾きモニター | **ピッチを反転**、**ロールを反転** |
| ハンドル | **ハンドル角度**（20～120°）、**音響効果** |
| ペダル | **音響効果** |
| マニュアル変速機 | **ギア数**（2～6） |
| オートマチック変速機 | **ギア数**（2～8） |
| ウインカー | **ウインカー出力を点滅させる**。スタイルタブでは **アイコン: left**、**アイコン: light**、**アイコン: right** |

数値の設定には、初期値に戻す **リセット** ボタンがあります。

## プログラムからプロパティを変更する {#change-properties-from-the-program}

ロジックブロックでは、プログラムの実行中にブロックでコントロールを変更できます。色を設定したり、インタラクティビティをオン / オフしたり、モニターに値を表示したりできます。[オンスクリーンコントローラーのブロック](/docs/Application/BlockBuilder/Blocks/DashboardControllers)を参照してください。
