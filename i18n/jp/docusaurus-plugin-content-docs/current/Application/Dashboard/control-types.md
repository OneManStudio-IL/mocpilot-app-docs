# コントロールの種類 {#control-types}

どの[テーマ](/docs/Application/Themes/ThemesOverview)も、同じ種類のコントロールをそれぞれのスタイルで描きます。無料の **基本** テーマには 9 種類があり、有料テーマにはさらに **ロータリーノブ** と 3 種類のグラフィックモニターが加わります。ハンドル、ペダル、シフトレバーなどの[特殊コントロール](/docs/Application/Dashboard/SpecialControls)は別売りの製品です。

| コントロール | ダッシュボード上の名前 | プログラムに渡すもの | 利用できるテーマ |
|---|---|---|---|
| ジョイスティック | JOY | X 軸と Y 軸 | すべてのテーマ |
| 方向パッド | DPAD | 上 / 下 / 左 / 右のボタン | すべてのテーマ |
| スライダー | SLDR | 値 | すべてのテーマ |
| 縦型スライダー | VSLDR | 値 | すべてのテーマ |
| ロータリーノブ | DIAL | 値 | 有料テーマ |
| ボタン | BTN | 押された / 離された | すべてのテーマ |
| スイッチ | SWCH | オン / オフ | すべてのテーマ |
| ステップスイッチ | STPR | ステップ番号 | すべてのテーマ |
| 縦型ステップスイッチ | VSTPR | ステップ番号 | すべてのテーマ |
| モニター | MNTR | テキストや値を表示 | すべてのテーマ |
| バッテリーレベル | MNTBT | レベルを表示 | 有料テーマ |
| スピードメーター | MNTSP | 速度を表示 | 有料テーマ |
| 傾きモニター | MNTLT | ピッチとロールを表示 | 有料テーマ |
| ハンドル、ペダル、変速機、サイドブレーキ、ウインカー、マスコン | STWHEEL、PDLS、GEAR、GEARA、HBRK、STALK、TRTHR | [特殊コントロール](/docs/Application/Dashboard/SpecialControls)を参照 | 特殊製品 |

ダッシュボード上の名前には番号が付きます。1 本目のジョイスティックは **JOY1**、2 本目は **JOY2** です。

## ジョイスティック {#joystick}

手を離すと中央に戻るスティックです。**X**（左右）と **Y**（上下）の値を返し、中央がゼロです。

- **軸の種類**：**両方の軸 (X, Y)**、**水平のみ (X)**、**垂直のみ (Y)**。走行だけ、またはステアリングだけに使う場合は、1 軸のジョイスティックのほうが扱いやすくなります。
- よくある使い方：Y で走行、X でステアリング。または戦車の左右のキャタピラに 1 本ずつ。

## 方向パッド {#directional-pad}

上、下、左、右の 4 つのボタンです。それぞれ押されているか離されているかのどちらかです。クイックリンクでは、方向パッドの軸は −1、0、+1 の値を返します（**上 / 下** または **左 / 右**）。クレーンのフックのように少しずつ動かしたいときに便利です。

## スライダーと縦型スライダー {#slider-and-ver-slider}

水平または垂直のレールに沿って動くハンドルです。

- **ゼロに戻す**：手を離すとハンドルが戻ります（スロットルのように）。オフにすると、離した位置にとどまります（列車の速度設定のように）。
- **負の値**：中央がゼロになり、スライダーが負と正の値（後退と前進）を返します。
- **ステップ値**：スライダーが段階的に動きます。

## ロータリーノブ {#rotary-knob}

音量つまみのような丸いノブで、すべての有料テーマの **スライダー** グループにあります。中心の周りを 1 本の指で回します。左右それぞれ約 135° 回り、離した位置にとどまります。

- **クリック段数（0 = なめらか）**（0～24）：段数を設定すると、ノブがクリック感とともに 1 段ずつ回ります。
- **中央ゼロ（-100..100）**：ノブが 0～100 ではなく、中央をゼロとして −100～100 を返します。
- ブロック：*ロータリーノブのイベント*（回した / 押した / 離した / 最小まで回した / 最大まで回した）、*ロータリーノブの値（数値）*、*ロータリーノブの値（真偽値）*（押されている / 最小 / 最大）。[オンスクリーンコントローラー](/docs/Application/BlockBuilder/Blocks/DashboardControllers#rotary-knob-blocks)を参照してください。
- クイックリンクでは、ノブは[スライダー](/docs/Application/Links/Blocks/InputBlocks#controller-knob)と同じように動作します。

基本テーマにはロータリーノブがありません。有料テーマにはすべてノブがあるので、**テーマを変更** でノブを別のテーマの外観に切り替えられます。

## ボタン {#button}

押している間は「押された」、離すと「離された」になります。ホーンや短い動きに使うほか、クイックリンクの **トグル** ブロックと組み合わせて何かをオン / オフするのにも使えます。

## スイッチ {#switch}

オンまたはオフの状態を保ちます。タップすると切り替わります。ライト、モード、ウインチのロックなどに使います。

## ステップスイッチと縦型ステップスイッチ {#step-switch-and-ver-step-switch}

ギアや列車の速度段階のように、ステップを数える **−** / **+** のコントロールです。

- **ステップ数**：1～100（初期値 10）。
- **負の値**：ゼロ未満のステップ（後退の段階）を使えるようにします。
- **リセットを有効にする**：値をタップするとゼロに戻ります。

## モニター {#monitor}

プログラムからのテキストや数値を表示します。速度、バッテリー、モード名、センサーの値などです。

- **テキストレイアウト**（1 行または複数行）、**テキストのはみ出し**（クリップ、折り返し、マーキー、スクロール）、**最大行数**、スクロールのオプション、**テキスト配置**、**テキスト倍率**。

## バッテリーレベル、スピードメーター、傾きモニター {#battery-level-speedometer-tilt-monitor}

有料テーマのグラフィックインジケーターです。値はプログラムが設定します。ハブのバッテリー、モーターの速度、ハブの傾きなどです。**傾きモニター** には **ピッチを反転** と **ロールを反転** があります。[インジケーターとモニター](/docs/Application/Dashboard/Indicators)を参照してください。

## 特殊コントロール {#special-controls}

ハンドル、ペダル、マニュアル変速機またはオートマチック変速機、サイドブレーキ、ウインカーレバー、マスコンです。それぞれが別売りの製品で、多くの外観があります。[特殊コントロール](/docs/Application/Dashboard/SpecialControls)を参照してください。

## インタラクティビティ {#interactivity}

インタラクティブなコントロールにはすべて **インタラクティビティ** があります（初期設定はオン）。インタラクティブでないコントロールは、タッチに反応しません。プログラムからインタラクティビティをオン / オフできます。たとえば、起動時のチェックが終わるまでスロットルを操作できないようにする、といった使い方です。
