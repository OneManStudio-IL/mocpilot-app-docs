# ダッシュボードエディター {#dashboard-editor}

**ダッシュボード** は、モデルを操作する画面です。ジョイスティック、スライダー、ボタン、モニターなどのコントロールを置きます。プロフィールごとに 1 つのダッシュボードがあります。

エディターの **ダッシュボード** ボタンで開きます（パソコンでは ⌘2 / Ctrl+2）。

- **スマートフォンとタブレット**：ダッシュボードがエディターの上に全画面で開きます。
- **パソコン**：ダッシュボードが専用の **ダッシュボード** ウインドウで開くので、プログラムの横に並べておけます。
- **Web エディター**：ドラッグやサイズ変更ができるフローティングパネルです。

<Screenshot name="dashboard-edit" alt="ドットグリッドが表示された編集モードのダッシュボード" width={900} />

## フィールドとグリッド {#the-field-and-the-grid}

- フィールドは常に **2:1** の形で画面に合わせて表示されるので、ダッシュボードはスマートフォン、タブレット、パソコンのどれでも同じように見えます。
- 編集モードでは、40 × 20 マスの **ドットグリッド** が表示されます。コントロールはグリッドに吸着します。
- コントロールは重ねられません。コントロールが収まらない場合は、元の位置に戻ります。

## ツールバー {#toolbar}

| ボタン | 機能 |
|---|---|
| ← | プログラムエディターに戻る |
| 元に戻す / やり直す | ダッシュボードの変更を元に戻す、やり直す |
| **+**（コントローラーを追加） | コントローラーのパレットを開く。[コントロールの追加と配置](/docs/Application/Dashboard/ArrangingControls)を参照 |
| ⚙（ダッシュボード設定） | 背景とグリッドのオプション（下記） |
| ▶ / ■ | **実行** / **停止**：プログラムを開始・停止する |

パソコンでは、ダッシュボードのウインドウにもメニューがあります：**ファイル**（プロフィールを閉じる、別ウインドウで開く、ダッシュボード設定…）、**編集**（元に戻す、やり直す、コントローラーを追加…）、**表示**（ブロック ⌘1、ダッシュボード ⌘2）。

プログラムの実行中は、編集用のボタンは非表示になります。

## 元に戻す・やり直す {#undo-and-redo}

ダッシュボードには、プログラムとは別の独自の履歴があります。移動、サイズ変更、プロパティの変更、追加、削除のすべてを元に戻せます。

## ダッシュボード設定 {#dashboard-settings}

**背景画像**：**変更** をタップして選びます。

- **プリセットを選択**：テーマに付属する既製の背景です。ギャラリーには、このダッシュボードに置かれているコントロールのテーマの背景が表示されます。プリセットの背景は常にフィールドの周りの画面全体を埋めるので、以下のオプションは適用されません。
- **自分の画像をアップロード**：デバイス内の任意の画像です。プロフィールに保存されます。

**削除** で背景を消去します。

<Screenshot name="dashboard-backgrounds" alt="プリセットの背景のギャラリーが表示されたダッシュボード設定" width={900} />

自分の画像では、さらに次の項目も設定できます。

- **画像の塗りつぶしモード**：引き伸ばし、縦横比を維持して合わせる、縦横比を維持して切り抜く、タイル表示、縦方向にタイル表示、横方向にタイル表示、余白を追加。
- **画像の親領域**：**作業領域**（フィールドのみ）または **画面全体**。
- **画像の不透明度**、**画像ぼかしを有効化**、**ぼかし値**：背景を落ち着かせて、コントロールを目立たせます。

**ドットを非表示**：プロフィールの実行中にグリッドのドットを非表示にします。編集モードでは、コントロールを整列できるようにドットは表示されたままです。

## コントロールとプログラム {#controls-and-the-program}

コントロールは値を渡し、その値で何をするかはプログラムが決めます。プログラムで使われているコントロールは、プログラムで使われなくなるまで削除できません。クイックリンクではそれを使っている行を、ロジックブロックではそのブロックを取り除いてください。
