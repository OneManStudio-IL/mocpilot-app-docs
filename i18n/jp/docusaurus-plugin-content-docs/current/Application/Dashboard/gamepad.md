# ゲームパッド {#gamepad}

実物のゲームパッドは、タッチスクリーンより操作しやすいことがよくあります。本物のスティック、トリガー、ボタンがあるからです。MOCPilot は、デバイスのシステムが対応している Bluetooth や USB のゲームパッドで動作します（iPhone、iPad、Android、Mac、Windows での Xbox や PlayStation タイプのコントローラー）。

ゲームパッドはダッシュボードと一緒に動作し、両方を同時に使えます。

## ゲームパッドを接続する {#connect-a-gamepad}

1. システムの Bluetooth 設定で、ゲームパッドをスマートフォン、タブレット、パソコンとペアリングします（または USB で接続します）。
2. プロフィールを開き、エディターで **ゲームパッド** をタップします。
3. ページのヘッダーに **ゲームパッド：（名前）** と表示されます。「Gamepad is not connected」（ゲームパッドが接続されていません）は、システムがまだゲームパッドを認識していないことを意味します。

## ゲームパッドのページ {#gamepad-page}

- **ゲームパッドブロックを有効にする**：このプロフィールでゲームパッドの入力をオンにします。オフのままだと、ゲームパッド入力を使うクイックリンクの行に「ゲームパッドページ（上部バー）でゲームパッドブロックをオンにしてください」と表示され、ロジックブロックにはゲームパッドのカテゴリが表示されません。
- **ゲームパッドのボタン配置**：**Xbox**（A、B、X、Y、LB、RB、LT、RT）または **Sony PS**（バツ、マル、四角、三角、L1、R1、L2、R2）。エディターでは、この選択に合わせてボタンの名前が表示されます。
- **ゲームパッドの値の範囲**（ロジックブロック）：スティックの値は **-1..1** または **-100..100**。
- **ゲームパッドを選択**：複数のゲームパッドが接続されているときに使います。
- **ゲームパッドをテスト** → **テスト**：ボタン、トリガー、スティック、十字キーを表示するライブテスターで、使う前にすべてを確認できます。

設定はプロフィールに保存されます。

## クイックリンクでゲームパッドを使う {#use-the-gamepad-in-quick-links}

**ゲームパッド** 入力を行にドラッグし、その **入力** を選びます。

- スティック：左スティック Y、左スティック X、右スティック Y、右スティック X
- トリガー：RT / LT（R2 / L2）
- フェイスボタン：A、B、X、Y（バツ、マル、四角、三角）
- バンパー：LB / RB（L1 / R1）
- 十字キー：上、下、左、右

例：*ゲームパッド*（左スティック Y）→ *スムーズ* → *モーター* → *ハブ*（ポート A）。[入力](/docs/Application/Links/Inputs#gamepad)を参照してください。

## ロジックブロックでゲームパッドを使う {#use-the-gamepad-in-logic-blocks}

**ゲームパッド** カテゴリには、イベントブロック（ボタン、十字キー、スティックが特定の状態になったとき）と値ブロック（ボタン、十字キー、スティック、トリガーの圧力）があります。[ゲームパッドのブロック](/docs/Application/BlockBuilder/Blocks/Gamepad)を参照してください。

## 公開用のプロフィール {#profiles-for-publishing}

ダッシュボードのコントロールがなくゲームパッドだけのプロフィールでも、カタログに公開できます。要件は「ダッシュボードのコントローラーまたはゲームパッド」です。
