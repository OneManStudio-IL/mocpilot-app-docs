# インジケーターとモニター {#indicators-and-monitors}

モニターは、操作中にダッシュボードに情報を表示します。バッテリー残量、速度、傾き、障害物までの距離、現在のギアやモードなどです。

| モニター | 表示内容 | テーマ |
|---|---|---|
| **モニター** | テキストまたは数値 | すべてのテーマ |
| **バッテリーレベル** | レベルゲージ | 有料テーマ |
| **スピードメーター** | 速度ゲージ | 有料テーマ |
| **傾きモニター** | モデルのピッチとロール | 有料テーマ |

モニターは情報を表示するだけで、操作には使えません。何を表示するかはプログラムが決めます。

## クイックリンクでは {#in-quick-links}

**インジケーター** 出力を使います。行はハブではなくインジケーターで終わります。

- *ハブ*（バッテリー）→ *インジケーター*（バッテリーレベル）：ハブのバッテリーをゲージに表示します。
- *ハブ*（モーターの速度、ポート A）→ *インジケーター*（スピードメーター）。
- *ハブ*（傾き：ピッチ）→ *インジケーター*（傾きモニター、傾き X）。さらに、傾き：ロール → 傾き Y の行をもう 1 つ作ります。
- *ハブ*（バッテリー電圧）→ *インジケーター*（モニター）：「7.85 V」のように値を単位付きで表示します。

インジケーターは値をそのまま表示するので、この行には動作がありません。[インジケーター](/docs/Application/Links/Blocks/OutputBlocks#dash-indicator)を参照してください。

## ロジックブロックでは {#in-logic-blocks}

オンスクリーンコントローラーのブロックを使います。

- モニターには *モニターに表示*
- バッテリーレベルとスピードメーターには *モニターに値を設定*
- 傾きモニターには *傾きモニターに値を設定*（ピッチ / ロール）

センサーの値、変数、「ギア 2」のようなテキストなど、計算できるものなら何でも表示できます。[オンスクリーンコントローラー](/docs/Application/BlockBuilder/Blocks/DashboardControllers#monitor-blocks)を参照してください。

## ヒント {#tips}

- バッテリーのモニターは、指で隠れない隅に置きましょう。
- 長いメッセージには、はみ出しを **マーキー** または **スクロール** にした複数行のモニターを使いましょう。
- プログラムでほとんどのコントロールの色を変えられます。たとえば、バッテリーが少なくなったらボタンを赤くする、といった使い方です。
