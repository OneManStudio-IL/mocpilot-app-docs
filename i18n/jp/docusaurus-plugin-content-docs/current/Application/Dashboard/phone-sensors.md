# スマートフォンのセンサー {#phone-sensors}

スマートフォンやタブレットにはモーションセンサーがあります。MOCPilot はそれを入力として使えます。スマートフォンを傾けてステアリングを操作したり、振って何かを動かしたり、スマートフォンのバッテリー残量をダッシュボードに表示したりできます。

スマートフォンのセンサーは **ロジックブロック**（**センサー** カテゴリ）で使えます。クイックリンクでは、ダッシュボードのコントロール、ゲームパッド、ハブのセンサーを入力として使います。

## センサーのブロック {#sensor-blocks}

| ブロック | 返す値 |
|---|---|
| `デバイス … 角度`（ピッチ、ロール） | デバイスの傾き（度） |
| `デバイス … 加速度 (m/s²)`（x、y、z） | デバイスの加速度（m/s²） |
| `デバイス … 加速度計 (m/s²)`（x、y、z） | 加速度計の生の値（m/s²） |
| `デバイス % バッテリー` | デバイスのバッテリー残量 |

詳細：[センサー](/docs/Application/BlockBuilder/Blocks/Sensors)。

## 例：スマートフォンを傾けてステアリングを操作する {#example-steer-by-tilting-the-phone}

```text
プログラムが開始されたとき
いつも繰り返す
    位置へ移動  (ハブ 1、ポート B)  ←  デバイス ロール 角度 × 2
```

ステアリングには、絶対位置に対応したモーター（アンギュラーモーター）を使います。

スマートフォンをハンドルのように横向きに持ちます。ステアリングがエンドストップに当たらないよう、*の間に* や *最小 / 最大* の演算子で値を制限してください。

## ヒント {#tips}

- デバイスの画面の回転をロックしてください。ロックしないと、傾けたときにシステムが画面を回転させることがあります。
- パソコンにはモーションセンサーがないため、ブロックはゼロを返します。
- 傾きをダッシュボードに表示するには、角度を **傾きモニター**（有料テーマ）に送ります。[インジケーターとモニター](/docs/Application/Dashboard/Indicators)を参照してください。
- ハブにも独自の傾きセンサーがあります。ハブのセンサーブロックと、クイックリンクの **ハブ** 入力を参照してください。
