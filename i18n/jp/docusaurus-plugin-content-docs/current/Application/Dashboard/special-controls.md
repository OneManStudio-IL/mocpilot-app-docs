# 特殊コントロール {#special-controls}

特殊コントロールは、本物そっくりの見た目と動きをします。ハンドル、ペダル、シフトレバー、サイドブレーキ、ウインカーレバー、そして機関車のマスコンです。それぞれが別売りの製品なので、必要なものだけを購入するか、[MocPilot Pro](/docs/Application/Account/Pro) ですべてを手に入れましょう。

<Screenshot name="special-controls-dashboard" alt="ハンドル、ペダル、シフトレバー、サイドブレーキ、ウインカー、マスコンを配置したダッシュボード" width={900} />

| コントロール | 製品 | ダッシュボード上の名前 | プログラムに渡すもの |
|---|---|---|---|
| [ハンドル](#steering-wheel) | ハンドル | STWHEEL | ハンドル角度、ホーン |
| [ペダル](#pedals) | ペダル | PDLS | アクセルとブレーキ |
| [マニュアル変速機](#gear-shifter) | シフトレバー | GEAR | ギア：R、N、1…6 |
| [オートマチック変速機](#gear-shifter) | シフトレバー | GEARA | セレクター：P、R、N、D |
| [サイドブレーキ](#handbrake) | サイドブレーキ | HBRK | 強さ、ロック |
| [ウインカー](#turn-signals) | ウインカー | STALK | 左ウインカー、右ウインカー、ライト |
| [マスコン](#train-controller) | マスコン | TRTHR | ノッチ、方向、牽引力 |

**ロータリーノブ** は別売りの製品ではなく、すべての有料テーマに付属しています。[コントロールの種類](/docs/Application/Dashboard/ControlTypes#rotary-knob)を参照してください。

## 特殊コントロールを追加する {#add-a-special-control}

1. ダッシュボードを開き、**+**（**コントローラーを追加**）をタップします。
2. コントロールの種類のリストで **車両・特殊** までスクロールし、コントロールを選びます。
3. 外観の一覧に、そのすべての外観が表示されます。1 つを選び、**設定** でコントロールを設定します。
4. **ダッシュボードに追加** をタップします。まだお持ちでないコントロールの場合は、**購入** または **MocPilot Pro ですべて** をタップします。

## 外観 {#looks}

どの特殊コントロールにも多くの **外観** があります。そのほとんどは有料テーマ（レーシング、オーラ、クラシック、ホログラムなど）に対応しているので、ハンドル、シフトレバー、サイドブレーキをダッシュボードのほかの部分とそろえられます。外観はいつでも変更できます。コントロールを選択し、**スタイル** タブの **外観** で別のものを選びます。外観で変わるのは見た目だけで、値、ブロック、プログラムはそのままです。

外観によっては、選んだときにアクセントカラーもその外観に合った色に設定されます。

## すべての特殊コントロールに共通の設定 {#settings-of-all-special-controls}

- **外観**（スタイルタブ）：上記を参照してください。
- **アクセントカラー**（スタイルタブ）：シフトレバー、サイドブレーキ、ウインカー、マスコン。
- **コントローラーをロックする** と **インタラクティビティ**（設定タブ）：ほかのコントロールと同じです。[コントロールのプロパティ](/docs/Application/Dashboard/ControlProperties)を参照してください。

## ハンドル {#steering-wheel}

ハンドルに指を置き、中心の周りを回します。指を離すと中央に戻ります。ハンドルの中央を押すとホーンが鳴ります。このときハンドルは回りません。

**設定**

- **ハンドル角度**（20～120°、初期値 60°）：ハンドルをいっぱいに切るまでに回す角度です。プログラムが受け取る値は変わりません。
- **音響効果**：ホーンの音と、プログラムがハンドルから再生する音です。アプリのサウンドがオンになっている必要があります。

**値**：ハンドル角度は −100（左いっぱい）から 0 を経て 100（右いっぱい）まで。ホーンは押している間 100、それ以外は 0 です。

**外観**：オフロード車、重型トラック、スーパーカー、ヴィンテージウッド、レーシングヨーク、ラリースエード、オフロードユーティリティ、コンセプトグロー、大型トラック、ファミリーセダン、シティカー、デューンバギー、クラシック4x4、建設機械、ハイファイオーディオ、オーラ、ブロック、サーキットコア、ディープスペース、ヘビーホール、ネオオービット、オフロードキャブ、レーシング、ロッククローラー、タクティカル、クラシック、サンセット、マイアミ、ハイテク、ホログラム

**プログラム用のサウンド**：乗用車のクラクション、トラックのホーン、スポーツカーのクラクション

**クイックリンク**：**ハンドル角度** と **ホーン** のチャンネルを持つ[ハンドル](/docs/Application/Links/Blocks/InputBlocks#controller-wheel)入力。

## ペダル {#pedals}

左がブレーキペダル、右がアクセルペダルです。指でペダルを押します。ペダルの上のほうを押すほど、強く踏み込んだことになります。下のほうでは軽く、上のほうではいっぱいに踏み込みます。指を離すとペダルは元に戻ります。両方のペダルを同時に押すこともできます。

**設定**：**音響効果**：プログラムがペダルの音を再生できるようにします。アプリのサウンドがオンになっている必要があります。

**値**：アクセルとブレーキ、それぞれ 0 から 100 まで。

**外観**：オフロード車、重型トラック、スーパーカー、ヴィンテージクローム、カーボン＆レッド、レーシングドリルド、オフロードグリップ、コンセプトグロー、大型トラック、ファミリーセダン、シティカー、デューンバギー、クラシック4x4、建設機械、ハイファイオーディオ、オーラ、ブロック、サーキットコア、ディープスペース、ヘビーホール、ネオオービット、オフロードキャブ、レーシング、ロッククローラー、タクティカル、クラシック、サンセット、マイアミ、ハイテク、ホログラム

**プログラム用のサウンド**：乗用車のブレーキ、スポーツカーのブレーキ、トラックのエアブレーキ、バック警告音

**クイックリンク**：**アクセルペダル** と **ブレーキペダル** のチャンネルを持つ[ペダル](/docs/Application/Links/Blocks/InputBlocks#controller-pedals)入力。

:::tip ペダルだけでは車になりません
ペダルが返すのは、それぞれがどれだけ踏み込まれているかだけです。行でアクセルをそのままモーターに送ると、モーターはペダルの踏み込み量のとおりに回るだけです。徐々に加速し、惰性で走り、ブレーキをかけ、後退するモデルにするには、[車両シミュレーター](#vehicle-simulator)を使いましょう。
:::

## シフトレバー {#gear-shifter}

**シフトレバー** 製品には、**マニュアル変速機** と **オートマチック変速機** の 2 つのコントロールがあります。

### マニュアル変速機 {#manual-gearbox}

後退と最大 6 段の前進ギアを持つ H パターンのゲートです。ノブを中央の列に沿ってドラッグし、上下に動かしてギアに入れます。指を離すと、ノブは最も近いギアに入るか、ニュートラルに戻ります。

- **ギア数**（2～6、初期値 6、設定タブ）：ゲートもそれに合わせて変わります。後退は常にいちばん左の列、ニュートラルは中央です。
- **値**：−1 = 後退（R）、0 = ニュートラル（N）、1…6 = 前進ギア。

### オートマチック変速機 {#automatic-gearbox}

**P**（パーキング）、**R**（後退）、**N**（ニュートラル）、**D**（ドライブ）の 4 つのポジションを持つセレクターです。操作方法は外観によって異なります。

| セレクター | 使い方 | 外観 |
|---|---|---|
| レバー | ハンドルを溝に沿ってスライドします。最も近いポジションで止まります | ハイテク |
| ダイヤル | 指でダイヤルを回します。P、R、N、D でカチッと止まります | クラシック、ディープスペース、タクティカル、建設機械、ハイファイオーディオ、オーラ、サーキットコア、ロッククローラー、オフロードキャブ、ネオオービット、オフローダー、ワークホース、コンセプト、セダン、シティカー、クラシック4x4 |
| ボタン | P、R、N、D をタップします | レーシング、ヘビーホール、ブロック、重型トラック、レトロ、ラリー、スーパーカー、フォーミュラ、長距離トラック、バギー、サンセット、マイアミ、ホログラム |

- **ギア数**（2～8、初期値 6、設定タブ）：D で[車両シミュレーター](#vehicle-simulator)が切り替えるギアの数です。シミュレーターがギアを選ぶと、セレクターにそのギアが表示されます（たとえば **D3**）。
- **値**：−2 = P、−1 = R、0 = N、1 = D。3 種類のセレクターはすべて同じ値を返すので、どの外観でもプログラムは同じように動作します。

両方の変速機の外観は共通です：クラシック、レーシング、ディープスペース、タクティカル、ヘビーホール、建設機械、ハイファイオーディオ、オーラ、サーキットコア、ロッククローラー、オフロードキャブ、ブロック、ネオオービット、重型トラック、レトロ、ラリー、オフローダー、スーパーカー、フォーミュラ、ワークホース、コンセプト、長距離トラック、セダン、シティカー、バギー、サンセット、クラシック4x4、マイアミ、ハイテク、ホログラム。

**クイックリンク**：[シフトレバー](/docs/Application/Links/Blocks/InputBlocks#controller-gear)入力。チャンネルは **ギア**（マニュアル：ギア数に対するギアの位置、後退は負の値。オートマチック：方向）と **方向（R − / 前進 +）**（後退で −1、ニュートラルとパーキングで 0、前進ギアで +1）です。

## サイドブレーキ {#handbrake}

サイドブレーキのレバーです。レバーのグリップを持って下に引きます。ブレーキの強さは引いた量に応じて変わります。指を離すとレバーは元に戻ります。

**ロック** するには、レバーをいっぱいまで引いてから、指をレバーの付け根に向かってスライドさせます。グリップが下にスライドし、レバーがロックされたままになります。ロックしたレバーを **解除** するには、コントロールをタップするか、レバーを戻すようにドラッグします。

**値**：強さ（0 から 100）と、レバーがロックされているかどうか。

**外観**：クラシック、ラリー、重型トラック、レトロ、ディープスペース、タクティカル、オーラ、ヘビーホール、建設機械、ハイファイオーディオ、ネオオービット、オフロードキャブ、レーシング、ブロック、サーキットコア、ロッククローラー、オフローダー、スーパーカー、フォーミュラ、ワークホース、コンセプト、長距離トラック、セダン、シティカー、バギー、サンセット、クラシック4x4、マイアミ、ハイテク、ホログラム

**クイックリンク**：**サイドブレーキ固定**（スイッチのようにオン / オフ）と **サイドブレーキの強さ** のチャンネルを持つ[サイドブレーキ](/docs/Application/Links/Blocks/InputBlocks#controller-handbrake)入力。

## ウインカー {#turn-signals}

ライトスイッチ付きのウインカーレバーです。

- レバーを **上** にドラッグすると左ウインカー、**下** にドラッグすると右ウインカーです。レバーは離した位置にとどまります。ウインカーを消すには、中央に戻すようにドラッグします。
- レバーまたはヘッドライトのボタンを **タップ** すると、ライトがオン / オフします。このときレバーは動きません。

**設定**

- **アイコン: left**、**アイコン: light**、**アイコン: right**（スタイルタブ）：表示灯のアイコン。
- **ウインカー出力を点滅させる**（設定タブ、初期設定はオン）：ウインカーの出力がレバーのランプと一緒に点滅するので、そこにつないだライトは自動で点滅します。オフにすると、ウインカーがオンの間、出力は点灯したままになります。ブロックが受け取るのは常に点灯したままの状態です。

**値**：左ウインカー、右ウインカー、ライト。それぞれオンまたはオフ。

**外観**：クラシック、レーシング、ディープスペース、タクティカル、ヘビーホール、建設機械、ハイファイオーディオ、オーラ、サーキットコア、ロッククローラー、オフロードキャブ、ブロック、ネオオービット、重型トラック、レトロ、ラリー、オフローダー、スーパーカー、フォーミュラ、ワークホース、コンセプト、長距離トラック、セダン、シティカー、バギー、サンセット、クラシック4x4、マイアミ、ハイテク、ホログラム

**クイックリンク**：[ウインカー](/docs/Application/Links/Blocks/InputBlocks#controller-turnsignals)入力。チャンネルは **ウインカー（左 − / 右 +）**（1 つのポートに極性が逆の 2 つのライト）、**左ウインカー**、**右ウインカー**、**ライト** です。

## マスコン {#train-controller}

スロットルレバーとレバーサを備えた機関車のマスターコントローラーです。

- **スロットル**：レバーを上下にドラッグします。8 段のノッチ（0～8）があり、離したノッチにとどまります。
- **レバーサ**：ノブを上にドラッグすると **前進**、下にドラッグすると **後退**、中央は **中立** です。ノブはポジションからポジションへ移動し、途中で止まることはありません。本物の運転台と同じく、スロットルが 0 のときだけ動きます。

**値**：ノッチ（0～8）、レバーサ（1 = 前進、0 = 中立、−1 = 後退）、そして **牽引力**：ノッチ ÷ 8 × 100 に方向の符号を付けたもので、−100 から 100 まで。牽引力でトレインモーターを直接動かせます。

**外観**：オリジナル、建設機械、ハイファイオーディオ、オーラ、ブロック、バギー、サーキットコア、シティカー、クラシック、コンセプト、ディープスペース、オフローダー、ヘビーホール、クラシック4x4、重型トラック、マイアミ、ネオオービット、スーパーカー、ワークホース、オフロードキャブ、レーシング、ラリー、ロッククローラー、セダン、サンセット、タクティカル、長距離トラック、レトロ、フォーミュラ、ハイテク、ホログラム

**クイックリンク**：[スライダー](/docs/Application/Links/Blocks/InputBlocks#controller-train)入力。牽引力を返します。

## ブロック {#blocks}

特殊コントロールを置くと、ロジックブロックの **オンスクリーンコントローラー** カテゴリに専用のブロックが追加されます。

| コントロール | イベント | 値 |
|---|---|---|
| ハンドル | *ハンドルを動かした / 押した / 離したとき* | *ハンドルの値*、*ハンドルが押されている / 離されているか* |
| ペダル | *いずれかのペダル / ブレーキ / アクセルを動かした / 押した / 離したとき* | *ペダルのアクセル / ブレーキの値*、*ペダルが押されている / 離されているか* |
| 変速機 | *ギアを変えた / シフトアップした / シフトダウンした / ニュートラル・後退・パーキングに入れたとき* | *ギア*、*変速機がニュートラル / 後退 / 前進ギア / パーキングか*、*ギア数* |
| サイドブレーキ | *サイドブレーキを引いた / ロックした / ロックを解除した / 離したとき* | *サイドブレーキの強さ*、*サイドブレーキがロック中 / 解除中 / 引かれているか* |
| ウインカー | *左ウインカー / 右ウインカー / ライトが点灯 / 消灯したとき* | *左ウインカー / 右ウインカー / ライトが点灯中か* |
| マスコン | *ノッチが変わった / 上がった / 下がった、ノッチオフ、レバーサを動かした、レバーを離したとき* | *マスコンの牽引力 / ノッチ / レバーサ*、*マスコンが前進 / 後退 / 中立 / ノッチ 0 か* |

ハンドルとペダルには *サウンド … の …* ブロックもあり、**サウンド** ブロック用にそれぞれのサウンドの 1 つを選べます。詳細：[オンスクリーンコントローラー](/docs/Application/BlockBuilder/Blocks/DashboardControllers)。

## 車両シミュレーター {#vehicle-simulator}

特殊コントロールが返すのは生の入力だけです。**車両シミュレーター** は、ペダル、シフトレバー、サイドブレーキを、車のように走るモデルに変えます。慣性を伴って加速し、惰性で走り、ブレーキをかけ、後退し、D ではギアを切り替え、サイドブレーキで停止状態を保ちます。

- **クイックリンク**：[車両](/docs/Application/Links/Blocks/InputBlocks#src-vehicle)入力を使います。ダッシュボードの **ペダル**、**シフトレバー**、**サイドブレーキ** を選び、**車両タイプ**（乗用車、オフロード車、スポーツカー、トラック）と **出力**（**速度**、**エンジン回転数（rpm）**、**ブレーキ中**、**サイドブレーキ中**）を選びます。
- **ロジックブロック**：ダッシュボードにペダル、シフトレバー、サイドブレーキがあると、**シミュレーター** カテゴリが表示されます。そこで車両を作成し（**車両を作成**）、*運転* ブロックをイベントの下に置きます。そのソケットに値を入れます：*アクセル*、*ブレーキ*、*ギア*、*の*（ギア数。*ギア数* ブロックがここに合います）、*サイドブレーキ*、*ロック*。そのほかのシミュレーターのブロックでは、車両タイプ、エンジンの慣性、後退速度を設定したり、速度、エンジン回転数、ギアを読み取ったり、車両の発進、停止、ブレーキ、変速に反応したりできます。

シミュレーターの走り方：

- **アクセル** で慣性を伴って加速し、離すと惰性で走ります。**ブレーキ** で減速します。
- **変速機なし** の場合、モデルが止まった状態でブレーキを踏み続けると後退します。
- **マニュアル変速機**：R で後退、N では走りません。オプションで、ギアごとに最高速度を制限できます。
- **オートマチック変速機**：R で後退、N では走らず、P ではロックしたサイドブレーキのようにモデルを止めておきます。D ではシミュレーターが自動でシフトアップ・ダウンし、セレクターにギアを表示します。
- **サイドブレーキ**：その強さがブレーキに加わります。ロックしたサイドブレーキでモデルを止めておけます。
- **車両タイプ**：トラックは重く（慣性が大きく）、エアブレーキがあります。スポーツカーは反応が速く、後退も速くなります。

プログラムでシミュレーターのブロックを使っている間は、最後のペダル、シフトレバー、サイドブレーキを削除できません。
