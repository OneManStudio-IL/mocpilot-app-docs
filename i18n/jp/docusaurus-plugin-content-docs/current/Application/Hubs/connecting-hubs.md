# ハブを追加して接続する {#add-and-connect-a-hub}

ハブをプロフィールに追加するのは 1 回だけです。その後は、プロフィールを開くたびに MOCPilot がハブに接続します。

## ハブを追加する {#add-a-hub}

1. プロフィールを開き、**マイハブ**（⇧⌘H / Ctrl+Shift+H）をタップします。**私のBluetoothハブ**ページにスロットが表示されます。
2. 空いているスロットで**新しいハブを追加**をタップします。
3. 一覧からハブを選びます。上部のフィルターで**すべて**、**LEGO**、**SBrick**、**BuWizz**、**Mould King** を切り替えられます。**追加**をタップします。
4. 画面の手順に従います：**ハブのボタンを押してください**、**検索がハブを見つけるまでお待ちください**。もう一度検索するには**スキャンを開始**をタップします。

ハブが見つかると接続され、スロットに残ります。

## スロットのメニュー {#the-slot-menu}

スロットの**接続**ボタンでハブに接続します。スロットのメニューには次の項目があります。

- **切断**
- **ハブの名前を変更**：新しい名前をハブ本体に保存します（対応している接続済みのハブのみ）。
- **ファームウェアを更新**：新しいファームウェアがあるときに表示されます。[ファームウェアの更新](/docs/Application/Hubs/FirmwareUpdating)を参照してください。
- **ハブのファームウェアを復旧**：ハブがリカバリーモードで接続されているときに表示されます。[ファームウェアの復旧](/docs/Application/Hubs/RecoveryHubFirmware)を参照してください。
- **設定を選択**：Technic Move の構成です。[Technic Move Hub の構成](/docs/Application/Hubs/TechnicMoveHubConfigurations)を参照してください。
- **チャンネルを選択: A / B / C**：Mould King のコントロールチャンネルです。
- **ハブを削除**：プロフィールからハブを削除します。

エディターの**マイハブ**ボタンには、接続中のハブの数が表示されます。

## ハブモニター {#hub-monitor}

接続中のハブを開くと、**ハブモニター**が表示されます。

- ハブ：モデル、名前、ファームウェア、バッテリー、充電、基板温度、構成、向き、傾き（ピッチ、ロール、ヨー）、加速度計
- 各ポート：接続されているデバイスと、その速度、位置、相対位置、色、反射光と周囲光、または距離

プログラムを作る前に、どのモーターがどのポートにあり、どちらに回るかを確認するのに使います。

## 接続のヒント {#connection-tips}

- ハブの電源は接続の直前に入れましょう。多くのハブは、接続されないまま数分たつと自動で電源が切れます。
- スマートフォンはハブの近くに置きましょう。壁や金属があると届く距離が短くなります。
- ハブは同時に 1 台のデバイスにしか接続できません。ハブを使うほかのアプリ（LEGO® のアプリ、ほかのリモコンアプリ）は閉じてください。
- **Bluetoothがオフです**：Bluetooth をオンにし、システム設定で MOCPilot に Bluetooth の使用を許可してください。
- **ハブが見つかりません**：ハブのボタンをもう一度押すか、スキャンをやり直すか、電池を交換してください。
- **Mould King** のハブは実際には「接続」しません。MOCPilot は Bluetooth アドバタイズでコマンドを送ります。ハブが反応しない場合は、**再接続**をタップし、チャンネルを確認してください。

詳しくは[トラブルシューティング](/docs/Help/Troubleshooting#hubs)を参照してください。
