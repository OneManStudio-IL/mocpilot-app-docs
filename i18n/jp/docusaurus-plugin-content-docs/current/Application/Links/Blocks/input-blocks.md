# 入力ブロック {#input-blocks}

どの行も入力から始まります。パレットの **入力** タブには、プロフィールで今使えるブロックが表示されます。ダッシュボードのコントロールごとに 1 つのブロック（複数のチャンネルを持つコントロールはチャンネルごとに 1 つ）、**車両** ブロック、**ゲームパッド** ブロック、ハブごとに 1 つの **ハブ** ブロックです。使い方：[入力](/docs/Application/Links/Inputs)。

各入力は、次の 2 種類のどちらかの信号を行に送ります。

- **値**：−1 から 1 までの数値（マイナス側のないコントロールでは 0…1）
- **オン/オフ**：1 または 0

処理ブロックと動作は、扱える信号だけを受け付けます。[処理ブロック](/docs/Application/Links/Blocks/ProcessingBlocks)を参照してください。

## コントローラー {#src-controller}

ダッシュボードのコントロールです。名前（**JOY1**、**SLDR1**、**BTN2**…）で表示されます。

- **コントローラー**：下に挙げるダッシュボードのコントロールのいずれか。モニターは出力であり、入力ではありません。
- **チャンネル**：複数のチャンネルを持つコントロールで、何を出力するか。パレットにはチャンネルごとに 1 つのブロックが表示されます。

ハンドル、ペダル、シフトレバー、サイドブレーキ、ウインカー、トランスファー、マスコンについては、[特殊コントロール](/docs/Application/Dashboard/SpecialControls)で説明しています。

コントロールがダッシュボードから削除されると、行に「ダッシュボードのコントローラーを選択してください」と表示されます。チャンネルがなくなった場合は「… が出力する値を選択」（ジョイスティックでは「… はこの軸に沿って動きません」）と表示されます。

### ジョイスティック {#controller-joystick}

- **チャンネル**：**X 軸** または **Y 軸**。**水平のみ (X)** または **垂直のみ (Y)** に設定したジョイスティックでは、その軸だけが選べます。
- 出力：値 −1…1、中央で 0。

### スライダー、垂直スライダー {#controller-slider}

- チャンネルはありません。
- 出力：値 0…1。**負の値** がオンなら −1…1。

### マスコン {#controller-train}

マスコン（特殊コントロール）は、クイックリンクではスライダーとして動作します。

- チャンネルはありません。
- 出力：値 −1…1。全ノッチ数に対するレバー位置の割合で、逆転器が後退のときは負、中立で 0。

### ロータリーノブ {#controller-knob}

有料テーマのロータリーノブは、クイックリンクではスライダーとして動作します。

- チャンネルはありません。
- 出力：値 0…1。ノブのゼロが中央にある場合は −1…1。

### ハンドル {#controller-wheel}

- **チャンネル**：**ハンドル角度**（既定）または **ホーン**。
- ハンドル角度の出力：値 −1…1、直進で 0。
- ホーンの出力：ホーンの部分を押している間は値 1、それ以外は 0。

### ペダル {#controller-pedals}

- **チャンネル**：**アクセルペダル**（既定）または **ブレーキペダル**。
- 出力：値 0…1。ペダルの踏み込み量です。
- ペダルはペダルの位置をそのまま出力します。自分で加速、減速、後退する車には、[車両](#src-vehicle)入力を使います。

### シフトレバー {#controller-gear}

マニュアルとオートマチックのシフトレバー（特殊コントロール）です。

- **チャンネル**：**ギア**（既定）または **方向（R − / 前進 +）**。
- ギア（マニュアル変速機）：入っているギアを前進ギアの数で割った値。トップギアで 1、ニュートラルで 0、後退で負。4 速なら、2 速で 0.5 になります。
- ギア（オートマチック変速機）：方向と同じです。
- 方向の出力：R で −1、N（と P）で 0、いずれかの前進ギアまたは D で +1。

### サイドブレーキ {#controller-handbrake}

- **チャンネル**：**サイドブレーキ固定**（既定）または **サイドブレーキの強さ**。
- サイドブレーキ固定の出力：オン/オフ。レバーが固定されている間はオン。
- サイドブレーキの強さの出力：値 0…1。レバーの引き量です。

### ウインカー {#controller-turnsignals}

ウインカーレバー（特殊コントロール）です。

- **チャンネル**：**ウインカー（左 − / 右 +）**（既定）、**左ウインカー**、**右ウインカー**、または **ライト**。
- ウインカーの出力：値 −1（左）、0（オフ）、+1（右）。
- 左ウインカーと右ウインカーの出力：そのウインカーがオンの間は値 1（コントロールの点滅がオンならランプに合わせて点滅）、それ以外は 0。
- ライトの出力：ライトがオンの間は値 1、それ以外は 0。

### トランスファー {#controller-transfercase}

[トランスファー](/docs/Application/Dashboard/SpecialControls#transfer-case)（特殊コントロール）です。

- **チャンネル**：**4WD**（既定）、**ローレンジ**、**フロントデフロック**、**センターデフロック**、または **リアデフロック**。
- 4WD の出力：オン/オフ。4H と 4L でオン。
- ローレンジの出力：オン/オフ。4L でオン。
- 各デフロックの出力：オン/オフ。そのロックが入っている間はオン。
- ポジション自体（2H、4H、N、4L）は、[車両](#src-vehicle)入力の **トランスファー** 設定を通じてシミュレーターに送られます。

### 十字キー {#controller-dpad}

- **チャンネル**：**上 / 下** または **左 / 右**。
- 出力：値 +1（上または右）、−1（下または左）、0。

### ボタン {#controller-button}

- チャンネルはありません。
- 出力：オン/オフ。押している間はオン。

### スイッチ {#controller-switch}

- チャンネルはありません。
- 出力：オン/オフ。

### ステップスイッチ {#controller-stepper}

- チャンネルはありません。
- 出力：値。現在のステップを **ステップ数** で割った値で、最後のステップが 1 になります（負側の最後のステップは −1）。

## 車両 {#src-vehicle}

ダッシュボードのペダル、シフトレバー、サイドブレーキ、トランスファーで操作する、シミュレーションの車です。本物の車両のように加速、ブレーキ、惰性走行、後退し、行にはその速度またはエンジン回転数が送られます。ダッシュボードにペダル、シフトレバー、サイドブレーキのいずれかがあると、パレットに車両ブロックが出力ごとに 1 つずつ表示されます。各ブロックは、それぞれの種類の最初のコントロールにすでにつながっています。

- **ペダル**：車両を操作するダッシュボードのペダル（必須）。
- **シフトレバー**：**なし** またはダッシュボードのシフトレバー。シフトレバーがない場合は、停車中にブレーキペダルを踏み続けると車両が後退します。
- **サイドブレーキ**：**なし** またはダッシュボードのサイドブレーキ。
- **トランスファー**：**なし** またはダッシュボードのトランスファー。2H と 4H ではトランスファーがないときと同じように走り、N では走らず（惰性で進みます）、4L では速度が 40 % に制限されます。
- **車両タイプ**：**乗用車**（既定）、**オフロード車**、**スポーツカー**、**トラック**。タイプによって慣性と後退速度が異なり、トラックにはエアブレーキもあります。
- **出力**：
  - **速度**（既定）：値 −1…1、後退中は負
  - **エンジン回転数（rpm）**：値 0…1
  - **ブレーキ中**：オン/オフ。車両がブレーキをかけている間はオン
  - **サイドブレーキ中**：オン/オフ

問題：「車両のペダルを選択してください」、「… はダッシュボードにありません」。

## ゲームパッド {#src-gamepad}

デバイスに接続されたゲームコントローラーです。このブロックは、**ゲームパッドブロックを有効にする** がオンのとき（上部バーの **ゲームパッド** ページ）だけパレットに表示されます。オフのときは、行に「ゲームパッドページ（上部バー）でゲームパッドブロックをオンにしてください」と表示されます。

- **入力**（既定は **左スティック Y**）。ラベルは **ゲームパッドのボタン配置**（Xbox / PlayStation）に従います。
  - **左スティック Y**、**左スティック X**、**右スティック Y**、**右スティック X**：値 −1…1
  - **RT** / **R2**、**LT** / **L2**（トリガー）：値
  - **A**、**B**、**X**、**Y** / **バツ**、**マル**、**四角**、**三角**：オン/オフ
  - **LB** / **L1**、**RB** / **R1**（バンパー）：オン/オフ
  - **上**、**下**、**左**、**右**（十字キー）：オン/オフ

## ハブ {#src-hub}

ハブ自身のボタン、またはハブ本体かそのポートにあるセンサーです。ハブ入力はプロフィールのハブごとに 1 つありますが、コマンドを受信するだけの Mould King のハブは除きます。

- **ハブ**：プロフィールのハブ。
- **ボタンまたはセンサー**：このハブが報告できるものだけ（下の一覧）。
- **ポート**：ポートにあるセンサー（モーターの値、ポートのセンサー）の場合。
- **ハブの向き**：向きを変更できるハブでの傾きと加速度の場合。**そのまま**（既定）、またはモデルへのハブの取り付け方。

センサーの値はフルスケールで割られ、−1…1 に収められて行を流れます。バッテリー残量 50 % なら 0.5 です。センサーの直後にテキストの **モニター** を置くと、単位付きの実際の値が表示されます。

| ボタンまたはセンサー | 信号 | 単位、フルスケール | ハブ |
|---|---|---|---|
| **ボタン 1、2…** | オン/オフ | | ボタンのあるハブ、LEGO® Powered Up リモコンのボタン |
| **バッテリー** | 値 | %、100 | 報告できるハブ |
| **バッテリー電圧** | 値 | V、12 | 報告できるハブ |
| **出力電圧** | 値 | V、12 | BuWizz 2.0 |
| **温度** | 値 | °C、100 | 報告できるハブ |
| **傾き ピッチ** | 値 | °、90 | 傾きセンサー付きのハブ |
| **傾き ロール** | 値 | °、180 | 傾きセンサー付きのハブ |
| **傾き ヨー** | 値 | °、180 | ヨー軸のあるハブ |
| **加速度 X / Y / Z** | 値 | m/s²、19.6 | 加速度計付きのハブ |
| **回転速度 X / Y / Z** | 値 | °/s、360 | ジャイロスコープ付きのハブ：Technic Hub、Technic Move Hub、Robot Inventor、SPIKE Prime |
| **ハブの電流** | 値 | mA、3000 | Technic Hub、BOOST Move Hub |
| **モーター速度** | 値 | %、100 | ポート、ポートのあるすべてのハブ |
| **モーター角度** | 値 | °、360（相対） | ポート、エンコーダー付きモーター。SBrick、BuWizz 2.0、WeDo 2.0 は除く |
| **モーター位置** | 値 | °、180（絶対） | ポート、アンギュラーモーター |
| **モーターパワー** | 値 | %、100 | ポート、Robot Inventor |
| **モーター電流** | 値 | A、3 | ポート、BuWizz 2.0、BuWizz 3.0 Pro |
| **距離センサー** | 値 | 250 | ポート。SBrick と BuWizz は除く |
| **カラーセンサー** | 値 | 色番号、10 | ポート。SBrick、BuWizz、WeDo 2.0 は除く |
| **反射光**、**周囲光** | 値 | %、100 | ポート。SBrick、BuWizz、WeDo 2.0 は除く |
| **色相** | 値 | °、360 | ポート。Technic カラーセンサーまたは BOOST カラー＆距離センサー。SBrick、BuWizz、WeDo 2.0 は除く |
| **彩度**、**明るさ** | 値 | %、100 | ポート。色相と同じ |
| **傾きセンサー ピッチ / ロール** | 値 | °、45 | ポート、WeDo 2.0 / BOOST 傾きセンサー。SBrick と BuWizz は除く |
| **パワーモード** | 値 | 1–4、4 | BuWizz 2.0 |
| **接続済み** | オン/オフ | | すべてのハブ |

ハブが接続されていると、MOCPilot はポートのデバイスもチェックします。「ポート A：モーターがありません」、「ポート A：モーターにエンコーダーがありません」、「ポート A：距離センサーがありません」などです。
