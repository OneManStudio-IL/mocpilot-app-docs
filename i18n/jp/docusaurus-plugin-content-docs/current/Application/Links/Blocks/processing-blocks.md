# 処理ブロック {#processing-blocks}

処理ブロックは入力と動作（またはインジケーター）の間に置き、途中で信号を変えます。1 つの行にいくつでも、どの順序でも置けます。入ってくる信号を受け取れないブロックははまりません。ファイル内にある場合は『「…」はこのコントローラーでは使えません』と報告されます。使い方：[処理](/docs/Application/Links/Processing)。

## 反転 {#mod-invert}

信号を反転します。

- 設定はありません。
- 受け取るもの：値またはオン/オフ。出力：同じ種類。
- 値：符号を変えます（0.7 は −0.7 になります）。オン/オフ：オンはオフに、オフはオンになります。

## 制限 {#mod-limit}

値を縮小し、いっぱいに倒しても最大値を超えないようにします。

- **最大**：20、30、40、50、60、70、80、90 %（既定は 50 %）。
- 受け取るもの：値またはオン/オフ。出力：値（制限をかけたボタンは 0 か最大値を出力）。

## デッドゾーン {#mod-deadzone}

ゼロ付近の小さな値をゼロとして扱います。残りの範囲は全範囲に引き伸ばされるので、いっぱいに倒せば 1 になります。

- **ゾーン**：5、10、15、20、30 %（既定は 10 %）。
- 受け取るもの：値。出力：値。

## しきい値 {#mod-threshold}

値をオン/オフに変えます。

- **オンになる条件：値が**：**上回る**（既定）または **下回る**。
- **レベル（フルスケール比）**：−50、−20、0、5、10、20、30、50、70、90 %（既定は 20 %）。
- 受け取るもの：値。出力：オン/オフ。
- 小さなヒステリシス（フルスケールの 2 %）があるため、値がレベル付近で揺れても出力がちらつきません。

## スムーズ {#mod-smooth}

入ってくる値に一気に飛ばず、徐々に近づきます。

- **加速（最高速まで）**：**即時**、0.25、0.5、1、2、3 秒（既定は 0.5 秒）。0 から（正負どちらの向きでも）最大値までの時間です。
- **減速（停止まで）**：同じ選択肢（既定は 0.5 秒）。最大値から 0 に戻るまでの時間です。
- 受け取るもの：値またはオン/オフ。出力：値（スムーズをかけたボタンは徐々に上がって下がります）。

## トグル {#mod-toggle}

押しボタンをスイッチに変えます。押すたびに出力がオンとオフの間で切り替わります。出力はオフから始まります。

- 設定はありません。
- 受け取るもの：オン/オフ。出力：オン/オフ。
