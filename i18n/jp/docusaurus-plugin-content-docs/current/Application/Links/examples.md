# 例 {#examples}

すぐに使えるレシピです。先にダッシュボードにコントロールを置き、マイハブにハブを追加してから、行を作ります。

## サーボステアリングの車 {#car-with-servo-steering}

ダッシュボード：左に **JOY1**（垂直のみ）、右に **JOY2**（水平のみ）、**BTN1** と **バッテリーレベル** モニター。

| # | 入力 | 処理 | 動作 | 出力 |
|---|---|---|---|---|
| 1 | JOY1、Y 軸 | デッドゾーン 10 %、スムーズ 0.5 秒 | モーター | Technic Hub、ポート A + B |
| 2 | JOY2、X 軸 | | サーボ（自動、±90°） | Technic Hub、ポート D |
| 3 | BTN1 | トグル | ライト | Technic Hub、ポート C |
| 4 | ハブ：バッテリー | | | インジケーター：バッテリーレベル |

駆動モーターの片方が逆に回る場合は、行 1 を 2 つの行に分け、片方に **反転** を追加します。

## ハンドル、ペダル、ギアボックス付きの車 {#car-with-a-wheel-pedals-and-a-gearbox}

ダッシュボード：**ハンドル**、**ペダル**、**シフトレバー**、**サイドブレーキ**、**ウインカー**。[車両](/docs/Application/Links/Blocks/InputBlocks#src-vehicle)入力は、ペダル、ギアボックス、サイドブレーキを、本物の車のように徐々に上がって下がる速度に変換します。

| # | 入力 | 処理 | 動作 | 出力 |
|---|---|---|---|---|
| 1 | 車両：速度 | | モーター | Technic Hub、ポート A + B |
| 2 | ハンドル：ハンドル角度 | | サーボ（自動） | Technic Hub、ポート D |
| 3 | 車両：ブレーキ中 | | ライト | Technic Hub、ポート C（ブレーキランプ） |
| 4 | ウインカー：左ウインカー | | ライト | City Hub、ポート A |
| 5 | ウインカー：右ウインカー | | ライト | City Hub、ポート B |

## 戦車（2 本のクローラー） {#tank-two-tracks}

ダッシュボード：**ゼロに戻す** と **負の値** をオンにした 2 つの垂直スライダー **VSLDR1** と **VSLDR2**。

| # | 入力 | 処理 | 動作 | 出力 |
|---|---|---|---|---|
| 1 | VSLDR1 | スムーズ 0.25 秒 | モーター | ハブ、ポート A |
| 2 | VSLDR2 | 反転、スムーズ 0.25 秒 | モーター | ハブ、ポート B |

ゲームパッドを使う場合は、行 1 に左スティック Y、行 2 に右スティック Y を使います。

## クレーン {#crane}

ダッシュボード：**DPAD1**、**SLDR1**、**SWCH1**。

| # | 入力 | 処理 | 動作 | 出力 |
|---|---|---|---|---|
| 1 | DPAD1、左 / 右 | 制限 50 % | モーター | ハブ、ポート A（旋回） |
| 2 | DPAD1、上 / 下 | | モーター | ハブ、ポート B（フックのウインチ） |
| 3 | SLDR1 | デッドゾーン 10 % | モーター | ハブ、ポート C（ブーム） |
| 4 | SWCH1 | | ライト（点滅 0.5 秒） | ハブ、ポート D（回転灯） |

## 列車 {#train}

ダッシュボード：**負の値**（前進と後退の速度段）をオンにした **ステップスイッチ** **STPR1** と、ライト用の **BTN1**。

| # | 入力 | 処理 | 動作 | 出力 |
|---|---|---|---|---|
| 1 | STPR1 | スムーズ 2 秒 | モーター | City Hub、ポート A |
| 2 | BTN1 | トグル | ライト | City Hub、ポート B |
| 3 | ハブ：バッテリー | | | インジケーター：モニター |

スムーズブロックのおかげで、列車は本物のように発車し、停車します。ダッシュボードに **マスコン** がある場合は、行 1 で STPR1 の代わりに使います。レバーの位置を出力し、後退では負の値になります。

## Technic Move の車 {#technic-move-car}

| # | 入力 | 処理 | 動作 | 出力 |
|---|---|---|---|---|
| 1 | 車両：速度 | | モーター | Technic Move（駆動） |
| 2 | ハンドル：ハンドル角度 | | サーボ | Technic Move（ステアリング） |
| 3 | BTN1 | トグル | ライト | Technic Move（ライト） |
| 4 | BTN2 | | Boost | Technic Move |

ダッシュボードにシフトレバーがない場合は、停車中にブレーキペダルを踏み続けると車が後退します。
