# クイックリンク {#quick-links}

**クイックリンク**は、MOCPilot のノーコードのプログラムエディターです。ダッシュボードのコントロール、ゲームパッド、ハブのセンサーを、モーター、ライト、インジケーターに **1 行ずつ** つないでいきます。従来の Controlz アプリを使ったことがあれば、すぐになじめるはずです。

<img src={useBaseUrl('/img/illustrations/editor_links.svg')} alt="クイックリンクの行" style={{width: '100%', maxWidth: 720}} />

## 行は文のように読めます {#a-row-reads-like-a-sentence}

各行は左から右へ流れます。

**入力 → 処理（省略可） → 動作 → 出力**

> *ジョイスティック 1、Y 軸* → *スムーズ* → *モーター* → *Technic Hub、ポート A*
>
> 「ジョイスティックを上下に動かすと、ポート A のモーターが回り、なめらかに動き出して止まる。」

| 部分 | 内容 | 例 |
|---|---|---|
| **入力** | 値の出どころ | ダッシュボードのコントロール、シミュレーションの車両、ゲームパッド、ハブのボタンやセンサー |
| **処理** | 途中で値を変える（なし、1 つ、または複数のブロック） | 反転、制限、デッドゾーン、しきい値、スムーズ、トグル |
| **動作** | ハブにさせること | モーター、サーボ、時間指定モーター、ライト、角度指定で回転、位置へ移動… |
| **出力** | 実行される場所 | ポート付きの**ハブ**、または直接出力：インジケーター、ハブ LED、LED マトリックス、サーボのキャリブレーション |

直接出力（インジケーター、ハブ LED、LED マトリックス、サーボのキャリブレーション）には動作は不要です：*バッテリー（ハブ） → インジケーター*。

## エディター {#the-editor}

<Screenshot name="links-editor" alt="行とパレットが表示されたクイックリンクエディター" width={900} />

- **行**は画面いっぱいに並び、縦にスクロールします。新しい行は、最後の空の行（「新しい行：入力」）から始めます。
- 下部の**パレット**には **入力**、**処理**、**出力** の 3 つのタブがあります。パレットはプロフィールから作られます。ダッシュボードのすべてのコントロールとマイハブのすべてのハブが自動的に表示され、ゲームパッドブロックがオンならゲームパッドも表示されます。動作は、プロフィールのハブがその動作に対応している場合にだけ表示されます。
- 上部バーの **問題** ボタンは、すべての行の準備ができていれば緑のチェックを、そうでなければ赤い「!」と問題の数を表示します。

## 行を作る {#build-a-row}

1. **入力** から入力を空の行にドラッグします。新しい行が作られます。
2. 必要なら、**処理** から処理ブロックを入力の後ろにドラッグします。
3. **出力** から動作（たとえば **モーター**）をドラッグします。
4. 動作の後ろに **ハブ** 出力をドラッグし、使うポートをタップします。
5. ブロックをタップすると設定を変更できます。チップから選ぶだけで、入力は不要です。

ブロックはパズルのピースのように組み合わさります。つなぎ目の形が信号の種類を表しているので、一緒に使えないブロックははまりません。

- −1 から 1 までの**値**（ジョイスティックの軸、スライダー、ペダル、センサー）
- **オン/オフ**（ボタン、スイッチ、しきい値）
- **動作 → ハブ** のつなぎ目。ハブは動作の後ろにしか置けません。

ブロックを削除するには、パレットにドラッグして戻す（「ここにドロップして削除」）か、ブロックをタップして **ブロックを削除** を選びます。

## 行 {#rows}

行番号をタップすると行メニューが開きます。

- **オフにする** / **オンにする**：オフにした行はプログラムに残りますが、実行されません。試しに使うときに便利です。
- **行を削除**。

行はいくつでも追加できます。

## 実行 {#run}

**実行** を押します。プログラムの実行中は、各つなぎ目に通過中の**ライブ値**が表示されるので、信号がどこで止まっているかがひと目でわかります。実行中は編集できません。編集に戻るには **停止** を押します。[実行と問題の解決](/docs/Application/Links/Problems)を参照してください。

## 元に戻す {#undo}

**元に戻す** と **やり直す**（⌘Z / ⇧⌘Z、Ctrl+Z / Ctrl+Shift+Z、またはフローティングボタン）で、最大 100 ステップまでさかのぼれます。プログラムの実行中は使えません。

## クイックリンクとロジックブロック、どちらを使う？ {#quick-links-or-logic-blocks}

各コントロールで何かを動かすだけなら、クイックリンクが最適です。ロジック（順序、条件、変数、センサーに対する複数ステップの反応）が必要なときは、[ロジックブロック](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing)を使います。プログラムの種類はプロフィールの作成時に選びます。[比較](/docs/Application/Profiles/CreateProfile#choose-the-program-type)を参照してください。
