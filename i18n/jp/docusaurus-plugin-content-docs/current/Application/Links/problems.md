# 実行と問題の解決 {#running-and-fixing-problems}

## 準備はできていますか？ {#is-everything-ready}

エディターの上部バーにある **問題** ボタンには、次のように表示されます。

- **緑のチェック**：「すべての行の準備ができました」
- **赤い「!」**：「問題: N」

タップすると問題パネルが開きます（スマートフォンではサイドパネル、タブレットやパソコンではメニュー）。「行 N — 理由」の形で一覧表示され、項目をタップするとその行へ移動します。問題の原因となっているブロックには**赤い枠**が付きます。問題がなければ、パネルに「オンになっているすべての行を実行できます。」と表示されます。

<Screenshot name="links-problems" alt="準備ができていない行がある問題パネル" width={900} />

問題のある行は実行されませんが、ほかの行は実行されます。

## よく表示されるメッセージ {#common-messages}

| メッセージ | 対処 |
|---|---|
| 入力と出力（ハブまたはダッシュボードのインジケーター）を行にドラッグしてください | 行が空です |
| 行の先頭に入力を追加してください | まずコントロール、車両、ゲームパッド、ハブのいずれかの入力をドラッグします |
| 出力を追加してください：ハブまたはダッシュボードのインジケーター | 行を出力で締めくくります |
| ハブの前に動作を追加してください：モーター、サーボ、ライト | ハブ出力の前には動作が必要です |
| ハブのポートを 1 つ以上選択してください | ハブブロックのポートのチップをタップします |
| ダッシュボードのコントローラーを選択してください | 入力ブロックをタップしてコントロールを選びます |
| … はこの軸に沿って動きません | ジョイスティックの軸が 1 つだけです。もう一方の軸を選ぶか、ジョイスティックを変更します |
| … が出力する値を選択 | コントロールにこのチャンネルがなくなりました。チャンネルを選び直します |
| 車両のペダルを選択してください | 車両入力には、ダッシュボードのペダルが必要です |
| … はダッシュボードにありません | 車両に指定したシフトレバーまたはサイドブレーキが削除されました |
| 「…」はこのコントローラーでは使えません | この処理ブロックは信号に合いません |
| ポート A：このデバイスはサーボとして使えません（エンコーダー付きモーターが必要です） | エンコーダー付きモーターか、別の動作を使います |
| ポート A にあるのはセンサーで、モーターではありません | ポートに何がつながっているか確認します |
| ポート A は行 2 でも使用されています | 各ポートは 1 つの行にしか属せません |
| ゲームパッドページ（上部バー）でゲームパッドブロックをオンにしてください | **ゲームパッド** を開き、**ゲームパッドブロックを有効にする** をオンにします |
| インジケーターは値をそのまま表示します：動作を削除してください | インジケーターの行には動作を置きません |
| キャリブレーションに動作は不要です：削除してください | サーボのキャリブレーションの行には動作を置きません |
| カラー LED 付きのハブを選択してください（LEGO ハブ） | ハブ LED は LEGO® ハブでのみ使えます |
| ポートの色は BuWizz 3 でのみ使えます | ポートの色には BuWizz 3.0 Pro が必要です |
| このプログラムには「自動」キャリブレーションのサーボがありません | サーボのキャリブレーションには、自動モードのサーボが必要です |
| このブロックには新しいバージョンのアプリが必要です | プロフィールは新しいバージョンで作成されています。MOCPilot をアップデートしてください |
| この行はオフです | 行メニューでオンにします |

## ライブ値 {#live-values}

プログラムの実行中は、ブロック間の各つなぎ目に通過中の値が表示されます。コントロールを動かし、行に沿って値を追ってみましょう。

- 入力で何も変わらない：コントロールやゲームパッドが何も送っていません。チャンネルや軸を確認してください。
- 値は変わるのにモーターが動かない：ハブの接続ドットとポートを確認してください。
- **制限** や **デッドゾーン** の後で値が小さい：それらの設定を調整してください。

<Screenshot name="links-live-values" alt="つなぎ目にライブ値が表示された実行中のクイックリンクプログラム" width={900} />

## モデルが動かない {#the-model-does-not-move}

1. ハブは接続されていますか？ **マイハブ** と、ハブブロックの接続ドットを確認してください。
2. 正しいポートを選んでいますか？モーターは思っているポートにつながっていますか？
3. 行はオンになっていて、赤い枠は付いていませんか？
4. プログラムは実行中（**実行**）ですか？
5. バッテリーは充電されていますか？ *バッテリー → インジケーター* の行を追加しておくと、残量を確認できます。

詳しくは[トラブルシューティング](/docs/Help/Troubleshooting)を参照してください。
