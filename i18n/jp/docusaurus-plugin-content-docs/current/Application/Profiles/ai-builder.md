# AI ビルダー {#ai-builder}

モデルを自分の言葉で、文字入力または音声で説明すると、**AI ビルダー** がプロフィールを設定してくれます。ハブとポート、ダッシュボードのコントロール、プログラムです。両方のエディターで使えます。[ロジックブロック](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing)のプロフィールではブロックを、[クイックリンク](/docs/Application/Links/LinksIntroducing)のプロフィールでは行を作ります。その後は、AI との会話を続けてプロフィールを変更することも、自分で編集することもできます。

AI ビルダーは [MocPilot Pro](/docs/Application/Account/Pro) の機能で、アプリと [Web エディター](/docs/Introducing/WebEditor)で使えます。インターネット接続が必要です。

## AI ビルダーを開く {#open-the-ai-builder}

1. プロフィールを編集用に開きます。
2. 上部バーの **AI ビルダー** ボタン（キラキラのアイコン）を押します。パソコンでは ⇧⌘I / Ctrl+Shift+I でも開けます。
3. **AI に何を作成または変更させますか？** にリクエストを入力し、**送信** を押します（または Enter。Shift+Enter で改行）。

MocPilot Pro がない場合、ボタンを押すと AI ビルダーでできることが表示され、**MocPilot Pro を入手** と **今はしない** が表示されます。

パネルが開く場所：

- **スマートフォン**：エディターの上に全画面のページとして開きます。
- **タブレット**：フローティングカードとして開きます。ヘッダーをドラッグして左右に移動できます。
- **パソコン**：右側にカードとして開きます。アプリでは（ブラウザーでは不可）、ヘッダーの **別ウインドウで開く** を押して、ウインドウをエディターの横に配置できます。

AI が作業している間、パネルには進行状況（**モデルを検討中…**、**プロフィールを確認中…** など）が表示されます。完了するとすぐに変更がエディターに反映され、変更内容の短い要約も表示されます。パネルが空のときは、いくつかのリクエスト例が表示されます。タップするとテキスト欄に入るので、そのまま送信するか、変更してから送信します。

会話はプロフィールごとに保存されるので、パネルを閉じて後で続きから再開できます。

## よいリクエストの書き方 {#ai-builder-tips}

:::tip 使うハブ、各ポートにつながっているもの、それぞれにさせたいことを伝えましょう
「ライト付きの車」のような 1 行のリクエストでは不十分です。AI はハブ、ポート、各モーターの役割を推測するしかなく、結果はおそらく修正が必要になります。次の内容を含めてください。

- **ハブ**：Technic Hub、City Hub、BOOST Move Hub、Robot Inventor、Technic Move Hub、BuWizz、SBrick…
- **各ポートにつながっているもの**：走行用モーター、ステアリング用モーター（サーボ）、ライト、センサー。
- **それぞれにさせたいこと**：走行、キャリブレーション付きのステアリング、オン / オフの切り替え、速度の制限。
- **操作方法**：ジョイスティック、スライダー、ボタン、ゲームパッド。
:::

友だちに説明するように書いてください。日本語で書いてかまいません。

それでもうまくいかないところがあれば、最初からやり直すのではなく、何を変えてほしいかを AI に伝えましょう。

## リクエストの例 {#example-requests}

**車**：「Technic Hub の車：走行モーターはポート A、ポート C のステアリングモーターはサーボとして動作、ライトはポート D。左にステアリングのジョイスティック、右にスロットル、ライトを切り替えるボタン。」

**クレーン**：「Technic Hub のクレーン：旋回モーターはポート A、ブームのモーターはポート B、フックのウインチはポート C。旋回はスライダー、ブームは上下ボタン、フックはジョイスティックで操作し、ブームの速度は 50% に制限。」

**列車**：「City Hub の City トレイン：トレインモーターはポート A、ライトはポート B。速度はステップスイッチで、スピードメーターとライト用のボタンも付けて。」

## 既存のプロフィールを変更する {#change-an-existing-profile}

手作業で作ったものも含め、既存のプロフィールで AI ビルダーを開き、変更したい内容を伝えます。AI は現在のハブ、ダッシュボード、プログラムを把握したうえで編集します。

- 「ステアリングを遅くして。」
- 「停止ボタンを追加して。」
- 「コントロールをゲームパッドにもコピーして。」
- 「ブームの速度を 50% に制限して。」

「ライトはどのポート？」のように、プロフィールについて質問することもできます。AI はパネルで回答し、プロフィールはそのままにします。

## プロフィールに起きること {#what-happens-to-your-profile}

- AI は開いているプロフィールを直接変更します。ハブ、ダッシュボード、プログラムが一度に更新されます。プログラムが実行中の場合は停止します。
- AI はプロフィールのプログラムの種類に合わせて作業します。ロジックブロックのプロフィールではブロックを、クイックリンクのプロフィールでは行を書き、一方を他方に変換することはありません。クイックリンクの行ではできないことが必要なリクエストの場合、AI はロジックブロックのプロフィールが必要だと伝えます。
- AI が変更する必要のない部分は、そのまま残ります。
- **最後の AI の変更を元に戻す**（パネルのヘッダーにある元に戻すボタン）を押すと、プロフィールは最後に AI が変更する前の状態に戻ります。もう一度押すとさらに前に戻り、最大 10 回分さかのぼれます。別のプロフィールを開くと、元に戻す履歴は消去されます。
- いつでも自分でプロフィールの編集を続けられます。

## 音声入力 {#voice-input}

**音声入力**（マイクのボタン）を押してリクエストを話すと、テキストが入力欄に表示され、送信前に修正できます。もう一度ボタンを押すと停止します。複数の言語が使える場合は、マイクの横にある小さな言語ボタンで音声入力の言語を切り替えられます。選んだ言語はアプリが記憶します。

| 環境 | 方法 |
|---|---|
| iPhone、iPad、Mac | **音声入力**。初回はマイクへのアクセスと音声認識を許可します |
| Android | **音声入力**。初回はマイクへのアクセスを許可します |
| Windows | **Win+H** を押して、Windows の音声入力で入力します（マイクのボタンで案内が表示されます） |
| Web エディター | Chrome、Edge、Safari で **音声入力**。サイトにマイクへのアクセスを許可します。Firefox には音声入力がありません |

音声入力のメッセージ：

| メッセージ | 対処法 |
|---|---|
| **システム設定で MOCPilot にマイクへのアクセスを許可してください** | システム設定で MOCPilot のマイクへのアクセスをオンにします |
| **システム設定で MOCPilot に音声認識を許可してください** | Apple デバイスで、システム設定の MOCPilot の音声認識をオンにします |
| **ブラウザーでこのサイトにマイクへのアクセスを許可してください** | ブラウザーのサイト設定でマイクを許可します |
| **何も聞き取れませんでした** | **音声入力** を押して、もう一度話します |
| **音声入力にはネット接続が必要です** | インターネットに接続するか、リクエストを入力します |
| **この言語では現在音声認識を利用できません** | 音声入力の言語を切り替えるか、リクエストを入力します |
| **マイクが見つかりません** / **このデバイスでは音声入力を利用できません** | リクエストを入力します |

## 制限 {#limits}

- 1 日あたり約 30 回のリクエストと、1 か月あたりの上限があります。パネルのヘッダーに使用量が表示されます：**今日 5/30 · 今月 12%**。
- 無料トライアル中は AI リクエストの回数が制限されています。サブスクリプションが始まると再び使えます。
- リクエストは一度に 1 つです。回答を待ってから次のリクエストを送信してください。
- AI ビルダーはプロフィールの作成と編集専用です。ほかの話題の質問には答えません。

## エラーメッセージ {#error-messages}

| メッセージ | 対処法 |
|---|---|
| **AI ビルダーは利用できません** / **AI サービスに接続できませんでした。インターネット接続を確認してもう一度お試しください。** | インターネット接続を確認し、もう一度パネルを開きます |
| **AI サービスに接続できません。インターネット接続を確認してもう一度お試しください。** | 接続を確認し、もう一度リクエストを送信します |
| **AI サービスとの接続が切れました…** | オンラインに戻ると回答がパネルに表示されます。もう一度リクエストを送信してもかまいません |
| **AI が時間内に応答しませんでした。もう一度リクエストを送信してください。** / **リクエストが失われました。もう一度送信してください** | もう一度リクエストを送信します |
| **このリクエストでは動作するプロファイルを作成できませんでした。別の言い方で試してください。** | リクエストを言い換えます。ハブ、ポート、それぞれの役割を明記しましょう |
| **プロファイルが大きすぎて一度に作成できません。一度に頼む内容を減らしてください。** | リクエストを小さなステップに分けます |
| **AI はこのリクエストを断りました。** | プロフィールに関する内容になるよう、リクエストを言い換えます |
| **本日の AI リクエストの上限に達しました。明日もう一度お試しください。** | 明日まで待つか、自分でプロフィールを編集します |
| **今月の AI の上限に達しました。** | 上限は翌月にリセットされます |
| **無料トライアルの AI リクエストをすべて使い切りました。サブスクリプションが始まると再び使えます。** | サブスクリプションが始まるまで待ちます |
| **AI ビルダーはプロフィールの作成と編集専用です。他の話題のリクエストが多すぎます。1 時間後にもう一度お試しください。** | 1 時間待ってから、プロフィールについてだけ質問します |
| **現在 AI へのリクエストが多すぎます。1 分後にもう一度お試しください。** | 1 分後にもう一度試します |
| **前のリクエストはまだ処理中です。** | 回答を待ちます |
| **AI サービスは一時的に利用できません。しばらくしてからお試しください。** / **MocPilot Pro をご利用中です。AI ビルダーは現在利用できません。後でもう一度お試しください。** | しばらくしてからもう一度試します |
| **この回答は別のプロフィール向けでした** | AI の作業中に別のプロフィールを開いたため、変更は適用されませんでした。最初のプロフィールをもう一度開き、リクエストを繰り返します |
| **先に編集するプロフィールを開いてください** | プロフィールをエディターで開いてから、リクエストを送信します |
| **エディターでプロフィールを更新できませんでした** / **変更を元に戻せませんでした** | もう一度試します。繰り返し起きる場合は、プロフィールを閉じて開き直します |
