# カタログと公開 {#catalog-and-publishing}

**プロフィールカタログ** は既製のプロフィールのライブラリです。MOCPilot チームが作った LEGO® セット用の公式プロフィールと、ほかのビルダーが共有したコミュニティのプロフィールがあります。[mocpilot.com](https://mocpilot.com) のカタログと同じものです。

## カタログを開く {#open-the-catalog}

- スマートフォン：**私のプロフィール** ページで **+** → **オンラインで検索**。
- タブレット：サイドバーの **プロフィールカタログ**、または **新しいプロフィール** メニューの **オンラインで検索**。
- パソコン：**ファイル → オンラインで検索**。

カタログにはインターネット接続が必要です。お使いのデバイスでアプリ内に表示できない場合は、**ブラウザで開く** をタップします。

カタログは、名前、説明、ハッシュタグ、作成者、セット番号で検索できます。カードには、プロフィールのダウンロード数が表示されます。

<Screenshot name="profile-catalog" alt="公式プロフィールとコミュニティのプロフィールが並ぶプロフィールカタログ" width={900} />

## プロフィールをインストールする {#install-a-profile}

カタログでプロフィールを開いて追加します。プロフィールリストにコピーが表示されます。

- 変更しない限り、プロフィールは公開されたとおりに動作します。お持ちでない有料テーマも含まれます。
- 作成者が新しいバージョンを公開すると、カードに **アップデートあり** と表示されます。**アップデート** をタップするとインストールされます。タップするまでは何も変わりません。
- 初めてプロフィールを変更するとき、MOCPilot が警告を表示します。変更後はカタログからの更新を受け取れなくなり、お持ちでない製品は基本テーマに置き換えられるかロックされます。[プロフィールの管理](/docs/Application/Profiles/ManageProfiles#paid-themes-in-shared-profiles)を参照してください。

Web サイトでは、カタログのどのプロフィールでも **Add to my account**（アカウントに追加）を押すことができます。追加したプロフィールは[同期](/docs/Application/Account/Sync)によってアプリに届きます。

## プロフィールを公開する {#publish-your-profile}

自分のモデルをみんなと共有しましょう。

1. サインインしていて、プロフィールが同期済みであることを確認します。カタログはアカウントからプロフィールをコピーし、あなたを作成者として表示します。
2. **プロフィールを編集** を開き、**カタログに送信** をタップします。
3. 要件を確認し、フォームに入力して **審査に送信** を押します。

<Screenshot name="publish-profile" alt="不足している要件のリストが表示された「カタログに公開」ページ" width={900} />

### 要件 {#requirements}

審査に送信する前に、プロフィールには次のものが必要です。

- 3 文字以上の名前（「New profile」や「Untitled」のような初期設定の名前は不可）
- 画像
- 20 文字以上の説明
- 1 台以上のハブ
- 操作手段：ダッシュボードのコントローラーまたはゲームパッド
- 1 つ以上のブロックまたは行があるプログラム
- 1 つ以上のハッシュタグ

不足しているものは公開ページに一覧表示されます。

### フォーム {#the-form}

- **名前** と **説明**：モデルでできることと操作方法。
- **ハッシュタグ**。
- **公開範囲**：**公開**（カタログに表示）または **リンクを知っている人のみ**。
- **ハブ**：プロフィールから取得されます。
- セット番号などの追加項目を求められることがあります。
- **新機能**：新しいバージョンの場合。

### 審査 {#review}

すべての投稿はモデレーターが確認します。結果は **通知** に届きます。

- 「プロファイル「…」が審査に通過しました」：Web サイトとアプリのカタログに掲載されました。
- 「プロファイル「…」は審査を通過しませんでした」：モデレーターのメモに修正すべき点が書かれています。修正して再送信してください。

公開ページにはステータスが表示されます：審査待ち、公開済み、公開済み（新しいバージョンが審査待ち）、却下、非表示。

1 か月に送信できるプロフィールまたは新しいバージョンは最大 5 件です。残りの件数はページに表示されます。

### 新しいバージョンと公開の取り下げ {#new-versions-and-unpublishing}

同じプロフィールをもう一度公開すると、**新しいバージョン** が審査に送られます。インストールした人には **アップデートあり** と表示されます。公開したプロフィールを非表示にすることもできます。
