# プロフィールの作成 {#create-a-profile}

1. **私のプロフィール** を開きます。
   - スマートフォン：**+** → **新しいプロフィール** をタップします。
   - タブレット：ヘッダーの **新しいプロフィール**。
   - パソコン：**ファイル → 新しいプロフィール**（⌘N / Ctrl+N）。
2. **プログラムの種類** を選びます（下記参照）。
3. プロフィールの詳細を入力します。
4. **作成** をタップします。プロフィールがエディターで開きます。

## プログラムの種類を選ぶ {#choose-the-program-type}

プログラムの種類によって、プロフィールで使うエディターが決まります。**後から変更することはできません。** もう一方のエディターを試すには、2 つ目のプロフィールを作成してください。

| | クイックリンク | ロジックブロック |
|---|---|---|
| 作り方 | 行：入力 → 処理 → 動作 → ハブ | ブロックをつなげてスクリプトにする |
| 習得時間 | 数分 | 長め。そのぶんできることが多い |
| 向いている用途 | 車、トラック、列車、クレーン：「このコントロールであのモーターを動かす」 | ロボット、自動シーケンス、センサーを使ったロジック、ゲーム |
| ロジック（条件分岐、ループ、変数） | なし（しきい値とトグルのみ） | あり |
| センサー | ハブのセンサーを入力に、値をインジケーターに | ハブとスマートフォンのすべてのセンサー、任意の計算 |
| なめらかな発進、制限、デッドゾーン | 既製のブロック | ブロックで組み立てる |
| キャリブレーション付きのサーボステアリング | 既製のブロック | ブロック |
| ゲームパッド | あり | あり |
| 複数のハブ | あり | あり |

**迷ったら** クイックリンクから始めましょう。後でロジックが必要になったら、そのモデル用にロジックブロックのプロフィールを作成します。

種類を選ばずに **作成** をタップすると、タイルが強調表示されます。各タイルには、このドキュメントの該当部分への **ドキュメント ↗** リンクがあります。

## プロフィールの詳細 {#profile-details}

- **画像**：画像エリアをクリック（タッチスクリーンでは長押し）して画像を選びます。画像を上下にドラッグして、表示する部分を決めます。後から **画像を更新** と **削除** で変更できます。
- **名前**：必須で、ほかと重複しない名前にする必要があります。「“…”という名前のプロフィールはすでに存在します」と表示された場合は、同じ名前のプロフィールがすでにあります。
- **ブロックレベル**（ロジックブロックのみ）：**初心者**、**上級者**、**達人**。このプロフィールでパレットに表示するブロックを決めます。後からエディター設定で変更できます。[エディターでの作業](/docs/Application/BlockBuilder/Editor#block-levels)を参照してください。
- **ハッシュタグ**：プロフィールの内容を表し、ほかの人が見つけやすくなります。ハッシュタグは共通のリストから選び、リストはオンライン時に読み込まれます。

プログラムの種類以外はすべて、後から **プロフィールを編集** で変更できます。そこでは説明を追加したり、プロフィールを **お気に入り** にしたりすることもできます。
