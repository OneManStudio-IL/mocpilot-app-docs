# プロフィールの管理 {#manage-profiles}

## プロフィールの詳細を編集する {#edit-profile-details}

プロフィールの **編集** をタップ（スマートフォン、タブレット）するか、**編集…** をクリック（パソコン）します。**プロフィールを編集** では次の項目を変更できます。

- **画像** と **名前**
- **説明**（プロフィールでできること、対象のモデル、操作方法）
- **ブロックレベル**（ロジックブロック）
- **ハッシュタグ**
- **お気に入り**（スマートフォン、タブレット）：お気に入りのプロフィールはリストのいちばん上に移動します。パソコンでは、**お気に入り** はプロフィールページの下部バーにあります。

<Screenshot name="edit-profile" alt="画像、名前、説明、ハッシュタグが表示された「プロフィールを編集」ウインドウ" width={900} />

プロフィールの削除や、サインイン後のカタログへの送信もここで行います。

プログラムの種類は変更できません。モデルをもう一方のエディターに移すには、新しいプロフィールを作成してください。

## プロフィールを共有（エクスポート）する {#share-export-a-profile}

**共有…** は、プロフィールを 1 つの `.dat` ファイル（`Technic Buggy_<id>.dat` のような名前）にまとめ、システムの共有シートを開きます。メッセージやメールで送ったり、ファイルに保存したりできます。

ファイルにはハブ、ダッシュボード、プログラムが含まれます。購入品は含まれません。受け取った人がお持ちでないテーマや特殊コントロールは、その人がプロフィールを編集すると置き換えられるかロックされます（[下記](#paid-themes-in-shared-profiles)参照）。

## プロフィールをインポートする {#import-a-profile}

1. **私のプロフィール** で **プロフィールをインポート…** を選びます（スマートフォン：**+** → **プロフィールをインポート…**、タブレット：**新しいプロフィール** メニュー、パソコン：**ファイル → プロフィールをインポート…**、⌘O / Ctrl+O）。
2. `.dat` ファイルを選びます。

同じプロフィールをすでに持っている場合：

- バージョンが異なる場合：**置換**、**コピーとして保存**（名前に「(copy)」が付きます）、**キャンセル** から選びます。
- まったく同じファイルの場合：再度読み込まれることはありません。

プロフィールではないファイルは読み込めません。

:::tip プロフィールを複製する
専用の「複製」コマンドはありません。コピーを作るには、プロフィールをファイルに共有し、**コピーとして保存** でインポートします。
:::

## プロフィールを削除する {#delete-a-profile}

**プロフィールを編集** を開きます。

- スマートフォンとタブレット：**プロフィールを削除するにはスライドしてください**
- パソコン：**プロフィールを削除** を押してから確認します。**プロフィールを削除** はプロフィールカードのメニューにもあります。

プロフィールはこのデバイスとアカウントから削除されるので、ほかのデバイスからも消えます。元に戻すことはできません。また必要になるかもしれない場合は、先にプロフィールをファイルに共有しておきましょう。

## カタログのプロフィール {#profiles-from-the-catalog}

[プロフィールカタログ](/docs/Application/Profiles/Catalog)からインストールしたプロフィールは、あなた専用のコピーです。

- 変更しない限り、公開されたとおりに動作します。作成者が新しいバージョンを公開したら、**アップデート** でインストールできます（**プロフィールを編集** の **カタログから更新** でも同じです）。
- 初めて変更するときに警告が表示されます。変更後は、カタログからの更新を受け取れなくなります。

## 共有プロフィールの有料テーマ {#paid-themes-in-shared-profiles}

プロフィールでは、有料の[テーマ](/docs/Application/Themes/ThemesOverview)や特殊コントロール（ハンドル、ペダル、変速機など）を使えます。お持ちでない製品を使っているプロフィールを編集すると：

- お持ちでないテーマのコントロールは、無料の **基本** テーマに切り替わります。
- 無料の代わりがない特殊コントロールは、購入するまでロックされます。
- お持ちの製品はそのまま残ります。

変更していないカタログのプロフィールは、お持ちでない製品も含めて、すべての製品を使って動作します。

## 同期 {#sync}

サインインしていれば、すべての変更がアップロードされ、ほかのデバイスに表示されます。[デバイス間の同期](/docs/Application/Account/Sync)を参照してください。

ほかのデバイスですでに編集中のプロフィールを開くと、MOCPilot は **閲覧のみ**（変更は保存されません）か **編集を引き継ぐ** を選ぶよう求めます。
