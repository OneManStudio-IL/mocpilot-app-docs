# モデルの操作（実行） {#driving-a-model-run}

プロフィールには 2 つのモードがあります。

- **編集**：ハブ、ダッシュボード、プログラムを変更します。
- **実行**：プログラムが動き、ダッシュボードのコントロールでモデルを操作します。

## 開始と停止 {#start-and-stop}

エディターまたはダッシュボードで **実行**（▶）を押します（パソコン：**プログラム → 実行**、⌘R / Ctrl+R）。**停止**（■）を押すと編集に戻ります（⌘. / Ctrl+.）。

<Screenshot name="dashboard-run" alt="プログラム実行中のダッシュボード" width={900} />

プログラムの実行中は：

- ダッシュボードのグリッドのドットと、追加ボタンや設定ボタンが非表示になります。
- コントロールがタッチとゲームパッドに反応します。
- モニターとインジケーターにリアルタイムの値が表示されます。
- クイックリンクでは、エディターの各行のブロック間にリアルタイムの値が表示され、行は編集できません。
- ロジックブロックでは、プログラムを編集できるままなので、動かしながら微調整できます。

## スマートフォンやタブレットでは {#on-a-phone-or-tablet}

プロフィールを開くと、スマートフォンは横向きの全画面に切り替わり、ダッシュボードが画面全体を使えます。操作中に画面が暗くならないよう、設定で **画面を常にオンにする** をオンにしてください。[設定](/docs/Application/Account/Settings)を参照してください。

## 実行を押す前に {#before-you-press-run}

- ハブの電源を入れ、**マイハブ** で接続されていることを確認します（ボタンのバッジに接続中の台数が表示されます）。
- クイックリンクでは、**問題** ボタンを確認します。赤い「!」は、実行できない行があることを意味します。[実行と問題の解決](/docs/Application/Links/Problems)を参照してください。
- 初めて試すときは、モデルを台に載せるか、テーブルの端から離しておきましょう。

## プログラムが停止したとき {#when-the-program-stops}

- **クイックリンク** は、行で使われているすべてのモーターを停止し、出力をリセットします（LED マトリックスの消去、ポートの色とセンサーのライトの消灯）。
- **ロジックブロック** は、エディター設定で **プログラム停止時にハブのポートを停止** がオンになっていれば、ハブのポートを停止します。
- プログラムの実行中にハブの接続が切れると、そのハブのモーターは停止します。クイックリンクでは、ハブの「接続済み」入力を使ってこれをダッシュボードに表示できます。
- リモートコントロールでは、リモコンとハブ端末の接続が約 4 秒間途切れると、ハブ端末はプロフィールとすべてのモーターを停止します。

## 別のデバイスから操作する {#drive-from-another-device}

[MocPilot Pro](/docs/Application/Account/Pro) があれば、1 台のデバイス（ハブに接続するハブ端末）でプロフィールを実行し、別のデバイスや Web エディターから操作できます。[リモートコントロール](/docs/Application/Profiles/RemoteControl)を参照してください。
