# プロフィール {#profiles}

**プロフィール** には、1 つのモデルについて MOCPilot が知っているすべて、つまりハブ、ダッシュボード、プログラムが入っています。モデルごとに 1 つのプロフィールを使います。

<Screenshot name="profiles-desktop" alt="「私のプロフィール」のリスト" width={900} />

## プロフィールの入手先 {#where-profiles-come-from}

- **自分のプロフィール**：**新しいプロフィール** で作成します。[プロフィールの作成](/docs/Application/Profiles/CreateProfile)を参照してください。
- **カタログのプロフィール**：MOCPilot チームが作った LEGO® セット用の公式プロフィールと、ほかのビルダーによるコミュニティのプロフィールです。インストールすると、自分用のコピーがリストに追加されます。[カタログと公開](/docs/Application/Profiles/Catalog)を参照してください。
- **インポートしたプロフィール**：誰かから共有された `.dat` ファイルです。[プロフィールの管理](/docs/Application/Profiles/ManageProfiles#import-a-profile)を参照してください。

どれも同じリストに並びます。

## プロフィールリスト {#the-profile-list}

このページの名前は **私のプロフィール** です。

- **検索** では、名前、ハッシュタグ、作成者、ハブ、セット番号、年でプロフィールを探せます。
- **並べ替えとフィルター** では、**最新のセット**、**最も古いセット**、**名前 (A–Z)**、**名前 (Z–A)**、**作成者 (A–Z)**、**作成者 (Z–A)**、**使用ハブ** で並べ替えられます。**自分のプロフィールのみ** を選ぶと、カタログからインストールしたプロフィールが非表示になります。
- **ハッシュタグで絞り込む**（タブレットとパソコン）では、選んだハッシュタグを持つプロフィールだけを表示します。
- **お気に入り** のプロフィールは常に先頭に表示されます。

カードにはプロフィールの画像と名前、わかっている場合はセット番号、発売年、パーツ数が表示されます。**アップデートあり** は、カタログのプロフィールの新しいバージョンをインストールできることを意味します。

## プロフィールの操作 {#profile-actions}

| 操作 | スマートフォン | タブレット | パソコン |
|---|---|---|---|
| 開く（起動） | カードの **起動する** | カードをダブルタップ、または選択して **起動する** をタップ | カードをダブルクリック、または **起動する** |
| 名前、画像、ハッシュタグ、説明の編集 | カードの **編集** | **編集** | **編集…** |
| お気に入りに追加 | **プロフィールを編集** で | **お気に入りに追加** | **お気に入りに追加** |
| ファイルとして共有 | カードの **共有** | **共有** | **共有…** |
| カタログから更新 | **アップデート** | **アップデート** | **アップデート** |
| カタログに送信 | **プロフィールを編集** で | **プロフィールを編集** で | **プロフィールを編集** で |
| 削除 | **プロフィールを編集** の **プロフィールを削除するにはスライドしてください** | 同じ操作、またはカードのメニューの **プロフィールを削除** | **プロフィールを編集** またはカードのメニューの **プロフィールを削除** |

## 2 種類のプログラム {#two-kinds-of-programs}

各プロフィールは、作成時に選んだ 2 種類のプログラムエディターのどちらかを使います。

- **クイックリンク**：コントロールをモーターやライトに結び付ける行で、コードは不要です。[クイックリンク](/docs/Application/Links/LinksIntroducing)を参照してください。
- **ロジックブロック**：イベント、ループ、条件、変数を使うブロックのプログラムです。[ロジックブロック](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing)を参照してください。

:::info
新しいバージョンの MOCPilot で作ったプロフィールは、古いバージョンでは開けないことがあります（「プロファイルに互換性がありません」）。そのデバイスのアプリをアップデートしてください。
:::
