# リモートコントロール {#remote-control}

リモートコントロールを使うと、別のデバイスに接続されたモデルを操作できます。一方のデバイスはモデルの近くに置いて Bluetooth でハブと通信し、もう一方のデバイスを手に持ってそのダッシュボードで操作します。ブラウザーはハブに接続できないため、[Web エディター](/docs/Introducing/WebEditor)からモデルを操作するときもこの方法を使います。

## 2 台のデバイス {#the-two-devices}

- **ハブ端末** は、モデルの近くにあるスマートフォン、タブレット、パソコンです。その MOCPilot アプリがハブに接続し、プロフィールを実行します。アカウントは不要です。
- **リモコン** は、操作に使う側です。別のデバイスの MOCPilot アプリ、または [mocpilot.com](https://mocpilot.com) の Web エディターです。プロフィールはリモコンで開き、リモコンがそれをハブ端末に送ります。

## 必要なもの {#what-you-need}

- **リモコン** でサインインしているアカウントの [MocPilot Pro](/docs/Application/Account/Pro)。ハブ端末にはアカウントも Pro も不要です。
- ハブ端末の MOCPilot アプリ。
- 両方のデバイスのインターネット接続。

## ハブ端末を接続する {#connect-a-hub-device}

1. リモコンでプロフィールを開き、プロフィールの上部バーで **実行** の隣にある **リモートコントロール**（リモコンのアイコン：電波の弧が付いた家）を押します。Web エディターでは、開いたパネルで **コードを表示** を押します。

   リモコンに **接続コード** が表示されます。QR コードと 6 桁の数字です。
2. ハブ端末で MOCPilot を開き、**私のプロフィール** ページで **リモコンを接続** をタップします。Mac では **ファイル → リモコンを接続…** も使えます。
3. コードを入力します。
   - **スマートフォンやタブレットでは**、カメラを QR コードに向けるか、**コードを入力** をタップして 6 桁の数字を入力します。
   - **パソコンでは**、6 桁の数字を入力して **接続** を押します。
4. デバイスが接続されます。リモコンがプロフィールをハブ端末に送ってそこで開始し、ハブ端末には全画面の **リモートコントロール** ページが表示されます。

<Screenshot name="remote-control-code" alt="開いたプロフィールで QR コードと 6 桁のコードを表示するリモートコントロールのパネル" width={900} />

接続コードについて：

- 1 回だけ使え、有効期間は 5 分です。リモコンに表示している間は、期限が切れると新しいコードに置き換わります。
- スマートフォンのカメラアプリではなく、MOCPilot アプリでスキャンしてください。
- ハブ端末が接続する前にリモコンのパネルを閉じると、何も設定されません。新しいコードを表示するには、もう一度 **リモートコントロール** を押してください。

<Screenshot name="remote-connect-code-entry" alt="6 桁の数字の入力欄があるパソコンの「リモコンを接続」ウインドウ" width={900} />

## デバイスが接続されると {#when-the-devices-are-connected}

**リモコンでは：**

- **リモートコントロール** ボタンが緑色になり（スマートフォンやタブレットでは緑のリング）、パネルにハブ端末の名前と **切断** ボタンが表示されます。
- **マイハブ** にハブ端末のハブが表示されます。いつもどおりそこからハブを接続します。ハブ端末がハブを検索するので、求められたらハブのボタンを押してください。
- ダッシュボードでモデルを操作します。

**ハブ端末では**、全画面の **リモートコントロール** ページに次の内容が表示されます。

- 状態。たとえば **「My car」を実行中**
- **接続済みハブ: N**。検索中は **ハブを検索中：ハブのボタンを押してください。**
- 注意書き：**このアプリを開いたままにしてください。これはハブ端末です。ハブを接続してプロフィールを実行し、リモコンは操作するだけです。**
- **停止** ボタン

接続している間、ハブ端末の画面はオンのままになります。プロフィールはハブ端末には保存されず、そのプロフィールリストにも表示されません。

## 実行と停止 {#run-and-stop}

- リモコンで **停止** を押すと、ハブ端末のプロフィールが停止します。プロフィールで **プログラム停止時にハブのポートを停止** がオフになっていても、ハブ端末は必ずすべてのモーターを停止します。
- リモコンで **実行** を押すと、ハブ端末でもう一度開始します。
- Web エディターでは、同じブラウザーのタブで開いたすべてのプロフィールで、ハブ端末とのペアリングが維持されます。**実行** を押すと、プロフィールがハブ端末で開始します。ハブ端末とペアリングしていないときは、**実行** でプロフィールがハブなしでブラウザー上で実行されます。

## 接続が切れた場合 {#if-the-connection-drops}

:::caution 安全のために
ハブ端末は、リモコンからの通信が 4 秒間途絶えると、プロフィールとすべてのモーターを停止します。
:::

その後：

- ハブ端末には **リモコンとの接続が切れました。プロフィールは停止しました。リモコンを待っています…** と表示され、待機します。
- リモコンのアプリには **接続が切れました。再試行しています…** と表示され、**再試行** と **切断** が表示されます。
- Web エディターには **ハブ端末が切断されました** と表示されます：「*デバイス* が応答しなくなりました。そのプロフィールは停止し、モーターはオフになりました。」 再接続は自動で試み続けます。**再接続**、**ブラウザーで実行**、**停止** を押すこともできます。

デバイスが再接続されたら、リモコンで状態を確認し、プロフィールが実行されていなければ **実行** を押してください。

## 切断する {#disconnect}

- **リモコンでは**：**リモートコントロール** を押して **切断** を選びます。
- **ハブ端末では**：**リモートコントロール** ページで **停止** を押します。

どちらの方法でも、プロフィールとモーターが停止し、ハブ端末はプロフィールを閉じます。

## トラブルシューティング {#troubleshooting}

| メッセージ | 表示される場所 | 対処法 |
|---|---|---|
| **リモートコントロールは MocPilot Pro の機能です** | リモコン | リモコンのアカウントで [MocPilot Pro](/docs/Application/Account/Pro) に登録します。ブラウザーでは登録できません。アプリで登録すれば、Web エディターでも Pro が使えます |
| **サーバーに接続できません** | どちらでも | インターネット接続を確認して再試行します |
| **サーバーからコードを取得できませんでした** | リモコン | **コードを表示** を押して再試行します |
| **コードが間違っているか期限切れです。リモコンに表示された 6 桁の数字を確認してください。** | ハブ端末 | リモコンに今表示されている 6 桁の数字を入力します |
| **コードの有効期限が切れました。リモコンに新しいコードを表示して、もう一度スキャンしてください。** | ハブ端末 | リモコンで **リモートコントロール** を押し、新しいコードをスキャンします |
| **これは MOCPilot のコードではありません。リモコンに表示されたコードをスキャンしてください。** | ハブ端末 | リモコンの **リモートコントロール** パネルの QR コードをスキャンします |
| **間違ったコードが多すぎます。数分後にもう一度お試しください。** | ハブ端末 | 数分待ってから、現在のコードを入力します |
| **コードをスキャンするには、システム設定で MOCPilot にカメラの使用を許可してください。** | ハブ端末 | システム設定でカメラへのアクセスを許可するか、**コードを入力** をタップして 6 桁の数字を入力します |
| **リモコンが応答しません。プロフィールが開かれていて、オンラインであることを確認してください。** | ハブ端末 | リモコンでプロフィールを開いたままにし、インターネット接続を確認します |
| **このバージョンのアプリはリモコンに接続できません** | どちらでも | MOCPilot をアップデートします |
| **このブラウザでは直接接続（WebRTC）を開けません** | Web エディター | Chrome、Edge、Safari など、別のブラウザーを使います |
| **プロファイルが大きすぎます** / **プロファイルが完全に届きませんでした** | どちらでも | 接続を確認し、もう一度 **実行** を押します |
| **相手のデバイスでプロファイルを保存できませんでした** / **相手のデバイスでプロファイルを開けませんでした** | リモコン | もう一度 **実行** を押します。繰り返し起きる場合は、ハブ端末をいったん切断してから接続し直します |
| ***デバイス* との接続が切れました** / **リモコンとの接続が切れました。待機中…** | どちらでも | [接続が切れた場合](#if-the-connection-drops)を参照してください |
