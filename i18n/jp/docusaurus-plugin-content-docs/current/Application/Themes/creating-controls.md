# テーマからコントロールを作成 {#create-controls-from-a-theme}

追加するコントロールは、どれもテーマをもとにしています。追加する前に設定でき、設定したコントロールを自分のデザインとして保存できます。

## 追加する前に設定する {#configure-before-adding}

1. **コントローラーを追加**（ダッシュボードの **+**、パソコンでは **+ コントローラー**）を開きます。
2. コントロールの種類を選び、外観の一覧から外観を選びます。
3. **設定** で **スタイル** と **設定** のタブを使います：サイズ（パレットには「幅 x 高さ ドット」で表示）、アクセントカラー、アイコン、テーマのオプション、動作。
4. **ダッシュボードに追加** をタップします。

## デザインを保存する {#save-a-design}

気に入った組み合わせ（たとえば、ホーンのアイコンを付けた赤いレーシングのボタン）ができたら、保存しておきましょう。

1. お持ちのテーマで設定したコントロールを選びます。
2. **デザインを保存** をタップします。
3. デザインは **マイデザイン** → **保存済みデザイン** に表示されます。どのプロフィールのダッシュボードにも、ワンタップで追加できます。

**削除** で保存したデザインを削除します。

## ダッシュボード上でコントロールをコピーする {#copy-controls-on-the-dashboard}

- **複製** は、すべてのプロパティを含めてコントロールをコピーします。
- **複製（種類のみ）** は、同じ種類のコントロールを初期設定のプロパティで追加します。
- **テーマを変更** は、位置やプログラムとのつながりを保ったまま、コントロールをお持ちの別のテーマに切り替えます。

## よいダッシュボードのために {#a-good-dashboard}

- 操作用のコントロールは親指の下に置きましょう。片側にジョイスティックやペダル、反対側にステアリング。
- よく使うコントロールは **L** サイズ、あまり使わないものは **S** サイズにしましょう。
- 機能ごとにアクセントカラーを 1 色決めましょう。走行は緑、ライトは黄、停止は赤など。
- レイアウトが完成したら、コントロールをロックしましょう（**すべてをロック**）。
- バッテリーモニターを追加して、充電のタイミングがわかるようにしましょう。

:::info 独自のグラフィック
アプリで完全に新しいコントロールやテーマを描くことはできません。テーマは MOCPilot チームが制作しています。テーマのアイデアがあれば、**ヘルプ → 質問する** からお知らせください。
:::
