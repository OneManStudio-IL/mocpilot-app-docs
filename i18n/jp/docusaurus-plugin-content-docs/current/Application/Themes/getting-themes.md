# テーマの入手、購入、アップデート {#get-buy-and-update-themes}

専用のストア画面はありません。テーマは、使う場所であるダッシュボードの **コントローラーを追加** パレットで、そのまま見て購入できます。

## テーマを試す {#try-a-theme}

1. ダッシュボードを開き、**+**（**コントローラーを追加**）をタップします。
2. コントロールの種類（たとえばジョイスティック）を選びます。外観の一覧に、すべてのテーマでの見た目が表示されます。特殊コントロールは **車両・特殊** にあります。
3. 外観をタップすると大きなプレビューで表示され、試すことができます。**設定** では、色、サイズ、オプションを試せます。

mocpilot.com の [Web エディターのデモ](/docs/Introducing/WebEditor)では、有料のコントロールをダッシュボードに置いて試すこともできます。

## 購入する {#buy}

お持ちでないテーマの場合、パレットには次のものが表示されます。

- **購入 &lt;価格&gt;**：このテーマ（またはこの特殊コントロール）を一度購入すれば、ずっと使えます。
- **MocPilot Pro ですべて**：サブスクリプションですべてのテーマと特殊コントロールを利用できます。[MocPilot Pro](/docs/Application/Account/Pro)を参照してください。

購入は App Store、Google Play、Microsoft Store を通じて行われ、MOCPilot アカウントに紐づくため、サインインしている必要があります。購入品はすべてのデバイスと Web エディターで使えます。

## インストールとアップデート {#install-and-update}

テーマを手動でインストールする必要はありません。サインインしていれば、MOCPilot がお持ちのテーマをダウンロードし、最新の状態に保ちます。無料の基本テーマはアプリに組み込まれています。

テーマが見当たらない場合：

- インターネット接続を確認し、正しいアカウントでサインインしているか確かめてください。
- **アカウント → 購入** を開き、**復元する**（購入を復元）をタップしてください。
- アプリを再起動してください。

## お持ちでないテーマを使ったプロフィール {#profiles-with-themes-you-dont-own}

- [カタログ](/docs/Application/Profiles/Catalog)からインストールしたプロフィールは、変更しない限り、すべてのテーマを使って動作します。
- お持ちでないテーマを使ったプロフィールを編集すると、それらのコントロールは基本テーマに切り替わり、特殊コントロール（ハンドル、ペダルなど）は購入するまでロックされたままになります。

## 代替ストア {#alternative-stores}

**アカウント → 購入 → 購入設定** で、**代替ストアを使用** と、支払いページを **システムのブラウザーで開く** をオンにできます。これらは、通常のストアが利用できない地域向けの設定です。
