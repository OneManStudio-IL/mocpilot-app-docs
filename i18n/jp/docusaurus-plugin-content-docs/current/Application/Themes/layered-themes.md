# レイヤー型テーマ {#layered-themes}

有料テーマと[特殊コントロール](/docs/Application/Dashboard/SpecialControls)は **レイヤー型** の形式を使っています。レイヤー型のコントロールは、1 枚の画像ではなく、重ねた複数のレイヤーで描かれます。

- **画像** レイヤー：本体、ベゼル、ガラス、影。それぞれ効果を付けて用意されています。
- **図形と円弧**：値に合わせて動くリング、目盛り、進行状況の円弧。
- **テキストとアイコン**：ラベル、数字、選んだアイコン。
- **モニターのテキスト**：モニターに表示されるテキスト。

アプリはレイヤーをリアルタイムに合成します。スライダーのハンドルがレールの上を動き、スピードメーターの針が回り、円弧が満ちていき、アクセントカラーが該当するレイヤーに色を付けます。

## これによって得られること {#what-this-gives-you}

- **どのサイズでもくっきり**：S、M、L のどのサイズでも、どの画面密度でも鮮明です。
- **自分好みの色**：アクセントカラーとテーマのオプションで、新しいグラフィックなしに見た目を変えられます。
- **なめらかで軽量**：コントロールごとの画像は数枚なので、古いスマートフォンでもダッシュボードが軽快に動きます。
- **同じ動作**：どのテーマのジョイスティックも基本テーマのジョイスティックとまったく同じように動作するので、プログラムに手を加えずにテーマを変更できます。

## バージョンと互換性 {#versions-and-compatibility}

テーマはサーバー上で随時更新されます。新しいコントロール、修正、グラフィックの改善などです。アプリは、表示できる最新のバージョンをダウンロードします。古いアプリには、そのアプリ向けに作られたバージョンが引き続き届くので、アップデート後にテーマが壊れることはありません。最新の見た目を使うには、MOCPilot を最新の状態に保ってください。
