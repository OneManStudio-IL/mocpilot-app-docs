# テーマとは {#what-is-a-theme}

**テーマ** は、ダッシュボードのコントロールの見た目のスタイルです。どのテーマにも同じ種類のコントロール（ジョイスティック、スライダー、ボタン、スイッチ、ステップスイッチ、モニター）があり、動作もすべて同じです。違うのは見た目だけです。

1 つのダッシュボードで複数のテーマを組み合わせられます。コントロールごとに個別のテーマがあります。

## 利用できるテーマ {#available-themes}

**基本** テーマは無料で、アプリに組み込まれています。ジョイスティック、方向パッド、スライダー、縦型スライダー、ボタン、スイッチ、ステップスイッチ、縦型ステップスイッチ、モニターがあります。

どの **有料テーマ** にも、基本テーマのすべてのコントロールに加えて、**ロータリーノブ**、**バッテリーレベル**、**スピードメーター**、**傾きモニター** があり、それぞれがテーマ独自のスタイルで描かれています。有料テーマは次のとおりです。

オーラ、ブロック、バギー、建設機械、サーキットコア、シティカー、クラシック、クラシック4x4、コンセプト、ディープスペース、フォーミュラ、ヘビーホール、重型トラック、ハイファイオーディオ、ハイテク、ホログラム、長距離トラック、マイアミ、ネオオービット、オフロードキャブ、オフローダー、レーシング、ラリー、レトロ、ロッククローラー、セダン、サンセット、スーパーカー、タクティカル、ワークホース。

新しいテーマは随時追加され、自動的にパレットに表示されます。

どの有料テーマにも、同じスタイルの既製の **ダッシュボードの背景** が付属しています。[ダッシュボード設定](/docs/Application/Dashboard/DashboardOverview#dashboard-settings)を参照してください。

**特殊コントロール** は別売りの製品です。ハンドル、ペダル、シフトレバー、サイドブレーキ、ウインカー、マスコンがあります。そのほとんどに、有料テーマごとの外観があります。[特殊コントロール](/docs/Application/Dashboard/SpecialControls)を参照してください。

すべての有料テーマと特殊コントロールは [MocPilot Pro](/docs/Application/Account/Pro) に含まれています。

## テーマのオプション {#theme-options}

一部のテーマには、コントロールの **スタイル** タブに独自のオプションがあります。

- レーシング：**カラー炭素**、**カラフルなベゼル**、**レースラインを表示**
- 建設機械：**インジケーターのセグメント数**
- オーラ：**値を表示**

## コントロールのテーマを変更する {#change-the-theme-of-a-control}

コントロールを長押し（または右クリック）→ **テーマを変更** を選ぶか、プロパティの **テーマを変更** を使います。お持ちのテーマのうち、同じ種類のコントロールがあるテーマに切り替えられます。位置、サイズ、プログラムとのつながりはそのままです。
