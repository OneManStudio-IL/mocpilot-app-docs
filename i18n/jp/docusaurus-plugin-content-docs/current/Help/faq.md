# よくある質問 {#frequently-asked-questions}

### MOCPilot は無料ですか？ {#is-mocpilot-free}
はい。両方のエディター、すべてのハブ、基本テーマ、プロフィールあたり 2 つのハブスロットは無料です。有料テーマ、特殊コントロール（ハンドル、ペダル、変速機など）、追加のハブスロットは個別に購入できます。MocPilot Pro にはそれらすべてに加えて、リモートコントロールと AI ビルダーが含まれます。[MocPilot Pro と購入](/docs/Application/Account/Pro)を参照してください。

### どのハブに対応していますか？ {#which-hubs-are-supported}
LEGO® Technic Hub、Technic Move Hub、City Hub、BOOST Move Hub、WeDo 2.0、Robot Inventor、Powered Up リモコン、BuWizz 2.0 と 3.0 Pro、SBrick と SBrick Plus、Mould King 4.0 と 6.0 に対応しています。[対応デバイス](/docs/Introducing/SupportedDevices)を参照してください。

### クイックリンクとロジックブロック、どちらがいいですか？ {#quick-links-or-logic-blocks}
「このコントロールであのモーターを動かす」ならクイックリンクを選びましょう。コードなしで数分で完成します。シーケンス、条件、変数、センサーなどのロジックを含むプログラムならロジックブロックを選びましょう。[比較](/docs/Application/Profiles/CreateProfile#choose-the-program-type)を参照してください。

### プロフィールのプログラムの種類は変更できますか？ {#can-i-change-the-program-type-of-a-profile}
いいえ。プログラムの種類はプロフィールの作成時に決まります。もう一方の種類で新しいプロフィールを作成してください。

### Controlz を使っていました。クイックリンクは同じものですか？ {#i-used-controlz-is-quick-links-the-same}
クイックリンクは同じ考え方（コントロールからハブへの行）に基づき、さらに処理ブロック、入力としてのハブのセンサー、リアルタイムの値、元に戻す機能が加わり、行数の制限もありません。[クイックリンク](/docs/Application/Links/LinksIntroducing)を参照してください。

### LEGO セット用の既製プロフィールはどこにありますか？ {#where-are-the-prebuilt-profiles-for-lego-sets}
[プロフィールカタログ](/docs/Application/Profiles/Catalog)（**オンラインで検索**）にあります。セット用の公式プロフィールと、コミュニティのプロフィールがあります。

### 1 つのモデルで複数のハブを使えますか？ {#can-i-use-several-hubs-in-one-model}
はい。プロフィールあたり最大 5 台まで使えます。2 つのスロットは無料で、さらに 3 つを解除できます。

### ゲームパッドで使えますか？ {#does-it-work-with-a-gamepad}
はい。お使いのデバイスが対応している Xbox や PlayStation タイプのゲームパッドが使えます。[ゲームパッド](/docs/Application/Dashboard/Gamepad)を参照してください。

### パソコンで MOCPilot を使えますか？ {#can-i-use-mocpilot-on-a-computer}
はい。Mac と Windows で使えます。また、mocpilot.com のブラウザーで編集もできます。[スマートフォン、タブレット、デスクトップ](/docs/Introducing/Layouts)、[システム要件](/docs/Introducing/SystemRequirements)、[Web エディター](/docs/Introducing/WebEditor)を参照してください。

### ブラウザーからモデルを操作できますか？ {#can-i-drive-a-model-from-the-browser}
ブラウザーは Bluetooth ハブを使えません。MocPilot Pro があれば、モデルの近くにあるスマートフォン、タブレット、パソコンの MOCPilot アプリがハブに接続し、ブラウザーがリモコンになります。[リモートコントロール](/docs/Application/Profiles/RemoteControl)を参照してください。

### インターネットなしで使えますか？ {#does-it-work-without-internet}
はい。ハブ、プロフィール、ダウンロード済みのテーマはオフラインで使えます。変更はオンラインに戻ったときにアップロードされます。カタログ、AI ビルダー、リモートコントロール、購入にはインターネットが必要です。[オフラインでの作業](/docs/Application/Account/Sync#working-offline)を参照してください。

### アカウントは必要ですか？ {#do-i-need-an-account}
必須ではありませんが、アカウントがないとプロフィールは 1 台のデバイスにしか保存されず、アプリを削除すると失われます。アカウントがあれば、同期、バックアップ、すべてのデバイスでの購入品の利用、公開ができます。

### 友だちとプロフィールを共有するには？ {#how-do-i-share-a-profile-with-a-friend}
**共有…** で `.dat` ファイルが作られます。友だちは **プロフィールをインポート…** を使います。または[カタログ](/docs/Application/Profiles/Catalog)に公開しましょう。

### 友だちのプロフィールに、持っていないコントロールが含まれています。どうなりますか？ {#my-friends-profile-has-controls-i-dont-own-what-happens}
そのまま実行できます。編集すると、持っていないテーマのコントロールは基本テーマに切り替わり、特殊コントロールは購入するまでロックされます。

### 自分でテーマを作れますか？ {#can-i-make-my-own-themes}
アプリではできません。テーマは MOCPilot チームが制作していますが、コントロールを設定してデザインを保存することはできます。[テーマからコントロールを作成](/docs/Application/Themes/CreatingControls)を参照してください。

### AI ビルダーへのリクエストには何を書けばいいですか？ {#what-should-i-write-in-an-ai-builder-request}
ハブの名前と、各ポートに何がつながっているか（走行用モーター、ステアリング用モーター、ライト、センサー）、それぞれに何をさせたいか、どう操作したいかを書いてください。書かないと AI はポートや役割を推測するしかなく、結果に修正が必要になることがあります。[よい結果を得るには](/docs/Application/Profiles/AiBuilder#ai-builder-tips)を参照してください。

### MOCPilot は LEGO が作っているのですか？ {#is-mocpilot-made-by-lego}
いいえ。MOCPilot は独立したアプリです。LEGO® は LEGO Group の商標であり、LEGO Group は MOCPilot のスポンサーではなく、MOCPilot を推奨するものでもありません。

### サポートに連絡するには？ {#how-do-i-contact-support}
アプリで **ヘルプ** を開き、**質問する** または **バグを報告する** を選びます。返信はメールと **通知** に届きます。コミュニティに参加するには、MOCPilot の Telegram グループに参加してください（リンクは **ヘルプ** にあります）。
