# 用語集 {#glossary}

**AI ビルダー**：モデルを言葉で説明すると、AI がプロフィールのハブ、ダッシュボード、プログラムを設定します。MocPilot Pro の機能です。[AI ビルダー](/docs/Application/Profiles/AiBuilder)を参照してください。

**ブロック**：ロジックブロックで、プログラムを構成する 1 つの部品です。イベント、命令、条件、値があります。ブロックはつなぎ合わせてスタックにします。[ロジックブロックの紹介](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing)を参照してください。

**カタログ**：オンラインの **プロフィールカタログ** です。LEGO® セット用の公式プロフィールと、コミュニティが共有したプロフィールがあります。自分のプロフィールを公開することもできます。[カタログと公開](/docs/Application/Profiles/Catalog)を参照してください。

**接続コード**：ハブ端末と連携するためにリモコンが表示する QR コードと 6 桁の数字です。有効期間は 5 分です。[リモートコントロール](/docs/Application/Profiles/RemoteControl)を参照してください。

**コントロール（コントローラー）**：ダッシュボード上の要素です。ジョイスティック、スライダー、ボタン、スイッチ、ステップスイッチ、モニター、特殊コントロールがあります。コントロールは値をプログラムに渡すだけです。[コントロールの種類](/docs/Application/Dashboard/ControlTypes)を参照してください。

**ダッシュボード**：モデルを操作する画面で、コントロールを並べたグリッドです。プロフィールごとに専用のダッシュボードがあります。[ダッシュボード](/docs/Application/Dashboard/DashboardOverview)を参照してください。

**ハブ**：モデルに組み込む Bluetooth ブロックで、モーター、ライト、センサーをつなぎます。[ハブ](/docs/Application/Hubs/HubsOverview)と[対応デバイス](/docs/Introducing/SupportedDevices)を参照してください。

**ハブ端末**：リモートコントロールで、モデルの近くに置くスマートフォン、タブレット、パソコンです。その MOCPilot アプリがハブに接続し、プロフィールを実行します。[リモートコントロール](/docs/Application/Profiles/RemoteControl)を参照してください。

**入力**：クイックリンクで、行の始まりです。値の出どころを表し、ダッシュボードのコントロール、ゲームパッド、車両、ハブのセンサーなどがあります。[入力](/docs/Application/Links/Inputs)を参照してください。

**接続部**：クイックリンクで、行の 2 つのブロックがつながる場所です。その形でどのブロックが合うかがわかり、プログラムの実行中はリアルタイムの値が表示されます。[クイックリンク](/docs/Application/Links/LinksIntroducing)を参照してください。

**リスト**：ロジックブロックで、複数の値を順番に保持する変数です。[リスト](/docs/Application/BlockBuilder/Blocks/Lists)を参照してください。

**ロジックブロック**：イベント、ループ、条件、変数、センサーのブロックでプログラムを組み立てるプログラムエディターです。[ロジックブロックの紹介](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing)を参照してください。

**外観**：特殊コントロールの見た目のスタイルの 1 つです。たとえばレース用ハンドルなど。外観で変わるのは見た目だけで、値は変わりません。[特殊コントロール](/docs/Application/Dashboard/SpecialControls#looks)を参照してください。

**MocPilot Pro**：すべての有料テーマ、特殊コントロール、ハブスロットに加えて、AI ビルダーとリモートコントロールが含まれるサブスクリプションです。[MocPilot Pro と購入](/docs/Application/Account/Pro)を参照してください。

**マイブロック**：ほかのブロックを組み合わせて自分で作り、プログラムの中で再利用するブロックです。[マイブロック](/docs/Application/BlockBuilder/Blocks/MyBlocks)を参照してください。

**動作**：クイックリンクで、ハブが値をどう使うかを表します。モーター、サーボ、ライト、角度指定で回転などがあります。[動作](/docs/Application/Links/Operations)を参照してください。

**出力**：クイックリンクで、行の終わりです。使用するポートを指定したハブ、またはインジケーターやハブの LED などの直接出力があります。[クイックリンク](/docs/Application/Links/LinksIntroducing)を参照してください。

**ポート**：ハブにあるモーター、ライト、センサー用の差し込み口で、アルファベットまたは数字で示されます。[ハブとポート](/docs/Application/Links/HubsAndPorts)を参照してください。

**処理**：クイックリンクで、行の途中に置く任意のブロックで、途中で値を変化させます。反転、デッドゾーン、スムーズなどがあります。[処理](/docs/Application/Links/Processing)を参照してください。

**プロフィール**：1 つのモデルに関するすべて、つまりハブ、ダッシュボード、プログラムをまとめたものです。[プロフィール](/docs/Application/Profiles/ProfilesOverview)を参照してください。

**クイックリンク**：コード不要のプログラムエディターです。各行が入力とハブを結び付けます：*入力 → 処理 → 動作 → 出力*。[クイックリンク](/docs/Application/Links/LinksIntroducing)を参照してください。

**リモコン**：リモートコントロールで、モデルを操作する側のデバイスです。別のデバイスの MOCPilot アプリ、または Web エディターです。[リモートコントロール](/docs/Application/Profiles/RemoteControl)を参照してください。

**行**：クイックリンクのプログラムの 1 行で、1 つの入力を 1 つの出力に結び付けます。[クイックリンク](/docs/Application/Links/LinksIntroducing)を参照してください。

**シミュレーター**：ペダル、シフトレバー、サイドブレーキを、慣性、ブレーキ、ギアを備えた本物の車のように走る車両に変えます。[シミュレーター](/docs/Application/BlockBuilder/Blocks/Simulator)を参照してください。

**スロット**：プロフィールでハブ 1 台を割り当てる場所です。プロフィールには 5 つのスロットがあり、2 つは無料、3 つは解除できます。[ハブスロット](/docs/Application/Hubs/HubsOverview#hub-slots)を参照してください。

**特殊コントロール**：本物そっくりの見た目と動きをするコントロールです。ハンドル、ペダル、変速機、サイドブレーキ、ウインカー、マスコンがあります。それぞれ個別に購入します。[特殊コントロール](/docs/Application/Dashboard/SpecialControls)を参照してください。

**スタック**：ロジックブロックで、つながったブロックのまとまりです。通常はイベントで始まり、1 つのスクリプトとして上から下へ実行されます。[ブロックのスタック](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing#block-stack)を参照してください。

**テーマ**：ダッシュボードのコントロールの見た目のスタイルです。基本テーマは無料で、ほかのテーマは有料です。[テーマ](/docs/Application/Themes/ThemesOverview)を参照してください。

**変数**：ロジックブロックで、速度やカウンターなどの値をプログラムが保持しておく、名前の付いた場所です。[変数](/docs/Application/BlockBuilder/Blocks/Variables)を参照してください。

**車両**：シミュレーターがペダル、シフトレバー、サイドブレーキから作る車です。ロジックブロックではシミュレーターのカテゴリで作成し、クイックリンクでは車両入力として使います。[車両](/docs/Application/BlockBuilder/Blocks/Simulator#vehicles)を参照してください。

**Web エディター**：mocpilot.com のブラウザーで動く MOCPilot で、アプリをインストールせずにプロフィールを編集できます。[Web エディター](/docs/Introducing/WebEditor)を参照してください。
