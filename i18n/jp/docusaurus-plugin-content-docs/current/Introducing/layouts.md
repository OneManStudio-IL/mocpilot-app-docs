# スマートフォン、タブレット、デスクトップ {#phone-tablet-and-desktop}

MOCPilot には 3 種類のレイアウトがあり、アプリが自動で選びます。

- **スマートフォン**：iPhone と Android スマートフォン。
- **タブレット**：iPad と Android タブレット（7 インチ以上）。
- **デスクトップ**：Mac と Windows パソコン。ブラウザーで使う [Web エディター](/docs/Introducing/WebEditor)もデスクトップ用のエディターを使います。

プロフィール、エディター、ダッシュボードはどこでも同じで、違うのは画面の移動方法だけです。

## スマートフォン {#phone}

<Screenshot name="profiles-phone" alt="下部バーのあるスマートフォンの「私のプロフィール」ページ" width={360} />

- **下部バー**には **プロフィール**、**設定**、**ヘルプ** があり、サインインしていれば **通知** も表示されます。
- **アカウント** は **設定** のいちばん上にあります。
- **私のプロフィール** のヘッダーには、**並べ替えとフィルター**、**リモコンを接続**（リモコンのアイコン）、**+**（新しいプロフィール、プロフィールをインポート…、オンラインで検索）と検索欄があります。
- メイン画面は縦向きです。プロフィールを開くと、アプリは**横向きの全画面**に切り替わり、エディターとダッシュボードが画面全体を使えます。プロフィールを閉じると縦向きに戻ります。
- エディターでは、上部に並ぶ丸いボタンから、ホーム、元に戻す、やり直す、AI ビルダー、エディター設定、問題（クイックリンク）、ゲームパッド、マイハブ、リモートコントロール、ダッシュボード、モニター（ロジックブロック）、実行 / 停止にすばやくアクセスできます。

<Screenshot name="editor-phone" alt="上部に丸いボタンが並ぶ、スマートフォンのプロフィールエディター" width={900} />

## タブレット {#tablet}

<Screenshot name="profiles-tablet" alt="サイドバーのあるタブレットの「私のプロフィール」ページ" width={900} />

- 左側の**サイドバー**には **プロフィール**、**プロフィールカタログ**、**通知**、**設定**、**ヘルプ** があります。その下に **MocPilot Pro** カードとアカウント（ゲストモードでは **サインイン**）があります。サイドバーはアイコンだけの表示に折りたためます。
- **私のプロフィール** のヘッダーには、**新しいプロフィール**（そのメニューにはプロフィールをインポート…、リモコンを接続、オンラインで検索もあります）、**並べ替えとフィルター**、**ハッシュタグで絞り込む**、**リモコンを接続** と検索欄があります。
- プロフィールカードをタップすると選択され、下部のバーに **共有**、**編集**、**お気に入りに追加**、**起動する** が表示されます。カードをダブルタップすると起動します。カードを長押しするとメニューが開き、**プロフィールを削除** もそこにあります。
- 画面が広い場合、設定とヘルプはリストの横に開きます。
- プロフィールは横向きで開き、エディターにはスマートフォンと同じ丸いボタンがあります。

## デスクトップ（Mac と Windows） {#desktop-mac-and-windows}

<Screenshot name="profiles-desktop" alt="パソコンの「私のプロフィール」" width={900} />

- 上部バーの右側：**アカウント**（ゲストモードでは **サインイン**）、**通知**（サインイン時）、**リモコンを接続**（リモコンのアイコン）、**設定**（歯車）。
- 設定、ヘルプ、アカウント、新しいプロフィール、プロフィールを編集、プロフィールカタログなどのページは、プロフィールリストの上に**ウインドウ**として開きます。
- プロフィールカードをクリックすると、できる操作（**共有…**、**編集…**、**お気に入りに追加**、**起動する**）が表示されます。ダブルクリックで起動します。カードを右クリックするとメニューが開き、**プロフィールを削除** もそこにあります。
- エディターでは、**ダッシュボード** が**専用のウインドウ**で開くので、プログラムとダッシュボードを並べて表示できます。

### メニュー {#menus}

Windows ではメニューはアプリの上部バーの左側にあります。Mac では画面上部のシステムのメニューバーにあります。

| メニュー | Windows | Mac |
|---|---|---|
| **MOCPilot**（アプリメニュー） | — | MOCPilot について、設定…、終了 |
| **ファイル** | 新しいプロフィール、プロフィールをインポート…、オンラインで検索、終了 | 新しいプロフィール、プロフィールをインポート…、オンラインで検索、リモコンを接続… |
| **表示** | フルスクリーンにする | フルスクリーンにする / フルスクリーンを終了 |
| **ウインドウ** | 最小化、最大化 / 元のサイズに戻す | 最小化 |
| **ヘルプ** | MOCPilot ヘルプ、質問する、バグを報告する、MOCPilot について | MOCPilot ヘルプ、質問する、バグを報告する |

プロフィールを開いているときは、エディターに専用の **ファイル**、**編集**、**表示**、**プログラム** メニューがあり（[デスクトップのメニュー](/docs/Application/BlockBuilder/Editor#desktop-menus)を参照）、ダッシュボードのウインドウには **ファイル**、**編集**、**表示** があります（[ダッシュボード](/docs/Application/Dashboard/DashboardOverview)を参照）。

### キーボードショートカット {#keyboard-shortcuts}

Mac では、Windows の Ctrl の役割を ⌘（Command）が担います。⇧ は Shift、⌃ は Control です。

**どこでも**

| 操作 | Windows | Mac |
|---|---|---|
| 設定 | Ctrl+2 | ⌘, |
| フルスクリーンにする / 終了する | F11 または Alt+Enter | ⌃⌘F |
| ウインドウを最小化 | — | ⌘M |
| 終了 | Alt+F4 | ⌘Q |

**私のプロフィール**（プロフィールを開いていないとき）

| 操作 | Windows | Mac |
|---|---|---|
| 新しいプロフィール | Ctrl+N | ⌘N |
| プロフィールをインポート | Ctrl+O | ⌘O |
| プロフィールを検索 | Ctrl+F | — |
| プロフィール / 設定 / ヘルプ / アカウント | Ctrl+1 / Ctrl+2 / Ctrl+3 / Ctrl+4 | — |

**プロフィールエディター**

| 操作 | Windows | Mac |
|---|---|---|
| プロフィールを閉じる | Ctrl+W | ⌘W |
| 実行 / 停止 | Ctrl+R / Ctrl+. | ⌘R / ⌘. |
| 元に戻す / やり直す | Ctrl+Z / Ctrl+Shift+Z または Ctrl+Y | ⌘Z / ⇧⌘Z |
| ダッシュボードを表示 | Ctrl+2 | ⌘2 |
| マイハブ | Ctrl+Shift+H | ⇧⌘H |
| AI ビルダー | Ctrl+Shift+I | ⇧⌘I |
| ブロックパレットの表示 / 非表示（ロジックブロック） | Ctrl+P | ⌘P |
| ブロックパレットを検索（ロジックブロック） | Ctrl+F | ⌘F |
| モニター（ロジックブロック） | Ctrl+Shift+M | ⇧⌘M |
| 拡大 / 縮小 / 実際のサイズ（ロジックブロック） | Ctrl++ / Ctrl+− / Ctrl+0 | ⌘+ / ⌘− / ⌘0 |

**ダッシュボード**

| 操作 | Windows | Mac |
|---|---|---|
| 元に戻す / やり直す | Ctrl+Z / Ctrl+Shift+Z または Ctrl+Y | ⌘Z / ⇧⌘Z |
| プログラムに戻る（ダッシュボードがメインウインドウにあるとき） | Ctrl+1 | ⌘1 |
| ダッシュボードのウインドウを閉じる | — | ⌘W |
| **選択** モードを終了する、またはプロパティパネルを閉じる | Esc | Esc |
| コントロールを削除（プロパティパネルが開いているとき） | Delete または Backspace | Delete または Backspace |
| コントロールを複製（プロパティパネルが開いているとき） | Ctrl+D | ⌘D |

キーボードを接続したタブレットでは、Ctrl+B（iPad では ⌘B）でサイドバーの表示 / 非表示を切り替えられます。

## 各レイアウトのプロフィールエディター {#the-profile-editor-on-every-layout}

エディターにタブはありません。**プログラム**（クイックリンクの行またはロジックブロック）が画面いっぱいに表示され、ほかの機能はボタンで開きます。

| ボタン | 開くもの |
|---|---|
| **マイハブ** | プロフィールの[ハブスロット](/docs/Application/Hubs/ConnectingHubs) |
| **ダッシュボード** | [ダッシュボード](/docs/Application/Dashboard/DashboardOverview) |
| **ゲームパッド** | [ゲームパッドの設定](/docs/Application/Dashboard/Gamepad) |
| **モニター** | 変数とリストの値（ロジックブロックのみ） |
| **エディター設定** | [エディターのオプション](/docs/Application/BlockBuilder/Editor#editor-settings) |
| **AI ビルダー** | [AI ビルダー](/docs/Application/Profiles/AiBuilder)（MocPilot Pro） |
| **問題** | 実行できない行（クイックリンクのみ） |
| **リモートコントロール** | プロフィールを別のデバイスで実行し、ここから操作（MocPilot Pro）。[リモートコントロール](/docs/Application/Profiles/RemoteControl)を参照 |
| **実行 / 停止** | プログラムを開始・停止 |
