# mocpilot.com の Web エディター {#web-editor-on-mocpilotcom}

Web エディターは、ブラウザーで動く MOCPilot です。エディター、ダッシュボード、テーマはアプリと同じなので、このドキュメントの内容はすべて Web エディターにも当てはまります。

ブラウザーは Bluetooth ハブと通信できないため、Web エディターは**編集**用です。プロフィールをテストするにはハブなしでブラウザー上で実行し、モデルを操作するにはスマートフォン、タブレット、パソコンの MOCPilot アプリでハブに接続します（[リモートコントロール](/docs/Application/Profiles/RemoteControl)を参照）。

## アカウントなしで試す {#try-it-without-an-account}

[mocpilot.com](https://mocpilot.com) のトップページには、各エディター（ロジックブロックとクイックリンク）に **Try demo**（デモを試す）ボタンがあり、デモ用のプロフィールが開きます。デモにはアカウントもハブも不要です。デモではすべてのテーマと特殊コントロールを試せますが、何も保存されません。

## 自分のプロフィールを編集する {#edit-your-own-profiles}

1. [mocpilot.com](https://mocpilot.com) に MOCPilot アカウントでサインインします。
2. プロフィールを開き、編集したいプロフィールの **編集** をクリックします。
3. アプリと同じように、ハブ、ダッシュボード、プログラムを変更します。
4. プロフィールを閉じます（ホームボタン）。エディターがプロフィールを保存してアップロードし、変更は[同期](/docs/Application/Account/Sync)によってお使いのデバイスのアプリに反映されます。

注意事項：

- 編集できるのは、サインインしているアカウントのプロフィールだけです。それ以外の場合は「このプロフィールはあなたのアカウントにありません」と表示され、**Web サイトに戻る** ボタンが表示されます。
- 購入品と MocPilot Pro は、アプリと同じようにブラウザーでも使えます。
- デスクトップ用ブラウザーでは、ダッシュボードはドラッグやサイズ変更ができるフローティングパネルになります。
- テーマはアクセスのたびに再ダウンロードされる（約 15 MB）ため、最初の表示に少し時間がかかることがあります。
- `.dat` ファイルのインポートとエクスポートはブラウザーではできません。アプリを使ってください。

## プロフィールを実行する {#run-a-profile}

Web エディターの **実行** は、プロフィールをブラウザー上で実行します。Bluetooth 以外のすべてのブロックと行が動作するので、ロジック、モニター、ダッシュボードのテストに便利です。ハブ端末とペアリングしている場合（MocPilot Pro、下記参照）、**実行** はプロフィールをハブ端末で開始します。

## リモートコントロール {#remote-control}

[MocPilot Pro](/docs/Application/Account/Pro) があれば、Web エディターを**リモコン**として使えます。モデルの近くにあるスマートフォン、タブレット、パソコンの MOCPilot アプリ（**ハブ端末**）がハブに接続してプロフィールを実行し、ブラウザーのページがそれを操作します。プロフィールの上部バーで **リモートコントロール** を押してから **コードを表示** を押し、ハブ端末で **私のプロフィール** ページの **リモコンを接続** をタップしてコードをスキャンします。[リモートコントロール](/docs/Application/Profiles/RemoteControl)を参照してください。
