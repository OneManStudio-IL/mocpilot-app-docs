# クイックリンクで作る初めての RC カー {#your-first-rc-car-with-quick-links}

このチュートリアルでは、[クイックリンク](/docs/Application/Links/LinksIntroducing)でリモコン操作の車を一通り作ります。1 本のジョイスティックで走行とステアリングを行い、ボタンでライトをオン / オフします。所要時間は約 15 分で、コードは一切書きません。

**必要なもの**

- LEGO® Technic™ Hub（88012）
- **ポート A** に走行用モーター
- **ポート B** に位置センサー（エンコーダー）付きのステアリング用モーター。たとえば Technic L または XL モーター、あるいは任意の Technic アンギュラーモーター。ステアリングにはエンドストップが必要です（タイヤが左右に一定の角度までしか曲がらない構造）。
- **ポート C** に LEGO® ライト（任意）
- Bluetooth を搭載したスマートフォン、タブレット、パソコンの MOCPilot

:::note City Hub
City Hub（88009）にはポートが 2 つしかありません。走行用モーターを **A** に、ステアリング用モーターを **B** につなぎ、ライトは省略するか、ライト用に 2 台目のハブを追加してください。それ以外の手順は同じです。
:::

**完成形**：3 行のプロフィール

| # | 入力 | 処理 | 動作 | 出力 |
|---|---|---|---|---|
| 1 | JOY1、Y 軸 | スムーズ | モーター | Technic Hub、ポート A |
| 2 | JOY1、X 軸 | | サーボ（自動） | Technic Hub、ポート B |
| 3 | BTN1 | トグル | ライト | Technic Hub、ポート C |

## 1. プロフィールを作成する {#create-the-profile}

1. **私のプロフィール** を開き、新しいプロフィールを作成します。スマートフォンでは **+** → **新しいプロフィール** をタップ、タブレットではヘッダーの **新しいプロフィール** をタップ、パソコンでは **ファイル → 新しいプロフィール** を選びます。
2. **クイックリンク** のタイルを選びます。
3. **名前** を入力します。たとえば「初めての車」。画像とハッシュタグは今は省略してかまいません。
4. **作成** をタップします。プロフィールがクイックリンクのエディターで開き、空の行が 1 つ表示されます。

プログラムの種類は後から変更できません。詳しくは[プロフィールの作成](/docs/Application/Profiles/CreateProfile)を参照してください。

## 2. ハブを追加して接続する {#add-the-hub}

1. エディターで **マイハブ** をタップします。
2. 空いているスロットで **新しいハブを追加** をタップし、リストから Technic Hub を選んで **追加** をタップします。
3. ハブの電源を入れてボタンを押します。MOCPilot がハブを見つけて接続し、ハブはスロットに登録されます。
4. **ファームウェア更新が必要です** ダイアログが表示されたら、**アップデート** をタップし、更新が終わるまでハブの電源を入れたまま近くに置いておきます。[ファームウェアの更新](/docs/Application/Hubs/FirmwareUpdating)を参照してください。

ヒント：接続したハブを開くと、[ハブモニター](/docs/Application/Hubs/ConnectingHubs#hub-monitor)が表示されます。各ポートにどのデバイスがつながっているかがわかるので、行を作る前にモーターを確認できます。

詳しくは[ハブの追加と接続](/docs/Application/Hubs/ConnectingHubs)を参照してください。

## 3. ダッシュボードにコントロールを配置する {#dashboard}

1. **ダッシュボード** を開き、**+**（**コントローラーを追加**）をタップします。
2. **ジョイスティック** グループで **ジョイスティック** を選び、**ダッシュボードに追加** をタップします。名前は **JOY1** になります。**軸の種類** は **両方の軸 (X, Y)** のままにします。上下で走行、左右でステアリングを操作します。
3. もう一度 **+** をタップします。**ボタンとスイッチ** で **ボタン** を選び、**ダッシュボードに追加** をタップします。名前は **BTN1** になります。
4. 親指が届く位置に、ジョイスティックを左側、ボタンを右側にドラッグします。コントロールをタップすると、サイズ（**S**、**M**、**L**）や外観を変更できます。

<Screenshot name="tutorial-car-dashboard" alt="左に JOY1 ジョイスティック、右に BTN1 ボタンを配置したダッシュボード" width={900} />

走行とステアリングを別々の親指で操作したい場合は、代わりにジョイスティックを 2 本追加します。**JOY1** は **垂直のみ (Y)**、**JOY2** は **水平のみ (X)** にして、ステアリングの行で JOY2 を使います。

詳しくは[コントロールの追加と配置](/docs/Application/Dashboard/ArrangingControls)と[コントロールの種類](/docs/Application/Dashboard/ControlTypes)を参照してください。

### オプション：ハンドルとペダル {#wheel-and-pedals}

**ハンドル** と **ペダル** の[特殊コントロール](/docs/Application/Dashboard/SpecialControls)をお持ちなら、ジョイスティックの代わりに使えます。手順 4 で、1 行目は **出力** を **速度** に設定した[車両](/docs/Application/Links/Blocks/InputBlocks#src-vehicle)入力で作り（本物の車のように加速・減速するので、スムーズは不要です）、2 行目は **ハンドル** 入力の **ハンドル角度** チャンネルで作ります。

## 4. 行を作る {#rows}

プログラムに戻ります。下部のパレットには **入力**、**処理**、**出力** の 3 つのタブがあります。各行は左から右へ進みます：入力 → 処理 → 動作 → ハブ。エディターの使い方は[クイックリンクの紹介](/docs/Application/Links/LinksIntroducing)を参照してください。

### 1 行目：走行 {#row-drive}

1. **入力** タブで、**Y 軸** チャンネルの **JOY1** を空の行（「新しい行：入力」）にドラッグします。その下に新しい空の行が現れます。
2. **処理** タブで、**スムーズ** を入力の後ろにドラッグします。初期値の **加速（最高速まで）** と **減速（停止まで）** 0.5 秒は、最初の設定として適しています。
3. **出力** タブで、**モーター** をスムーズの後ろにドラッグします。
4. **Technic Hub** 出力をモーターの後ろにドラッグし、ポート **A** のチップをタップします。

### 2 行目：ステアリング {#row-steering}

1. **X 軸** チャンネルの **JOY1** を次の空の行にドラッグします。
2. **出力** から **サーボ** をドラッグします。
3. サーボブロックをタップし、**キャリブレーション** を **自動** に設定します。
4. **Technic Hub** 出力をサーボの後ろにドラッグし、**B** をタップします。

**自動** モードでは、プログラムを開始するたびにステアリング用モーターが左右のエンドストップまで回ります。その中間が中心になり、可動範囲がステアリング角になります。すぐに試すには、ハブを接続した状態でサーボの設定にある **今すぐキャリブレーション** をタップします。キャリブレーションに失敗した場合は、ハブ、モーター、そしてステアリングに本当にエンドストップがあるかを確認してください。

<Screenshot name="links-servo-settings" alt="サーボブロックの設定" width={900} />

エンドストップがない場合は **手動** を使います。手でタイヤをまっすぐにして **ゼロに設定** をタップし、**角度** を選びます。[サーボ](/docs/Application/Links/Blocks/OutputBlocks#op-servo)を参照してください。

### 3 行目：ライト {#row-lights}

1. **BTN1** を次の空の行にドラッグします。
2. **処理** から **トグル** をドラッグします。押しボタンがスイッチになり、1 回押すとオン、もう 1 回押すとオフになります。
3. **出力** から **ライト** をドラッグします。
4. **Technic Hub** 出力をライトの後ろにドラッグし、**C** をタップします。

<Screenshot name="tutorial-car-links-rows" alt="完成した車の 3 行：走行、ステアリング、ライト" width={900} />

3 行すべての準備ができると、上部バーの **問題** ボタンに緑のチェックが表示されます。赤い「!」は残っている問題の数を示します。それをタップしてから問題をタップすると、該当する行に移動します。[実行と問題の解決](/docs/Application/Links/Problems)を参照してください。

## 5. 実行してテストする {#run}

1. 車を台に載せるか手で持って、タイヤがテーブルから浮くようにします。
2. **実行** を押します。ステアリング用モーターのキャリブレーションが始まり、左右に回ってから中央に戻ります。
3. ジョイスティックを上下に動かすと、車がなめらかに発進・停止しながら前後に走ります。左右に動かすと、タイヤが曲がります。
4. **BTN1** を押すとライトがつきます。もう一度押すと消えます。
5. **停止** を押すと編集に戻ります。

プログラムの実行中は、ブロック間の各接続部に通過中の値が表示されるので、ジョイスティックからハブまで信号の流れを追えます。

<Screenshot name="links-live-values" alt="接続部にリアルタイムの値が表示された、実行中のクイックリンクのプログラム" width={900} />

詳しくは[モデルの操作（実行）](/docs/Application/Profiles/PlayMode)を参照してください。

## 6. 微調整する {#tune}

まず **停止** を押してください。プログラムの実行中は行を編集できません。

- **ジョイスティックを上に倒すと車が後ろに走る場合**：1 行目に **反転** を追加します。タイヤが逆に曲がる場合は、2 行目にも同じように追加します。
- **ジョイスティックを離してもモーターがうなる、またはじわじわ動く場合**：1 行目のスムーズの前に **デッドゾーン** を追加します。初期値の **ゾーン** 10 % から始めるとよいでしょう。
- **速すぎる場合**：1 行目に **制限** を追加します。たとえば **最大** を 50 % にします。
- **反応が鈍い場合**：スムーズをタップして短い時間を選ぶか、**即時** を選びます。

走行の行は *デッドゾーン → 制限 → スムーズ* の順にするのがおすすめです。すべての設定は[処理ブロック](/docs/Application/Links/Blocks/ProcessingBlocks)を参照してください。

## 7. オプション：ゲームパッドで操作する {#gamepad}

1. Xbox または PlayStation タイプのゲームパッドを、システムの Bluetooth 設定でデバイスとペアリングします。
2. エディターで **ゲームパッド** を開き、**ゲームパッドブロックを有効にする** をオンにします。
3. 各行で、ダッシュボードの入力をパレットにドラッグして戻して削除し、その位置に **ゲームパッド** 入力をドラッグします。**入力** を設定します：1 行目は **左スティック Y**、2 行目は **右スティック X**、3 行目は **A**（PlayStation では **バツ**）。

各ポートは 1 つの行にしか割り当てられないため、1 つの行はダッシュボードかゲームパッドのどちらかでポートを操作します。詳しくは[ゲームパッド](/docs/Application/Dashboard/Gamepad)を参照してください。

## 何かが動かないときは {#if-something-does-not-move}

1. ハブは接続されていますか？ **マイハブ** と、ハブブロックの接続ドットを確認してください。
2. モーターは、行で選んだポートにつながっていますか？
3. **問題** ボタンに緑のチェックが表示され、すべての行がオンになっていますか？
4. プログラムは実行中ですか？
5. プログラムを実行してリアルタイムの値を確認します。入力の値は変わるのにモーターが回らない場合は、ハブとポートを確認してください。

「ポート B：このデバイスはサーボとして使えません（エンコーダー付きモーターが必要です）」のようなメッセージは、そのポートのモーターにエンコーダーがないことを意味します。そのほかのメッセージと対処法は、[実行と問題の解決](/docs/Application/Links/Problems)と[トラブルシューティング](/docs/Help/Troubleshooting)を参照してください。

## 8. 保存して共有する {#save-and-share}

保存ボタンはありません。変更はプロフィールに自動で保存されます。サインインしていれば、ほかのデバイスにも[同期](/docs/Application/Account/Sync)されます。

- **ファイルとして共有**：**私のプロフィール** で、プロフィールカードの **共有** をタップします（パソコンでは **共有…**）。友だちに送れる `.dat` ファイルができます。[プロフィールの管理](/docs/Application/Profiles/ManageProfiles)を参照してください。
- **カタログに公開**：**プロフィールを編集** を開き、**カタログに送信** をタップします。先に画像、説明、ハッシュタグを追加してください。[カタログと公開](/docs/Application/Profiles/Catalog)を参照してください。
