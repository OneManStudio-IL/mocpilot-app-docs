# Bedieningselementen maken uit een thema {#create-controls-from-a-theme}

Elk bedieningselement dat je toevoegt, begint bij een thema. Je kunt het configureren voordat je het toevoegt, en het geconfigureerde bedieningselement als je eigen ontwerp opslaan.

## Configureren vóór het toevoegen {#configure-before-adding}

1. Open **Controller toevoegen** (**+** op het dashboard, **+ Controller** op een computer).
2. Kies een soort bedieningselement en een stijl in de strook met stijlen.
3. Gebruik bij **Configureren** de tabbladen **Stijl** en **Instellingen**: grootte (het palet toont die als “B x H punten”), accentkleur, pictogram, opties van het thema, werking.
4. Tik op **Toevoegen aan dashboard**.

## Een ontwerp opslaan {#save-a-design}

Heb je een combinatie gevonden die je bevalt (bijvoorbeeld een rode Racen-knop met een claxonpictogram), bewaar die dan:

1. Selecteer een geconfigureerd bedieningselement van een thema dat je bezit.
2. Tik op **Ontwerp opslaan**.
3. Het ontwerp verschijnt onder **Mijn ontwerpen** → **Opgeslagen ontwerpen**. Je kunt het met één tik aan het dashboard van elk profiel toevoegen.

**Verwijderen** verwijdert een opgeslagen ontwerp.

## Bedieningselementen op het dashboard kopiëren {#copy-controls-on-the-dashboard}

- **Dupliceren** kopieert een bedieningselement met al zijn eigenschappen.
- **Dupliceren (alleen type)** voegt dezelfde soort bedieningselement toe met standaardeigenschappen.
- **Thema wijzigen** zet een bedieningselement over op een ander thema dat je bezit, zonder dat het zijn plek of zijn koppelingen met het programma verliest.

## Een goed dashboard {#a-good-dashboard}

- Zet de rijbediening onder je duimen: een joystick of pedalen aan de ene kant, de besturing aan de andere kant.
- Gebruik grootte **L** voor de bedieningselementen die je het meest gebruikt en **S** voor de zeldzame.
- Gebruik één accentkleur per functie: groen voor rijden, geel voor lampen, rood voor stoppen.
- Vergrendel de bedieningselementen als de indeling klaar is (**Alles vergrendelen**).
- Voeg een batterijmonitor toe, zodat je weet wanneer je moet opladen.

:::info Je eigen graphics
In de app kun je geen volledig nieuwe bedieningselementen of thema's tekenen. Thema's worden gemaakt door het MOCPilot-team; heb je een idee voor een thema, laat het ons dan weten via **Help → Stel een vraag**.
:::
