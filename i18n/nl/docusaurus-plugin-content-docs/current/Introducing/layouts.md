# Telefoon, tablet en desktop {#phone-tablet-and-desktop}

MOCPilot heeft drie indelingen, en de app kiest er automatisch een:

- **Telefoon**: iPhone en Android-telefoons.
- **Tablet**: iPad en Android-tablets (7 inch en groter).
- **Desktop**: Mac- en Windows-computers. De [webeditor](/docs/Introducing/WebEditor) in een browser gebruikt ook de desktopeditor.

Profielen, editors en het dashboard zijn overal hetzelfde; alleen de navigatie verschilt.

## Telefoon {#phone}

<Screenshot name="profiles-phone" alt="De pagina Mijn profielen op een telefoon met de balk onderaan" width={360} />

- De **balk onderaan** bevat **Profielen**, **Instellingen** en **Help**, plus **Meldingen** als je bent ingelogd.
- **Account** staat bovenaan in **Instellingen**.
- De kop van **Mijn profielen** bevat **Sorteren en filteren**, **Afstandsbediening verbinden** (het pictogram van de afstandsbediening), **+** (Nieuw profiel, Profiel importeren…, Online zoeken) en het zoekveld.
- De hoofdschermen staan in staande stand. Als je een profiel opent, schakelt de app over naar **liggend, volledig scherm**, zodat de editor en het dashboard het hele scherm krijgen. Sluit je het profiel, dan keert de staande stand terug.
- In de editor geven ronde knoppen bovenaan snel toegang tot Home, Ongedaan maken, Opnieuw, AI-bouwer, Editorinstellingen, Problemen (Snelle koppelingen), Gamepad, Mijn hubs, Afstandsbediening, Dashboard, Monitor (Logicablokken) en Start / Stop.

<Screenshot name="editor-phone" alt="De profieleditor op een telefoon met de ronde knoppen bovenaan" width={900} />

## Tablet {#tablet}

<Screenshot name="profiles-tablet" alt="De pagina Mijn profielen op een tablet met de zijbalk" width={900} />

- De **zijbalk** links bevat **Profielen**, **Profielcatalogus**, **Meldingen**, **Instellingen** en **Help**. Daaronder staan de kaart **MocPilot Pro** en je account (**Inloggen** in gastmodus). Je kunt de zijbalk inklappen tot alleen pictogrammen.
- De kop van **Mijn profielen** bevat **Nieuw profiel** (het menu daarvan heeft ook Profiel importeren…, Afstandsbediening verbinden en Online zoeken), **Sorteren en filteren**, **Filteren op hashtags**, **Afstandsbediening verbinden** en het zoekveld.
- Tik op een profielkaart om die te selecteren: de balk onderaan toont **Delen**, **Bewerken**, **Aan favorieten toevoegen** en **Starten**. Dubbeltik op een kaart om het profiel te starten. Houd een kaart ingedrukt voor het menu, dat ook **Profiel verwijderen** bevat.
- Op brede schermen openen Instellingen en Help naast de lijst.
- Een profiel opent in liggende stand, en de editor heeft dezelfde ronde knoppen als op een telefoon.

## Desktop (Mac en Windows) {#desktop-mac-and-windows}

<Screenshot name="profiles-desktop" alt="Mijn profielen op een computer" width={900} />

- Rechts in de bovenbalk: **Account** (**Inloggen** in gastmodus), **Meldingen** (als je bent ingelogd), **Afstandsbediening verbinden** (het pictogram van de afstandsbediening) en **Instellingen** (het tandwiel).
- Instellingen, Help, Account, Nieuw profiel, Profiel bewerken, de Profielcatalogus en andere pagina's openen als **vensters** boven de profiellijst.
- Klik op een profielkaart om te zien wat je ermee kunt doen (**Delen…**, **Bewerken…**, **Aan favorieten toevoegen**, **Starten**); dubbelklikken start het profiel. Klik met de rechtermuisknop op een kaart voor het menu, dat ook **Profiel verwijderen** bevat.
- In de editor opent het **Dashboard** in een **eigen venster**, zodat je het programma en het dashboard naast elkaar ziet.

### Menu's {#menus}

Op Windows staan de menu's links in de bovenbalk van de app. Op een Mac staan ze in de systeemmenubalk bovenaan het scherm.

| Menu | Windows | Mac |
|---|---|---|
| **MOCPilot** (appmenu) | — | Over MOCPilot, Instellingen…, Afsluiten |
| **Bestand** | Nieuw profiel, Profiel importeren…, Online zoeken, Afsluiten | Nieuw profiel, Profiel importeren…, Online zoeken, Afstandsbediening verbinden… |
| **Weergave** | Volledig scherm | Volledig scherm / Volledig scherm verlaten |
| **Venster** | Minimaliseren, Maximaliseren / Herstellen | Minimaliseren |
| **Help** | MOCPilot Help, Stel een vraag, Meld een bug, Over MOCPilot | MOCPilot Help, Stel een vraag, Meld een bug |

Als er een profiel open is, heeft de editor eigen menu's **Bestand**, **Bewerken**, **Weergave** en **Programma** (zie [Desktopmenu's](/docs/Application/BlockBuilder/Editor#desktop-menus)), en het Dashboard-venster heeft **Bestand**, **Bewerken** en **Weergave** (zie [Dashboard](/docs/Application/Dashboard/DashboardOverview)).

### Sneltoetsen {#keyboard-shortcuts}

Op een Mac doet ⌘ (Command) wat Ctrl op Windows doet; ⇧ is Shift, ⌃ is Control.

**Overal**

| Actie | Windows | Mac |
|---|---|---|
| Instellingen | Ctrl+2 | ⌘, |
| Volledig scherm openen / sluiten | F11 of Alt+Enter | ⌃⌘F |
| Venster minimaliseren | — | ⌘M |
| Afsluiten | Alt+F4 | ⌘Q |

**Mijn profielen** (geen profiel open)

| Actie | Windows | Mac |
|---|---|---|
| Nieuw profiel | Ctrl+N | ⌘N |
| Profiel importeren | Ctrl+O | ⌘O |
| Profielen zoeken | Ctrl+F | — |
| Profielen / Instellingen / Help / Account | Ctrl+1 / Ctrl+2 / Ctrl+3 / Ctrl+4 | — |

**Profieleditor**

| Actie | Windows | Mac |
|---|---|---|
| Profiel sluiten | Ctrl+W | ⌘W |
| Start / Stop | Ctrl+R / Ctrl+. | ⌘R / ⌘. |
| Ongedaan maken / Opnieuw | Ctrl+Z / Ctrl+Shift+Z of Ctrl+Y | ⌘Z / ⇧⌘Z |
| Dashboard tonen | Ctrl+2 | ⌘2 |
| Mijn hubs | Ctrl+Shift+H | ⇧⌘H |
| AI-bouwer | Ctrl+Shift+I | ⇧⌘I |
| Blokkenpalet tonen / verbergen (Logicablokken) | Ctrl+P | ⌘P |
| Zoeken in het blokkenpalet (Logicablokken) | Ctrl+F | ⌘F |
| Monitor (Logicablokken) | Ctrl+Shift+M | ⇧⌘M |
| Inzoomen / uitzoomen / werkelijke grootte (Logicablokken) | Ctrl++ / Ctrl+− / Ctrl+0 | ⌘+ / ⌘− / ⌘0 |

**Dashboard**

| Actie | Windows | Mac |
|---|---|---|
| Ongedaan maken / Opnieuw | Ctrl+Z / Ctrl+Shift+Z of Ctrl+Y | ⌘Z / ⇧⌘Z |
| Terug naar het programma (als het dashboard in het hoofdvenster staat) | Ctrl+1 | ⌘1 |
| Het Dashboard-venster sluiten | — | ⌘W |
| Modus **Selecteren** verlaten, of het eigenschappenpaneel sluiten | Esc | Esc |
| Het bedieningselement verwijderen (eigenschappenpaneel open) | Delete of Backspace | Delete of Backspace |
| Het bedieningselement dupliceren (eigenschappenpaneel open) | Ctrl+D | ⌘D |

Op een tablet met toetsenbord toont of verbergt Ctrl+B (⌘B op een iPad) de zijbalk.

## De profieleditor in elke indeling {#the-profile-editor-on-every-layout}

De editor heeft geen tabbladen. Het **programma** (rijen van Snelle koppelingen of Logicablokken) vult het scherm, en met knoppen open je al het andere:

| Knop | Opent |
|---|---|
| **Mijn hubs** | de [hubslots](/docs/Application/Hubs/ConnectingHubs) van het profiel |
| **Dashboard** | het [dashboard](/docs/Application/Dashboard/DashboardOverview) |
| **Gamepad** | de [gamepadinstellingen](/docs/Application/Dashboard/Gamepad) |
| **Monitor** | waarden van variabelen en lijsten (alleen Logicablokken) |
| **Editorinstellingen** | de [editoropties](/docs/Application/BlockBuilder/Editor#editor-settings) |
| **AI-bouwer** | de [AI-bouwer](/docs/Application/Profiles/AiBuilder) (MocPilot Pro) |
| **Problemen** | rijen die niet kunnen worden uitgevoerd (alleen Snelle koppelingen) |
| **Afstandsbediening** | het profiel op een ander apparaat uitvoeren en het van hieruit besturen (MocPilot Pro); zie [Afstandsbediening](/docs/Application/Profiles/RemoteControl) |
| **Start / Stop** | start en stopt het programma |
