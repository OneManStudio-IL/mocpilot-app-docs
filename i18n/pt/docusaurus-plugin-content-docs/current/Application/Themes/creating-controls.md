# Criar controles a partir de um tema {#create-controls-from-a-theme}

Todo controle que você adiciona parte de um tema. Você pode configurá-lo antes de adicioná-lo e salvar o controle configurado como um design seu.

## Configurar antes de adicionar {#configure-before-adding}

1. Abra **Adicionar controlador** (**+** no painel, **+ Controlador** no computador).
2. Selecione um tipo de controle e um visual na faixa de visuais.
3. Em **Configurar**, use as abas **Estilo** e **Configurações**: tamanho (a paleta o mostra como “L x A pontos”), cor de acento, ícone, opções do tema, comportamento.
4. Toque em **Adicionar ao painel**.

## Salvar um design {#save-a-design}

Quando encontrar uma combinação de que goste (digamos, um botão vermelho do tema Corrida com ícone de buzina), guarde-a:

1. Selecione um controle configurado de um tema que você possui.
2. Toque em **Guardar design**.
3. O design aparece em **Meus designs** → **Designs salvos**. Você pode adicioná-lo ao painel de qualquer perfil com um toque.

**Excluir** remove um design salvo.

## Copiar controles no painel {#copy-controls-on-the-dashboard}

- **Duplicar** copia um controle com todas as propriedades dele.
- **Duplicar (só o tipo)** adiciona o mesmo tipo de controle com as propriedades padrão.
- **Alterar tema** passa um controle para outro tema que você possui, sem perder a posição nem as ligações com o programa.

## Um bom painel {#a-good-dashboard}

- Coloque os controles de condução sob os seus polegares: um joystick ou pedais de um lado, a direção do outro.
- Use o tamanho **L** para os controles que você mais usa e **S** para os que usa raramente.
- Use uma cor de acento por função: verde para dirigir, amarelo para as luzes, vermelho para parar.
- Bloqueie os controles quando o layout estiver pronto (**Bloquear tudo**).
- Adicione um monitor de bateria para saber quando recarregar.
