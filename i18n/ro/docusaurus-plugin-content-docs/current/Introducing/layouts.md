# Telefon, tabletă și desktop {#phone-tablet-and-desktop}

MOCPilot are trei aspecte, iar aplicația îl alege automat pe cel potrivit:

- **Telefon**: telefoane iPhone și Android.
- **Tabletă**: iPad și tablete Android (de 7 inchi și mai mari).
- **Desktop**: computere Mac și Windows. [Editorul web](/docs/Introducing/WebEditor) din browser folosește tot editorul de desktop.

Profilurile, editoarele și tabloul de bord sunt la fel peste tot; diferă doar navigarea.

## Telefon {#phone}

<Screenshot name="profiles-phone" alt="Pagina Profilurile mele pe telefon, cu bara inferioară" width={360} />

- **Bara inferioară** conține **Profiluri**, **Setări** și **Ajutor**, plus **Notificări** când ești conectat.
- **Cont** se află în partea de sus a paginii **Setări**.
- Antetul **Profilurile mele** conține **Sortare și filtrare**, **Conectează o telecomandă** (pictograma de telecomandă), **+** (Profil nou, Importă profil…, Caută online) și câmpul de căutare.
- Ecranele principale sunt în mod portret. Când deschizi un profil, aplicația trece în **mod peisaj, pe tot ecranul**, astfel încât editorul și tabloul de bord să aibă tot ecranul. La închiderea profilului revine modul portret.
- În editor, butoanele rotunde din partea de sus oferă acces rapid la Acasă, Anulează, Refă, Constructor AI, Setări editor, Probleme (Legături rapide), Gamepad, Huburile mele, Control de la distanță, Tablou de bord, Monitor (Blocuri logice) și Rulează / Oprește.

<Screenshot name="editor-phone" alt="Editorul de profil pe telefon, cu butoanele rotunde în partea de sus" width={900} />

## Tabletă {#tablet}

<Screenshot name="profiles-tablet" alt="Pagina Profilurile mele pe tabletă, cu bara laterală" width={900} />

- **Bara laterală** din stânga conține **Profiluri**, **Catalog de profiluri**, **Notificări**, **Setări** și **Ajutor**. Sub ele se află cardul **MocPilot Pro** și contul tău (**Conectează-te** în modul invitat). Poți restrânge bara laterală doar la pictograme.
- Antetul **Profilurile mele** conține **Profil nou** (meniul lui are și Importă profil…, Conectează o telecomandă și Caută online), **Sortare și filtrare**, **Filtrează după hashtaguri**, **Conectează o telecomandă** și câmpul de căutare.
- Atinge cardul unui profil ca să-l selectezi: bara din partea de jos afișează **Partajează**, **Editează**, **Adaugă la favorite** și **Lansează**. Atinge de două ori un card ca să-l lansezi. Ține apăsat pe un card pentru meniul lui, care are și **Șterge profilul**.
- Pe ecranele late, Setările și Ajutorul se deschid lângă listă.
- Un profil se deschide în mod peisaj, iar editorul are aceleași butoane rotunde ca pe telefon.

## Desktop (Mac și Windows) {#desktop-mac-and-windows}

<Screenshot name="profiles-desktop" alt="Profilurile mele pe computer" width={900} />

- În dreapta barei de sus: **Cont** (**Conectează-te** în modul invitat), **Notificări** (când ești conectat), **Conectează o telecomandă** (pictograma de telecomandă) și **Setări** (rotița).
- Setările, Ajutorul, Contul, Profil nou, Editează profilul, Catalogul de profiluri și alte pagini se deschid ca **ferestre** peste lista de profiluri.
- Dă clic pe cardul unui profil ca să vezi ce poți face cu el (**Partajează…**, **Editează…**, **Adaugă la favorite**, **Lansează**); dublu clic îl lansează. Clic dreapta pe un card deschide meniul lui, care are și **Șterge profilul**.
- În editor, **Tabloul de bord** se deschide în **fereastră proprie**, astfel încât vezi programul și tabloul de bord unul lângă altul.

### Meniuri {#menus}

Pe Windows, meniurile se află în stânga barei de sus a aplicației. Pe Mac, ele sunt în bara de meniu a sistemului, în partea de sus a ecranului.

| Meniu | Windows | Mac |
|---|---|---|
| **MOCPilot** (meniul aplicației) | — | Despre MOCPilot, Setări…, Ieșire |
| **Fișier** | Profil nou, Importă profil…, Caută online, Ieșire | Profil nou, Importă profil…, Caută online, Conectează o telecomandă… |
| **Vizualizare** | Ecran complet | Intră în / ieși din ecran complet |
| **Fereastră** | Minimizează, Maximizează / Restaurează | Minimizează |
| **Ajutor** | Ajutor MOCPilot, Pune o întrebare, Raportează o eroare, Despre MOCPilot | Ajutor MOCPilot, Pune o întrebare, Raportează o eroare |

Când un profil este deschis, editorul are propriile meniuri **Fișier**, **Editare**, **Vizualizare** și **Program** (vezi [Meniurile pe desktop](/docs/Application/BlockBuilder/Editor#desktop-menus)), iar fereastra Tablou de bord are **Fișier**, **Editare** și **Vizualizare** (vezi [Tablou de bord](/docs/Application/Dashboard/DashboardOverview)).

### Comenzi rapide de la tastatură {#keyboard-shortcuts}

Pe Mac, ⌘ (Command) face ce face Ctrl pe Windows; ⇧ este Shift, ⌃ este Control.

**Peste tot**

| Acțiune | Windows | Mac |
|---|---|---|
| Setări | Ctrl+2 | ⌘, |
| Intră în / ieși din ecran complet | F11 sau Alt+Enter | ⌃⌘F |
| Minimizează fereastra | — | ⌘M |
| Ieșire | Alt+F4 | ⌘Q |

**Profilurile mele** (niciun profil deschis)

| Acțiune | Windows | Mac |
|---|---|---|
| Profil nou | Ctrl+N | ⌘N |
| Importă profil | Ctrl+O | ⌘O |
| Caută profiluri | Ctrl+F | — |
| Profiluri / Setări / Ajutor / Cont | Ctrl+1 / Ctrl+2 / Ctrl+3 / Ctrl+4 | — |

**Editorul de profil**

| Acțiune | Windows | Mac |
|---|---|---|
| Închide profilul | Ctrl+W | ⌘W |
| Rulează / Oprește | Ctrl+R / Ctrl+. | ⌘R / ⌘. |
| Anulează / Refă | Ctrl+Z / Ctrl+Shift+Z sau Ctrl+Y | ⌘Z / ⇧⌘Z |
| Afișează tabloul de bord | Ctrl+2 | ⌘2 |
| Huburile mele | Ctrl+Shift+H | ⇧⌘H |
| Constructor AI | Ctrl+Shift+I | ⇧⌘I |
| Afișează / ascunde paleta de blocuri (Blocuri logice) | Ctrl+P | ⌘P |
| Caută în paleta de blocuri (Blocuri logice) | Ctrl+F | ⌘F |
| Monitor (Blocuri logice) | Ctrl+Shift+M | ⇧⌘M |
| Mărește / micșorează / dimensiune reală (Blocuri logice) | Ctrl++ / Ctrl+− / Ctrl+0 | ⌘+ / ⌘− / ⌘0 |

**Tablou de bord**

| Acțiune | Windows | Mac |
|---|---|---|
| Anulează / Refă | Ctrl+Z / Ctrl+Shift+Z sau Ctrl+Y | ⌘Z / ⇧⌘Z |
| Înapoi la program (când tabloul de bord este în fereastra principală) | Ctrl+1 | ⌘1 |
| Închide fereastra Tablou de bord | — | ⌘W |
| Ieși din modul **Selectează** sau închide panoul de proprietăți | Esc | Esc |
| Șterge comanda (panoul de proprietăți deschis) | Delete sau Backspace | Delete sau Backspace |
| Duplică comanda (panoul de proprietăți deschis) | Ctrl+D | ⌘D |

Pe o tabletă cu tastatură, Ctrl+B (⌘B pe iPad) afișează sau ascunde bara laterală.

## Editorul de profil în fiecare aspect {#the-profile-editor-on-every-layout}

Editorul nu are file. **Programul** (rândurile Legături rapide sau Blocurile logice) ocupă tot ecranul, iar butoanele deschid restul:

| Buton | Deschide |
|---|---|
| **Huburile mele** | [sloturile de hub](/docs/Application/Hubs/ConnectingHubs) ale profilului |
| **Tablou de bord** | [tabloul de bord](/docs/Application/Dashboard/DashboardOverview) |
| **Gamepad** | [setările gamepadului](/docs/Application/Dashboard/Gamepad) |
| **Monitor** | valorile variabilelor și listelor (doar Blocuri logice) |
| **Setări editor** | [opțiunile editorului](/docs/Application/BlockBuilder/Editor#editor-settings) |
| **Constructor AI** | [constructorul AI](/docs/Application/Profiles/AiBuilder) (MocPilot Pro) |
| **Probleme** | rândurile care nu pot rula (doar Legături rapide) |
| **Control de la distanță** | rulează profilul pe alt dispozitiv și îl controlează de aici (MocPilot Pro); vezi [Control de la distanță](/docs/Application/Profiles/RemoteControl) |
| **Rulează / Oprește** | pornește și oprește programul |
