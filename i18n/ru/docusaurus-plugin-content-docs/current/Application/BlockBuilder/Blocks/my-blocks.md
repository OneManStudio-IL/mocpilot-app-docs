# Мои блоки

В категории «Мои блоки» можно создавать собственные блоки и использовать их повторно.
Это похоже на функцию в обычном программировании: поведение описывается один раз, а пользоваться им можно сколько угодно.

## Блоки

### `определить …` (Гуру) {#block_my_block_define}

<img src={useBaseUrl('/img/blocks/block_my_block_define.svg')} alt="block_my_block_define.svg" />

Нажмите **Создать блок** в начале категории, чтобы сделать новый блок. В области программы появится стартовый блок `определить` с именем вашего блока: блоки, присоединённые под ним, и есть то, что делает ваш блок.

- Для чего: собрать повторяющуюся логику в один блок с понятным именем.

### Ваш блок (Гуру) {#block_my_block}

<img src={useBaseUrl('/img/blocks/block_my_block.svg')} alt="block_my_block.svg" />

Каждый созданный блок появляется в палитре под своим именем. Когда он выполняется, запускаются блоки, присоединённые к его блоку `определить`.

- Тип: командный блок
- Для чего: использовать одну и ту же логику в разных местах, не копируя стеки.

## Собственный блок в программе

<img src={useBaseUrl('/img/my-blocks/my-blocks-usage-example.png')} alt="my-blocks-usage-example.png" />

Здесь собственный блок стоит под `when program starts`, а в стеке `define` лежит логика мотора, которую он выполняет.

- Обычная схема: вызывать свои блоки из скриптов событий.
- Польза: одно определение — много мест, где оно используется.

## Редактор блока

<img src={useBaseUrl('/img/my-blocks/my-blocks-editor-cropped.png')} alt="my-blocks-editor-cropped.png" />

В редакторе **Создать блок** вы задаёте внешний вид блока: добавляете надписи (**Добавить метку**) и входы (**Добавить ввод**: *число или текст* либо *булевый*). Внутри стека `определить` входы работают как переменные со значениями, переданными блоку.

## Зачем нужны Мои блоки

- Повторное использование: написали один раз — пользуетесь много раз.
- Читаемость: одно понятное имя вместо длинных повторяющихся стеков.
- Простые правки: логику достаточно исправить в одном месте, а не в каждой копии.
- Порядок: большую программу легко разбить на небольшие логические части.

## Примечания

- Собственные блоки принадлежат профилю, и их можно использовать в любом месте его программы.
- Называйте блоки по тому, что они делают, а не по тому, как.
- Блок, который вызывает сам себя, может зациклиться; редактор предупредит об этом.
