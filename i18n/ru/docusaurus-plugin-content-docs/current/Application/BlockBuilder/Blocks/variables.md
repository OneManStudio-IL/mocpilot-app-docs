# Переменные

Переменные хранят значения, которые может читать и менять любой скрипт программы. Создают, переименовывают и удаляют их кнопки **Создать переменную**, **Переименовать переменную** и **Удалить переменную** в начале категории. Блоки ниже появляются, когда в программе есть хотя бы одна переменная.

## Изменение переменной

### `установить … к …` (Новичок) {#block_variables_set_to}

<img src={useBaseUrl('/img/blocks/block_variables_set_to.svg')} alt="block_variables_set_to.svg" />

Записывает значение в выбранную переменную.

- Для чего: задать начальное значение, заменить прежнее.

### `изменить … на …` (Продвинутый) {#block_variables_change_by}

<img src={useBaseUrl('/img/blocks/block_variables_change_by.svg')} alt="block_variables_change_by.svg" />

Прибавляет число к выбранной переменной. Чтобы вычесть, укажите отрицательное число.

- Для чего: счётчики, очки, накопленное расстояние или время.

## Чтение переменной

### Переменная (Новичок) {#block_variables_value}

<img src={useBaseUrl('/img/blocks/variable.svg')} alt="variable.svg" />

У каждой переменной есть свой блок-репортёр с её именем. Он возвращает текущее значение переменной.

- Для чего: подставлять значение в операторы, условия и поля других блоков.
- [Монитор](/docs/Application/BlockBuilder/Editor#monitor) показывает значения всех переменных во время работы программы.
