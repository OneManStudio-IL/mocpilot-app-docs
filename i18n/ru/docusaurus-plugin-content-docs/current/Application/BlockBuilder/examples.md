# Примеры

Короткие программы, с которых удобно начать. Названия блоков — как в [справочнике блоков](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing#block-reference); в скобках указаны хаб, порт или блок-репортёр, вставленный в гнездо. Строки с отступом стоят внутри C-блока.

## Езда джойстиком

На панели — джойстик **JOY1**. Ходовой мотор на порту A.

```text
когда программа запускается
повторять всегда
    запустить мотор на (джойстик JOY1 ось Y) % скорость  (Хаб 1, порт A)
```

## Руление сервоприводом

Рулевой мотор (угловой) на порту B. Текущее положение мотора объявляется центром, дальше руль следует за джойстиком: `× 0.9` превращает −100…100 джойстика в −90…90 градусов.

```text
когда программа запускается
установить относительное положение 0  (Хаб 1, порт B)
повторять всегда
    перейти в относительную позицию (джойстик JOY1 ось X × 0.9) в 100 % скорость  (Хаб 1, порт B)
```

Если у рулевой рейки есть упоры, сначала откалибруйте её (см. [Моторы](/docs/Application/BlockBuilder/Blocks/Motors#block_hubs_all_motors_port_calibrate_steering_rack)). `центр` и `ход` — переменные. После калибровки рейка стоит посередине, но её относительное положение там равно значению центра, а не 0, поэтому перед рулением обнулите его:

```text
когда программа запускается
калибровать рейку (центр) центр (ход) градусы  (Хаб 1, порт B)
установить относительное положение 0  (Хаб 1, порт B)
повторять всегда
    перейти в относительную позицию ((ход × джойстик JOY1 ось X) ÷ 100) в 100 % скорость  (Хаб 1, порт B)
```

## Свет на переключателе

```text
когда переключатель SWCH1 включён
    включить на 100 % яркость  (Хаб 1, порт C)
когда переключатель SWCH1 выключен
    выключить  (Хаб 1, порт C)
```

## Кнопка клаксона

```text
когда кнопка BTN1 нажата
    звук Клаксон играть до конца
```

## Предупреждение о разряде

Монитор **MNTR1**; кнопка краснеет, когда батарея садится.

```text
когда программа запускается
повторять всегда
    показать (Хаб 1 % батареи) на мониторе MNTR1
    если (Хаб 1 % батареи) < 20 тогда
        установить цвет BTN1 в красный
    ждать 5 секунды
```

## Остановка перед препятствием

Датчик расстояния Technic на порту D, ходовой мотор на порту A.

```text
когда программа запускается
повторять всегда
    если (расстояние см  (Хаб 1, порт D)) < 10 тогда
        остановить мотор  (Хаб 1, порт A)
        установить цвет LED в красный  (Хаб 1)
    то
        запустить мотор на (слайдер SLDR1) % скорость  (Хаб 1, порт A)
        установить цвет LED в зелёный  (Хаб 1)
```

## Ограничение скорости шаговым переключателем

Шаговый переключатель **STPR1** с 4 ступенями ограничивает максимальную скорость.

```text
когда программа запускается
повторять всегда
    установить (предел скорости) к (шаговый переключатель STPR1 × 25)
    запустить мотор на (джойстик JOY1 ось Y × предел скорости / 100) % скорость  (Хаб 1, порт A)
```

`предел скорости` — переменная (**Переменные → Создать переменную**).

## Проверка при запуске

Газ заблокирован, пока не подключатся оба хаба.

```text
когда программа запускается
установить интерактивность JOY1: выключить
подождите до (Хаб 1 подключено) и (Хаб 2 подключено)
показать "Готово" на мониторе MNTR1
установить интерактивность JOY1: включить
```

## Геймпад

На [странице «Геймпад»](/docs/Application/Dashboard/Gamepad) выберите **Диапазон значений геймпада** −100…100 и включите **Включить блоки геймпада**.

```text
когда программа запускается
повторять всегда
    запустить мотор на (джойстик левый ось Y) % скорость  (Хаб 1, порт A)
    перейти в относительную позицию (джойстик правый ось X × 0.9) в 100 % скорость  (Хаб 1, порт B)
```
