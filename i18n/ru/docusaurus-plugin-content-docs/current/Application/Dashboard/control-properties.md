# Свойства элементов управления

В режиме редактирования нажмите (кликните) на элемент, чтобы открыть его свойства.

- **Телефон и планшет**: свойства открываются поверх панели; нажмите за их пределами, чтобы закрыть.
- **Компьютер**: свойства открываются сбоку, и с панелью можно продолжать работать.

<Screenshot name="controller-properties" alt="Свойства элемента с вкладками «Стиль» и «Настройки»" width={900} />

В заголовке — имя элемента (например, **JOY1**), кнопка корзины, меню дублирования и **OK**.

## Вкладка «Стиль»

- **Размер**: S, M или L. См. [размеры](/docs/Application/Dashboard/ArrangingControls#sizes).
- **Акцентный цвет**: основной цвет элемента.
- **Иконка**: картинка на элементе (кнопки, переключатели, мониторы), на выбор больше 260 иконок.
- **Внешний вид**: вариант оформления [специального элемента](/docs/Application/Dashboard/SpecialControls), например стиль руля.
- Параметры темы, свои у каждой темы: например, **Цветной углерод**, **Цветные рамки** и **Показать гоночные линии** в теме «Гонки», **Количество сегментов индикатора** в «Строительной технике», **Отображать значения** в «Ауре».
- **Сменить тему**: переключить элемент на другую вашу тему с таким же типом элемента.

## Вкладка «Настройки»

Общие настройки:

- **Заблокировать контроллер**: заблокированный элемент нельзя переместить или удалить.
- **Интерактивность**: неинтерактивный элемент не реагирует на нажатия.

Настройки отдельных типов:

| Элемент | Настройки |
|---|---|
| Джойстик | **Тип осей**: Обе оси (X, Y), Только по горизонтали (X), Только по вертикали (Y) |
| Слайдер, Верт. слайдер | **Возврат к нулю**, **Отрицательные значения**, **Шаговое значение** |
| Поворотная ручка | **Шаги с фиксацией (0 = плавно)** (0–24), **Ноль в центре (-100..100)** |
| Шаговый переключатель, Вер. шаговый переключатель | **Количество шагов** (1–100), **Отрицательные значения**, **Включить сброс** |
| Монитор | **Макет текста**, **Переполнение текста**, **Максимум строк**, **Направление прокрутки**, **Скорость прокрутки**, **Показывать полосу прокрутки**, **Интерактивная прокрутка**, **Выравнивание текста**, **Масштаб текста** |
| Монитор наклона | **Инвертировать наклон**, **Инвертировать вращение** |
| Руль | **Угол поворота руля** (20–120°), **Звуковые эффекты** |
| Педали | **Звуковые эффекты** |
| Механическая коробка | **Число передач** (2–6) |
| Автоматическая коробка | **Число передач** (2–8) |
| Поворотники | **Выходы поворотников мигают**; на вкладке «Стиль» — **Иконка: левый поворот**, **Иконка: фары**, **Иконка: правый поворот** |

У числовых настроек есть кнопка **Сбросить**, которая возвращает значение по умолчанию.

## Изменение свойств из программы

В Логических блоках программа может менять элемент прямо во время работы: задавать его цвет, включать и выключать интерактивность, выводить значения на мониторы. См. [Наэкранные контроллеры](/docs/Application/BlockBuilder/Blocks/DashboardControllers).
