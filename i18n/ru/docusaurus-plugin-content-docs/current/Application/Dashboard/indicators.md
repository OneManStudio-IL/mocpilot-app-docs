# Индикаторы и мониторы

Мониторы показывают информацию на панели, пока вы управляете моделью: заряд батареи, скорость, наклон, расстояние до препятствия, текущую передачу или режим.

| Монитор | Что показывает | Тема |
|---|---|---|
| **Монитор** | текст или число | все темы |
| **Уровень заряда батареи** | шкалу уровня | платные темы |
| **Спидометр** | шкалу скорости | платные темы |
| **Монитор наклона** | тангаж и крен модели | платные темы |

Мониторы только показывают — управлять с них нельзя. Что на них выводить, решает программа.

## В Быстрых связях

Используйте выход **Индикатор**. Строка заканчивается индикатором вместо хаба:

- *Хаб* (Батарея) → *Индикатор* (Уровень заряда батареи): заряд батареи хаба на шкале.
- *Хаб* (Скорость мотора, порт A) → *Индикатор* (Спидометр).
- *Хаб* (Наклон: тангаж) → *Индикатор* (Монитор наклона, Наклон X) и вторая строка для крена (Наклон: крен) → Наклон Y.
- *Хаб* (Напряжение батареи) → *Индикатор* (Монитор): показывает значение с единицей измерения, например «7.85 V».

Индикатор показывает значение как есть, поэтому операций в такой строке нет. См. [Индикатор](/docs/Application/Links/Blocks/OutputBlocks#dash-indicator).

## В Логических блоках

Используйте блоки наэкранных контроллеров:

- *показать … на … монитор* — для Монитора;
- *установить … к … монитор* — для Уровня заряда батареи и Спидометра;
- *установить … к …* [тангаж / крен] *монитор* — для Монитора наклона.

Вывести можно всё, что получается посчитать: показания датчика, переменную, текст вроде «Передача 2». См. [Наэкранные контроллеры](/docs/Application/BlockBuilder/Blocks/DashboardControllers#monitor-blocks).

## Советы

- Разместите монитор батареи в углу, где его не закрывают пальцы.
- Для длинных сообщений используйте многострочный Монитор с переполнением **Бегущая строка** или **Прокрутка**.
- Программа может менять цвет большинства элементов — например, сделать кнопку красной, когда батарея садится.
