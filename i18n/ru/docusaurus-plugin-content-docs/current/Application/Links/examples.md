# Примеры

Готовые рецепты. Сначала поставьте элементы на панель и добавьте хабы в «Мои хабы», затем соберите строки.

## Машина с серворулём

Панель: **JOY1** (Только по вертикали (Y)) слева, **JOY2** (Только по горизонтали (X)) справа, **BTN1** и монитор **Уровень заряда батареи**.

| # | Вход | Обработка | Операция | Выход |
|---|---|---|---|---|
| 1 | JOY1, Ось Y | Мёртвая зона 10 %, Плавность 0,5 с | Мотор | Technic Hub, порты A + B |
| 2 | JOY2, Ось X | | Серво (Авто, ±90°) | Technic Hub, порт D |
| 3 | BTN1 | Защёлка | Свет | Technic Hub, порт C |
| 4 | Хаб: Батарея | | | Индикатор: Уровень заряда батареи |

Если один из ходовых моторов крутится не в ту сторону, разделите строку 1 на две и добавьте в одну из них **Инверсию**.

## Машина с рулём, педалями и коробкой передач

Панель: **Руль**, **Педали**, **Рычаг передач**, **Ручник** и **Поворотники**. Вход [Автомобиль](/docs/Application/Links/Blocks/InputBlocks#src-vehicle) превращает педали, коробку и ручник в скорость, которая нарастает и спадает, как у настоящей машины.

| # | Вход | Обработка | Операция | Выход |
|---|---|---|---|---|
| 1 | Автомобиль: Скорость | | Мотор | Technic Hub, порты A + B |
| 2 | Руль: Угол поворота руля | | Серво (Авто) | Technic Hub, порт D |
| 3 | Автомобиль: Торможение | | Свет | Technic Hub, порт C (стоп-сигналы) |
| 4 | Поворотники: Левый поворотник | | Свет | City Hub, порт A |
| 5 | Поворотники: Правый поворотник | | Свет | City Hub, порт B |

## Танк (две гусеницы)

Панель: два вертикальных слайдера **VSLDR1** и **VSLDR2** с включёнными **Возврат к нулю** и **Отрицательные значения**.

| # | Вход | Обработка | Операция | Выход |
|---|---|---|---|---|
| 1 | VSLDR1 | Плавность 0,25 с | Мотор | Хаб, порт A |
| 2 | VSLDR2 | Инверсия, Плавность 0,25 с | Мотор | Хаб, порт B |

С геймпадом: Левый стик Y для строки 1 и Правый стик Y для строки 2.

## Кран

Панель: **DPAD1**, **SLDR1**, **SWCH1**.

| # | Вход | Обработка | Операция | Выход |
|---|---|---|---|---|
| 1 | DPAD1, Влево / вправо | Ограничение 50 % | Мотор | Хаб, порт A (поворот) |
| 2 | DPAD1, Вверх / вниз | | Мотор | Хаб, порт B (лебёдка крюка) |
| 3 | SLDR1 | Мёртвая зона 10 % | Мотор | Хаб, порт C (стрела) |
| 4 | SWCH1 | | Свет (мигание 0,5 с) | Хаб, порт D (маячок) |

## Поезд

Панель: **Шаговый переключатель** **STPR1** с **Отрицательными значениями** (ступени скорости вперёд и назад) и **BTN1** для света.

| # | Вход | Обработка | Операция | Выход |
|---|---|---|---|---|
| 1 | STPR1 | Плавность 2 с | Мотор | City Hub, порт A |
| 2 | BTN1 | Защёлка | Свет | City Hub, порт B |
| 3 | Хаб: Батарея | | | Индикатор: Монитор |

Благодаря Плавности поезд трогается и останавливается, как настоящий. Если на панели есть **контроллер машиниста**, поставьте его в строку 1 вместо STPR1: он выдаёт положение рукояти, а при движении назад — отрицательное значение.

| # | Вход | Обработка | Операция | Выход |
|---|---|---|---|---|
| 1 | Автомобиль: Скорость | | Мотор | Technic Move (ход) |

Если рычага передач на панели нет, машина поедет назад, когда вы на месте держите нажатой педаль тормоза.
