# Блок хаба и порты

Выход [Хаб](/docs/Application/Links/Blocks/OutputBlocks#hub-out) завершает строку после операции. Для каждого хаба из **Мои хабы** есть свой блок Хаб, поэтому сначала добавьте хабы туда. Пока их нет, на вкладке написано: «Добавьте хабы в «Мои хабы» или индикаторы на панель: они появятся здесь».

## Что показывает блок Хаб

- название хаба и **точку подключения** (подключён он или нет);
- **порты** в виде кнопок: A, B, C, D… у хабов LEGO® и SBrick (A–F у Robot Inventor и Mould King 6.0), 1–4 у BuWizz 2.0, 1–4 плюс A и B у BuWizz 3.0 Pro;
- подпись: «порты A, B», «выберите порты», «весь хаб» (после операции для всего хаба) или «ход, руль, свет» (Technic Move).

## Выбор портов

Нажмите на порт, чтобы задействовать его, и ещё раз, чтобы освободить. Одна строка может управлять **несколькими портами** сразу, например двумя ходовыми моторами на A и B.

Нужно, чтобы два мотора крутились в разные стороны? Сделайте две строки от одного входа и добавьте в одну из них **Инверсию**.

## Один порт — одна строка

Порт принадлежит только одной строке. Если выбрать порт, который уже занят другой строкой, MOCPilot спросит:

> **Порт уже используется**: На «Technic Hub» порт A используется в строке 2 (Мотор). Использовать его в этой строке? Другая строка потеряет этот порт и перестанет им управлять.

**Использовать в этой строке** переносит порт, **Отмена** оставляет всё как было. Порт, занятый двумя строками (например, в старом файле), отмечается как проблема: «Порт A также используется в строке 2».

## Проверки портов

Когда хаб подключён, MOCPilot знает, что подключено к каждому порту, и проверяет, подходит ли операция:

| Проблема | Что это значит |
|---|---|
| «Порт A: это устройство не может работать как серво (нужен мотор с энкодером)» | для Серво и Поворота на градусы нужен мотор с энкодером |
| «Порт A: у мотора нет абсолютной позиции (только угловые моторы)» | для операции В позицию нужен угловой мотор |
| «На порту A датчик, а не мотор» | к порту подключён датчик |
| «Порт A принимает только простые команды скорости: без управления позицией» | этот порт не умеет управлять позицией |
| «У порта A нет светодиода: используйте порты 1-4» | Цвет порта работает только на портах 1–4 BuWizz 3.0 Pro |
| «Свет датчика: выберите один порт — тот, где датчик расстояния» | Свету датчика нужен ровно один порт |

Операции, которые хаб не умеет выполнять, для него не предлагаются. Если переключить строку на другой хаб, она сообщит, какая операция не подходит, например «Тормоз: только Technic Move (у … нет команды тормоза)».

## Technic Move Hub

Technic Move Hub (в радиоуправляемых машинах LEGO® Technic) управляется по функциям, а не по портам: его блок Хаб показывает **ход, руль, свет**, и порты в нём не выбираются. Для езды используйте **Мотор** или **Мотор на время**, для руля — **Серво**, для фар — **Свет**, а для особых функций — **Тормоз**, **Boost** и **Импульс мощности**.

Ходом, рулём, светом, тормозом и Boost может управлять только одна строка («Строка 2 уже управляет ходом этого Technic Move»).

Чтобы загрузить в хаб конфигурацию машины (Porsche, Lamborghini, Batmobile), используйте **Мои хабы → Выбрать конфигурацию**. См. [Конфигурации Technic Move Hub](/docs/Application/Hubs/TechnicMoveHubConfigurations).

## Mould King

Хабы Mould King только принимают команды, поэтому входов у них нет, а о подключении они ничего не сообщают. Чтобы переключить канал управления хаба, используйте операцию [Канал](/docs/Application/Links/Blocks/OutputBlocks#op-channel).
