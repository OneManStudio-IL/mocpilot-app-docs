# Входы

С входа начинается каждая строка. На вкладке **Входы** палитры есть:

- по блоку на каждый **элемент панели**; у элементов с несколькими каналами (оси джойстика и крестовины, руль, педали, рычаг передач, ручник, поворотники) — по блоку на каждый канал;
- блоки **Автомобиль**, если на панели есть педали, рычаг передач или ручник;
- блок **Геймпад**, если включены блоки геймпада;
- по блоку **Хаб** на каждый хаб профиля (кроме Mould King: у него нет ни кнопок, ни датчиков).

Пока вкладка пуста, на ней написано: «Добавьте контроллеры на панель или хабы в «Мои хабы»: они появятся здесь».

Все настройки и значения каждого входа — в справочнике [Блоки входов](/docs/Application/Links/Blocks/InputBlocks).

## Элементы панели

Блок [Контроллер](/docs/Application/Links/Blocks/InputBlocks#src-controller) берёт элемент вашей панели по имени (**JOY1**, **SLDR1**, **BTN2**…) и, если у элемента несколько каналов, нужный **Канал**:

| Элемент | Что получает строка |
|---|---|
| [Джойстик](/docs/Application/Links/Blocks/InputBlocks#controller-joystick) | **Ось X** или **Ось Y**, −1…1 |
| [Слайдер](/docs/Application/Links/Blocks/InputBlocks#controller-slider), [контроллер машиниста](/docs/Application/Links/Blocks/InputBlocks#controller-train), [поворотная ручка](/docs/Application/Links/Blocks/InputBlocks#controller-knob) | положение |
| [Руль](/docs/Application/Links/Blocks/InputBlocks#controller-wheel) | **Угол поворота руля** −1…1 или **Гудок** |
| [Педали](/docs/Application/Links/Blocks/InputBlocks#controller-pedals) | **Педаль газа** или **Педаль тормоза**, 0…1 |
| [Рычаг передач](/docs/Application/Links/Blocks/InputBlocks#controller-gear) | **Передача** или **Направление (R − / вперёд +)** |
| [Ручник](/docs/Application/Links/Blocks/InputBlocks#controller-handbrake) | **Ручник затянут** (вкл/выкл) или **Сила ручника** |
| [Поворотники](/docs/Application/Links/Blocks/InputBlocks#controller-turnsignals) | **Поворотники (левый − / правый +)**, **Левый поворотник**, **Правый поворотник** или **Свет** |
| [Раздатка](/docs/Application/Links/Blocks/InputBlocks#controller-transfercase) | **Полный привод**, **Понижающая**, **Блокировка переднего дифференциала**, **Блокировка центрального дифференциала** или **Блокировка заднего дифференциала** (вкл./выкл.) |
| [Крестовина](/docs/Application/Links/Blocks/InputBlocks#controller-dpad) | **Вверх / вниз** или **Влево / вправо**: −1, 0 или +1 |
| [Кнопка](/docs/Application/Links/Blocks/InputBlocks#controller-button) | вкл, пока нажата |
| [Переключатель](/docs/Application/Links/Blocks/InputBlocks#controller-switch) | вкл / выкл |
| [Шаговый переключатель](/docs/Application/Links/Blocks/InputBlocks#controller-stepper) | текущая ступень |

Когда вы добавляете, переименовываете или меняете элемент на панели, палитра и строки обновляются сами. Если переключить джойстик на **Только по горизонтали (X)**, строки с его осью Y сообщат: «… не двигается по этой оси».

## Как настоящая машина

Руль, педали, рычаг передач и ручник передают только своё положение: строка с педалью крутит мотор ровно настолько, насколько нажата педаль. Если нужна модель, которая ведёт себя как автомобиль (разгоняется с инерцией, катится накатом, тормозит и едет назад на R), возьмите вход [Автомобиль](/docs/Application/Links/Blocks/InputBlocks#src-vehicle). Он учитывает педали, рычаг передач и ручник вместе и выдаёт **Скорость**, **Обороты двигателя (об/мин)**, **Торможение** или **На ручнике**:

- *Автомобиль (Скорость)* → *Мотор* → ходовые моторы;
- *Руль (Угол поворота руля)* → *Серво* → рулевое управление;
- *Автомобиль (Торможение)* → *Свет* → стоп-сигналы;
- *Поворотники (Левый поворотник)* → *Свет* → левый поворотник.

## Геймпад {#gamepad}

Один блок [Геймпад](/docs/Application/Links/Blocks/InputBlocks#src-gamepad) отвечает за весь контроллер; стик, триггер или кнопка выбираются в поле **Вход**. Сначала включите **Включить блоки геймпада** на [странице «Геймпад»](/docs/Application/Dashboard/Gamepad). Подписи зависят от параметра **Расположение кнопок геймпада** (Xbox или PlayStation).

## Кнопки и датчики хаба

Вход [Хаб](/docs/Application/Links/Blocks/InputBlocks#src-hub) читает кнопку хаба или один из его датчиков: батарею, наклон, ускорение, скорость и позицию мотора, датчики расстояния и цвета на портах и другие. В списке только то, что умеет сообщать этот хаб. Для наклона и ускорения укажите **Ориентацию хаба** — как он стоит в модели.

По строке значение идёт в масштабе −1…1. Текстовый **Монитор** сразу после датчика показывает настоящее значение с единицей измерения, например «7,85 В» или «−12°».

Типичные примеры:

- *Батарея* → *Индикатор* (Уровень заряда батареи);
- *Датчик расстояния* → *Порог* (Ниже, 20 %) → *Мотор на время*: отъехать, когда что-то слишком близко;
- *Кнопка 1* (пульт Powered Up) → *Мотор*: управление настоящим пультом.
