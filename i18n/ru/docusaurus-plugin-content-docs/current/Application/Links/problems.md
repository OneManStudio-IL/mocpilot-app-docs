# Запуск и исправление проблем

## Всё ли готово?

Кнопка **Проблемы** в верхней панели редактора показывает:

- **зелёную галочку**: «Все строки готовы»;
- **красный «!»**: «Проблемы: N».

Нажмите её, чтобы открыть панель проблем (на телефоне это боковая панель, на планшете и компьютере — меню). В ней перечислены пункты «Строка N — причина»; нажмите на пункт, чтобы перейти к строке. Блок, из-за которого возникла проблема, обведён **красной рамкой**. Если всё в порядке, панель сообщает: «Каждая включённая строка может работать.»

<Screenshot name="links-problems" alt="Панель проблем со строкой, которая не готова" width={900} />

Строки с проблемами не работают, остальные — работают.

## Частые сообщения

| Сообщение | Что делать |
|---|---|
| Перетащите в строку вход и выход (хаб или индикатор панели) | строка пуста |
| Добавьте вход в начало строки | сначала перетащите вход: элемент панели, автомобиль, геймпад или хаб |
| Добавьте выход: хаб или индикатор панели | завершите строку выходом |
| Добавьте операцию перед хабом: мотор, серво, свет | перед выходом Хаб нужна операция |
| Выберите хотя бы один порт хаба | нажмите на порт в блоке Хаб |
| Выберите контроллер панели | нажмите на блок входа и выберите элемент |
| … не двигается по этой оси | у джойстика только одна ось: выберите другую ось или измените джойстик |
| Выберите, что выдаёт … | у элемента больше нет такого канала: выберите канал |
| Выберите педали транспортного средства | входу «Автомобиль» нужны педали на панели |
| … нет на панели | рычаг передач или ручник, выбранные для «Автомобиля», убрали с панели |
| «…» не работает с этим контроллером | этот блок обработки не подходит к сигналу |
| Порт A: это устройство не может работать как серво (нужен мотор с энкодером) | подключите мотор с энкодером или выберите другую операцию |
| На порту A датчик, а не мотор | проверьте, что подключено к порту |
| Порт A также используется в строке 2 | порт может принадлежать только одной строке |
| Включите блоки геймпада на странице «Геймпад» (верхняя панель) | откройте **Геймпад** и включите **Включить блоки геймпада** |
| Индикатор показывает значение как есть: удалите операцию | в строке с Индикатором не бывает операции |
| Калибровке не нужна операция: удалите её | в строке с Калибровкой серво не бывает операции |
| Выберите хаб с цветным светодиодом (хабы LEGO) | Светодиод хаба работает только на хабах LEGO® |
| Цвета портов есть только у BuWizz 3 | для Цвета порта нужен BuWizz 3.0 Pro |
| В этой программе нет серво в режиме автокалибровки | для Калибровки серво нужно Серво в режиме «Авто» |
| Для этого блока нужна более новая версия приложения | профиль создан в более новой версии: обновите MOCPilot |
| Строка выключена | включите её в меню строки |

## Текущие значения

Пока программа работает, на каждом стыке между блоками видно проходящее через него значение. Подвигайте элемент управления и проследите значение вдоль строки:

- на входе ничего не меняется — элемент или геймпад ничего не передаёт; проверьте канал или ось;
- значение меняется, а мотор стоит — проверьте точку подключения хаба и порт;
- после **Ограничения** или **Мёртвой зоны** значение слишком маленькое — поправьте их настройки.

## Модель не двигается

1. Подключён ли хаб? Посмотрите в **Мои хабы** и на точку подключения в блоке Хаб.
2. Выбран ли нужный порт? Моторы подключены туда, куда вы думаете?
3. Строка включена и без красной рамки?
4. Программа запущена (**Запустить**)?
5. Заряжена ли батарея? Добавьте строку *Батарея → Индикатор*, чтобы следить за зарядом.

Подробнее — в разделе [Решение проблем](/docs/Help/Troubleshooting).
