# Создание профиля

1. Перейдите в **Мои профили**.
   - Телефон: нажмите **+** → **Новый профиль**.
   - Планшет: **Новый профиль** в шапке.
   - Компьютер: **Файл → Новый профиль** (⌘N / Ctrl+N).
2. Выберите **тип программы** (см. ниже).
3. Заполните данные профиля.
4. Нажмите **Создать**. Профиль откроется в редакторе.

## Выберите тип программы {#choose-the-program-type}

Тип программы определяет, в каком редакторе работает профиль. **Изменить его потом нельзя.** Чтобы попробовать другой редактор, создайте второй профиль.

| | Быстрые связи | Логические блоки |
|---|---|---|
| Как строится | Строки: вход → обработка → операция → хаб | Блоки, собранные в скрипты |
| Время на освоение | Минуты | Больше, зато и возможностей больше |
| Лучше всего для | Машин, грузовиков, поездов, кранов: «этот элемент двигает тот мотор» | Роботов, автоматических последовательностей, логики на датчиках, игр |
| Логика (условия, циклы, переменные) | Нет (только пороги и защёлки) | Да |
| Датчики | Датчики хаба как входы; значения на индикаторы | Все датчики хабов и телефона, любые вычисления |
| Плавный старт, ограничения, мёртвая зона | Готовые блоки | Собираются из блоков |
| Рулевое серво с калибровкой | Готовый блок | Блоки |
| Геймпад | Да | Да |
| Несколько хабов | Да | Да |

**Сомневаетесь?** Начните с Быстрых связей. Если позже понадобится логика, создайте для модели профиль с Логическими блоками.

Если нажать **Создать**, не выбрав тип, плитки подсветятся. На каждой плитке есть ссылка **Документация ↗** на соответствующий раздел этой документации.

## Данные профиля

- **Изображение**: щёлкните область изображения (на сенсорном экране — нажмите и удерживайте), чтобы выбрать картинку. Сдвиньте изображение вверх или вниз, чтобы выбрать видимую часть. Позже его можно сменить кнопками **Обновить изображение** и **Удалить**.
- **Название**: обязательное и должно быть уникальным; сообщение «Профиль с названием … уже существует» значит, что профиль с таким названием у вас уже есть.
- **Уровень блоков** (только Логические блоки): **Новичок**, **Продвинутый** или **Гуру**. Определяет, какие блоки палитра показывает для этого профиля. Его можно изменить позже в Настройках редактора. См. [Работа в редакторе](/docs/Application/BlockBuilder/Editor#block-levels).
- **Хэштеги**: описывают профиль и помогают его найти. Хэштеги выбираются из общего списка, который загружается, когда есть интернет.

Всё, кроме типа программы, можно изменить позже в окне **Редактировать профиль**; там же можно добавить описание и отметить профиль как **Избранный**.
