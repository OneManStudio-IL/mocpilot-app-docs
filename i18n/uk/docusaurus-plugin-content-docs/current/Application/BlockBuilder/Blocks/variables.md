# Змінні {#variables}

Змінні зберігають значення, які може читати й змінювати будь-який скрипт програми. Створюйте, перейменовуйте й видаляйте їх кнопками **Створити змінну**, **Перейменувати змінну** і **Видалити змінну** вгорі категорії. Наведені нижче блоки з’являються, щойно в програмі є хоча б одна змінна.

## Зміна змінної {#changing-a-variable}

### `налаштувати … до …` (Початківець) {#block_variables_set_to}

<img src={useBaseUrl('/img/blocks/block_variables_set_to.svg')} alt="block_variables_set_to.svg" />

Задає вибраній змінній значення.

- Для чого: задати початкове значення, замінити попереднє.

### `змінити … на …` (Просунутий) {#block_variables_change_by}

<img src={useBaseUrl('/img/blocks/block_variables_change_by.svg')} alt="block_variables_change_by.svg" />

Додає число до вибраної змінної. Щоб відняти, використайте від’ємне число.

- Для чого: лічильники, рахунок, підсумовування відстані чи часу.

## Читання змінної {#reading-a-variable}

### Змінна (Початківець) {#block_variables_value}

<img src={useBaseUrl('/img/blocks/variable.svg')} alt="variable.svg" />

Кожна змінна має власний блок-репортер зі своєю назвою. Він повертає поточне значення змінної.

- Для чого: підставляти значення в оператори, умови й поля інших блоків.
- [Монітор](/docs/Application/BlockBuilder/Editor#monitor) показує значення всіх змінних під час роботи програми.
