# Приклади {#examples}

Короткі програми, з яких можна почати. Назви блоків відповідають [довіднику блоків](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing#block-reference); значення в дужках — це хаб, порт або блок-репортер, вставлений у поле. Рядки з відступом розташовані всередині C-блока.

## Керування джойстиком {#drive-with-a-joystick}

Панель: джойстик **JOY1**. Ходовий мотор на порту A.

```text
коли програма запускається
повторювати завжди
    запустити мотор на (джойстик JOY1 вісь Y) % швидкість  (Хаб 1, порт A)
```

## Кермо із серво {#steer-with-a-servo}

Мотор керма (кутовий мотор) на порту B. Задайте його поточну позицію як центр, а потім слідуйте за джойстиком: `× 0.9` перетворює −100…100 джойстика на −90…90 градусів.

```text
коли програма запускається
встановити відносну позицію 0  (Хаб 1, порт B)
повторювати завжди
    перейти до відносної позиції (джойстик JOY1 вісь X × 0.9) на 100 % швидкість  (Хаб 1, порт B)
```

Рульову рейку з упорами спершу відкалібруйте (див. [Мотори](/docs/Application/BlockBuilder/Blocks/Motors#block_hubs_all_motors_port_calibrate_steering_rack)). `центр` і `діапазон` — змінні. Після калібрування рейка стоїть посередині, але її відносна позиція там дорівнює значенню центру, а не 0, тому перед керуванням установіть її на 0:

```text
коли програма запускається
калібрувати рейку (центр) центр (діапазон) градуси  (Хаб 1, порт B)
встановити відносну позицію 0  (Хаб 1, порт B)
повторювати завжди
    перейти до відносної позиції ((діапазон × джойстик JOY1 вісь X) ÷ 100) на 100 % швидкість  (Хаб 1, порт B)
```

## Світло на перемикачі {#lights-on-a-switch}

```text
коли перемикач SWCH1 перемкнуто увімкнено
    увімкнути на 100 % яскравість  (Хаб 1, порт C)
коли перемикач SWCH1 перемкнуто вимкнено
    вимкнути  (Хаб 1, порт C)
```

## Кнопка клаксона {#horn-button}

```text
коли кнопка BTN1 є натиснута
    звук Клаксон автомобіля грати до кінця
```

## Попередження про батарею {#battery-warning}

Монітор **MNTR1**; кнопка стає червоною, коли батарея розряджається.

```text
коли програма запускається
повторювати завжди
    показати (Хаб 1 % батареї) на MNTR1 монітор
    якщо (Хаб 1 % батареї) < 20 тоді
        налаштувати BTN1 колір до червоний
    чекати 5 секунди
```

## Зупинка перед перешкодою {#stop-before-an-obstacle}

Датчик відстані Technic на порту D, ходовий мотор на порту A.

```text
коли програма запускається
повторювати завжди
    якщо (відстань см  (Хаб 1, порт D)) < 10 тоді
        зупинити мотор  (Хаб 1, порт A)
        встановити колір LED на червоний  (Хаб 1)
    інше
        запустити мотор на (слайдер SLDR1) % швидкість  (Хаб 1, порт A)
        встановити колір LED на зелений  (Хаб 1)
```

## Обмеження швидкості кроковим перемикачем {#speed-limit-on-a-stepper}

Кроковий перемикач **STPR1** із 4 кроками обмежує максимальну швидкість.

```text
коли програма запускається
повторювати завжди
    налаштувати (обмеження швидкості) до (кроковий перемикач STPR1 × 25)
    запустити мотор на (джойстик JOY1 вісь Y × обмеження швидкості / 100) % швидкість  (Хаб 1, порт A)
```

`обмеження швидкості` — це змінна (**Змінні → Створити змінну**).

## Перевірка під час запуску {#startup-check}

Заблокуйте газ, доки не підключаться обидва хаби.

```text
коли програма запускається
вимкнути JOY1 інтерактивність
чекайте до (Хаб 1 підключено) і (Хаб 2 підключено)
показати "Готово" на MNTR1 монітор
увімкнути JOY1 інтерактивність
```

## Геймпад {#gamepad}

Задайте **Діапазон значень геймпада** −100…100 на [сторінці «Геймпад»](/docs/Application/Dashboard/Gamepad) і ввімкніть **Увімкнути блоки геймпада**.

```text
коли програма запускається
повторювати завжди
    запустити мотор на (джойстик лівий вісь Y) % швидкість  (Хаб 1, порт A)
    перейти до відносної позиції (джойстик правий вісь X × 0.9) на 100 % швидкість  (Хаб 1, порт B)
```
