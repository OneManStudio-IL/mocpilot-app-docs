# Властивості елементів керування {#control-properties}

У режимі редагування торкніться (клацніть) елемента керування, щоб відкрити його властивості.

- **Телефон і планшет**: панель поверх панелі керування; торкніться поза нею, щоб закрити її.
- **Комп’ютер**: бічна панель; поки вона відкрита, можна працювати з панеллю керування далі.

<Screenshot name="controller-properties" alt="Панель властивостей елемента керування з вкладками «Стиль» і «Налаштування»" width={900} />

У заголовку показано назву елемента керування (наприклад, **JOY1**), кнопку кошика, меню дублювання й **OK**.

## Вкладка «Стиль» {#style-tab}

- **Розмір**: S, M або L. Див. [розміри](/docs/Application/Dashboard/ArrangingControls#sizes).
- **Акцентний колір**: основний колір елемента керування.
- **Іконка**: зображення на елементі керування (кнопки, перемикачі, монітори), яке можна вибрати з понад 260 іконок.
- **Зовнішній вигляд**: вигляд [спеціального елемента керування](/docs/Application/Dashboard/SpecialControls), наприклад стиль керма.
- Параметри теми, залежно від теми: наприклад, **Кольоровий вуглець**, **Кольорові рамки** й **Показати гоночні лінії** в темі «Перегони», **Кількість сегментів індикатора** в темі «Будівельна техніка», **Відображати значення** в темі «Аура».
- **Змінити тему**: перевести елемент керування на іншу вашу тему, яка має такий самий тип елемента.

## Вкладка «Налаштування» {#settings-tab}

Загальні налаштування:

- **Заблокувати контроллер**: заблокований елемент керування не можна перемістити чи видалити.
- **Інтерактивність**: неінтерактивний елемент керування не реєструє натискань.

Налаштування кожного типу:

| Елемент керування | Налаштування |
|---|---|
| Джойстик | **Тип осей**: Обидві осі (X, Y), Лише по горизонталі (X), Лише по вертикалі (Y) |
| Повзунок, Вер. повзунок | **Повернути до нуля**, **Від’ємні значення**, **Крокове значення** |
| Поворотна ручка | **Кроки з фіксацією (0 = плавно)** (0–24), **Нуль у центрі (-100..100)** |
| Кроковий перемикач, Вер. кроковий перемикач | **Кількість кроків** (1–100), **Від’ємні значення**, **Увімкнути скидання** |
| Монітор | **Макет тексту**, **Переповнення тексту**, **Максимум рядків**, **Напрямок прокручування**, **Швидкість прокручування**, **Показувати смугу прокручування**, **Інтерактивне прокручування**, **Вирівнювання тексту**, **Масштаб тексту** |
| Монітор нахилу | **Інвертувати нахил**, **Інвертувати обертання** |
| Кермо | **Кут повороту керма** (20–120°), **Звукові ефекти** |
| Педалі | **Звукові ефекти** |
| Механічна коробка | **Кількість передач** (2–6) |
| Автоматична коробка | **Кількість передач** (2–8) |
| Поворотники | **Виходи поворотників блимають**; на вкладці «Стиль» — **Іконка: left**, **Іконка: light**, **Іконка: right** |

Числові параметри мають кнопку **Скинути**, яка відновлює стандартне значення.

## Зміна властивостей із програми {#change-properties-from-the-program}

У Логічних блоках блоки можуть змінювати елемент керування під час роботи програми: задавати його колір, вмикати й вимикати інтерактивність, показувати значення на моніторах. Див. [Блоки наекранних контролерів](/docs/Application/BlockBuilder/Blocks/DashboardControllers).
