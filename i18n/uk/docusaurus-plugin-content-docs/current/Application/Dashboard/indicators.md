# Індикатори й монітори {#indicators-and-monitors}

Монітори показують інформацію на панелі під час керування: рівень заряду батареї, швидкість, нахил, відстань до перешкоди, поточну передачу чи режим.

| Монітор | Що показує | Тема |
|---|---|---|
| **Монітор** | текст або число | усі теми |
| **Рівень заряду батареї** | шкалу рівня | платні теми |
| **Швидкомір** | шкалу швидкості | платні теми |
| **Монітор нахилу** | тангаж і крен моделі | платні теми |

Монітори лише відображають інформацію; керувати ними не можна. Що вони показують, вирішує програма.

## У Швидких зв’язках {#in-quick-links}

Використовуйте вихід **Індикатор**. Рядок закінчується індикатором замість хаба:

- *Хаб* (Батарея) → *Індикатор* (Рівень заряду батареї): заряд батареї хаба на шкалі.
- *Хаб* (Швидкість мотора, порт A) → *Індикатор* (Швидкомір).
- *Хаб* (Нахил: тангаж) → *Індикатор* (Монітор нахилу, Нахил X) і другий рядок для Нахил: крен → Нахил Y.
- *Хаб* (Напруга батареї) → *Індикатор* (Монітор): показує значення з одиницею вимірювання, наприклад «7.85 V».

Індикатор показує значення як є, тож рядок не має операції. Див. [Індикатор](/docs/Application/Links/Blocks/OutputBlocks#dash-indicator).

## У Логічних блоках {#in-logic-blocks}

Використовуйте блоки наекранних контролерів:

- *показати … на моніторі …* для Монітора;
- *встановити … на моніторі …* для Рівня заряду батареї та Швидкоміра;
- *встановити … на моніторі тангажу / крену …* для Монітора нахилу.

Показати можна все, що можна обчислити: значення датчика, змінну, текст на кшталт «Передача 2». Див. [Наекранні контролери](/docs/Application/BlockBuilder/Blocks/DashboardControllers#monitor-blocks).

## Поради {#tips}

- Розмістіть монітор батареї в куті, де його не закриватимуть пальці.
- Для довших повідомлень використовуйте багаторядковий Монітор із переповненням **Рухомий рядок** або **Прокручування**.
- Програма може змінювати колір більшості елементів керування, наприклад робити кнопку червоною, коли батарея розряджається.
