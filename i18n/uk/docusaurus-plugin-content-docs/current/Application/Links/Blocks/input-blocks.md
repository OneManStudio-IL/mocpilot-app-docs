# Блоки входів {#input-blocks}

Кожен рядок починається з входу. Вкладка **Входи** палітри показує блоки, які ваш профіль може використати просто зараз: по блоку на кожен елемент панелі (по одному на канал для елементів із кількома каналами), блоки **Автомобіль**, блок **Геймпад** і по блоку **Хаб** на кожен хаб. Як ними користуватися: [Входи](/docs/Application/Links/Inputs).

Кожен вхід надсилає рядком один із двох сигналів:

- **значення**: число від −1 до 1 (0…1 для елементів без від’ємного боку);
- **увімк./вимк.**: 1 або 0.

Блоки обробки й операції приймають лише ті сигнали, з якими вміють працювати; див. [Блоки обробки](/docs/Application/Links/Blocks/ProcessingBlocks).

## Контролер {#src-controller}

Елемент вашої панелі, показаний за назвою (**JOY1**, **SLDR1**, **BTN2**…).

- **Контролер**: будь-який елемент панелі з наведених нижче. Монітори — це виходи, а не входи.
- **Канал**: що видає елемент, для елементів із кількома каналами. Палітра пропонує по блоку на канал.

Кермо, педалі, важіль передач, ручник, поворотники, роздавальну коробку й контролер машиніста описано на сторінці [Спеціальні контролери](/docs/Application/Dashboard/SpecialControls).

Якщо елемент видалено з панелі, рядок повідомляє «Виберіть контролер панелі». Якщо його каналу більше немає, рядок повідомляє «Виберіть, що видає …» (для джойстика: «… не рухається по цій осі»).

### Джойстик {#controller-joystick}

- **Канал**: **Вісь X** або **Вісь Y**. Джойстик, налаштований як **Лише горизонтально (X)** або **Лише вертикально (Y)**, пропонує лише цю вісь.
- Видає: значення −1…1, 0 у центрі.

### Повзунок, вертикальний повзунок {#controller-slider}

- Без каналу.
- Видає: значення 0…1 або −1…1, коли ввімкнено **Від’ємні значення**.

### Контролер машиніста {#controller-train}

Контролер машиніста (спеціальний контролер) працює у Швидких зв’язках як повзунок.

- Без каналу.
- Видає: значення −1…1: положення ручки як частку всіх позицій, від’ємне, коли реверсор на задньому ходу, 0 у нейтралі.

### Регулятор {#controller-knob}

Поворотний регулятор із платних тем працює у Швидких зв’язках як повзунок.

- Без каналу.
- Видає: значення 0…1 або −1…1, коли нуль регулятора посередині.

### Кермо {#controller-wheel}

- **Канал**: **Кут повороту керма** (типово) або **Клаксон**.
- Кут повороту керма видає: значення −1…1, 0 — прямо.
- Клаксон видає: значення 1, поки натиснуто зону клаксона, інакше 0.

### Педалі {#controller-pedals}

- **Канал**: **Педаль газу** (типово) або **Педаль гальма**.
- Видає: значення 0…1 — наскільки натиснуто педаль.
- Педалі передають сире положення педалі. Для автомобіля, який сам розганяється, сповільнюється й їде заднім ходом, використовуйте вхід [Автомобіль](#src-vehicle).

### Важіль передач {#controller-gear}

Механічний та автоматичний важелі передач (спеціальний контролер).

- **Канал**: **Передача** (типово) або **Напрямок (R − / вперед +)**.
- Передача, механічна коробка: увімкнена передача, поділена на кількість передач уперед: найвища передача 1, нейтраль 0, задній хід — від’ємне значення. З 4 передачами 2-га передача дає 0,5.
- Передача, автоматична коробка: те саме, що Напрямок.
- Напрямок видає: −1 на R, 0 на N (і P), +1 на будь-якій передачі вперед або D.

### Ручник {#controller-handbrake}

- **Канал**: **Ручник затягнуто** (типово) або **Сила ручника**.
- Ручник затягнуто видає: увімк./вимк., увімк., поки важіль зафіксовано.
- Сила ручника видає: значення 0…1 — наскільки витягнуто важіль.

### Поворотники {#controller-turnsignals}

Підрульовий перемикач поворотників (спеціальний контролер).

- **Канал**: **Поворотники (лівий − / правий +)** (типово), **Лівий поворотник**, **Правий поворотник** або **Світло**.
- Поворотники видає: значення −1 (ліворуч), 0 (вимк.) або +1 (праворуч).
- Лівий поворотник і Правий поворотник видають: значення 1, поки цей поворотник увімкнено (блимає разом із лампою, коли в елемента ввімкнено блимання), інакше 0.
- Світло видає: значення 1, поки світло ввімкнено, інакше 0.

### Роздавальна коробка {#controller-transfercase}

[Роздавальна коробка](/docs/Application/Dashboard/SpecialControls#transfer-case) (спеціальний контролер).

- **Канал**: **Повний привід** (типово), **Знижувальна**, **Блокування переднього диференціала**, **Блокування центрального диференціала** або **Блокування заднього диференціала**.
- Повний привід видає: увімк./вимк., увімкнено в 4H і 4L.
- Знижувальна видає: увімк./вимк., увімкнено в 4L.
- Кожне блокування диференціала видає: увімк./вимк., увімкнено, поки це блокування ввімкнене.
- Саме положення (2H, 4H, N, 4L) передається симулятору через налаштування **Роздавальна коробка** входу [Автомобіль](#src-vehicle).

### Хрестовина {#controller-dpad}

- **Канал**: **Вгору / вниз** або **Вліво / вправо**.
- Видає: значення +1 (угору чи праворуч), −1 (униз чи ліворуч) або 0.

### Кнопка {#controller-button}

- Без каналу.
- Видає: увімк./вимк., увімк., поки натиснуто.

### Перемикач {#controller-switch}

- Без каналу.
- Видає: увімк./вимк.

### Кроковий перемикач {#controller-stepper}

- Без каналу.
- Видає: значення — поточний крок, поділений на **Кількість кроків**, тож останній крок дає 1 (−1 для останнього від’ємного кроку).

## Автомобіль {#src-vehicle}

Змодельований автомобіль, яким керують педалі, важіль передач, ручник і роздавальна коробка панелі: він розганяється, гальмує, котиться накатом і їде заднім ходом, як справжній, а рядок отримує його швидкість або оберти двигуна. Палітра показує блоки «Автомобіль», коли на панелі є педалі, важіль передач або ручник, по блоку на кожен вихід, уже пов’язаних із першим елементом кожного типу.

- **Педалі**: педалі панелі, що керують автомобілем (обов’язково).
- **Важіль передач**: **немає** або важіль передач на панелі. Без нього утримання педалі гальма під час стоянки веде автомобіль назад.
- **Ручник**: **немає** або ручник на панелі.
- **Роздавальна коробка**: **немає** або роздавальна коробка на панелі. У 2H і 4H автомобіль їздить так само, як без неї, у N не їде (котиться накатом), у 4L його швидкість обмежено до 40 %.
- **Тип транспортного засобу**: **легковий** (типово), **позашляховик**, **спорткар** або **вантажівка**. Типи відрізняються інерцією та швидкістю заднього ходу; вантажівка також має пневмогальмо.
- **Вихід**:
  - **швидкість** (типово): значення −1…1, від’ємне на задньому ходу;
  - **Оберти двигуна (об/хв)**: значення 0…1;
  - **гальмує**: увімк./вимк., увімк., поки автомобіль гальмує;
  - **на ручнику**: увімк./вимк.

Проблеми: «Виберіть педалі транспортного засобу», «… немає на панелі».

## Геймпад {#src-gamepad}

Ігровий контролер, підключений до вашого пристрою. Блок є в палітрі лише тоді, коли ввімкнено **Увімкнути блоки геймпада** (сторінка **Геймпад** на верхній панелі); інакше рядок повідомляє «Увімкніть блоки геймпада на сторінці «Геймпад» (верхня панель)».

- **Вхід** (типово **Лівий стік Y**). Підписи відповідають налаштуванню **Розташування кнопок геймпада** (Xbox / PlayStation):
  - **Лівий стік Y**, **Лівий стік X**, **Правий стік Y**, **Правий стік X**: значення −1…1;
  - **RT** / **R2**, **LT** / **L2** (тригери): значення;
  - **A**, **B**, **X**, **Y** / **Хрест**, **Коло**, **Квадрат**, **Трикутник**: увімк./вимк.;
  - **LB** / **L1**, **RB** / **R1** (бампери): увімк./вимк.;
  - **Вгору**, **Вниз**, **Ліворуч**, **Праворуч** (хрестовина): увімк./вимк.

## Хаб {#src-hub}

Власна кнопка хаба або датчик: на самому хабі чи на одному з його портів. На кожен хаб профілю є один вхід «Хаб», крім хабів Mould King, які лише приймають команди.

- **Хаб**: хаб профілю.
- **Кнопка або датчик**: лише те, що може повідомити цей хаб (список нижче).
- **Порт**: для датчиків на порту (значення мотора, датчики на портах).
- **Орієнтація хаба**: для нахилу й прискорення на хабах, які це підтримують: **Не змінювати** (типово) або те, як хаб закріплено в моделі.

Значення датчика йде рядком, поділене на повну шкалу й обмежене діапазоном −1…1: батарея на 50 % дає 0,5. Текстовий **Монітор** одразу після датчика показує справжнє значення з одиницею виміру.

| **Кнопка 1, 2…** | увімк./вимк. | | хаби з кнопкою; кнопки пульта LEGO® Powered Up |
| **Батарея** | значення | %, 100 | хаби, що її повідомляють |
| **Напруга батареї** | значення | V, 12 | хаби, що її повідомляють |
| **Вихідна напруга** | значення | V, 12 | BuWizz 2.0 |
| **Температура** | значення | °C, 100 | хаби, що її повідомляють |
| **Нахил: тангаж** | значення | °, 90 | хаби з датчиком нахилу |
| **Нахил: крен** | значення | °, 180 | хаби з датчиком нахилу |
| **Нахил: рискання** | значення | °, 180 | хаби з віссю рискання |
| **Прискорення X / Y / Z** | значення | м/с², 19,6 | хаби з акселерометром |

| **Колірний тон** | значення | °, 360 | порт; датчик кольору Technic або датчик кольору й відстані BOOST; не SBrick, BuWizz і WeDo 2.0 |
