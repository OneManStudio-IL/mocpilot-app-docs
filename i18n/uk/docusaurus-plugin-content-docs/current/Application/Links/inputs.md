# Входи {#inputs}

Кожен рядок починається з входу. Вкладка **Входи** палітри містить:

- по одному блоку на кожен **елемент панелі**; елементи з кількома каналами (осі джойстика та хрестовини, кермо, педалі, важіль передач, ручник, поворотники) мають по блоку на канал;
- блоки **Автомобіль**, коли на панелі є педалі, важіль передач або ручник;
- блок **Геймпад**, коли ввімкнено блоки геймпада;
- по одному блоку **Хаб** на кожен хаб профілю (крім Mould King, який не має кнопок і датчиків).

Якщо вкладка порожня, вона показує «Додайте контролери на панель або хаби в «Мої хаби»: вони з’являться тут».

Усі налаштування та значення кожного входу описано в довіднику [Блоки входів](/docs/Application/Links/Blocks/InputBlocks).

## Елементи панелі {#dashboard-controls}

Блок [Контролер](/docs/Application/Links/Blocks/InputBlocks#src-controller) бере елемент з вашої панелі за його назвою (**JOY1**, **SLDR1**, **BTN2**…) і, якщо в елемента їх кілька, потрібний **Канал**:

| Елемент | Що отримує рядок |
|---|---|
| [Джойстик](/docs/Application/Links/Blocks/InputBlocks#controller-joystick) | **Вісь X** або **Вісь Y**, −1…1 |
| [Повзунок](/docs/Application/Links/Blocks/InputBlocks#controller-slider), [контролер машиніста](/docs/Application/Links/Blocks/InputBlocks#controller-train), [регулятор](/docs/Application/Links/Blocks/InputBlocks#controller-knob) | його положення |
| [Кермо](/docs/Application/Links/Blocks/InputBlocks#controller-wheel) | **Кут повороту керма** −1…1 або **Клаксон** |
| [Педалі](/docs/Application/Links/Blocks/InputBlocks#controller-pedals) | **Педаль газу** або **Педаль гальма**, 0…1 |
| [Важіль передач](/docs/Application/Links/Blocks/InputBlocks#controller-gear) | **Передача** або **Напрямок (R − / вперед +)** |
| [Ручник](/docs/Application/Links/Blocks/InputBlocks#controller-handbrake) | **Ручник затягнуто** (увімк./вимк.) або **Сила ручника** |
| [Поворотники](/docs/Application/Links/Blocks/InputBlocks#controller-turnsignals) | **Поворотники (лівий − / правий +)**, **Лівий поворотник**, **Правий поворотник** або **Світло** |
| [Хрестовина](/docs/Application/Links/Blocks/InputBlocks#controller-dpad) | **Вгору / вниз** або **Вліво / вправо**: −1, 0 або +1 |
| [Кнопка](/docs/Application/Links/Blocks/InputBlocks#controller-button) | увімкнено, поки натиснута |
| [Перемикач](/docs/Application/Links/Blocks/InputBlocks#controller-switch) | увімк. / вимк. |
| [Кроковий перемикач](/docs/Application/Links/Blocks/InputBlocks#controller-stepper) | поточний крок |

Коли ви додаєте, перейменовуєте або змінюєте елемент на панелі, палітра й рядки оновлюються автоматично. Якщо налаштувати джойстик як **Лише горизонтально**, рядки, що використовують його вісь Y, повідомлять «… не рухається по цій осі».

## Керування як справжнім автомобілем {#drive-like-a-real-car}

Кермо, педалі, важіль передач і ручник передають свої сирі положення: рядок із педаллю крутить мотор рівно настільки, наскільки натиснуто педаль. Для моделі, яка поводиться як автомобіль (розганяється з інерцією, котиться накатом, гальмує й їде заднім ходом на R), використовуйте натомість вхід [Автомобіль](/docs/Application/Links/Blocks/InputBlocks#src-vehicle). Він зчитує педалі, важіль передач і ручник разом і видає **швидкість**, **Оберти двигуна (об/хв)**, **гальмує** або **на ручнику**:

- *Автомобіль (швидкість)* → *Мотор* → ходові мотори;
- *Кермо (Кут повороту керма)* → *Серво* → кермо;
- *Автомобіль (гальмує)* → *Світло* → стоп-сигнали;
- *Поворотники (Лівий поворотник)* → *Світло* → лівий покажчик повороту.

## Геймпад {#gamepad}

Один блок [Геймпад](/docs/Application/Links/Blocks/InputBlocks#src-gamepad) охоплює весь контролер; виберіть стік, тригер або кнопку в полі **Вхід**. Спершу ввімкніть **Увімкнути блоки геймпада** на [сторінці «Геймпад»](/docs/Application/Dashboard/Gamepad). Підписи відповідають налаштуванню **Розташування кнопок геймпада** (Xbox або PlayStation).

## Кнопки й датчики хаба {#hub-buttons-and-sensors}

Вхід [Хаб](/docs/Application/Links/Blocks/InputBlocks#src-hub) зчитує кнопку хаба або один із його датчиків: батарею, нахил, прискорення, швидкість і позицію мотора, датчики відстані й кольору на портах тощо. У списку лише те, що може повідомити цей хаб. Для нахилу й прискорення задайте **Орієнтація хаба** відповідно до того, як хаб розташовано в моделі.

Значення йде рядком у масштабі −1…1. Текстовий **Монітор** одразу після датчика показує справжнє значення з одиницею виміру, наприклад «7.85 V» або «−12°».

Типові приклади:

- *Батарея* → *Індикатор* (Рівень батареї);
- *Датчик відстані* → *Поріг* (Нижче, 20 %) → *Мотор на час*: від’їхати назад, коли щось наближається;
- *Кнопка 1* (пульт Powered Up) → *Мотор*: керування фізичним пультом.
