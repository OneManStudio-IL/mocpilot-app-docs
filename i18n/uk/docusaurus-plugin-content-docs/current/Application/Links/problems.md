# Запуск і виправлення проблем {#running-and-fixing-problems}

## Чи все готово? {#is-everything-ready}

Кнопка **Проблеми** на верхній панелі редактора (на комп’ютері — одразу перед **Запустити**) показує:

- **зелену галочку**: «Усі рядки готові»;
- **червоний «!»**: «Проблеми: N».

На комп’ютері текст написано на самій кнопці; у вузькому вікні залишаються лише значок і кількість проблем. На телефоні чи планшеті кнопка показує значок, а кількість — у червоному бейджі.

Торкніться її, щоб відкрити панель проблем (бічна панель на телефоні, меню на планшеті чи комп’ютері). У ній перелічено «Рядок N — причина»; торкніться пункту, щоб перейти до цього рядка. Блок, що спричиняє проблему, має **червону рамку**. Коли все гаразд, панель показує «Кожен увімкнений рядок може працювати.»

<Screenshot name="links-problems" alt="Панель проблем із неготовим рядком" width={900} />

Рядки з проблемами не виконуються; інші рядки працюють.

## Типові повідомлення {#common-messages}

| Повідомлення | Що робити |
|---|---|
| Перетягніть у рядок вхід і вихід (хаб або індикатор панелі) | рядок порожній |
| Додайте вхід на початок рядка | спершу перетягніть елемент панелі, автомобіль, геймпад або вхід хаба |
| Додайте вихід: хаб або індикатор панелі | завершіть рядок виходом |
| Додайте операцію перед хабом: мотор, серво, світло | перед виходом «Хаб» потрібна операція |
| Виберіть хоча б один порт хаба | торкніться кнопки порту на блоці «Хаб» |
| Виберіть контролер панелі | торкніться блока входу й виберіть елемент |
| … не рухається по цій осі | джойстик має лише одну вісь: виберіть іншу вісь або змініть джойстик |
| Виберіть, що видає … | елемент більше не має цього каналу: виберіть інший |
| Виберіть педалі транспортного засобу | вхід «Автомобіль» потребує педалей на панелі |
| … немає на панелі | важіль передач або ручник, вибраний для «Автомобіля», видалено |
| «…» не працює з цим контролером | цей блок обробки не підходить до сигналу |
| Порт A: цей пристрій не може працювати як серво (потрібен мотор з енкодером) | використайте мотор з енкодером або іншу операцію |
| На порту A датчик, а не мотор | перевірте, що підключено до порту |
| Порт A також використовується в рядку 2 | кожен порт може належати лише одному рядку |
| Увімкніть блоки геймпада на сторінці «Геймпад» (верхня панель) | відкрийте **Геймпад** і ввімкніть **Увімкнути блоки геймпада** |
| Індикатор показує значення як є: видаліть операцію | у рядку з Індикатором немає операції |
| Калібруванню не потрібна операція: видаліть її | у рядку з Калібруванням серво немає операції |
| Виберіть хаб із кольоровим світлодіодом (хаби LEGO) | Світлодіод хаба працює лише на хабах LEGO® |
| Кольори портів є лише в BuWizz 3 | Колір порту потребує BuWizz 3.0 Pro |
| У цій програмі немає серво в режимі автокалібрування | Калібрування серво потребує Серво в режимі Авто |
| Для цього блоку потрібна новіша версія застосунку | профіль створено в новішій версії: оновіть MOCPilot |
| Рядок вимкнено | увімкніть його в меню рядка |

## Поточні значення {#live-values}

Поки програма працює, кожне з’єднання між блоками показує значення, що через нього проходить. Порухайте елемент керування й простежте значення вздовж рядка:

- на вході нічого не змінюється: елемент або геймпад нічого не надсилає; перевірте канал чи вісь;
- значення змінюється, але мотор не рухається: перевірте точку з’єднання хаба й порт;
- після **Обмеження** або **Мертва зона** значення мале: змініть їхні налаштування.

## Модель не рухається {#the-model-does-not-move}

1. Чи підключено хаб? Перевірте **Мої хаби** і точку з’єднання на блоці «Хаб».
2. Чи вибрано правильний порт? Чи підключено мотори туди, куди ви думаєте?
3. Чи ввімкнено рядок і чи немає червоної рамки?
4. Чи запущено програму (**Запустити**)?
5. Чи заряджено батарею? Додайте рядок *Батарея → Індикатор*, щоб стежити за нею.
