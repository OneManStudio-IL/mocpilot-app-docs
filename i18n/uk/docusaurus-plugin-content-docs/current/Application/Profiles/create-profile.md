# Створення профілю {#create-a-profile}

1. Перейдіть до **Мої профілі**.
   - Телефон: торкніться **+** → **Новий профіль**.
   - Планшет: **Новий профіль** у заголовку.
   - Комп’ютер: **Файл → Новий профіль** (⌘N / Ctrl+N).
2. Виберіть **тип програми** (див. нижче).
3. Заповніть відомості про профіль.
4. Торкніться **Створити**. Профіль відкриється в редакторі.

## Виберіть тип програми {#choose-the-program-type}

Тип програми визначає, який редактор використовує профіль. **Змінити його пізніше не можна.** Щоб спробувати інший редактор, створіть другий профіль.

| | Швидкі зв’язки | Логічні блоки |
|---|---|---|
| Як створюється | Рядки: вхід → обробка → операція → хаб | Блоки, з’єднані в скрипти |
| Час на освоєння | Хвилини | Довше; більше можливостей |
| Найкраще для | Автомобілі, вантажівки, потяги, крани: «цей елемент керування рухає той мотор» | Роботи, автоматичні послідовності, логіка на датчиках, ігри |
| Логіка (якщо, цикли, змінні) | Ні (лише пороги й фіксація) | Так |
| Датчики | Датчики хаба як входи; значення на індикатори | Усі датчики хаба й телефона, будь-які обчислення |
| Плавний старт, обмеження, мертва зона | Готові блоки | Збираються з блоків |
| Серворуль із калібруванням | Готовий блок | Блоки |
| Геймпад | Так | Так |
| Кілька хабів | Так | Так |

**Не впевнені?** Почніть зі Швидких зв’язків. Якщо згодом знадобиться логіка, створіть для моделі профіль Логічних блоків.

Якщо торкнутися **Створити**, не вибравши тип, плитки буде виділено. На кожній плитці є посилання **Документація ↗** на відповідну частину цієї документації.

## Відомості про профіль {#profile-details}

- **Зображення**: клацніть область зображення (на сенсорному екрані утримуйте її), щоб вибрати зображення. Перетягніть зображення вгору або вниз, щоб вибрати видиму частину. **Оновити зображення** і **Видалити** дають змогу змінити його пізніше.
- **Назва**: обов’язкова й має бути унікальною: «Профіль із назвою «…» вже існує» означає, що у вас уже є профіль із такою назвою.
- **Рівень блоків** (лише Логічні блоки): **Початківець**, **Просунутий** або **Гуру**. Він визначає, які блоки палітра показує для цього профілю. Змінити його можна пізніше в Налаштуваннях редактора. Див. [Робота в редакторі](/docs/Application/BlockBuilder/Editor#block-levels).
- **Хештеги**: описують профіль і допомагають іншим його знайти. Хештеги беруться зі спільного списку, який завантажується, коли ви в мережі.

Усе, крім типу програми, можна змінити пізніше в **Редагувати профіль**; там також можна додати опис і позначити профіль як **Улюблений**.

## Що далі {#next-steps}

1. Додайте хаби: [Додавання й підключення хаба](/docs/Application/Hubs/ConnectingHubs).
2. Розмістіть елементи керування: [Панель](/docs/Application/Dashboard/DashboardOverview).
3. Напишіть програму: [Швидкі зв’язки](/docs/Application/Links/LinksIntroducing) або [Логічні блоки](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing).

:::tip ШІ-конструктор
З [MocPilot Pro](/docs/Application/Account/Pro) можна описати модель словами або голосом, і ШІ-конструктор створить хаби, панель і програму (Логічні блоки або Швидкі зв’язки). Скажіть, який хаб ви використовуєте, що підключено до кожного порту і що воно має робити. Див. [Як отримати хороший результат](/docs/Application/Profiles/AiBuilder#ai-builder-tips).
:::
