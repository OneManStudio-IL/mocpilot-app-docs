# Створення елементів керування з теми {#create-controls-from-a-theme}

Кожен елемент керування, який ви додаєте, починається з теми. Його можна налаштувати перед додаванням і зберегти налаштований елемент як власний дизайн.

## Налаштування перед додаванням {#configure-before-adding}

1. Відкрийте **Додати контролер** (**+** на панелі).
2. Виберіть тип елемента керування й варіант зовнішнього вигляду в стрічці стилів.
3. У розділі **Налаштувати** скористайтеся вкладками **Стиль** і **Налаштування**: розмір (палітра показує його як «Ш x В точок»), акцентний колір, іконка, параметри теми, поведінка.
4. Торкніться **Додати на панель**.

## Збереження дизайну {#save-a-design}

Коли знайдете комбінацію, яка вам до вподоби (скажімо, червону кнопку теми «Перегони» з іконкою клаксона), збережіть її:

1. Виберіть налаштований елемент керування з вашої теми.
2. Торкніться **Зберегти дизайн**.
3. Дизайн з’явиться в розділі **Мої дизайни** → **Збережені дизайни**. Його можна одним дотиком додати на панель будь-якого профілю.

**Видалити** прибирає збережений дизайн.

## Копіювання елементів керування на панелі {#copy-controls-on-the-dashboard}

- **Дублювати** копіює елемент керування з усіма його властивостями.
- **Дублювати (Лише тип)** додає елемент керування того самого типу зі стандартними властивостями.
- **Змінити тему** переводить елемент керування на іншу вашу тему, не змінюючи його місця й зв’язків із програмою.

## Хороша панель {#a-good-dashboard}

- Розмістіть елементи керування рухом під великими пальцями: джойстик або педалі з одного боку, кермо з іншого.
- Використовуйте розмір **L** для найчастіше вживаних елементів керування й **S** для рідкісних.
- Використовуйте один акцентний колір для кожної функції: зелений для руху, жовтий для світла, червоний для зупинки.
- Заблокуйте елементи керування, коли розташування готове (**Заблокувати все**).
- Додайте монітор батареї, щоб знати, коли час заряджати.

:::info Власна графіка
Намалювати зовсім нові елементи керування чи теми в застосунку не можна. Теми створює команда MOCPilot; якщо у вас є ідея теми, напишіть нам через **Допомога → Поставити запитання**.
:::
